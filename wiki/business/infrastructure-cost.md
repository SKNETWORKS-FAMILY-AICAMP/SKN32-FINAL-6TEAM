# 현재 여행 인프라 비용의 확인 기준

과거 구독·쇼핑몰 요청의 토큰·비용·처리시간과 당시 GPU 시세는 아래 기록으로 보존합니다. 현재 여행 상품 원가·현재 모델 채택의 근거로 재사용하지 않습니다.

## 현재 비용을 기록할 때

여행1건의 일수·인원·일정 항목·감시 주기·외부 API 호출량·모델 호출량·재시도·배달·기계 사용량을 분모와 함께 기록합니다. 무료 한도와 실제 청구, 예상과 실측, 연구 전용 비용과 고객 서비스 비용을 구분합니다. 모델별 학습 여부·양자화·입력 길이·동시성·실행 기계가 다르면 단가·지연을 직접 비교하지 않습니다.

[여행 사업 검토 입구](index.md)와 [현재 모델 평가](../../final_project_cs/wiki/quality/slm-model-evaluation.md)의 최신 증거를 확인합니다. 이 문서 정리에서 새 가격 조회·실청구 수집·새 비용 측정은 수행하지 않았습니다. 과거3.03원/요청이나 상담원 인건비 비중을 오늘 여행 원가로 채우지 않습니다.

## 과거 기록

[수정 전 문서](../records/commerce_2026-10-11/wiki--business--infrastructure-cost.md)는 당시 기록입니다. 현재 여행 제품의 사양·평가·시연·완료 증거로 사용하지 않습니다. 원문 바이트는 같은 폴더의 백업에도 보존했습니다.
