# 알림 링크의 계정·소유권 확인

2026-10-18 확정 동작: 알림 링크는 현재 로그인된 계정이 해당 여행을 소유하는지 먼저 확인한다. 기존 회원과 본인 여행을 가진 게스트 모두 포함한다. 세션이 없거나 다른 계정이면 로그인 화면에서 본래 여행으로 돌아갈 주소를 보존한다. 신규 가입 대기는 필수 동의가 저장돼야 완료된다.

- 기존 `GET /v1/web/auth/me`의 선택 입력 `trip_id`는 UUID다. 입력했을 때만 `trip_access` 참·거짓을 추가한다. 현재 인증된 tenant와 customer로 여행 소유권을 조회한다. 다른 계정의 여행과 존재하지 않는 여행은 모두 거짓이다. 세션이 없으면 기존대로 401이다. 응답은 `no-store`이며 인증·여행·소유자 식별자를 추가 공개하지 않는다.
- 이 확인은 실제 여행 읽기·수정 권한을 부여하지 않는다. 본문 API의 본인 소유권·차단·점검·필수 동의 검사는 유지한다. 미완료 가입은 먼저 가입용 동의 화면으로 이동한다.
- 계정 확인 실패를 동의 실패로 표시하지 않는다. 로그인·동의 화면은 다른 화면의 동의 확인 오류로 가리지 않는다. 외부 복귀 주소와 제어문자가 든 복귀 주소는 거절한다.

구현·배포·실제 시험 범위는 [날짜별 기록](../records/reports/2026-10-18_notice-resend-and-service-delivery.md)을 따른다.
