# 시스템 경계

## 현재 외부 이용자와 경로 — 2026-10-12

| 이용자·외부 시스템 | 하는 일 | 연결 경로 |
|---|---|---|
| 여행 고객 | 여행 입력·일정 구성·조회·설정·변경 요청 | 고객 웹 앱 → 인증된 REST API |
| 고객의 개인 AI | 고객이 허용한 여행 제출·조회·도구 호출 | API/MCP, 해당 고객 권한 검사 |
| 공유 링크 수신자 | 공유된 여행의 최신 일정 읽기 | 읽기 범위를 제한한 공유 링크 |
| 개발자·QA | 기능 설정·장애·장소 미매칭·영향 고객을 사후 분석 | 운영자 웹 앱, 개발·QA 권한 |
| 외부 에이전트 시스템 | 선언된 업무를 위임받아 결과 반환 | A2A 계약·환경별 구현 상태 별도 확인 |
| 장소·이동·예약 정보 제공자 | 외부 근거·예약 정보를 제공 | 허용된 자료 조회 도구 |

고객 대신 문제를 실시간으로 수정하는 상주 상담원 역할은 두지 않습니다. 고객 웹·개인 AI·공유 링크는 같은 여행 상태를 사용하며, 인증·소유권·쓰기 권한·공급자 거래 승인 경계는 각각 검사합니다. 분류 에이전트는 질의·계획·상황·사용자 성향에 따라 담당 에이전트 팀과 순서·우선순위를 결정하는 목표 책임을 가집니다. Controller는 공통 실행 장치, TeamRegistry는 등록·활성 상태 확인 장치입니다. Activity 에이전트 팀에 다른 팀의 호출 순서 결정을 맡기지 않습니다.

[고객 이용 방식·범위](../product/scope.md), [REST 계약](../../final_project_cs/wiki/external/rest-endpoints.md), [MCP 계약](../../final_project_cs/wiki/external/mcp-tools.md), [변경 전 경계 설명](_backup/2026-10-12_retirement-and-approved-wiki/system-context.md)을 확인합니다. v11 당시의 ‘접점 둘·자체 앱 없음·MCP 미확보’ 설명은 현재 사양으로 재사용하지 않습니다. 구현·배포 여부는 각 계약의 증거로 별도 확인합니다.
