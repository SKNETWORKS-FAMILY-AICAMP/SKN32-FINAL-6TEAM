# D-022 관광콘텐츠랩 사진·이미지는 학업용으로만 로컬 보관한다

`[결정 2026-10-03]` 사용자 지시. 「지금은 학업용이라 괜찮다. 상업으로 넘어갈 때 안 쓰게 할 수 있게 문서에 남겨 둬라.」

## 무엇을 했나

| 항목 | 내용 |
|---|---|
| 출처 | 한국관광콘텐츠랩 「관광 콘텐츠 통합 검색」(관광공사) |
| 관광정보 이미지 | 전국 176,458개 주소 중 169,933장을 가로 480px **AVIF**(품질 40)로 줄여 보관 — 약 1.8GB. 원본 링크 6,525개(3.7%)는 이미 404 |
| 고품질사진 | 전국 112,508장 중 **장소와 정확히 이어지는 46,254장만**(제목이 장소 이름 하나와 같고 촬영지 시·도도 같은 것) 가로 720px AVIF(품질 40)로 줄여 보관 — 약 1.4GB(예상). 나머지 66,254장은 링크만(사진 쪽에 장소 번호가 없어 연결이 안 됨) |
| 링크 | 관광정보 이미지 링크 178,838개 · 고품질사진 114,555건(썸네일·원본·depot 주소와 공공누리 유형 포함) |
| 장소 매핑 | 텍스트·이미지·사진을 장소 번호로 묶은 표 `images/place_map.*` · `photo_map.jsonl` · `text_index.csv`(사용법 `images/README.md`) |
| 위치 | `datasets/travel/kto_contentlab_text/`(**git 이 무시하는 폴더** — 저장소·DB·배포물에 들어가 있지 않다) |
| 이용 목적 신고 | 사이트에 「개인 · 개인(학생) · 교육자료 · 부트캠프 학습 목적」으로 적었다(2026-10-02). 마케팅 수신 동의는 하지 않았다 |
| 방법 | 원본은 디스크에 쓰지 않고 메모리에서 줄여 AVIF 만 저장(`convert_images.py` · `convert_photos.py`) |

## 라이선스 사실 (확인한 것)

| 대상 | 유형 | 뜻(사이트 표기) |
|---|---|---|
| 고품질사진 114,058건 | 공공누리 **제1유형** | 출처 표시 / 상업·비상업적 이용 가능 / 변경·2차 저작물 작성 가능 |
| 고품질사진 497건 | 공공누리 **제4유형** | 출처 표시 / **비상업적 이용만** / **변경·2차 저작물 작성 불가** |
| 관광정보 이미지 169,933장 | **유형을 모른다** | 링크 목록에 유형 칸이 없다. 사이트 이미지 묶음 파일 이름에는 「공공1유형」「공공3유형」이 붙어 있었으나(서울 1쪽 표본) 우리 변환본에는 그 정보가 없다 |

## 알려진 위험 — 알고 정했다

- **크기 줄이기·형식 바꾸기는 「변경」에 해당할 수 있다.** 제4유형(497건)과 유형을 모르는 관광정보 이미지는 이 변환이 조건 위반일 수 있다. 사용자가 「학업용이라 괜찮다」고 정했다 — 위반 소지가 없다는 판정이 아니다.
- **사이트에 신고한 목적(부트캠프 학습)과 다른 용도로 쓰면 안 된다.**
- 변환본은 **참고용 로컬 보관**이다. DB(`place_catalog` 등)·저장소·서버 배포물·외부 공유에 넣지 않는다.

## ★상업으로 넘어갈 때 — 반드시 할 것 (체크리스트)

상업 서비스·유료 전환·외부 배포를 정하는 순간 **먼저** 아래를 한다.

1. **서비스에서 뺀다**: 앱·서버·CDN·DB 어디에도 이 변환본이 들어가 있지 않은지 확인한다. 확인 명령(저장소 전체, 자르지 않고):
   `git ls-files | grep -iE "\.avif$|kto_contentlab"` — 나오면 안 된다.
2. **지운다**: `datasets/travel/kto_contentlab_text/images/` · `photos/` · `manifest*.jsonl` · `progress*.txt` · `convert*.log`. 링크 파일(`links/`)은 사실 정보(주소·분류)라 남겨도 되지만 **이미지 주소를 이용자 화면에 그대로 보여 줄 때도 아래 3번을 따른다.**
3. **다시 쓰려면 유형별로 새로 확인한다**:
   - 제1유형(고품질사진): 출처 표시(ⓒ한국관광공사 + 촬영자 `koCmanNm`)를 달면 상업 이용·변경 가능. 변환은 새로 해서 쓴다. ★촬영자 이름은 `datasets/travel/kto_contentlab_text/links/photo_links_p*.json` 에만 있다(공유용 `images/` 에서는 2026-10-03 에 뺐다 — 아래 「촬영자 이름」).
   - **제4유형 497건: 상업 서비스에서 쓰지 않는다**(비상업 한정 · 변경 불가). 목록: 링크 파일에서 `cpyrhtDivCd == "Type4"`, 변환본에서는 `manifest_photos.jsonl` 의 같은 칸.
   - 관광정보 이미지: 유형을 모르므로 **상업 서비스에서 쓰지 않는다.** 쓰려면 사이트 이미지 묶음 파일 이름의 유형(공공N유형)을 읽거나 관광공사에 확인한 뒤에 쓴다. 제3유형(변경 금지) 등이 섞여 있을 수 있다.
4. **사이트 이용 목적을 다시 신고한다**: 상업 목적으로 쓰는 사진은 이용 목적(콘텐츠랩 다운로드 입력창)을 상업 목적으로 새로 적어 받는다. 「부트캠프 학습 목적」으로 받은 파일을 상업에 쓰지 않는다.
5. **이 문서와 루트 `CLAUDE.md` 의 「외부 공공데이터 저장」 행을 같이 고친다.**

## 촬영자 이름(2026-10-03, 사용자 지시 · 코덱스와 검토)

- 사진 목록 응답의 촬영자 칸(`koCmanNm`)은 사람 이름이 많다(고유 993명, 사람 이름처럼 보이는 것 814). 우리 앱·스크립트·시험·위키는 이 칸을 읽지 않는다.
- **`images/`(공유할 수 있는 폴더)에서는 지웠다**: `photo_map.jsonl` 의 `photographer` 칸 112,508줄 · 생성 스크립트 `build_place_map.py`. 지우기 전 백업은 `datasets/travel/kto_contentlab_text/_backup/…_photo_map_with_photographer/`.
- **원본 추출본(`links/`)에는 남겼다** — 코덱스 검토 결과: 사진 목록 API 를 오늘 다시 받을 수 있었다는 것이 나중에도 같은 값을 받을 수 있다는 보장은 아니다(공급자가 바꾸거나 사진을 내리면 못 받는다). 공공누리는 제1·4유형 모두 출처 표시를 요구하고 표시 예시에 기관명과 작성자명이 함께 나온다.
- 그래서 **`links/` 는 밖으로 내보내지 않는다**(팀원·외부 공유 때 `images/` 만). 사진을 이용자 화면에 보여 줄 때는 `links/` 에서 촬영자를 꺼내 출처 표시를 붙인다.
- 기각: 두 곳 모두 지우기(복구 보장이 없다) · 「한국관광공사 소속」 한 칸만 남기기(「김지호」·「라이브스튜디오」 같은 값의 권리자를 못 가린다).

## 기각한 대안

| 대안 | 기각한 까닭 |
|---|---|
| 이미지 파일을 받지 않고 링크만 저장해 이용자에게 링크를 보여 준다 | 링크가 3.7%(관광정보 표본 기준) 이미 죽어 있었다. 이용자 화면에서 이미지가 깨진다 |
| 원본(고품질사진 `depotOrg`, 평균 3.2MB) 그대로 받는다 | 약 360GB 로 이 PC 디스크(여유 약 10GB)에 안 들어간다. 모바일에는 필요 없다 |
| 고품질사진 112,508장 전부 받는다 | 사진 쪽에 장소 번호가 없어 59%가 장소와 안 이어진다. 받으면 약 3.5GB, 정확히 이어진 것만 받으면 약 1.4GB(2026-10-03 사용자 결정) |
| base64 로 바꿔 받는다 | 용량이 약 33% 늘어난다(줄이지 않는다) |
