# 여행 프로젝트 진행 기준

현재 사양은 wiki의 확정 결정·계약, 구현·배포 상태는 코드와 해당 환경 실행 기록으로 확인합니다. 오래된 발표 전 카운트다운·쇼핑몰 성과·상담원 시간 절감 추정치를 현재 진행 상태로 사용하지 않습니다.

| 찾는 것 | 정본 |
|---|---|
| 제품 범위 | [여행 범위](../product/scope.md) |
| 개발 책임 | [개발 역할](roles.md)·[코드 위치](../../final_project_cs/wiki/teams/code-layout.md) |
| 완료·검증 | [완료 기준](dod.md)·[릴리스 확인](release-gate.md) |
| 남은 일 | [남은 작업](open-items.md)·[직접 정할 일](todo-user.md) |
| 일정 | [일정](timeline.md)·[발표 계획](milestones/index.md) |

모든 숫자는 확인일·분자·분모를 붙입니다. 구현·회귀 시험·운영 반영·실사용 완료를 따로 보고합니다. D-023에 따른 과거 보존은 과거 완료표를 오늘 성과로 합산하는 근거가 아닙니다.

## 과거 기록

[수정 전 문서](../records/commerce_2026-10-11/wiki--delivery--index.md)는 당시 기록입니다. 현재 여행 제품의 사양·평가·시연·완료 증거로 사용하지 않습니다. 원문 바이트는 같은 폴더의 백업에도 보존했습니다.
