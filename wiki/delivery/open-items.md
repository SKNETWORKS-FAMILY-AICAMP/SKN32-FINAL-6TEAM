# 현재 남은 작업

현재 남은 작업은 최신 확정 결정과 해당 작업의 실행 기록으로 갱신합니다. 과거 쇼핑몰 라우팅·수집·평가 항목을 여행의 미완료 목록으로 재사용하지 않습니다.

## 현재 확인할 범위

- [wiki 검토](../../program/research/wiki_review_2026-10-11/wiki-review-v1.html)에서 아직 확정·구현 검증이 끝나지 않은 계약을 구분합니다. 문구 정정만으로 구현 완료로 올리지 않습니다.
- [Team 도구 경계](../../final_project_cs/wiki/teams/team-boundary.md)의 선언과 실제 호출 경계 차이는 별도 검토 대상입니다.
- [릴리스 확인](release-gate.md)은 현재 여행 증거·대상 환경을 요구합니다. 이번 잔재 정리는 전체 제품 출시 승인이나 외부 API 실사용 검증이 아닙니다.

## 2026-10-11 이동 실사용 검증의 남은 범위

택시 출발 시각·현재 택시 안내·후속 버스 할인 경계 결함3건과 기존 실패7건은 로컬 코드에서 해결했습니다. 신규55/55, 계획56/56·관련227/227 통과입니다. 전체21기능의 엄격 완료는0/21이며 운영 반영·실탑승/결제는 확인하지 않았습니다. 남은 것은 실시간 후속 환승·급행/순환선, 같은 좌표·시각·경로의 새 웹 검증, 복잡한 도로 제약, 실제 제품 요청·알림 배달 검증입니다. [코드 수정·검증 보고서](../../final_project_cs/wiki/records/reports/2026-10-11_2054_택시출발과환승운임_결함3건_마무리.md).

2026-10-11 추가: 대중교통 출발 접근 시간의 손상값 예외1건을 로컬에서 수정했습니다. 신규43/43·관련160/160(신규 포함) 통과이며 기존 미해결 범위·전체21기능 완료 판정은 유지합니다. [결과](../../final_project_cs/wiki/records/reports/2026-10-11_2129_출발접근시간_범위검사_복구검증.md).

## 과거 기록

[수정 전 문서](../records/commerce_2026-10-11/wiki--delivery--open-items.md)는 당시 기록입니다. 현재 여행 제품의 사양·평가·시연·완료 증거로 사용하지 않습니다. 원문 바이트는 같은 폴더의 백업에도 보존했습니다.
