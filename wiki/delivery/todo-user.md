# 고객·개발 담당자가 정할 일

현재 고객이 직접 입력해야 할 정보와 개발 담당자가 결정·실행할 일을 구분합니다. 과거 쇼핑몰 수집·패치·이슈 숫자는 오늘 할 일로 재사용하지 않습니다.

## 등록 기준

할 일을 추가할 때 대상 기능·현재 막힌 이유·누가 무엇을 입력/결정할지·추천안·확인 방법을 적습니다. 누락 값이 있으면 자동으로 확보할 수 있는 소스와 추천안을 먼저 검토합니다. 상주 상담원이 대기하며 대신 고치는 단계는 만들지 않습니다.

[현재 남은 작업](open-items.md)과 [wiki 검토](../../program/research/wiki_review_2026-10-11/wiki-review-v1.html)의 미확정 항목이 입구입니다. 게시·배포·DB 삭제·키 설정은 작업 범위와 대상 환경을 확인한 구체적인 절차로 별도 진행합니다. 이 문서 자체는 그런 실행을 승인하지 않습니다.

## 과거 기록

[수정 전 문서](../records/commerce_2026-10-11/wiki--delivery--todo-user.md)는 당시 기록입니다. 현재 여행 제품의 사양·평가·시연·완료 증거로 사용하지 않습니다. 원문 바이트는 같은 폴더의 백업에도 보존했습니다.
