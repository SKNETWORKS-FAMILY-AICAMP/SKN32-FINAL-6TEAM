# 여행 제품 릴리스 확인

현재 여행 기능·권한·고객 승인·일정 변경·알림 계약을 해당 환경에서 검증한 증거로 판단합니다. 과거 쇼핑몰 v8의 24/29·540행 judge 결과는 현재 제품의 출시 근거가 아닙니다.

## 계획서 판올림과 구분 — 2026-10-11 사용자 지시

W11은 이 출시 검증 문서의 낡은 검사 경로·성과 수치 문제를 가리키며 계획서 v11 그 자체가 아닙니다. 계획서 v11을 현재 사양으로 고쳐 쓰지 않습니다. 과거 원문으로 보존하고 현재 기준에서는 사용하지 않습니다. wiki·구현·검증 정리를 마친 뒤 v12 안내서를 새로 작성합니다. v12·최종 베이스라인의 완료를 선행 선언하지 않습니다. 현재 제품 사양의 정본은 wiki입니다.


## 필요한 증거

1. [현재 완료 기준](dod.md)과 wiki 계약별 재현 명령·결과·실패를 연결합니다.
2. [여행 평가](../../final_project_cs/wiki/quality/eval-harness.md)의 현재 자료와 실제 모델·판단·적용 결과를 구분합니다. 합성 자료 검사·mock 서버 반응·실제 외부 응답·운영 환경 검증을 합치지 않습니다.
3. 고객·tenant 격리, 업체 거래 승인, 멱등·동시성, 알림 중복·실패, 개인 정보·로그 노출을 확인합니다.
4. 해당 환경의 코드·설정·DB 상태를 확인하고 배포·복구 절차 및 미해결 위험을 기록합니다.

이 문서는 절차이며 현재 RC 통과 선언이 아닙니다. 모델 judge 점수를 사용할 때는 현재 여행 표본에서 사람 검수와 비교한 증거를 붙입니다. 과거 judge 검수 미완료를 오늘 유일한 출시 차단 사유로 단정하지 않습니다. [남은 작업](open-items.md)을 함께 봅니다.

## 과거 기록

[수정 전 문서](../records/commerce_2026-10-11/wiki--delivery--release-gate.md)는 당시 기록입니다. 현재 여행 제품의 사양·평가·시연·완료 증거로 사용하지 않습니다. 원문 바이트는 같은 폴더의 백업에도 보존했습니다.
