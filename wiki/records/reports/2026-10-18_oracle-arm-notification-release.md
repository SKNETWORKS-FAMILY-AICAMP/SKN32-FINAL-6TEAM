# 오라클 ARM 현장 시험용 알림 수정 배포

- 사용자 요청: 기존 앱의 현행 기능을 오라클 ARM에서도 현장 시험할 수 있게 배포하고 알림 동작을 확인한다. 원본 데이터셋·고객 DB를 원격과 일치시키거나 복사하는 작업은 범위가 아니다.
- 기준 Git 커밋: `405f970682cbc832cd3835589ae65a0f444fd48d`. 알림 담당 v5 51파일과 정상 종료 실행기 3파일을 격리 사본에 통합했다. 49파일은 동일 기준이며 두 공유 파일은 기존 변경을 보존해 자동 병합했다.
- 배포 후보 트리: `a6cd5113c8aaca8de353641ff5ffa28cc0a37423`. 아직 Git 원격에 게시한 커밋이 아니다. 실행기 v2는 시험·문서만 보완하며 실행기 코드는 이 트리와 바이트가 같다.
- 로컬 독립 검증: 백엔드·아키텍처·계약·보안 921/921 통과, 고객 웹 단위 시험 835/835 통과, 관리자 단위 시험 37/37 통과, 타입 검사 2/2 통과. 외부 제공처 응답을 시험 대역으로 바꾼 논리 검증이며 실제 외부 알림 수신 검증이 아니다. 별도 mock 서버 화면 시험은 이 회차에서 실행하지 않았다.
- 오라클 ARM의 격리 Linux dash 시험 14/14 통과. 실제 PID1 dash의 진행 중 작업 종료와 대기 중 종료 2/2 통과. 네트워크·고객 DB·자격 증명이 없는 별도 컨테이너로 검증했으며 실제 알림 중복 방지를 종단 확인한 결과는 아니다.
- 최초 dash 시험은 표시 저장 실패의 종료 코드를 Bash의 1로 고정해 13/14였다. 실제 dash는 2를 반환했으며 실행기가 이를 그대로 보존했다. 동일 셸의 독립 쓰기 실패 기준과 정확히 비교하는 v2 시험으로 보완했다. 실행기 코드를 바꿔 시험을 통과시키지 않았다.
- 배포 입력 보안 검사: UTF-8 텍스트 1,245개 검사, 문제 0개. 환경 파일·데이터셋·브라우저 프로필·고객 자료는 배포 압축에 포함하지 않았다. 바이너리 자산 14개는 텍스트 검사 대상이 아니다.
- 오라클 ARM의 기존 DB 백업 13,977,798바이트 및 복원 목록 906행을 같은 기계의 비공개 폴더에서 확인했다. 백업·기존 이미지·기존 소스·시험 컨테이너는 삭제하지 않았다.
- 오라클 ARM 고객 발송 스위치는 켜져 있으나 연결된 고객 채널은 0건이다. 디스코드 고객 웹훅 발송에는 Discord OAuth가 필수라는 뜻이 아니다. 기존 실패 90건·발송 제외 16건은 재전송하지 않는다.
- Google 설정 두 항목 복사는 자동 승인 검토가 구체적 승인 부족으로 거절했다. 이후 사용자가 기존 환경 서비스에 지장이 없으면 복사하도록 직접 승인했다. 기존 원본·서비스·제공처 설정은 바꾸지 않는 두 항목 복사를 별도 담당과 조율 중이다. 비밀값을 기록·Git·대화에 넣지 않는다.
