# G 학습 모델 허깅페이스 비공개 백업 연결

## 2026-10-17 18:39 KST — 계정·비공개 목적지 확인

- 사용자 요청: 학습 완료 뒤 학습된 두 모델을 허깅페이스에도 백업. 기존 모델·자료 보존 지시 유지.
- 기존 허깅페이스 계정 인증 확인. 인증 만료는 2026-11-12이며 토큰 값은 출력·문서화하지 않음. A4000에는 기존 허깅페이스 인증이 없어 백업 전용 경로에 제한적으로 전달할 예정. 기존 로그인 설정은 바꾸지 않음.
- 두 모델 전용 새 비공개 저장소를 만들고 백업 대기 안내 파일로 쓰기·비공개 상태 2/2 확인. 실제 학습 결과 가중치는 아직 업로드하지 않음. [목적지·초기 커밋 기록](../../../datasets/core/travel_tasks/20261017_audited_G/hf_backup_after_training_G/repo_registration_G.json).
- 백업 범위: 실제 학습에 사용한 기반 가중치 + 새 어댑터 + 학습 설정·완료 증명·체크포인트 + 토크나이저·E4B 해독 설정·라이선스·복원 코드·파일 지문. 데이터셋 원문·사람 답안·접속 정보·인증 파일은 백업 목록에 넣지 않음. 기존 파일을 읽어 직접 올리고 병합된 대형 모델을 디스크에 새로 만들지 않음.
- 남은 일: 완료 조건·명시한 파일만 업로드하는 도구와 무결성 검사 구현, CPU 시험·작은 실제 업로드 검증, 기존 단일 큐에 두 학습 성공 후 백업 등록, 현재 평가 작업 유지 확인. 실제 GPU 모델 학습 완료·모델 백업 완료·모델 평가 완료를 아직 주장하지 않음.

[허깅페이스 업로드 문서](https://huggingface.co/docs/huggingface_hub/guides/upload)를 확인했고 설치된 라이브러리 API도 대조했다. 기반 모델의 출처 라이선스·NOTICE를 보관해 백업에 동봉한다. 외부 저장소는 비공개이며 기존 저장소의 가시성·내용은 변경하지 않는다.
