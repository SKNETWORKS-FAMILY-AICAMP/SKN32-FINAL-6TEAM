# 구구루트 이름 변경에서 기존 이름을 유지하는 부분

2026-10-18 사용자 지시: 기존 이름을 유지해야 하는 부분은 위치와 이유를 기록하면서 작업합니다. 이 문서는 실제 변경·잔존 검사로 확인한 유지 위치와 이유를 보존합니다.

| 유지 대상 | 이유 | 새 이름으로 전환하는 조건 |
|---|---|---|
| 실제 접속 주소·배포 경로·실행 중인 서비스 이름 | 글자만 바꾸면 기존 접속·운영 명령이 다른 대상을 가리킴 | 해당 기계의 자원 변경과 검증을 함께 수행 |
| 이미 등록한 모델 이름·모델 저장 경로 | 모델을 새 이름으로 등록하지 않은 상태에서는 호출·파일 읽기 실패 | 새 이름 등록과 호출 검증 후 전환 |
| 로그인 쿠키·브라우저 저장소의 기존 키 | 기존 로그인·설정·동의·여행 상태를 잃을 수 있음 | 구·신 키를 함께 읽는 이관을 검증한 뒤 전환 |
| 식별자 계산에 쓰는 고정 문자열 | 같은 여행·장소가 다른 식별자로 계산되어 중복될 수 있음 | 기존 식별자와의 대응·중복 방지 검증 후 전환 |
| 기존 파일·그림·문서를 찾는 경로와 과거 절 링크 | 실제 파일 이름·링크를 함께 바꾸지 않으면 참조가 끊김 | 참조 대상과 모든 호출부를 함께 이관 |
| 백업·복구·격리 사본·실측 원자료 | 다른 세션의 작업과 복구 근거를 보존해야 함 | 현재 문서·코드와 분리해 원문으로 보관 |

이 표는 유지 원칙이며, 파일별 실제 잔존 위치와 개수는 아래 검사 결과에 기록했습니다. 개발 팀 이름 A-COPilot은 제품의 옛 이름이 아니므로 변경 대상에 넣지 않습니다.
