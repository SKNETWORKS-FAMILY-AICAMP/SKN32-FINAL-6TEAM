# wiki 수정 계획 v2 — 사용자 의견과 Claude Sonnet 5.5 검토 반영

25개 검토 항목에 각각 선택지 3개·추천 기본안·실제 수정 문장·대상 파일·완료 검사를 작성했다. 이번 산출물은 수정 실행 계획이며 제품 wiki의 요구사항 반영·코드 구현·DB 변경·배포 완료가 아니다.

## 반영

- 고객 웹 화면·개인 AI 연동·공유 계획서의 역할을 구체적인 이름과 기능으로 설명했다.
- 항로 지킴이 켜짐은 검증한 변경 자동 적용, 꺼짐은 제안으로 정리하고 고정 일정·재난 정지 예외를 유지했다. 미응답 기본값 정렬은 동작 변경으로 표시했다.
- 상담원 대기 없는 자동 처리·고객 보완 입력·개발자/QA 사후 분석으로 계획했다. 실제 고객 문의 화면의 운영팀 답변 대기와 차단 안내 문구를 후속 수정 대상에 추가했다.
- 인증 수단별 권한표, 공유 토큰 보강, 자료 조회 장애 격리, 기록 보존과 규모 확장 조건을 구체화했다. 초기 수치를 표준의 의무값이나 실측값으로 쓰지 않았다.

## Claude 검토

사용자가 설계 요약 외부 전송을 명시 승인한 뒤 도구를 끈 Claude Code CLI에서 `claude-sonnet-5-5`로 두 차례 설계 검토를 받았다. 정상 호출의 modelUsage를 확인했다. Claude는 전달된 사실과 발췌만 읽었으며 실제 코드·DB·앱을 시험하지 않았다.

[합의 범위·그대로 채택하지 않은 의견·추가 정책](../../../program/research/wiki_review_2026-10-11/claude-review/decision-v2.md)

## 검증

| 검사 | 결과 |
|---|---|
| 항목·선택지·대상 실재·근거·범위 구분 | 12/12 = 100% |
| 1280px/375px·선택 저장·결과 생성·초기화·링크·인쇄·브라우저 오류 | 11/11 = 100% |
| HTML에 포함된 흐름도 자체 검사 | 1/1 = 100% |

합계는 이 산출물의 검사 24/24이며 제품 기능 또는 출시 통과 수가 아니다. 전체 wiki 정독 확인 범위는 기존 보수적 목록 31/284개다. 새 코드 발췌 확인은 전체 본문 정독으로 세지 않았다.

최초 선택 파일 다운로드 자동 확인이 취소되어 선택 결과를 화면에서 생성·복사하는 방식으로 바꿨고 최종 검사를 다시 통과했다. 전체 페이지를 그림 전용 검사기에 넣으면 외부 출처 링크·선택용 스크립트 때문에 실패하므로, 흐름도만 추출해 그림 자체를 검사했다. 전체 페이지는 별도 브라우저·내용 검사를 수행했다.
