# AWS 구조 브리핑 HTML 제작·확인

## 2026-10-18 작성 기록

요청: 대화에서 제안한 구조의 그림을 포함한 HTML을 브리핑 폴더에 보관하고 AWS 로그인창을 다시 표시한다.

### 한 일

- 기존 파일을 덮어쓰지 않고 [브리핑 HTML](../../../program/briefing/triPilot-AWS-EKS-구조브리핑-2026-10-18.html)을 새로 작성했다. 최초 저장 도구 출력 시각은 2026-10-18 01:12 KST다.
- 현재 배치는 2026-10-17 이 대화의 AWS 직접 조회 범위로 한정했다. 오늘 실시간 상태로 재사용하지 않았다. API의 마지막 모델 설정 오류와 EKS 앱 분리 미적용을 명시했다.
- 그림 3개: 마지막 확인 배치, 미적용 분리 제안, 통합 worker 한 회차의 실행 순서. SVG를 HTML에 직접 내장했고 외부 폰트·스크립트·이미지를 불러오지 않는다.
- 문서의 기능명과 제안 배포 식별자를 구분했다. 모니터링 루프, 일일 정기점검·당일 새벽 구글 확인, 알림 생성·배달, 일일 피드백 집계·운영 정리를 구분했다.
- AWS 로그인 페이지가 로드된 것과 화면 표시 설정 적용을 브라우저 도구로 확인했다. 실제 사용자 화면의 탭 선택과 로그인 성공은 확인하지 않았다. 앱의 열기 요청은 queued를 반환했다.

### 검사와 한계

- diagram-design의 self_check.py가 단일 HTML 검사에 OK를 반환했다. SVG 이미지 3개다.
- 상대 근거 링크를 파일 존재로 검사했다. 로컬에서 직접 열지 못한 D-020 링크는 사용자가 대화에 제공한 확정 정정문으로 출처를 바꿨다. 링크 수정 직전에 [초안 백업](../../../program/briefing/_backup/2026-10-18_0114_source-link-correction/)을 만들었다.
- 로컬 HTML의 브라우저 미리보기는 완료하지 못했다. 로컬 미리보기 HTTP 접속은 시간 초과였고, file 프로토콜은 브라우저 정책으로 거부됐다. 브라우저 차단을 우회하지 않았다. 임시 미리보기 프로세스는 종료했다.
- 근거: D-017, cs 운영 call-budget·always-on, 여행 API 계약, 현재 run_sweepers.py, 기존 EKS 배포 묶음을 읽기 전용으로 대조했다.

### 남은 일

AWS 재로그인 후 실제 EKS 배포·실행 명령·DB 상태 재조회, 모델 연결·실제 여행 요청·관리자 인증·고객 알림 경로 확인이 남았다. 앱 분리안은 미적용이다. 예약·자동화 생성, GPU 할당, 배포 변경, 커밋·푸시는 수행하지 않았다. 원본 Git 설정·자료 복구·삭제·동기화도 수행하지 않았다.
