# API 정상 종료 대기 문제 후속 인계

2026-10-18 09:44 KST 담당 기록 전달 기준입니다. 이 채팅에서 x600 서버에 추가 신호·재시작·배포를 실행한 결과가 아닙니다.

- 알림 담당자는 x600 서버의 기존 API가 Uvicorn의 `Waiting for connections to close` 상태에서 계속 기다리는 것을 확인했다고 전달했습니다. 정상 종료 대기만으로 배포가 끝난다고 가정하면 안 됩니다.
- 전달 당시 새 핵심 앱 교체는 0/3이며, 기존 웹·작업 실행기는 정상 종료됐고 기존 API는 종료 대기 중입니다. 이후 상태는 담당자의 최신 실행 기록을 확인해야 합니다.
- 담당자가 전달한 조회 범위에서 DB 활성 쓰기 거래는 0건, API 연결은 두 개, 외부 연결 중 CLOSE-WAIT는 한 개였습니다. 이것만으로 요청 취소가 무해하거나 모든 작업이 끝났다고 단정하지 않습니다.
- 추가 API 신호에 따른 요청 취소·교체는 담당자가 사용자 승인을 기다리고 있습니다. 이 인계는 조작 승인이나 별도 실행 요청이 아닙니다.
- 작업 실행기 TERM/INT 정상 종료 시험은 API의 열린 연결·장시간 요청 종료 검증을 대신하지 않습니다. 향후 배포에서는 API의 장시간 연결과 진행 요청을 별도 확인하고, 제한 시간 이후 처리·요청 중단 영향·재시도 경계를 검증해야 합니다.
- 오라클 ARM의 이번 배포에서 API 정상 종료 대기가 재현됐다는 근거는 없습니다. 오라클 ARM 배포 완료 및 Google 허용 주소 등록 대기 상태와 구분합니다.
