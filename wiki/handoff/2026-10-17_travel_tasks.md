# 여행 요청 통합 자료 제작 인계

사용자가 가져온 사람 답안과 기존 평가·여행 원문을 합쳐 로컬 `datasets/core/travel_tasks/20261017_v4/`에 새 학습·평가 자료를 만들었습니다. 데이터는 git 밖이며 모델 학습·추론·배포는 실행하지 않았습니다.

- 사람 확인 772행: 중복 제출 37행을 합쳤고 변경 답안 충돌은 0건입니다. AI 답을 보고 확인한 방식입니다. E2는 처리 갈래·대상만 사람이 확인했습니다.
- 기존 A/B/C 채점, D·D2·D3, E, E2, H를 보존했습니다. [E3 의뢰](../../program/research/daily_rag_slm/2026-10-13_notice_judgment_E3_request.md)의 종료·여행 영향 자료도 실제 파일에서 합쳤습니다.
- 새 일정 처리 44상황 11,880행, 전체 일정 생성 9,600행, 합성 글 추출 300행과 기관 순서 정규화를 추가했습니다.
- 총 37,750행: 학습 18,927 · 개발 2,755 · 새 합성 평가 3,959 · 기존 평가 11,243 · 사람 확인 평가 772 · 격리 94입니다. 격리는 확신 낮은 공지 학습 91행과 동일 입력의 다른 정답 3행입니다.

현재 받은 일정 입력 121,043개(합성 300 포함)를 새 폴더에서 전처리했습니다. 수집 전체가 완료된 것은 아닙니다. 원래 `datasets/travel/plan_samples/`와 수집 원본을 유지했습니다. 실제 글 196개는 모델 초안이며 사람 확인 전까지 학습·평가에서 제외합니다.

검사 결과는 자료 37,750행 오류 0건, 분할 간 가족·입력·일정 문맥 중복 0건, 원본 92개 해시 일치입니다. 채점기 오류 검사 8/8개가 통과했습니다. 생성 일정 1,200개 경로도 분할 간 동일 경로 중복 0건을 확인했습니다.

로컬 안내: [자료 사용법](../../datasets/core/travel_tasks/README.md) · [기계 보고서](../../datasets/core/travel_tasks/20261017_v4/reports/build_report.json) · [검증](../../datasets/core/travel_tasks/20261017_v4/reports/validation.json). 압축 JSONL을 사용하며 평가에는 정답 없는 `*_inputs.jsonl.gz`, 학습에는 `train_messages.jsonl.gz`만 전달합니다.

중간 생성본과 이전 스크립트는 `datasets/core/travel_tasks/_backup/`에 보존했습니다. 저장 공간 부족으로 중간 판 하나의 쓰기가 실패했고, 최종 판은 압축 저장 후 검증했습니다. 사람 검수 전 실제 글 196개를 정답으로 승격하지 않습니다. 기존 GPU 큐·운영 앱·DB는 이번 작업에서 변경하지 않았습니다.
