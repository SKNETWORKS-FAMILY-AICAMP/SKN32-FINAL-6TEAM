# 로컬 DoD 오류 수정과 검증 인계

사용자 지시: 로컬 오류 2건의 원인을 확인하고 전체 DoD 26항목을 단일 실행으로 검증한다. 커밋·양쪽 role-manager 반영·운영 배포는 사용자가 지정한 `git commit push` 세션에서 수행한다.

- 기준: 격리 사본 `748e25c6e32d70161419860431be124f71661029`. 공유 원본의 코드·자료·Git 설정을 동기화하지 않았다.
- 원래 전체 계측 실행은 201/203·DoD 24/26이며, 새 DB 연결 중 상대 연결 종료 오류 2건을 확보했다. 과거 정리 ERROR 2건의 traceback은 이전 검증기가 보존하지 않아 소실됐으며 원문을 복구했다고 주장하지 않는다.
- 검증기에서 정리 ERROR·자식 비정상 종료의 전체 근거를 보존하고 Windows 자식 출력의 UTF-8을 명시했다. 접속 자격정보를 가리고, 새 근거 폴더만 생성한다. 원래 시험 선택·순서·판정·재시도 기준은 유지한다. 실제 pytest 오류 주입과 기존 관문 회귀는 65/65 통과했다.
- 원격 접속 경로에서도 별도 연결 timeout을 재현했다. 원격 WSL이 중지돼 추가 원격 부하를 멈추고, 이 PC에 루프백 전용 PostgreSQL 16.15·pgvector 0.8.6 합성 시험 DB를 준비했다. 기존 원격 시험 DB 17과의 버전 차이는 명시한다.

현재 로컬 검증: 연결 3,000/3,000, 정식 단일 전체 DoD 26/26·203/203, 추가 계약·보안 455/455, 검증 도구 회귀 65/65, ruff F·E9 통과. 실패·ERROR·건너뜀 0이며 자동 재시도·제외는 하지 않았다. 검수 요약과 정확한 실행 경계는 아래 기록을 따른다.

남은 일: 지정 커밋푸시 세션에서 최신 role-manager 변경을 보존 통합·검증하고 양쪽 원격 반영을 확인한다. 원격 WSL 복구 후 운영 자동배포·실제 실행판·건강 상태를 확인한다. 로컬 통과를 운영 배포 완료로 쓰지 않는다.

기록: [원인·수정·실행별 경계](../../final_project_cs/wiki/records/reports/2026-10-18_dod-local-errors-root-cause.md).

공유할 수 없는 자료: raw JUnit·비밀 DSN·원격 접속 설정·민감한 traceback. 모두 git 밖 QA 폴더에 보존한다. 새 예약·운영 DB 수정·제품 재시도 추가는 하지 않았다.
