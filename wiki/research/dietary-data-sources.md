# 식이 제약 데이터 소스 실측

`[실측 2026-09-22]` [여행자 프로필](../product/traveler-profile.md)에서 **무엇을 물어볼지 정하기 전에** 그 값에 대응하는 데이터가 실제로 오는지 부른 기록이다. 결론은 그쪽에 있다. 짝이 되는 문서는 [무장애·이동 제약 데이터 소스 실측](accessibility-data-sources.md).

## 한 줄 결론

**알러지는 어디에도 없다. 할랄은 관광공사가 전국 약 370곳(서울 약 86곳)을 PDF 로 무료 공개한다. 채식은 OpenStreetMap 이 서울 55곳으로 가장 많고 키 없이 무료다 — 단 서울 음식점의 0.21% 라 거르는 조건이 아니라 가점으로만 쓴다. 구글 `servesVegetarianFood` 는 키가 없어 확인 전이다.**

## 실측 1 — 식이 제약(채식·할랄·알러지)

`[실측 2026-09-22]` 네 곳을 확인했다. 결론은 **알러지와 할랄은 못 한다, 채식만 조건부**다.

### 한국관광공사 TourAPI (KorService2) — 호출함

키는 `ACOP_TOUR_API_KEY`가 비어 있어 `ACOP_DATA_GO_KR_KEY`로 불렀다. 대조군(`searchKeyword2` 경복궁 12건)이 정상이라 키 문제는 아니다.

| 키워드 (전국) | totalCount | 내용 |
|---|---|---|
| 할랄 | **1** | 「비건·할랄뷰티페어」 — 행사(타입 15)다. 식당이 아니다 |
| 무슬림 | **0** | |
| 채식 | 6 | 서울은 「채식요리전문점 오세계향」 정도 |
| 비건 | 2 | 서울 1건(카페) |
| 사찰음식 | 2 | 발우공양 등 |
| 이슬람 | 1 | 「이태원 이슬람거리」 — 장소(타입 12) |

음식점 상세(`detailIntro2`, contentTypeId=39)가 주는 필드 **전부**다.

```
seat · kidsfacility · firstmenu · treatmenu · smoking · packing · infocenterfood
scalefood · parkingfood · opendatefood · opentimefood · restdatefood
discountinfofood · chkcreditcardfood · reservationfood · lcnsno
```

**할랄·채식·알러지 필드는 없다.** `treatmenu`(취급 메뉴)가 자연어로 오지만 「돈까스 / 육개장 / 생선까스」 수준이라 성분을 알 수 없다.

★**커버리지도 문제다.** 서울 등록이 **음식점 968건 · 관광지 382건**이다. 서울 식당 수에 비하면 TourAPI로 식당 대안을 고르는 것 자체가 무리다.

### 카카오 로컬 API — 호출함

서울시청 기준 반경 20km(최대값), 음식점 카테고리(`FD6`).

| 키워드 | total_count | 상위 결과 |
|---|---|---|
| 할랄 | 11 | 다샨 위구르 할랄 레스토랑, 할랄부산집 |
| 무슬림 | 0 | |
| 이슬람 | 0 | |
| vegan | 17 | 비건키친, 비건인사 |
| 사찰음식 | 17 | 발우공양, 산촌 본점 |
| 인도 | 12 | 구르카인도레스토랑 |
| 채식 | 405 | ★한가람 본점(한정식), 전주유할머니비빔밥집 |
| 비건 | 416 | ★위와 **동일** |
| 터키 | 248 | ★**써브웨이 시청점**이 1위 |

★★**앞의 세 줄이 이 API를 쓸 수 없다는 증거다.** 「채식」과 「비건」의 상위 결과가 같고, 「터키」에 써브웨이가 1위로 나온다. **상호가 아니라 관련도로 매기기 때문에 `total_count`는 필터로 못 쓴다.** 상호에 단어가 든 곳만 잡히는 검색(`할랄` 11건, `vegan` 17건)은 쓸 수 있지만, 그건 **가게 이름에 써 붙인 집만** 찾는 것이다.

응답 문서의 필드 전부 — 식이 속성은 없다.

```
address_name · category_group_code · category_group_name · category_name
distance · id · phone · place_name · place_url · road_address_name · x · y
```

### 구글 Places — **호출하지 못했다**

`[외부 2026-09-22]` 프로젝트에 **구글 API 키가 없다.** 릴리스 저장소의 `.env.apikeys`에 항목 자체가 없고, `.env.apikeys.example`에는 호출 한도 두 줄(`ACOP_RATE_GOOGLE_PLACES_PER_DAY` · `ACOP_RATE_GOOGLE_ROUTES_PER_DAY`)만 있다. 아래는 공식 문서만 본 값이다.

| 항목 | 값 |
|---|---|
| 필드 | `servesVegetarianFood` — 존재한다 |
| 요금제 | Place Details **Enterprise + Atmosphere** |
| 단가 | $25 / 1,000건 (0~10만 구간), 월 1,000건 무료 |
| 환산 | 건당 약 **37.5원** (환율 1,500원). 팀당 식당 후보 5곳이면 **188원** |
| 할랄 | 필드 없음 |
| 알러지 | 필드 없음 |

팀당 188원은 49,000원 상품에서 감당된다(기계 상한 10,000원). ★다만 **한국 식당에 이 값이 얼마나 채워져 있는지는 확인하지 못했다.** 키를 받아 서울 식당 30곳을 찍어 보기 전에는 「쓸 수 있다」고 적지 않는다.

**키 발급 조건** `[외부 2026-09-22]` — 카드가 등록된 Cloud Billing 계정이 **있어야** API가 켜진다. 대신 과금은 SKU별 월 무료 한도를 먼저 깎고, 신규 계정은 $300 체험 크레딧이 따로 붙는다. Place Details Enterprise + Atmosphere의 무료 한도는 **월 1,000건**이라 30곳 확인은 0원이다. 운영에서도 팀당 5곳이면 월 200팀까지 무료 한도 안이다.

★**계정 생성과 카드 등록은 AI 세션이 하지 않는다.** 사람이 발급해 `.env.apikeys`에 넣은 뒤 측정한다.

### 네이버 — **호출하지 못했다**

저장소 어디에도 네이버·NCP 키가 없다. `[외부]` 지역 검색 API 응답 필드는 `title · link · category · description · telephone · address · roadAddress · mapx · mapy`이고 **한 번에 최대 5건**이다. 식이 속성은 없다.

### OpenStreetMap (Overpass) — 호출함. **채식은 여기가 가장 많다**

`[실측 2026-09-22]` Overpass API 는 **키가 없어도 무료로 부른다.** OSM 은 식이 정보를 `diet:*` 태그로 갖고 있고 값이 `yes`(해당 메뉴가 있다) · `only`(전용) · `no` 로 갈린다.

| 태그 (`yes|only`) | 서울 | 전국 |
|---|---|---|
| `diet:vegan` | **55** | 111 |
| `diet:vegetarian` | **53** | 144 |
| `diet:halal` | **10** | 22 |
| `diet:kosher` | 0 | — |
| `diet:gluten_free` | 3 | 9 |
| 대조군 `amenity=restaurant` | **26,555** | — |

서울 비건 55곳은 서울 음식점 26,555곳의 **0.21%**(55/26,555)다.

그래도 **채식은 지금까지 본 소스 중 OSM 이 가장 많다.**

| 소스 | 서울 채식·비건 |
|---|---|
| **OSM** | **55** |
| 문화정보원 `채식메뉴 Y` | 33 — 라벨이 엉터리(아래) |
| 카카오 `vegan` 상호 매칭 | 17 |
| TourAPI | 1~2 |

라벨의 뜻도 분명하다. `yes` 와 `only` 가 갈려 있어 **「채식 메뉴가 있다」와 「채식 전용이다」를 구분**할 수 있다.

**이름을 직접 봤다.** 서울 `diet:vegan` 표본 12곳 — 오세계향(`only`) · 발우공양(`yes`) · 수카라 · Plant · Yona's Kitchen(`only`) · 야미요밀 Vegan Bakery(`only`) · DalYang(vegan·vegetarian 둘 다 `only`) · Vegetus · The Raw by Twins 등. **전부 말이 되는 곳이다.** 문화정보원 데이터가 바베큐집과 이자카야를 채식으로 찍은 것과 대조된다.

서울 `diet:halal` 표본 10곳 — 할랄부산집 · **더 할랄 가이즈**(`only`) · Om Restaurant · 고고인디안쿠진 · 봄베그릴 · 마리푸드 등. 이쪽도 라벨이 맞다. ★교차 확인도 된다 — Om Restaurant 은 카카오에서 「옴 레스토랑 광화문점」으로, 발우공양은 TourAPI 「사찰음식」으로도 잡혔다.

**한계 둘**

1. **자원봉사 입력이라 커버리지가 들쭉날쭉하다.** 0.21% 로는 **후보를 거르는 조건으로 못 쓴다** — 거르면 후보가 사라진다. **순위 가점**에만 쓴다
2. **라이선스가 ODbL 이다.** 출처 표시 의무가 있고, 가공한 DB 를 배포하면 같은 조건으로 공개해야 할 수 있다. **상용화 전에 법무 검토가 필요하다**

호출 방법 — `https://overpass-api.de/api/interpreter` 에 POST, 본문은
`[out:json][timeout:50];(nwr["diet:vegan"~"yes|only"](37.42,126.76,37.70,127.18););out count;`
★**호출 제한은 한 IP 당 동시 2슬롯이다.** `https://overpass-api.de/api/status` 를 `User-Agent` 를 붙여 부르면 `Rate limit: 2` 와 남은 슬롯이 나온다. `[사고 2026-09-22]` 질의를 3~4개 **동시에** 던져 429 와 타임아웃으로 절반이 실패했고, 「측정 실패」로 문서에 적었다가 **하나씩 순차로 다시 던져 전부 받았다.** 데이터가 없어서가 아니라 호출을 잘못해서 못 받은 것이었다 — **응답이 안 온 것과 값이 없는 것을 가려서 적는다.**

### HappyCow — **공개 API 가 없다**

`[실측 2026-09-22]` 세계 최대 채식 식당 사이트(22만 개 업소, 180여 개국)라 후보로 봤다.

| 확인한 것 | 결과 |
|---|---|
| `happycow.net/api` | **HTTP 404** |
| 파트너 프로그램(2022~, Premium·Essentials·Lite) | **업체가 자기 가게를 홍보하는 상품**이지 데이터 제공이 아니다 |
| 검색에 나오는 접근 경로 | 전부 **제3자 스크래퍼**(Apify 등) |

★**스크래퍼는 쓰지 않는다.** 약관 위반 소지가 있고, 산출물에 「경쟁 사이트를 긁었다」가 남는다.

확인 범위는 `/api` 경로와 웹검색이다. **놓칠 수 있는 것** — 메일로 문의하는 비공개 제휴 경로는 안 해 봤다.

### 공공데이터포털 — 「할랄」로 다시 찾았다

★`[정정 2026-09-22]` 처음에 「무슬림」 한 낱말로만 찾고 **「서울을 주는 데이터가 없다」고 적었다.** 「할랄」로 다시 찾으니 **전국 무료 데이터가 나왔다.** 한 낱말로 찾고 없다고 말한 것이 잘못이었다.

| 데이터 | 제공 | 범위 | 형태 | 비용 |
|---|---|---|---|---|
| **한국문화정보원_전국 세계 음식점 데이터** | 한국문화정보원 | 전국 9,502건 | CSV·XML·JSON 내려받기 | **무료** |
| 무슬림 친화 식당 데이터 | 레드테이블(문화빅데이터플랫폼) | 전국 | CSV 61.35 KB | **유료 11,000,000원** (맛보기 5.58 KB는 0원) |
| 경기도 무슬림 친화 음식점 | 경기관광공사 | 경기도 | 파일 | 무료 |
| 할랄 메뉴 데이터 | 레드테이블 | 전국 | 연계데이터 | 확인 안 함 |
| 한국식품산업클러스터진흥원_인증 | 동 | 전국 | 오픈API | 확인 안 함 — 식품 제조 인증으로 보인다 |

레드테이블 것은 1,100만원이라 사는 것은 검토 대상이 아니다. ★`[정정 2026-09-22]` 앞서 「6,084건」이라고 적었는데 **그 숫자는 조회수로 보인다** — 상세 화면의 `2025.08.07 업데이트 6085 19`에서 뽑은 값이고, 건수는 화면에 없다. 파일이 61.35 KB이므로 **수백 건 규모로 추정**한다 `[추정]`.

### 다만 레드테이블 데이터는 라벨이 제대로다

`[실측 2026-09-22]` 상세 화면의 **미리보기**로 실제 20행을 봤다(로그인 없이 보인다). 컬럼이 이렇다.

```
RSTRNT_ID · HALAL_CRTFC_FLAG_NM(할랄인증구분명) · CRTFC_INSTT_NM(인증기관명)
RSTRNT_NM · 지번/도로명 주소 · 전화번호 · PRYRM_AT(기도실여부)
위도 · 경도 · 이미지URL · COUNTRY_NM · CTY_NM
```

미리보기 20행의 분포 — **할랄 공식 인증 1 · 무슬림 프렌들리 12 · 무슬림 자가인증 3 · 포크프리 3 · 외국인서포터즈추천 1**. 관광공사 분류제가 그대로 들어 있고, 기도실 여부는 Y 1 · N 19다. 도시는 seoul 9 · gyeongi 3 · daegu 2 등.

식당 이름도 「포렌 레스토랑(이태원)」 · 「수엠부 인도음식점」 · 「Ganga(롯데잠실)」처럼 **말이 되는 곳들이다.** 문화정보원 데이터가 맥주집을 할랄로 찍은 것과 대조된다.

★**인증기관명이 「한국관광공사」다.** 원천은 관광공사이고 레드테이블은 재판매하는 쪽이다.

### ★원천을 찾았다 — 관광공사가 무료로 공개한다

`[실측 2026-09-22]` 관광공사 영문 사이트(`english.visitkorea.or.kr`)의 **Muslim-friendly Travel** 쪽에 공식 책자가 PDF 로 걸려 있다. 받아서 셌다.

| 항목 | 값 |
|---|---|
| 파일 | `Muslim-friendly_restaurants.pdf`, 52.1 MB, 118쪽 |
| 식당 수 | **좌표쌍 373개 (중복 제거 358)** — 약 **370곳** |
| 서울 | 약 **86곳** (경기 약 62 · 강원 26 · 부산 21 · 제주 20 …) |
| 한 곳당 싣는 것 | 영문·국문 상호 · 주소 · 전화 · 홈페이지 · 음식 종류 · 대표 메뉴 · 영업시간 · 가격대 · 좌석 수 · 주차 · **위경도** |
| 분류 | 할랄 공식 인증 · 자가인증 · 무슬림 프렌들리 · 포크프리 |
| 비용 | **무료** (로그인 없이 내려받힌다) |
| 판 | 본문에 2023 까지 나온다 — 그 무렵 판으로 보인다 `[추정]` |

★**이게 레드테이블이 1,100만원에 파는 것과 같은 원천이다.** 관광공사 쪽은 좌표까지 들어 있고 무료다.

**단 형식이 PDF 다.** 쓰려면 표를 뽑아 한 번 정리해야 하고, 그 뒤로는 **갱신이 수동**이 된다. API 가 아니라서 새 판이 올라오면 다시 받아야 한다.

그리고 **370곳은 전국이다.** 서울 86곳이면 우리 대상 도시에서 쓸 만한 크기지만, 이걸로 「이 식당이 할랄인가」를 묻는 게 아니라 **「할랄 식당 후보를 고른다」**에 쓴다 — 목록 밖의 식당은 판정 대상이 아니라 모름이다.

### 무료 데이터를 받아서 재 봤다 — 필드는 있고 값이 엉터리다
