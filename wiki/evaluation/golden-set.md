# 여행 골든·홀드아웃 안내

현재 여행 평가 입력은 [여행 평가 안내](index.md)에서 확인합니다. 골든과 독립 홀드아웃은 서로 다른 파일이며, 파일 행 수와 정답 검토 완료 수를 구분합니다.

## 책임·검증 경계

골든은 개발 중 반복 평가에, 홀드아웃은 독립 비교에 사용합니다. 정답 필드는 모델의 예측 입력·검색 필터·라우팅 결정에 흘러들면 안 됩니다. 자료의 형식과 도메인 검사는 [여행 자료 검사기](../../final_project_cs/scripts/verify_travel_eval_datasets.py), 재생 조건은 [여행 분류 재생 도구](../../final_project_cs/eval/travel_classification/replay.py)를 확인합니다.

사람 검토·라벨 합의가 없는 입력을 독립 검증 완료로 표시하지 않습니다. 합성·층화 표본의 분포를 실제 고객 분포로 주장하지 않습니다. 과거 쇼핑몰 감정·승인·채널 분포는 현재 여행 제품의 고객 구성이나 운영 정책을 정하는 근거가 아닙니다.
