# 여행 평가 절차 안내

현재 여행 모델 비교의 합격 조건과 반복·분리 기준은 [모델 평가 정본](../../final_project_cs/wiki/quality/slm-model-evaluation.md)에서 확인합니다. 기존 쇼핑몰 A/B/Proposed 결과를 현재 여행 성능으로 인용하지 않습니다.

## 평가 실행 때 고정할 것

자료 판본·분리, 예측 입력, 모델·우리 데이터 학습 여부, 프롬프트, 추론 조건을 함께 고정합니다. 정답을 예측 입력이나 검색·라우팅 필터에 넣지 않습니다. 실행 실패를 분모에서 빼서 정확도를 높이지 않습니다. 반복 수와 편차, 미실행·건너뜀을 함께 기록합니다.

자료 검사, 모델 예측 평가, 코드 회귀 시험과 실제 운영 환경 확인은 각각 다른 검증입니다. [여행 평가 안내](index.md)에서 해당 도구로 이동합니다. 과거 실험의 비용·속도·Judge 수치는 아래 기록에 보존했습니다.
