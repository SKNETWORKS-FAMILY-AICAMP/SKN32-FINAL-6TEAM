# 여행 평가 지표와 보고 기준

현재 여행 자료에 적용할 지표의 정의입니다. 과거 쇼핑몰 점수·상담원 페르소나·주문 환불 예시는 현재 성능 근거에서 제외합니다.

| 지표 | 분자·분모 또는 정의 |
|---|---|
| 요청 분류 정확도 | 정답 intent와 일치한 건 / 분류 평가 전체 건. 호출 실패 별도 표시 |
| 이슈 macro-F1 | 현재 여행 issue_code별 F1의 평균. 라벨별 표본 수 함께 보고 |
| 잘못된 팀 라우팅률 | 기대 에이전트 팀과 다른 팀에 보낸 건 / 라우팅 평가 전체 건 |
| 근거 정합률 | 확인한 사실·정책과 일치하는 제안 필드 수 / 검사한 제안 필드 수 |
| 근거 초과율 | 확인한 사실·정책에 없는 주장 수 / 검사한 전체 주장 수 |
| 계약 준수율 | 파싱·출력 계약 검사 통과 수 / 전체 출력 시도 수 |
| 필수 조건 위반률 | 필수 조건을 위반한 적용 일정 수 / 검사한 모든 적용 일정 버전 수 |
| 지연·비용 | 구간·시작/종료 정의와 실패를 포함한 분포·호출 비용 |

## 해석의 한계

고객 승인을 기다리는 비율과 개발자·QA가 결함을 사후 분석하는 일을 상담원 인계율로 합치지 않습니다. 항로 지킴이 자동 적용과 업체 거래의 고객 승인도 구분합니다. 답이 조회 값과 일치하더라도 조회 값 자체나 계산 규칙이 틀리면 별도 결함입니다. 예를 들어 이동 시간이 원본과 일치해도 휴일 운행 여부를 빠뜨리면 일정이 성립하지 않을 수 있습니다.

측정치에는 자료·모델·학습 여부·프롬프트·환경·반복·실패·표본 수를 붙입니다. 측정하지 않은 지표는 미측정이라고 쓰고 과거 점수로 채우지 않습니다. [모델 평가](../../final_project_cs/wiki/quality/slm-model-evaluation.md)와 [현재 여행 하네스](../../final_project_cs/wiki/quality/eval-harness.md)가 실제 경로를 안내합니다.

## 과거 기록

[수정 전 문서](../records/commerce_2026-10-11/wiki--evaluation--metrics.md)는 당시 기록입니다. 현재 여행 제품의 사양·평가·시연·완료 증거로 사용하지 않습니다. 원문 바이트는 같은 폴더의 백업에도 보존했습니다.
