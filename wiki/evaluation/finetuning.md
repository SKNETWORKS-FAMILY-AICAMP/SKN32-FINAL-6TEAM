# 여행 모델 학습·평가 안내

현재 모델 선정·학습·서비스 채택 기준은 [cs 모델 평가 기준](../../final_project_cs/wiki/quality/slm-model-evaluation.md)입니다. 이 페이지는 그 기준을 찾는 안내이며 새 합격 기준을 추가하지 않습니다.

## 작업 순서

1. **우리 데이터로 학습하지 않은 원본 모델**을 같은 여행 평가 조건으로 비교합니다.
2. 학습 후보와 데이터 범위를 정하고, 학습·검증·독립 홀드아웃의 중복을 확인합니다.
3. **우리 데이터로 학습한 모델**을 같은 원본 모델 및 비교 후보와 같은 조건으로 평가합니다.
4. 학습 완료, 평가 통과, 서비스 채택, 실제 배포를 각각 기록합니다. 한 단계의 완료를 다음 단계 완료로 적지 않습니다.

정확한 후보·원본/학습 여부·채택 조건과 최신 실행 기록은 위 정본에서 확인합니다. 특히 Jev 계열 모델은 서비스 이름만 쓰지 않고 정확한 모델 이름과 우리 데이터 학습 여부를 함께 적습니다.

## 남길 기록

| 항목 | 적을 내용 |
|---|---|
| 모델 | 정확한 모델 ID·원본 판본·우리 데이터 학습 여부·체크포인트 |
| 자료 | 여행 자료 경로·판본·해시·분리 방식 |
| 조건 | 프롬프트·추론 엔진·양자화·시드·입력 제한 |
| 비교 | 같은 조건의 분자/분모·실패 수·반복 횟수·편차 |
| 채택 | 평가 통과 여부와 서비스 적용 여부를 별도 표시 |

평가 자료 입구는 [여행 평가 안내](index.md)입니다. **과거 Qwen2.5-3B LoRA와 쇼핑몰 Stage 3 실험 결과는 여행 모델 채택 근거가 아닙니다.** 당시 결과는 아래 보존본에 남겼습니다.
