# 여행자 프로필 — 받을 것과 안 받을 것

## 결론

**여행자에게 받는 값은 네 개다.** 나머지는 물어봐도 쓸 데가 없어서 받지 않는다.

| 받는 것 | 값의 모양 | 어디에 쓰나 |
|---|---|---|
| 알림 언어 | 언어 코드 하나 | 알림·여행계획서를 보낼 때 그 언어로 생성 (v11 결정 14) |
| 인원 구성 | 성인 수 · 미성년 수 | 예약 가능 인원, 요금, 연령 제한 장소 탈락 |
| 최대 연속 도보 시간 | 분 | 경로 대안 탈락, 알림 ③의 출발 시각 역산 여유 |
| 식사 제약 | 있음 / 없음 **한 칸** | **있으면 식당 대안을 자동 적용하지 않는다** — 후보만 제시 |

여기에 알림을 받을 **연락 채널**이 필요하다. 이건 프로필이 아니라 접점 설정이지만 없으면 알림 세 시점이 전부 못 돈다.

## 왜 이 문서가 있나

설문 초안 열두 항목을 놓고 「이건 받고 저건 빼자」를 **데이터를 확인하지 않고** 판단했다. 그 판단 중 둘이 실측에서 뒤집혔다.

- 「알러지는 식당 대안의 탈락 조건이다」 → **거를 데이터가 없다.** 조건으로 쓸 수 없다
- 「유아·노약자는 이동 제약으로 받자」 → **서울 장소의 유모차·접근성 데이터가 사실상 비어 있다.** 받아도 못 쓴다

v11 결정 15는 **값을 모르는 상황을 만들지 않는 것**이다. 물어놓고 못 쓰는 항목은 그 반대다 — 고객에게는 「반영된다」는 기대를 주고 우리는 못 지킨다.

## 항목을 거르는 기준

**그 답이 판정을 바꾸지 않으면 받지 않는다.** 프로필 값이 쓰이는 자리는 둘뿐이다.

1. 대안 후보를 **떨어뜨리는 조건** (v11 §6-C 탈락 조건)
2. 남은 후보의 **순위를 가르는 값** (§6-C 사전식 비교)

확인하는 법은 간단하다. 시나리오에 그 값을 A와 B로 바꿔 넣어 보고 **결과가 같으면 뺀다.**

## 안 받는 것과 이유

| 뺀 항목 | 이유 |
|---|---|
| 여행 테마, 재방문 여부 | 일정을 **만드는 쪽**이 쓰는 값이다. 우리는 만들어진 일정을 받는다 (v11 §4-A) |
| 숙박 일자·장소, 도착·출발 일정 | 설문이 아니라 **제출된 일정에 이미 들어 있어야** 하는 값 |
| 알러지 종류 | 식당 단위로 거를 데이터가 없다 (아래 실측) |
| 유아·노약자 동반, 계단·유모차 | 서울 장소 데이터가 비어 있다 (아래 실측) |
| 종교 (할랄) | 서울을 덮는 공개 데이터가 없다 (아래 실측) |
| 우선순위 1·2 (음식/활동/이동) | 답이 판정으로 번역되지 않는다. **대신 「바뀌어야 할 때 무엇을 먼저 지킬까」**(예산·시간표·장소·이동 편함)를 물으면 §6-C 비교 순서에 그대로 들어간다 |
| 내국인 여부 | 외국인 전용 패스·요금에서 실익이 있는지 확인 전. 언어와 중복될 수 있다 `[미확보]` |

프로필은 **한 번 받고 끝내지 않는다.** 예산은 여행 중에 줄고 동행은 지친다. 여행계획서 링크에서 고칠 수 있어야 그다음 재평가가 맞게 돈다.

## 실측 1 — 식이 제약(채식·할랄·알러지)

`[실측 2026-09-22]` 네 곳을 확인했다. 결론은 **알러지와 할랄은 못 한다, 채식만 조건부**다.

### 한국관광공사 TourAPI (KorService2) — 호출함

키는 `ACOP_TOUR_API_KEY`가 비어 있어 `ACOP_DATA_GO_KR_KEY`로 불렀다. 대조군(`searchKeyword2` 경복궁 12건)이 정상이라 키 문제는 아니다.

| 키워드 (전국) | totalCount | 내용 |
|---|---|---|
| 할랄 | **1** | 「비건·할랄뷰티페어」 — 행사(타입 15)다. 식당이 아니다 |
| 무슬림 | **0** | |
| 채식 | 6 | 서울은 「채식요리전문점 오세계향」 정도 |
| 비건 | 2 | 서울 1건(카페) |
| 사찰음식 | 2 | 발우공양 등 |
| 이슬람 | 1 | 「이태원 이슬람거리」 — 장소(타입 12) |

음식점 상세(`detailIntro2`, contentTypeId=39)가 주는 필드 **전부**다.

```
seat · kidsfacility · firstmenu · treatmenu · smoking · packing · infocenterfood
scalefood · parkingfood · opendatefood · opentimefood · restdatefood
discountinfofood · chkcreditcardfood · reservationfood · lcnsno
```

**할랄·채식·알러지 필드는 없다.** `treatmenu`(취급 메뉴)가 자연어로 오지만 「돈까스 / 육개장 / 생선까스」 수준이라 성분을 알 수 없다.

★**커버리지도 문제다.** 서울 등록이 **음식점 968건 · 관광지 382건**이다. 서울 식당 수에 비하면 TourAPI로 식당 대안을 고르는 것 자체가 무리다.

### 카카오 로컬 API — 호출함

서울시청 기준 반경 20km(최대값), 음식점 카테고리(`FD6`).

| 키워드 | total_count | 상위 결과 |
|---|---|---|
| 할랄 | 11 | 다샨 위구르 할랄 레스토랑, 할랄부산집 |
| 무슬림 | 0 | |
| 이슬람 | 0 | |
| vegan | 17 | 비건키친, 비건인사 |
| 사찰음식 | 17 | 발우공양, 산촌 본점 |
| 인도 | 12 | 구르카인도레스토랑 |
| 채식 | 405 | ★한가람 본점(한정식), 전주유할머니비빔밥집 |
| 비건 | 416 | ★위와 **동일** |
| 터키 | 248 | ★**써브웨이 시청점**이 1위 |

★★**앞의 세 줄이 이 API를 쓸 수 없다는 증거다.** 「채식」과 「비건」의 상위 결과가 같고, 「터키」에 써브웨이가 1위로 나온다. **상호가 아니라 관련도로 매기기 때문에 `total_count`는 필터로 못 쓴다.** 상호에 단어가 든 곳만 잡히는 검색(`할랄` 11건, `vegan` 17건)은 쓸 수 있지만, 그건 **가게 이름에 써 붙인 집만** 찾는 것이다.

응답 문서의 필드 전부 — 식이 속성은 없다.

```
address_name · category_group_code · category_group_name · category_name
distance · id · phone · place_name · place_url · road_address_name · x · y
```

### 구글 Places — **호출하지 못했다**

`[외부 2026-09-22]` 프로젝트에 **구글 API 키가 없다.** `final_project_cs/.env.apikeys`에 항목 자체가 없고, `.env.apikeys.example`에는 호출 한도 두 줄(`ACOP_RATE_GOOGLE_PLACES_PER_DAY` · `ACOP_RATE_GOOGLE_ROUTES_PER_DAY`)만 있다. 아래는 공식 문서만 본 값이다.

| 항목 | 값 |
|---|---|
| 필드 | `servesVegetarianFood` — 존재한다 |
| 요금제 | Place Details **Enterprise + Atmosphere** |
| 단가 | $25 / 1,000건 (0~10만 구간), 월 1,000건 무료 |
| 환산 | 건당 약 **37.5원** (환율 1,500원). 팀당 식당 후보 5곳이면 **188원** |
| 할랄 | 필드 없음 |
| 알러지 | 필드 없음 |

팀당 188원은 49,000원 상품에서 감당된다(기계 상한 10,000원). ★다만 **한국 식당에 이 값이 얼마나 채워져 있는지는 확인하지 못했다.** 키를 받아 서울 식당 30곳을 찍어 보기 전에는 「쓸 수 있다」고 적지 않는다.

### 네이버 — **호출하지 못했다**

저장소 어디에도 네이버·NCP 키가 없다. `[외부]` 지역 검색 API 응답 필드는 `title · link · category · description · telephone · address · roadAddress · mapx · mapy`이고 **한 번에 최대 5건**이다. 식이 속성은 없다.

### 무슬림 친화 식당 — 제도는 있고 데이터가 없다

`[외부 2026-09-22]` 관광공사가 분류제를 운영한다(할랄 공식인증 · 무슬림 프렌들리 · 포크 프리 · 자가인증). 그러나 공공데이터포털에 올라온 것은 **경기관광공사 파일데이터(경기도)**와 용산구 특화거리 도형 파일이다. **서울 전체를 주는 오픈API는 없었다.**

확인 범위: `data.go.kr` 키워드 「무슬림」 검색 결과 7건. **놓칠 수 있는 것** — 「할랄」·「HALAL」 등 다른 키워드, 문화빅데이터플랫폼의 회원용 데이터, 서울관광재단 자체 공개분.

### 그래서 식이 제약은 이렇게 다룬다

1. **자동 적용을 끈다.** 제약이 있다고 답한 여행자에게는 식당 대안을 자동 교체하지 않고 후보만 제시한다. 자동 교체는 불편이 아니라 사고가 될 수 있다
2. **카테고리 수준의 순위 강등은 한다.** 「해산물 전문」 분류는 있으므로 뒤로 민다. 단 **「여기는 안전하다」고는 말하지 않는다** — 틀리는 방향이 안전한 쪽일 때만 쓴다
3. **확인 수단을 붙인다.** 대안 카드에 업체 전화번호와 메뉴 링크를 싣고 「알러지 정보는 확인하지 못했습니다. 방문 전 업체에 확인하세요」를 붙인다

★**리뷰·메뉴 글을 LLM에게 읽혀 알러지를 판정하는 방법은 쓰지 않는다.** 틀렸을 때의 결과가 일정 불편이 아니라 응급실이다.

## 실측 2 — 유모차·무장애

`[실측 2026-09-22]` **결론: 받지 않는다. 쓸 데가 없다.**

### 무장애 전용 서비스는 못 부른다

`KorWithService2`(무장애 여행 정보)의 `areaBasedList2` · `detailWithTour2` · `areaCode2` 모두 **HTTP 403 Forbidden**이다. 서비스는 존재하지만 우리 키에 활용신청이 되어 있지 않다. 신청하면 열릴 수 있다 — 안 해봤다.

### 일반 서비스의 관련 필드는 비어 있다

| 필드 | 표본 | 결과 |
|---|---|---|
| `chkbabycarriage` (서울 관광지) | 40건 | 빈칸 21 · 「없음」 16 · 「불가」 3 — **「있음/가능」 0건** |
| `kidsfacility` (서울 음식점) | 30건 | **30건 전부 `0`** |

값이 있는 것도 전부 부정이다. 게다가 이 필드는 이름이 **「유모차 대여」**다. 계단·엘리베이터 같은 접근성이 아니라 **대여 서비스 유무**를 재는 것이라 애초에 다른 것을 잰다.

### 대신 경로 쪽에서 받는다

이동 제약은 **장소 속성이 아니라 경로**에서 판정할 수 있다. 도보 시간과 환승 횟수는 경로 API가 준다. 그래서 프로필에는 **「최대 연속 도보 시간(분)」 한 칸**만 둔다. 이 값은 지금 있는 데이터로 바로 탈락 조건이 된다.

## 아직 안 해본 것

「불가」라고 적기 전에 남겨 두는 목록이다. 비어 있지 않으므로 위 결론은 **지금 가진 것 기준**이다.

| 안 해본 것 | 하면 무엇이 달라지나 |
|---|---|
| 구글 API 키 발급 → 서울 식당 30곳 `servesVegetarianFood` 채움률 | 채식을 진짜 탈락 조건으로 쓸 수 있는지 갈린다 |
| `KorWithService2` 활용신청 | 무장애 상세(휠체어·수유실 등)가 열릴 수 있다 |
| 서울교통공사 지하철 승강기 데이터 | 환승 경로의 계단 제약을 판정할 수 있다 |
| `data.go.kr` 「할랄」·「HALAL」 키워드 재검색, 서울관광재단 공개분 | 서울 할랄 데이터가 있을 수 있다 |
| 네이버 키 발급 | 지역 검색 커버리지 비교. 단 식이 속성 필드는 없다 |

## 다시 확인하는 법

키는 `final_project_cs/.env.apikeys`에서 읽는다. 값은 여기 적지 않는다.

| 확인 | 요청 |
|---|---|
| TourAPI 키워드 | `GET {KorService2}/searchKeyword2` — `keyword` · `numOfRows` · `_type=json` |
| TourAPI 음식점 상세 | `GET {KorService2}/detailIntro2` — `contentId` · `contentTypeId=39` |
| TourAPI 서울 목록 | `GET {KorService2}/areaBasedList2` — `areaCode=1` · `contentTypeId` · `arrange=A` |
| 무장애 | `GET {KorWithService2}/areaBasedList2` — 지금은 403 |
| 카카오 | `GET https://dapi.kakao.com/v2/local/search/keyword.json` — `query` · `category_group_code=FD6` · `x` · `y` · `radius=20000`, 헤더 `Authorization: KakaoAK <키>` |

`{KorService2}` = `https://apis.data.go.kr/B551011/KorService2`, `{KorWithService2}` = 같은 자리의 `KorWithService2`.

TourAPI 일일 한도는 `ACOP_RATE_TOUR_API_PER_DAY=1000`이고, 이 문서를 만들 때 약 120건을 썼다.
