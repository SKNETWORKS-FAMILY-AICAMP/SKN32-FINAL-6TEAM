# 여행자 프로필 — 받을 것과 안 받을 것

## 결론

**여행자에게 받는 값은 네 개다.** 나머지는 물어봐도 쓸 데가 없어서 받지 않는다.

| 받는 것 | 값의 모양 | 어디에 쓰나 |
|---|---|---|
| 알림 언어 | 언어 코드 하나 | 알림·여행계획서를 보낼 때 그 언어로 생성 (v11 결정 14) |
| 인원 구성 | 성인 수 · 미성년 수 | 예약 가능 인원, 요금, 연령 제한 장소 탈락 |
| 최대 연속 도보 시간 | 분 | 경로 대안 탈락, 알림 ③의 출발 시각 역산 여유 |
| 식사 제약 | 있음 / 없음 **한 칸** | **있으면 식당 대안을 자동 적용하지 않는다** — 후보만 제시 |

여기에 알림을 받을 **연락 채널**이 필요하다. 이건 프로필이 아니라 접점 설정이지만 없으면 알림 세 시점이 전부 못 돈다.

## 왜 이 문서가 있나

설문 초안 열두 항목을 놓고 「이건 받고 저건 빼자」를 **데이터를 확인하지 않고** 판단했다. 그 판단 중 둘이 실측에서 뒤집혔다.

- 「알러지는 식당 대안의 탈락 조건이다」 → **거를 데이터가 없다.** 조건으로 쓸 수 없다
- 「유아·노약자는 이동 제약으로 받자」 → **서울 장소의 유모차·접근성 데이터가 사실상 비어 있다.** 받아도 못 쓴다

v11 결정 15는 **값을 모르는 상황을 만들지 않는 것**이다. 물어놓고 못 쓰는 항목은 그 반대다 — 고객에게는 「반영된다」는 기대를 주고 우리는 못 지킨다.

## 항목을 거르는 기준

**그 답이 판정을 바꾸지 않으면 받지 않는다.** 프로필 값이 쓰이는 자리는 둘뿐이다.

1. 대안 후보를 **떨어뜨리는 조건** (v11 §6-C 탈락 조건)
2. 남은 후보의 **순위를 가르는 값** (§6-C 사전식 비교)

확인하는 법은 간단하다. 시나리오에 그 값을 A와 B로 바꿔 넣어 보고 **결과가 같으면 뺀다.**

## 안 받는 것과 이유

| 뺀 항목 | 이유 |
|---|---|
| 여행 테마, 재방문 여부 | 일정을 **만드는 쪽**이 쓰는 값이다. 우리는 만들어진 일정을 받는다 (v11 §4-A) |
| 숙박 일자·장소, 도착·출발 일정 | 설문이 아니라 **제출된 일정에 이미 들어 있어야** 하는 값 |
| 알러지 종류 | 식당 단위로 거를 데이터가 없다 (아래 실측) |
| 유아·노약자 동반, 계단·유모차 | 서울 장소 데이터가 비어 있다 (아래 실측) |
| 종교 (할랄) | 서울을 덮는 공개 데이터가 없다 (아래 실측) |
| 우선순위 1·2 (음식/활동/이동) | 답이 판정으로 번역되지 않는다. **대신 「바뀌어야 할 때 무엇을 먼저 지킬까」**(예산·시간표·장소·이동 편함)를 물으면 §6-C 비교 순서에 그대로 들어간다 |
| 내국인 여부 | 외국인 전용 패스·요금에서 실익이 있는지 확인 전. 언어와 중복될 수 있다 `[미확보]` |

프로필은 **한 번 받고 끝내지 않는다.** 예산은 여행 중에 줄고 동행은 지친다. 여행계획서 링크에서 고칠 수 있어야 그다음 재평가가 맞게 돈다.

## 식이 제약을 다루는 방법

1. **자동 적용을 끈다.** 제약이 있다고 답한 여행자에게는 식당 대안을 자동 교체하지 않고 후보만 제시한다. 자동 교체는 불편이 아니라 사고가 될 수 있다
2. **카테고리 수준의 순위 강등은 한다.** 「해산물 전문」 분류는 있으므로 뒤로 민다. 단 **「여기는 안전하다」고는 말하지 않는다** — 틀리는 방향이 안전한 쪽일 때만 쓴다
3. **확인 수단을 붙인다.** 대안 카드에 업체 전화번호와 메뉴 링크를 싣고 「알러지 정보는 확인하지 못했습니다. 방문 전 업체에 확인하세요」를 붙인다

★**리뷰·메뉴 글을 LLM에게 읽혀 알러지를 판정하는 방법은 쓰지 않는다.** 틀렸을 때의 결과가 일정 불편이 아니라 응급실이다.

## 실측 요약 — 자세한 것은 조사 문서로

근거는 [../research/dietary-data-sources.md](../research/dietary-data-sources.md) · [../research/accessibility-data-sources.md](../research/accessibility-data-sources.md)에 전부 있다. 여기서는 결론만 적는다.

| 물어보고 싶었던 것 | 데이터가 있나 | 판정 |
|---|---|---|
| 알러지 종류 | **다섯 소스 어디에도 필드가 없다** | 못 받는다 |
| 할랄 | 관광공사 분류제는 있으나 **무료 공개분이 없다**. 유료 1,100만원 | 못 받는다 |
| 채식 | 구글 `servesVegetarianFood` — **키가 없어 확인 전** | 보류 |
| 유모차·계단 | 서울 관광지 40건 중 「있음」 **0건**. 무장애 전용 API 는 활용신청 전 | 못 받는다 |
| 최대 도보 시간 | 경로 API 가 준다 | **받는다** |

★**필드가 있다는 것과 값을 믿을 수 있다는 것은 다르다.** 무료 데이터(한국문화정보원 전국 세계 음식점 9,502건)에는 `할랄음식 여부` 열이 실제로 있지만, **무료주차 Y 가 9,502건 전부(100%)**이고 서울 할랄 Y 11곳에 수제맥주집과 우동집이 들어 있다.
