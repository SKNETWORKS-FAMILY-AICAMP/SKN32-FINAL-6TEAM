choice: OTHER — 「26B 를 이긴다」를 목표에서 내리고, **12B 를 뺀 판(FT 재평가 0.6B + 구조 + E4B)을 새 기준선**으로 삼아 「26B 대비 −3%p 이내를 활성 4B 이하로」로 목표를 다시 정의한 뒤, 남은 격차 5~7문제는 **E4B 짚기 전용 LoRA(합성 자료가 이미 있음)와 후보 제한 목록**으로 줄여 본다.

- 12B 를 E4B 로 바꿔도 종단이 161 → 160/176 으로 거의 같다(12B 는 호출의 12~14% 뿐이라 영향이 작다). 그러므로 12B 는 빼도 된다.
- 26B 를 넘은 조합은 어떤 것도 없다(176문제 합계 26B 166 대 최고 소형 165 · 12B 뺀 판 160). 「이긴다」는 표현은 근거가 없다.
