# 질문: 일정 질문 인식 파이프라인에 Jev(System One 결정 모델)·앙상블·평가 방법론을 어떻게 적용하는 것이 최적인가

파일을 만들거나 고치지 마라. 명령은 읽기만. 한 번에 답하라. 사실표와 어긋나는 주장은 근거를 대라. 이 밖의 저장소 파일은 읽지 마라(필요한 사실은 아래에 모두 넣었다).

## 정할 것 (한 문장)
고객이 여행 일정에 대해 짧은 한국어 채팅으로 물을 때 「어느 일정 항목을 가리키는가(또는 해당 없음)」를 알아내는 단계를 **아래 A~F 중 무엇으로 설계하고, 확정 전에 어떤 순서로 무엇을 재야 하는가**.

## 선택지 (빠진 것이 있으면 `OTHER:` 로 제안)
- **A**: 로컬 LLM 이 일정 목록에서 번호 하나만 고르고(JSON 스키마 강제, 온도 0), 규칙으로 되확인. 지금 최고: Gemma 4 26B.
- **B**: Jev 단독(choice 질문: 항목들 + 「없음」, 보정 확률로 자동/검토 결정).
- **C**: 계층형 — Jev(또는 A)를 1차로, 확신이 낮으면 다른 층으로 재확인, 그래도 낮으면 「못 찾음」. 순서(어느 것이 앞)도 정해라.
- **D**: 로컬 다중 모델 합의(예: Gemma 4 26B · Qwen3.8 27B · gemma4 12B 투표, 불일치면 기권).
- **E**: 로컬 LLM 의 토큰 로그확률로 확신도를 내어 기권 문턱을 두는 방식(Jev 없이 보정 확률 흉내).
- **F**: 작은 모델(12B 급) LoRA 증류/파인튜닝(데이터 확보 후).

## 제품 제약 (사용자 결정 — 바꿀 수 없음)
1. **모델은 값(시각·장소·가격·이름)을 생성하지 않는다.** 항목 번호만 낸다. 답 문장은 DB 값 + 문장 틀. (지어내지 않는다)
2. **값을 모르는 상황을 만들지 않는다**: 필요한 값마다 대체 소스, 대체까지 실패하면 서버를 끈다(결정 15). 후보가 불확실해도 하나를 고르되 근거 없는 문장 금지. 단 이 단계에서는 「못 찾았다 + 일정 요약」이 이미 허용된 응답이다.
3. **고객 문장을 외부 서비스로 보낼 때는 개인정보를 가려야 한다**(전화·이메일·카드 등). 장소명·시각은 원값이 필요.
4. 팀당 상품가 49,000원, 서울·7일·4인. 운영 상한: 기계 비용 10,000원/팀, 사람 1건·15분. 2분 폴링은 무료 소스에만.
5. 최종발표 2026-10-26(약 26일 남음). MVP = Activity·Dining·Mobility.
6. 실제 고객 질문은 **0개**(서비스 공개 전). 사람이 친 것은 팀원 시험 입력 96문장 + 자동 시험 대화 77종 = 서로 다른 132문장뿐(정답 라벨 없음).
7. 서비스 서버의 GPU 사양은 **미정**. 지금 실험 서버는 16GB GPU + CPU 6.8코어(26B 는 GPU 에 다 안 들어가 질문당 8.7초).

### Jev (TypeSafe AI, 2026-09-15 공개; 출처: github jev-code README · 개인 측정 gist · LangChain 블로그 — 요약 도구가 읽은 것이며 원문 전체는 아님)
- 글을 쓰지 않는 **결정 전용 모델**. 질문 유형: choice(선택지별 확률) · score(순서 척도) · noul(예/아니오 확률). 도구: classify(label·probability·margin·confidence·decision "auto"|"review") · check(예/아니오/uncertain) · score · **rank(후보 중 질문에 답이 되는 것, any_relevant)** · ask.
- 보정된 확률(RLCD로 학습). 「보정은 집단에 대한 것이지 개별 답의 보장이 아니다」. 신뢰 문턱은 결과의 무게에 맞춰 정하라(높음 행동/중간 확인/낮음 에스컬레이션).
- 약 250ms/호출, 입력 100만 토큰당 0.042달러(출력 무료), 항목당 약 0.00004달러. 입력 한도 약 32k 토큰(107,500자). 한 요청에 질문 13개 묶음이 13번 호출보다 12배 싸고 10배 빠름.
- **실측된 함정**: `items[i]` 위치 인덱스 방식은 150개에서 86/320, 25개에서 29/320 오답. 키가 있는 객체(`items.k137`)나 질문에 항목을 직접 넣으면 320개에서 0/320 오답(2026-09-18 측정).
- 인증: TypeSafe 직접(`TYPESAFE_API_KEY`), OpenRouter, Vercel AI Gateway 로도 제공.
- **문서에 없음(확인 못 함)**: 한국어 지원·성능, 데이터 보관·학습 사용 정책, API 약관, 파인튜닝·라벨 예시 적응 가능 여부, 호출당 항목 수 한도.
