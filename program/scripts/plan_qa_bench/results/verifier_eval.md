# 검토자(짧은 확인 질문) 모델 비교 — 문턱 없이 가려내는 힘

입력은 짚기 모델 시드 1·2·3·oos1 이 D · D2 · D3 에서 항목을 골랐던 답(중복 제거)이다. 「맞은 답」 = 고른 항목이 정답, 「틀린 답」 = 정답이 「없음」인데 고른 것(오지목) 또는 다른 항목을 고른 것.
AUROC = 맞은 답이 틀린 답보다 YES 확률이 높을 확률(0.5 = 구분 못 함, 1.0 = 완벽). TNR@TPR95 = 맞은 답의 95% 를 YES 로 남기는 문턱에서 틀린 답을 NO 로 잡는 비율.
