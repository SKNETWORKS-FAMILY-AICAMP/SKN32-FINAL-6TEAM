# 본 시험 전 고정한 분석 기준

본 실행 전에 작성했습니다. 예비 시험 2개는 설정·응답·비용 동작 확인용이고 성능 집계에서 제외합니다.

- 본 시험: 24개 가상 문제 × 3회, 6개 구성. 첫 두 회는 동일 후보 순서, 셋째는 순서를 바꿉니다.
- top-1, 선형 효용 nDCG@3, 정답 상위 3개 회수율을 모든 예정 시도 기준으로 집계합니다. 호출·형식 실패는 0점이며 정상 출력만의 점수도 별도로 보관합니다.
- 비교의 재표집 단위는 문제입니다. 각 문제의 3회 평균 차이를 5,000번 paired bootstrap하여 95% 구간을 계산합니다. 공유 서술 템플릿 때문에 이 구간은 실제 고객 모집단을 대표하지 않습니다.
- nano/Luna 이진 적중의 McNemar 검사는 첫 회 24개만 사용합니다. 동일 입력 반복과 순열 변화의 순위 일치율은 각각 24개 짝에서 측정합니다. 순열 변화 결과는 모델의 통상 변동과 혼재하므로 순서만의 인과 효과로 단정하지 않습니다.
- 각 구성 비용은 그 요청 경로의 모든 단계를 포함합니다. 선별 요청 하나를 두 재정렬 모델이 공유하는 비교 실행의 실제 전체 지출은 중복 제거한 비용 기록에서 계산합니다. 경로 비용 합계를 전체 지출로 쓰지 않습니다.
- 지연은 단계 합계 p50·p95를 사용합니다. 규칙 구성은 외부 요청 지연 0이며 코드 연산 시간은 별도 미측정입니다. 회계 사용량이 없으면 예약한 상한을 비용으로 유지하며 실측 과금이라고 쓰지 않습니다.
- 모델 별칭, 반환 모델, 캐시·추론 토큰, 형식 실패·HTTP 실패, 선별 최고 후보 보존율을 기록합니다. 설명문 근거 정확도·실제 고객 만족은 이번 자동 점수에 포함하지 않습니다.
- Jev API(유료)는 후보별 성격 제공 여부를 Noul로 평가합니다. 추가 학습과 별도 보정은 하지 않습니다. 이를 Jev 계열 Winnow-E4B 실행이나 학습 실험으로 부르지 않습니다.
- 본 비교 결과를 본 뒤 본 비교 설정을 바꾸거나 본 점수에 추가 호출을 합치지 않습니다. 예정 시험이 비용 상한으로 중단되면 부분 실행으로 보고하며 예산을 늘리지 않습니다. 본 비교 진행 중 발견한 출력 한도 소진은 [별도 진단 계획](diagnostic-plan.md)에 따라 같은 전체 비용·요청 수 상한 안에서만 추가 확인하며, 본 결과와 분리합니다.
