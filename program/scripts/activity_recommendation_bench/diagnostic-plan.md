# 출력 한도 진단: 본 비교와 분리

본 비교 진행 중 nano가 1,536 출력 토큰을 추론에 사용하고 `incomplete`로 끝나는 사례를 관찰하여 추가한 진단입니다. 본 비교 설정·문제·채점·결과는 변경하지 않습니다.

- 목적: 같은 1,536 토큰 상한에서의 실패와 모델의 추천 능력을 구분하기 위한 출력 상한 민감도 확인.
- 문제 선택: 성능 결과를 기준으로 고르지 않고 본 자료의 case_id를 정렬한 첫 5개(`seoul_01`~`seoul_05`).
- nano와 Luna 모두 동일한 4,096 토큰 상한, 동일 프롬프트·자료·low 추론 수준. 모델 순서를 교대하여 문제당 한 번씩 호출, 총 10회.
- 비용 기록은 기존 전체 US$0.50와 380회 상한을 공유합니다. 본 비교 360회+예비 10회 이후 남은 범위에서만 실행하며 예산을 확대하지 않습니다. 남은 상한이 부족하면 미실행으로 기록합니다.
- 이 5개 1회 진단은 본 24개 3회 결과와 합치지 않으며, 일반 성능 우위나 안정성의 통계적 증거로 쓰지 않습니다. 최대 출력량을 높이면 nano의 품질·가격·지연이 어떻게 변하는지 관찰합니다.
- 설정 변경은 이 별도 실행의 메모리 안에서만 적용합니다. 파일 설정이나 본 결과는 덮어쓰지 않습니다.
