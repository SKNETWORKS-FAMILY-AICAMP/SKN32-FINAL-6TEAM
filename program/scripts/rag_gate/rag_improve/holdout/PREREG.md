# 규정 검색 개선 — 보류(holdout) 세트 사전 등록 (2026-10-06, 보류 세트 결과를 보기 전)

**목적**: 개발 세트(A 180문제 · B 160문제)에서 고른 개선안이 새 질문에서도 먹히는지 확인한다. 보류 세트는 **개선안을 고르는 데 쓰지 않고, 아래 변형을 한 번씩만 잰다.**

## 보류 세트
- 140문제 [`holdout_questions.json`](holdout_questions.json): 답 있음 68 · 근접·부분 답 25 · 답 없음(범위 안인데 조각에 없음) 27 · 주제 밖 20.
- 질문 작성: Claude 작업자 1(규정 조각 12개 문서의 **제목 목록만** 보고 작성, 검색 결과·조각 본문 못 봄). 정답 라벨: Claude 작업자 2(조각 글만 보고 독립 라벨, 검색 결과 못 봄). 둘 다 Claude 계열이라 **같은 계열 편향 가능**.
- 개발 세트(A · B)와 질문이 겹치는지는 확인하지 않았다(작성자가 다른 세트를 본 적 없음). 합성 질문이라 실서비스 점수가 아니다.

## 잴 변형 (사전 고정 — 결과를 보고 바꾸지 않는다)
| 변형 | 내용 |
|---|---|
| V0 | 운영 색인(직원용 본문 임베딩), 상위 3 |
| V1 | 색인 E(문서 제목 + 절 제목 + 고객용 문장), 상위 3 |
| V5d | V1 + 예상 질문(doc2query, 조각마다 gemma4:12b 가 만든 6개) 상위 2 평균을 z 점수로 합(가중 1.0) |
| V7a | V5d 로 후보 10개 → gemma4:12b 재순위(직접 답하는 줄 최대 3개) |
| V7b | V5d 로 후보 10개 → gemma4:e4b 재순위(개발 세트에서 e4b 결과가 나온 뒤에도 이 목록은 그대로) |

## 지표 (사전 고정)
- 답 있음 68문제: Recall@3(정답 줄이 상위 3 안) · MRR · (V7 만) 모델이 고른 줄 안에 정답이 있는 비율 · 틀린 줄만 보인 비율.
- 답 없음 47문제(범위 안 없음 27 + 주제 밖 20): 규정을 보이는 비율(V0·V1·V5d 는 색인 E 점수 문턱 0.55 기준, V7 은 모델이 고른 줄이 있으면 보임).
- 근접·부분 답 25문제: 규정을 보이는 비율(참고, 양성·음성에 넣지 않음).
- 각 변형 1회. 개발 세트와의 비교는 같은 표에 둔다.

## 선택 기준 (사전)
- 「양식 목표 Recall@3 0.90」과 비교해 **미달·달성을 그대로 적는다.** 개발 세트에서 달성해도 보류 세트에서 미달이면 미달로 적는다.
- 결과가 나쁘면(개발 세트 대비 5%p 이상 떨어지면) 「개발 세트에 맞춘 개선」으로 기록한다.

## 부록 — 개발 세트 결과를 본 뒤, 보류 세트를 재기 **전에** 더한 변형 (2026-10-07, 보류 세트 결과는 아직 못 봄)

개발 세트에서 재순위의 후보 수를 10 → 20 으로 늘리니 B 의 Recall@3 이 42/48(0.875) → 45/48(0.938)로 올랐다(A 는 99/100 그대로, MRR 0.959 → 0.969). 보류 세트를 재기 전에 아래를 **추가로 사전 고정**한다. 위 V0~V7b 의 정의는 바꾸지 않았다.

| 변형 | 내용 |
|---|---|
| V7c | V5d 로 후보 **20개** → gemma4:12b 재순위(직접 답하는 줄 최대 3개). 개발 세트에서 후보 수만 바꾼 것이고 다른 값은 V7a 와 같다 |
| 문턱 0.45 규칙(V7a · V7b · V7c 에 각각 덧붙여 따로 보고) | 모델이 고른 줄 중 **색인 E 점수가 0.45 이상**인 줄만 고객에게 보인다. 개발 세트에서 「답 없는 질문에 보임」을 B 2% 이하로 누르는 가장 낮은 문턱으로 골랐다(문턱 0.50 · 0.55 는 정답을 보이는 비율이 B 0.79 · 0.67 로 떨어졌다) |

- 지표는 위와 같다(Recall@3 · MRR · 모델이 고른 줄 안의 정답 · 틀린 줄만 · 답 없음 47문제에 규정을 보임 · 근접·부분 25문제 보임). 문턱 0.45 규칙은 「정답을 보임 · 답 없음 보임 · 근접·부분 보임」만 따로 낸다.
- **권장안은 V7c + 문턱 0.45** 로 미리 정한다. 달성·미달 판정은 「양식 목표 Recall@3 0.90」 대비 V7c 의 Recall@3 로 적는다. 개발 세트 대비 5%p 이상 떨어지면 「개발 세트에 맞춘 개선」으로 기록한다.
- 보류 세트는 이 부록까지 포함해 **한 번만** 돌린다. 결과를 보고 변형·문턱·후보 수를 바꿔 다시 돌리지 않는다.
- 한계: 후보 수 20 과 문턱 0.45 는 개발 세트(A · B)에서 골랐으므로 개발 세트 점수는 낙관적이다. 보류 세트가 그 확인이다.
