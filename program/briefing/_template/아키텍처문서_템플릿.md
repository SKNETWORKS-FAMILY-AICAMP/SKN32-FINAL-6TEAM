# 아키텍처 문서 템플릿 — 실무형

`[2026-09-10]` A-COP 브리핑 중 **아키텍처 문서**를 만들 때 쓰는 틀이다.
`A-COP_여행Team모듈_아키텍처.html`(v1)의 디자인 체계를 그대로 잇고, v2 를 만들다
실제로 터진 사고를 막는 규칙을 더했다.

★**왜 만들었나.** v2 를 손으로 처음부터 그리다가 v1 의 도해를 버렸고, 좌표를 글자 폭을
안 재고 찍어 **넘침 8 · 겹침 3 · 선통과 3** 이 났다. 그리고 v1 이 쓰던 검사 관문
(`check_fragment.py`)을 건너뛰었다. **틀과 관문이 문서 밖에 없으면 다음 사람이 또 건너뛴다.**

---

## 1. 만드는 순서 — 이 순서를 바꾸지 않는다

```
① 실측        코드에서 사실을 뽑는다 (줄수 · capability · 도구 · next_action · 모름 사유)
② 데이터      뽑은 사실을 JSON 한 벌로 둔다 — 도해와 표가 같은 데이터를 쓴다
③ 도해 생성   규칙 프롬프트 + 데이터로 SVG 조각을 만든다 (코덱스 가능)
④ 관문        check_arch_doc.py  → 규칙 위반 0
               check_text_fit.js  → 브라우저에서 넘침·겹침·선통과 0
⑤ 대조        코드 인용을 전수 대조한다 — 범위 밖 0
⑥ 검토        코덱스에 반박시킨다. 볼 파일을 세어서 준다
⑦ 통합        조각을 문서에 붙인다
```

★**④를 건너뛰고 ⑦로 가지 않는다.** 이 문서가 생긴 이유가 그것이다.
★**좌표를 손으로 고쳤으면 ④를 다시 돈다.** 글자 한 줄만 바꿔도 폭이 바뀐다.

---

## 2. 장 구성 — 실무 아키텍처 문서

독자가 **이 문서만 보고 일을 할 수 있어야** 한다. 장마다 「누가 무엇을 하려고 읽나」를 먼저 정한다.

| # | 장 | 담는 것 | 형식 | 주 독자 |
|---|---|---|---|---|
| 0 | **문서 정보** | 판 · 기준선 · 실측 시각 · 대상 커밋 · 검증 기록 위치 | 머리 한 줄 + 표 | 모두 |
| 1 | **한 장 요약** | 시스템 경계 · 부품 · 호출 방향 · 상태 배지 | **큰 도해 1장** + 카드 3 | 처음 보는 사람 |
| 2 | **책임 경계** | 누가 판단하고 누가 실행하나 · 승인과 대조가 어디 있나 | 도해 또는 표 | 설계 검토자 |
| 3 | **구성요소 — 공통 내부** | 모든 구성요소가 똑같이 도는 흐름 | **도해 1장** | 구현자 |
| 4 | **구성요소 — 개별** | 구성요소마다 실제로 다른 것 — 분기 · 도구 · 결과 | **구성요소당 도해 1장** + 한두 문장 | 구현자 · QA |
| 5 | **동적 흐름** | 대표 시나리오 한 건이 처음부터 끝까지 가는 길 | 단계 표 | 흐름 담당 · 연동 |
| 6 | **계약과 인터페이스** | 입력 · 출력 · 식별자 · 라우팅 축 | 표 | 연동 개발자 |
| 7 | **교차 관심사** | 검증 · 멱등 · 근거 · 권한 · 실패 처리 | 표 | 보안 · 감사 |
| 8 | **알려진 결함과 미구현** | 항목 · 지금 상태 · 근거 · **완료 확인 기준** | 표 | 담당자 · 릴리스 |
| 9 | **이 문서가 답하지 않는 것** | 역할별로 무엇을 못 하고 무엇이 더 필요한가 | 표 | 다음에 쓸 사람 |
| 10 | **용어** | 문서에 나오는 코드 이름의 뜻 | 표 | 비전공자 |
| 11 | **근거와 검증 기록** | 실측 명령 · 대조 결과 · 검토 회차 | 목록 | 감사 |

★**1·3·4 는 도해가 주인공이다.** 표로 대신하지 않는다 — v2 가 팀별 도해를 표 한 줄로
뭉갰다가 「Activity 가 어떻게 판정하나」를 못 찾는 문서가 됐다.
★**5·8·9 는 표가 주인공이다.** 도해로 그리면 확인 여부를 칸마다 적을 자리가 없다.

## 3. 디자인 체계 — v1 을 그대로 쓴다

### 토큰

```
paper   #fbfcfd    paper-2 #f1f4f8    ink   #161c28    muted #6b7488
soft    #7a8599    rule    rgba(22,28,40,0.12)          rule-solid #dbe0ea
accent  #a8720c    accent-tint rgba(168,114,12,0.10)   link  #2f5bd8
```

### 서체

| 쓰임 | 서체 |
|---|---|
| 제목 | `'Instrument Serif'`, `'Noto Sans KR'` |
| 본문 · 이름 | `'Geist'`, `'Noto Sans KR'` |
| 코드 · 기술 라벨 | `'Geist Mono'` |

### 도해 규칙 — 어기면 관문에서 떨어진다

| # | 규칙 | 왜 |
|---|---|---|
| 1 | 인라인 SVG 만. 외부 이미지·스크립트 없음 | 한 파일로 돌아야 한다 |
| 2 | `role="img"` + `aria-labelledby` · **`<title>` 이 첫 자식** · `<desc>` 채움 · id 는 장마다 다르게 | 접근성 · id 충돌 |
| 3 | **좌표·크기는 4의 배수** · font-size 는 **8 · 12 · 16** 만 | 격자가 흔들리면 흐트러져 보인다 |
| 4 | **한글은 12px 미만 금지.** 작은 라벨은 코드·라틴으로 | 한글은 작으면 뭉개진다 |
| 5 | 화살표는 **직각 엘보**(r=8). 대각선 `<line>` 금지 | 선이 글자를 가로지르는 사고의 주범 |
| 6 | 화살표 라벨은 **불투명 마스크 rect** + 선과 6~10px 간격 | 선이 글자를 뚫고 지나가지 않게 |
| 7 | 화살표를 **노드보다 먼저** 그린다 | 노드가 선을 덮는다 |
| 8 | **accent 는 도해당 최대 2곳** — 그 장의 핵심 하나에만 | 다 강조하면 아무것도 강조 안 된다 |
| 9 | 상자 `rx="6"` · 그림자 금지 · 테두리 1px | |
| 10 | 범례는 **하단 가로 띠**로 | 도해 안에 띄우면 겹친다 |
| 11 | ★**글자는 상자 안에 들어가야 한다** — 브라우저로 재서 넘침·겹침·선통과 **0** | v2 사고. 좌표만 보고는 모른다 |
| 12 | ★**한국어와 영어만.** 가나·한자 금지 | v1 Booking 도해에 일본어 3줄이 샜다 |
| 13 | ★**작업 메모를 본문에 남기지 않는다** — 「제공 원문이」 「과제에 명시된」 같은 문장 | v1 공통 도해 설명에 샜다 |

### 상태 표시 — 색이 아니라 글자로

| 표시 | 뜻 |
|---|---|
| `코드 확인` | 이 저장소에서 열어 확인했다. **줄 번호를 같이 적는다** |
| `문서 기재` | 주석·계획서에만 있고 실행 연결은 확인 안 했다 |
| `부분 구현` | 경로는 있고 내용이 비었다 |
| `미확인` | 확인 못 했다. **무엇을 못 봤는지 적는다** |
| `미구현` | 없다. **어디서 찾았고 없었는지 범위를 적는다** |

★**등록 여부 · 기능 범위 · 검증 수준은 다른 축이다.** 한 배지에 섞지 않는다.

## 4. 쓰는 규칙

| 규칙 | 왜 |
|---|---|
| **숫자는 세어서 넣는다. 한 곳에서 세고 그 값만 쓴다** | v1 은 한 문서에서 204 와 274 를 둘 다 말했다 |
| **줄수로 성숙도를 말하지 않는다** | 줄수는 파일을 가리키는 표시일 뿐이다 |
| **코드 인용은 `파일.py:줄` 로 적고 전수 대조한다** | 조건줄과 예외줄이 한 줄 차이로 어긋났다 |
| **삭제된 코드를 인용하지 않는다.** 필요하면 커밋 해시 | 커머스 가드 통계가 근거 없이 남았다 |
| **「없다」를 쓸 때는 찾은 범위를 같이 적는다** | 전역 작업 규칙 §1 |
| **연결됐다와 막힌다를 가른다** | 호출이 있다고 차단이 되는 것은 아니다 — 반대도 확인해야 한다 |
| **논문·외부 근거는 원문에서 확인한 것만 인용한다** | v1 은 논문에 없는 문장을 따옴표로 인용했다 |
| 설명은 한국어 평서체(「…한다」) | |

## 5. 파일

| 파일 | 무엇 |
|---|---|
| `아키텍처문서_템플릿.md` | 이 문서 |
| `check_arch_doc.py` | 관문 — 도해 규칙 · 문자 · 작업 메모 · 코드 인용 전수 대조 · 장 번호 |
| `check_text_fit.js` | 관문 — 브라우저에서 글자 폭을 재 넘침 · 겹침 · 선통과를 센다 |

```bash
python program/briefing/_template/check_arch_doc.py program/briefing/<문서>.html
```

`check_text_fit.js` 는 문서를 브라우저에 연 뒤 콘솔(또는 브라우저 도구의 JS 실행)에 붙여 넣는다.
결과가 `{넘침:0, 겹침:0, 선통과:0}` 이어야 통과다.
