우선 고객은 서울 여행 중 예약 일정과 자유 방문을 함께 수행하는 외국인 개인·친구 그룹이다. 확정 페르소나는 K-콘텐츠를 계기로 방한한 대만인 여성 친구이며, 본인은 한국 식자재·디저트·마트 쇼핑, 친구는 향수·화장품·쇼룸에 관심이 있다.

검산식은 다음과 같다.

\[
m=\frac{49,000}{1.1}\times(1-3\%)
-(10,000+7,500+1,000+49,000\times4\%)
=\frac{250,240}{11}
\approx22,749.09\text{원}
\quad[\text{추정 — 예산 시나리오}]
\]

후속 계산은 표시용 반올림값 대신 위 식의 \(m\)을 사용한다. 사람 예산은 평균 실적이 아니라 지원 상한을 반영한 값이다. 실제 지원비는 `여행당 사건 수×인계율×인계당 작업 시간×분당 완전원가`로 계측한다. 고객·업체 응답 대기와 운영자의 실제 작업 시간을 분리한다.

기계 예산에는 조회·모델·번역·재시도를 포함한다. 작업·저장·통지의 변동분도 원가 로그에서 확인하고 예산에 포함되지 않은 비용이 발견되면 재산정한다. 기존 커머스 모델 로그의 낮은 호출비를 여행 전체 원가로 사용하지 않는다.

상한을 넘으면 선택적 탐색을 멈추고 미해결 이유·마지막 확인 시각·업체 링크를 제공한다. 필수 감시를 몰래 줄여 원가를 맞추지 않는다.

**CAC 함수·손익 경계**

연간 판매량을 \(Q\), 연간 고정비를 \(F\), 인바운드 CAC를 \(C\)로 둔다.

\[
기여이익Ⅱ=m-C,\qquad 연간손익=Q(m-C)-F
\]

| 경계 | 의미 |
|---|---|
| \(C<m\) | 추가 판매가 고정비 회수에 기여한다. 조직 흑자를 보장하지 않는다. |
| \(C=m\) | 추가 판매의 기여가 **0원 `[추정 — 경계 산술]`**이다. 고정비 손실은 남는다. |
| \(C>m\) | 다른 조건이 같다면 추가 판매가 손실을 늘린다. |
| \(C\le m-F/Q\) | 해당 판매량에서 고정비까지 회수한다. |

연간 고정비는 다음의 가상 상용 조직 예산이다.

`개발 120,000,000＋사업·운영 30,000,000＋기본 인프라 18,000,000＋관리·회계·보안 12,000,000＝180,000,000원 [추정 — 연간 예산 전체]`

현재 프로젝트 팀의 실제 급여가 아니다. 건별 지원·획득 업무를 고정비에 다시 넣지 않는다. 손익분기는 \(m>C\)인 경우에만 `ceil(F÷(m−C))`로 계산한다.

## 시스템 구성 기획

고객이 외부에서 만든 일정·예약·필수 조건을 제출하면 A-COP는 장소와 대상을 식별하고 사실 근거를 조회한다. 시간·이동·예산·동행 조건은 코드로 판정한다. 통과한 일정은 버전으로 저장하고, 시스템 감지와 고객 신고를 같은 사건 처리 경로에 연결한다.

## 모델링 계획

모델링의 목적은 **필수 조건을 지키는 결과를 만들고, 모르는 내용을 정확히 남기며, 고객의 다음 행동 결정 시간을 줄이는 것**이다. 계산 가능한 제약은 코드로 처리하고 LLM은 요청 해석·후보 생성·설명·필요한 번역에 사용한다. 자체 모델 학습을 선행 조건으로 두지 않는다.

확정 시나리오는 시연·회귀용으로 사용하고, 동일 사건을 표현만 바꾸어 보류 평가에 넣지 않는다. 장소·예약·날짜·원 사건 단위로 분리한다. 정상 상태, 단독 변경, 복합 변경, 무예약, 비교값 미확인, 동률, 소스 장애, 번역 오류를 포함한다. 반복 실행은 독립 여행 표본으로 세지 않는다.
