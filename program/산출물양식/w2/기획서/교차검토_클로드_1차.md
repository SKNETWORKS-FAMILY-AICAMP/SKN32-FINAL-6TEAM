# 기획서 두 판 교차 검토 — Claude 1차

`[2026-09-10]` 코덱스 판(`기획서_본문_코덱스.md`)과 Claude 판(`기획서_본문_클로드.md`)을 대조했다.
★**astra 2차 교차검증 결과를 보기 전에 적었다.** 두 판정이 서로를 보지 않고 나와야 합의에 뜻이 있다.

---

## 0. 한 줄

**3절은 코덱스 판이 더 깊고 더 정직하다. 다만 팀이 정한 가격을 문서가 혼자 바꿨다.** 클로드 판은 모르는 값(인바운드 CAC)을 다루는 방식이 낫고 4~6절이 너무 얇다.

---

## 1. 갈린 곳 셋의 판정

### 1-1. 기여이익Ⅰ — 22,197원 대 36,521원

★**원인은 입력값이 아니라 상품이다.** 둘 다 산술은 맞다 `[검산]`.

| | 코덱스 | 클로드 |
|---|---:|---:|
| 상품 | **3일·2인·서울 · 39,000원** | 7일·4인·2도시 · **59,000원** |
| 순매출 | 39,000 ÷ 1.1 × 0.95 = **33,682원** | 59,000 ÷ 1.1 × 0.97 = **52,027원** |
| 변동비 합계 | **11,485원** | **15,506원** |
| 기여이익Ⅰ | 33,682 − 11,485 = **22,197원** | 52,027 − 15,506 = **36,521원** |

```
차이 14,324원 = 순매출 −18,345원 (상품가 차이)
              + 변동비 +4,021원 (코덱스가 원가를 낮게 잡음)
```

**판정 — 코덱스의 방향은 맞고, 한 일은 월권이다.**

| | |
|---|---|
| ✔ 맞은 것 | 서울 1도시면 v3 의 「7일·2도시」 상품이 아니다. **v3 상품표의 「단기 여행 39,000원(3일·1도시)」이 더 가깝다.** 클로드 판이 §3-1 에서 이걸 **지적만 하고 계산에는 59,000원을 썼다.** 일관성은 코덱스가 낫다 |
| ✘ 월권 | **v11 §1 은 59,000원을 `[결정]` 으로 적었고, 2도시 대 1도시 불일치는 §0-3 의 팀 결정 사항(U4)이다.** 코덱스는 그걸 `[추정]` 39,000원으로 **혼자 덮어썼다.** 기획서가 팀 결정을 대신 내리면 안 된다 |

→ **병합: 두 상품을 시나리오로 나란히 둔다.** 59,000원(v11 결정) · 39,000원(1도시 현실안). 고르는 것은 팀이다.

### 1-2. 판매량 — 연 1,200건 대 8,000건

**판정 — 코덱스가 정직하다. 클로드 판의 약점이다.**

클로드 판은 v3 의 **연 8,000건을 기준 시나리오로 남겼다.** "인바운드 근거 아님"이라고 달았지만, **근거가 아닌 수를 기준으로 두는 것 자체가 문제**다. 그 8,000건은 한국어 채널 16만 적격 방문 × 5% 전환에서 나왔고, **그 채널은 인바운드에 없다.**

코덱스는 **접점 연결 단계를 추가해 연 1,200건으로 내리고** "건별은 양수, 조직 손익은 부적합"이라고 결론 냈다. **불편하지만 맞는 결론이다.**

→ **병합: 코덱스의 판매량과 결론을 채택한다.**

### 1-3. 모르는 CAC 를 다루는 방식

**판정 — 클로드가 정직하다.**

| | |
|---|---|
| 코덱스 | CAC **12,000원을 가정해 넣고** 결과를 냈다. 경계는 「연 20,000건일 때 허용 CAC 13,197원」 하나 |
| 클로드 | CAC 를 **변수로 두고** 「36,521원을 넘으면 팔수록 손해」를 보였다. **모르는 값이 결론을 얼마나 흔드는지 한 표로 보인다** |

인바운드 CAC 는 `[미확보]` 다. **가정한 한 값보다, 값이 바뀔 때 결론이 어떻게 바뀌는지가 더 쓸모 있다.**

→ **병합: 두 상품 각각에 CAC 함수 손익분기표를 둔다.** 코덱스의 12,000원은 그 표의 한 행으로 들어간다.

## 2. 사실 오류

| 무엇이 | 어느 판 어디 | 왜 틀렸나 | 고침 |
|---|---|---|---|
| ★**「Places·Routes 적용 단가 `[미확보]`」** | 코덱스 3절 원가 대조표 | **v3 §7 에 공개 단가가 있다** — Place Details Enterprise $20/1,000건 · Text Search Pro $32/1,000건 · Route Matrix Essentials $5/1,000요소 `[외부]`. **모르는 것은 사용량이다.** ★클로드도 비용 문서·v11 §11-A 에 같은 오류를 적었고 **오늘 정정했다** | 「단가는 공개, 사용량 `[추정]`」 |
| **장소 상세 20원/건이 공개 단가보다 낮다** | 코덱스 3절 단위경제표 | $20/1,000건 = $0.020/건. v3 환율 1,500원이면 **30원/건**, 단위경제 문서 환율 1,400원이면 **28원/건**. 20원은 **약 33% 낮다.** 96회면 1,920원 → **2,880원**(+960원) | 공개 단가로 다시 계산. 환율 하나로 통일 |
| **환율이 두 개다** | 두 판 · 원 문서 | v3 는 1,500원, 단위경제 문서는 1,400원 `[추정]` | 기획서 전체에 하나를 정해 명시 |
| **판매량 8,000건을 기준으로 둠** | 클로드 3-6·3-7 | 1-2 참고 | 코덱스 판매량 채택 |
| **4~6절이 템플릿 비중에 한참 못 미친다** | 클로드 4·5·6절 | 템플릿 비중 13·10·10% 인데 **8.3·3.8·4.6%** `[실측]` | 코덱스 판을 바탕으로 |

★**둘 다 「없는 것을 있다고」 적지는 않았다.** `read.route` 미구현 · `tier=='simulated'` 0건 · `trips` 마이그레이션 없음을 두 판 모두 `[미구현]` 으로 적었다.

## 4. 병합해도 남는 약점 — 어느 판도 못 채운 것

| | 왜 못 채우나 |
|---|---|
| **인바운드 CAC · 획득 채널** | 조사가 없다. 두 판 다 가정이다 |
| **SAM 의 두 비율** — 서울 방문률 · 개인 에이전트 사용률 | 조사가 없다 |
| **인바운드 대상 경쟁사** | 조사가 없다. 두 판의 경쟁표는 한국인·전 세계 대상이다 |
| **평균 동행 수** | TAM 을 원 단위로 못 박지 못하는 이유다 |
| **해외 카드 결제 요율** | 계약 전이다 |
| **인계 비율 · 처리 시간** | 파일럿 전이다 |

★**여섯이 전부 「사업 쪽 조사」다.** 기술 쪽 미확보는 구현하면 풀리지만 이것들은 **누가 조사를 해야** 풀린다. 그래서 R&R 의 「사업 검증 담당 `[미배정]`」 이 이 기획서의 가장 큰 구멍이다.
