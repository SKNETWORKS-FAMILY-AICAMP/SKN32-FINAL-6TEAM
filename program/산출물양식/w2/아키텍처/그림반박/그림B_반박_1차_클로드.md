최종 메시지는 ```python 코드블록 **하나**(고친 스크립트 전문)와, 그 뒤에 1차 때와 같은 한 줄 표(상자 수·간선 수·줄인 것)만 담는다.

## 반박

| # | 무엇 | 근거 | 고칠 방향 |
|---|---|---|---|
| **S1** | ★**dot 가 죽는다.** `Warning: … was already in a rankset, deleted from cluster service_architecture` 가 **`controller` · `recovery` · `sources` · `llm` · `a2a`** 다섯에 나오고, `Warning: removing empty cluster` 다음 `Error: install_in_rank ... cluster_external ... rank 6` 으로 종료 코드 1 | Claude 실행 기록. 122~125행의 `rank="same"` 묶음, 그리고 같은 노드가 둘 이상의 cluster(또는 cluster 와 같은 줄 묶음)에 들어간 자리로 보인다 | **한 노드는 한 cluster 에만 둔다. `rank=same` 묶음과 cluster 를 겹치지 않는다.** 줄 맞춤이 필요하면 보이지 않는 간선(`style=invis`)이나 `newrank="true"` 를 쓴다. ★**판정 기준: 공식 Graphviz 16 에서 경고 「already in a rankset」·「removing empty cluster」 0건 · 종료 코드 0** |
| **S2** | 1차가 「색상 세 값은 지정 열람 범위에 없어 대체」라고 적었다 — **1차 브리프가 가리킨 줄 범위가 좁았다(Claude 의 잘못)** | 아래 원문 | **아래 상수를 그대로 쓴다. 대체하지 마라.** 사람 승인·업체 경계를 구분할 강조색이 하나 더 필요하면 `ORANGE` 상수 **하나만** 정의해 쓴다. `rankdir` 는 네가 고른 것을 유지한다 |
| **S3** | 스크립트가 **혼자서도** 공식 Graphviz 로 돌아야 한다 — 뒤에 산출물 빌드가 이 스크립트를 직접 실행한다 | `make_figs_codex.py:1~6` | 맨 위에 아래 **PATH 세 줄**을 그대로 넣는다 |
