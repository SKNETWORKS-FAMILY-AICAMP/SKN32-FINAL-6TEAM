```json
[
  {"id": "S1", "old": "문서에 있는 글자 그대로", "new": "바꾼 글자"}
]
```

| 규칙 | |
|---|---|
| `old` | 아래 **[현재 줄]** 에서 **글자 하나 다르지 않게** 복사한 부분 문자열이다. 문서 전체에서 **한 번만** 나오도록 앞뒤를 조금 붙여도 된다 |

| `new` | 한국어. **한자·가나·「。」「、」를 쓰지 마라** |
