개요
목표 : 기존 분류 학습 결과를 유지하고, 이동 판정 ML 대조와 고객 계획 읽기 방식 선정의 결과·한계를 비교한다

사용 프레임워크 : scikit-learn, PyTorch, Hugging Face Transformers, Ollama(교사 라벨)

2.3 실험 파이프라인
같은 과제·같은 실험판의 후보 모델은 동일한 검증·시험 조각과 seed(7)를 사용했다. 전체판은 실제 글 학습 조각에 합성 문장을 더했다. 인코더는 NVIDIA RTX 5090 32GB 공유 GPU 서버(학습 프로세스당 GPU 메모리 7GB 상한)에서 bfloat16 자동 혼합정밀도로 학습했고(ml/train_gpu.py, ml/train_labels_gpu.py), 선정 감정 모델의 CPU 지연은 Intel Core i5-1135G7 노트북(torch 4스레드)에서 로컬 시험 어댑터로 불러 측정했다.
선정 규칙: 기준선을 포함한 후보 가운데 검증 조각 점수(감정은 정확도, 요청 종류·문제 코드는 교사 일치도)가 가장 높은 모델을 고른다. 인코더의 검증 점수는 저장한 모델인 마지막 에폭 기준이며, 에폭 중간의 최고점 체크포인트는 저장하지 않았다. 점수가 같으면 더 단순한 기준선을 택한다. 시험 조각은 선정이 끝난 뒤 성능 보고에만 쓴다. GPU 처리량은 실행 결과 JSON에 기록된 참고값이며, 같은 GPU를 쓰던 다른 프로세스의 동시 실행 조건은 통제하지 않았다.
감정 임계값 0.9는 첫 인코더 실험 뒤 정한 고정값이다. 같은 여행 문장 41건을 이미 확인한 뒤 정했으므로 여행 3분류 결과는 독립 평가가 아니라 방향 확인용이다.

이동 비교는 구간 단위 GroupKFold 5폴드·시드 5를 사용한다. 라벨은 현행 판정이며 사람이 검수한 분류 정답과의 정확도로 해석하지 않는다. v2 성립 전환 건수는 이동 보고의 대표 시드 집계다. 버스 소요시간 슬롯은 ML 학습이 아니라 공공 통행시간 프로파일을 규칙 v0.9에 반영했다(6126599d·296ffa0b, 2026-09-25).
계획 읽기 비교는 새 모델 학습이 아니라 쓰는 모델의 선정·평가다. 출처는 고객 계획 읽기 설계서(2026-09-26) 실측 절이다. Gemma 4 12B, 온도 0, 생각 모드 끔을 기본으로 쟀다. 합성 사진 1장, 시각 항목 분모 6, 방식마다 1회 측정이며 생각 모드를 켠 비교는 따로 표시했다.
받아쓰기는 원문 보존에, 구조 읽기는 규칙에 맡긴다. 규칙이 못 읽은 줄만 LLM이 원문 위치를 가리킨다. 장소는 임베딩 점수로 확정하지 않고 자모 오타 교정과 실시간 조회로 확인한다.
구현 뒤 실측은 별도다. 09-27 전체·반쪽 받아쓰기와 규칙 읽기는 6/6·56.6초, 09-28 웹 사진 경로는 6/6 항목·6/6 장소·50.9초다. 같은 합성 사진 1장, 각 1회이며 방식 선정 표의 받아쓰기 단독 시간과 직접 비교하지 않는다(2026-09-27~28 팀 실측, 각 1회).
3.2 과적합 · 과소적합 관리 및 개선 방향
라벨 지침은 2026-09-17.v2에서 2026-09-22.v3으로 바뀌었다. booking_revert_request가 추가되어 제품 문제 코드는 18종이지만, 학습 데이터와 제출 모델은 v2의 17종 그대로다. 2026-09-17 이후 재학습은 없다. 취소와 되돌림을 구분하려면 v3 지침으로 다시 라벨을 붙이고 학습해야 한다(ml/label_with_gemma.py, 커밋 36cc1b99).
2026-09-28 기준 사람 검수 라벨은 0건이다. 팀 브랜치의 홀드아웃 자료는 템플릿이며 검수 완료 라벨이 아니다. 요청 종류·문제 코드 점수는 교사(Gemma) 일치도다.
다음 과제는 v3 재라벨·재학습, 사람 정답 홀드아웃 확보, 실제 사진·손글씨·저해상도 평가다. 계획 읽기 평가셋 60건은 아직 없으며, 장소 별칭과 앞뒤 장소에 가까운 후보 선택도 남아 있다. 새 비교는 소표본 실측과 팀 보고이므로 제품 전체 품질로 일반화하지 않는다.
선정 감정 모델은 2에폭 동안 검증 정확도가 하락하지 않았다(0.9395, 0.9430). 다만 관측 구간이 짧아 과적합이 없다고 단정하지 않는다. weight decay 0.01과 기울기 절단 1.0은 학습 스크립트(ml/train_gpu.py, ml/train_labels_gpu.py)의 고정값이다.
요청 종류·문제 코드의 첫 판(빈도 역수 가중 상한 20, 4에폭)에서 문제 코드 인코더가 다수 라벨을 거의 예측하지 않고 검증 점수가 기준선보다 크게 낮았다. 학습 손실이 계속 내려가던 점을 근거로 과소적합과 과한 가중을 원인으로 보고, 제곱근 가중(상한 5)·8에폭·배치 16으로 조정했다(문제 코드 A.X 검증 0.3333에서 0.7383, 요청 종류 A.X 검증 0.7980에서 0.8344).
임계값 0.9에서 여행 문장 3분류 macro F1은 선정 감정 모델(kf-deberta-base)이 0.739였다(평가 표본 n=41). A.X-Encoder-base(0.837)가 더 높아 리뷰 검증 결과와 방향이 달랐다. 41건은 소표본이라 선정 기준으로 쓰지 않았고, 여행 문장 라벨을 늘려 다시 비교하는 것을 다음 과제로 둔다.
요청 종류·문제 코드는 교사 라벨의 오류가 그대로 학습되므로, 사람 검수 표본으로 교사 라벨의 정확도를 재는 것이 다음 과제다.
