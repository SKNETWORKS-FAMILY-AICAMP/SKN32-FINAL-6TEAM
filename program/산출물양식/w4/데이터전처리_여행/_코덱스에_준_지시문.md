## 4. 지킬 것

- **지어내지 않는다.** 사실표·근거 파일에 없는 수치·주장은 쓰지 않는다. 모르면 「확인 안 했다」·「미확보」로 적는다.
- **잰 값과 예상을 섞지 않는다.** 반복 횟수와 날짜를 같이 적는다(대부분 1회다 — 그렇다고 적는다). 소표본은 소표본이라고 쓴다.
- **점수 이름을 지킨다.** 요청 종류·문제 코드 점수는 「교사(Gemma) 일치도」다. 사람 정답 기준 정확도로 쓰지 않는다.
- **비율에는 분모를 같이 적는다**(예: 6/9 = 67%).
- **공개 문서에 인프라·접속 정보를 쓰지 않는다** — 서버 이름·별칭·계정·IP·내부 경로·드라이브 문자(`C:\`, `E:\`, `F:\`)·기계 이름. 장치는 사양으로만(3차 스크립트의 `PRIVATE_MARKERS` 검사를 유지·확장).
- 문체는 3차 본문과 같게(평서문 「~다」, 표 위주). 줄표(—)·화살표(→)·별표(★) 등은 `docxfill.check` 가 막으니 docx 본문에는 쓰지 않는다(이 지시문과 사실표에는 있어도 된다).
- 이동 팀 내용은 그 팀 문서가 적은 값이다 — 「이동 팀 보고(2026-09-16) 기준」처럼 출처를 단다.
