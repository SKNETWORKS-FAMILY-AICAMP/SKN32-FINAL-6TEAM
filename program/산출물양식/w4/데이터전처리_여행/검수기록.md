# 검수기록

- 빌드 스크립트 실행으로 DOCX·검수본문·그림·변경요약을 생성했다. 원본 워크스페이스는 읽기만 했다.
- 생성 DOCX를 다시 열어 본문과 XML의 금지 문자, 양식 예시 잔존, 공개 금지 식별자를 검사했다. 모두 통과했다.
- 기존 EXP-01~21의 행은 3차 검수본문과 완전히 같다. 기존 변경 이력과 표지의 저장소·작성자 정보도 유지했다.
- 삽입 그림 높이는 본문 사용 가능 높이의 80% 이하이며, 생성 그림의 삽입 후 본문 글자 크기는 6pt 이상이다.
- 제출 모델 파일 해시는 SHA256SUMS.txt와 직접 대조해 17/17 일치했다. 상세 기록은 검사결과.json이다.
- 이번 R1~R7 재빌드 후 DOCX와 검수본문의 내부 메모명 0건, 금지 문자·예시 잔존·공개 금지 식별자 검사를 다시 통과했다. 비율의 JSON 일치, 카카오 재측정 비고, 사용 도구, 모델 개요의 세 줄 연속 배치, 그림 5 설명, 공통 소개 문장도 확인했다.
- 페이지 렌더링은 확인하지 못했다. 이번에도 제공 런타임에서 documents 스킬의 render_docx.py를 실행했으나 LibreOffice soffice.exe가 없어 PDF·페이지 PNG를 생성하지 못했다. 임시 폴더 정리에서도 접근 거부가 발생했다. 표의 페이지 경계·잘림·겹침에 대한 전 페이지 육안 검수는 미완료다.
- 제공 런타임에는 matplotlib가 없어 빌드가 중단되었고, 지정된 기존 Python 빌드 방식으로 재실행하여 완료했다.
- 이동 실험·계획 읽기 실측·개발 DB 집계·제품 전체 시험은 재실행하지 않았다. 사실표와 팀 보고에 적힌 값을 날짜·표본 조건과 함께 인용했다.
- 신규 수치는 사실표에서만 사용했다. 유지된 3차 수치와 기존 분할 건수의 합계 분모는 기존 JSON·빌드에서 읽었으며 상세 출처는 변경요약_4차.md에 기록했다.
