| 학습한 ML / DL 모델 (Trained ML / DL Model) |

개정 기준 2026년 9월 28일(4차 v3). 팀 A-COPilot이 만드는 여행 운영 서비스 triPilot의 데이터 전처리와 학습·평가를 다룬다. 2026-09-08 여행 도메인 전환 뒤의 자료만 담는다. 쇼핑몰 시절 자료(쇼핑 리뷰 감정 말뭉치 199,908건과 그 학습·평가, 쇼핑몰 정책 문서 25건·306청크, 커머스 주문·배송 데이터)는 이 판에서 뺐다. 제출 모델 폴더에는 3차 제출 당시의 감정 모델(쇼핑 리뷰 학습)도 들어 있으나 이 판의 설명 대상에서 뺐다.

| 이 문서를 읽는 법 / · 제출한 학습 모델은 요청 종류·문제 코드 인코더 2종이다. 요식 대체 유사도(e5 미세조정)와 이동 판정 ML은 시험·비교 모델이고 제품에는 쓰이지 않는다. / · 제품의 인라인 분류는 Gemma 4 12B(Ollama, 없으면 OpenAI)가 한다. 로컬 모델은 어댑터와 계약 시험까지 구현됐고 제품 분류 조립에는 연결되지 않았다(2026-09-28 코드 확인). / · 점수는 교사(Gemma) 일치도이며 사람 정답과의 정확도가 아니다. |


| 2종 / 제출한 학습 모델 / 요청 종류·문제 코드, kf-deberta-base 인코더 각 709 MiB | 10/10 / 이 판 모델 파일 해시 일치 / 제출 폴더 전체는 17/17(2026-09-28 직접 대조) | 미연결 / 제품 분류와의 연결 / 제품 분류는 LLM. 연결 전 v3 지침(18종)으로 재라벨·재학습 필요 | 3종 / 시험·비교 모델 / 요식 e5 미세조정 1종(제품 미적용), 이동 HGB 2종(미채택) |

모델 개요
모델 유형 : 파인튜닝한 인코더 분류기 2종(kf-deberta-base, 요청 종류·문제 코드, 과제별로 검증 조각에서 선정). 시험·비교 모델: 요식 문장 임베딩 미세조정(multilingual-e5-small), 이동 판정 HistGradientBoosting(미채택)
담당 태스크 : 로컬 분류 시험: 요청 종류 5종, 문제 코드 17종(제품 18종). 요식: 대체 식당 유사도 시험. 이동: 판정 대조 실험
프레임워크 / 버전 : 학습 PyTorch 2.13.0+cu130(CUDA 13.0), Transformers 5.16.1, scikit-learn 1.9.1 / 추론 검증 PyTorch 2.12.0+cpu, Transformers 5.13.0, scikit-learn 1.5.2
라벨 지침은 2026-09-17.v2에서 2026-09-22.v3으로 바뀌었다. booking_revert_request(이미 바꾸거나 취소한 예약을 되돌려 달라는 요청)가 더해져 제품의 문제 코드는 18종이지만, 학습 데이터와 제출 모델은 v2의 17종 그대로다. 2026-09-17 이후 재학습은 없다. 로컬 학습 모델은 어댑터와 계약 시험까지 구현했고 제품 분류 조립에는 연결되지 않았다. 제품의 인라인 분류는 Gemma 4 12B(Ollama)가 맡고, 없으면 OpenAI를 쓴다(2026-09-28 코드 확인).

| 모델 | 입·출력 필드 | 타입 | shape / 길이 | 설명 |
|---|---|---|---|---|
| 분류 모델 | text | str | 메시지 1건 | 마스킹된 고객 입력 |
| 분류 모델 | input_ids | int64 | [1, 최대 96] | 인코더 토크나이저 출력 |

| 분류 모델 | label, confidence | str, float | 1개, 0~1 | 제품 어휘 라벨과 최대 확률(어휘 밖이면 분류 실패로 처리) |
