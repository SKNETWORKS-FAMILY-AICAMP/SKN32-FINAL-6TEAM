전처리 개요
1-1. 코어(진입·분류 층)
전처리 목적 : guguroute의 코어가 쓰는 데이터를 여행 도메인 기준으로 정제한다. 고객 메시지 분류의 학습·평가 데이터, 고객이 올린 여행 계획(글·사진·PDF·docx·xlsx)을 근거가 붙은 일정 항목으로 읽는 운영 입력, 장소 조회값과 영업시간 원문의 구조화, 규정 검색용 여행 문서를 만든다
전처리 범위 : 분류: 공정위 상담 사건제목의 여행 서비스 품목, 정규화, 마스킹, 중복 제거, 교사 라벨, 층화 분할. 계획 읽기: 접수, 글자로 바꾸기, 규칙 읽기, 남은 줄의 원문 인용, 날짜·장소 해석, 확인과 등록. 영업시간: 관광공사 원문을 요일별 구간으로. 규정 문서: 절 단위 청크와 임베딩 적재
사용 도구 : Python 3.12(csv, json, re, unicodedata, hashlib), scikit-learn, 제품 개인정보 마스킹 모듈, Ollama Gemma 4 12B(교사 라벨·남은 줄 원문 인용·사진 받아쓰기, 온도 0), python-docx·openpyxl·PyMuPDF·Pillow(파일 읽기), 관광공사·카카오 장소 조회 API, bge-m3 임베딩(Ollama, 1024차원), PostgreSQL(pgvector)
1-2. 이동 에이전트(mobility)
전처리 목적 : 이동·동선을 판정하는 코드가 읽는 참조 데이터(지하철 시간표·역 순서·좌표·환승 도보·혼잡도·버스·공항 리무진·공휴일·버스 구간 통행시간·요금)를 소스 간 정합성이 검증된 형태로 만든다. 판정 경로에 LLM·RAG가 없으므로 임베딩·청킹 단계를 두지 않는다
전처리 범위 : 공공 정형 데이터(API 응답·CSV·XLSX) 원천, 정규화(시각·행선지·역명), 소스 간 대조(C1~C6), 2차에서 더한 버스 구간 통행시간 분위수 표·요금·역사정보·환승 칸, 적재와 검증. 비정형 문서·개인정보는 없다
사용 도구 : Python 3.11, requests, python-dotenv, csv·json, sqlite3, openpyxl, 검증 스크립트 consistency_check.py · check_line_station_order.py · verify_time.py · selfcheck_mobility.py · load_mobility_db.py, 2차 빌드 스크립트 build_bus_seg_profile_v1.py
1-3. 액티비티 에이전트(activity)
전처리 목적 : 서울의 관광지·활동 추천에 쓸 장소 데이터를 주소·좌표·표준 분류가 붙은 형태로 만들어 일정 생성과 대체 후보 추천이 읽게 한다. 데이터랩의 「외국인 관심 관광지」 랭킹에는 주소·좌표·표준 분류가 없어 그대로 쓸 수 없으므로 한국관광공사 TourAPI(KorService2)의 실제 장소 상세와 결합한다
전처리 범위 : TourAPI 서울 관광지 후보 805행(관광공사 신분류 lclsSystm1: 관광지·문화시설·레포츠·쇼핑 등). 서울 주소 필터, 분류 확인, 중복·결측 검사, 영업시간·휴무의 원문 보존. 브랜드 매장(올리브영·다이소·무신사·아트박스) 크롤링과 그 병합·매칭 산출물은 이 문서에서 제외한다. 영업시간·휴무는 원문 그대로 싣고 해석하지 않는다
사용 도구 : Python 3.11, requests, python-dotenv, csv, re, 관광공사 TourAPI(KorService2). 적재 스크립트: load_place_catalog_csv.py(CSV의 출처·분류를 골라 적재, EV 제외 옵션). 09-17 검토본의 초기 산출물 스크립트: extract_popular_places.py · tour_api_collect.py · manual_lookup.py · merge_manual_overrides.py · preprocess_activities.py
1-4. 요식업 에이전트(dining)
전처리 목적 : 식사가 성립하는지 판정하는 코드가 읽는 식당 원장과 평소 규칙(요일별 영업 구간·브레이크·라스트오더·휴무·매장 속성)을, 출처별 저장 조건을 지키며 만든다. 판정 경로에는 LLM·RAG가 없어 임베딩·청킹 단계를 두지 않는다. 대체 식당의 유사도 모델은 시험 단계다
전처리 범위 : 관광공사 음식점 목록 990곳과 소개정보 989곳, 영업시간·휴무·속성 문장 구조화, 사람이 확인한 정답 대조(100곳), 원장 적재. 사람 손이 낀 새 원천: 비건 목록, 할랄 시트, 미쉐린 서울 2026, 노키즈 검수 시트. 메뉴의 별도 수집·검색·재료 판정은 제외. 캐치테이블 자동 수집은 기본 꺼짐, 트립어드바이저는 보류
사용 도구 : Python 3.11, requests, python-dotenv, pyproj(EPSG:5174에서 WGS84), csv·json, re, difflib, intfloat/multilingual-e5-small(대체 유사도 시험), 스크립트 fetch_tourapi_hours.py · analyze_tourapi_hours.py · make_truth_sql.py · make_vegan_sql.py · make_halal_sql.py · google_link.py · place_link.py · ml/dining_similarity.py

액티비티 에이전트(activity)
