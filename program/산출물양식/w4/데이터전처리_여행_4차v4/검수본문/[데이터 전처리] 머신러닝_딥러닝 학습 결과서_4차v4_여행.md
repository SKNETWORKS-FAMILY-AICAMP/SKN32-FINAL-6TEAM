개요
직접 학습, 기존 모델 방식 시험, 미채택 비교 실험을 구분해서 읽어야 한다. 팀 순서는 코어, 이동, 액티비티, 요식업이다.

코어(진입·분류 층)
고객 메시지 분류(요청 종류 5종·문제 코드 17종)를 로컬 모델로 수행할 수 있는지 검증하고, 고객 계획 읽기에 쓸 모델·방식을 정한다. 제품의 문제 코드는 18종이나 학습 라벨은 v2의 17종이다.
이동 에이전트(mobility)
시간표를 보지 않고 입력 특징만으로 이동 판정(성립·불가·근거없음)을 배울 수 있는지 대조한다. 판정 경로에 ML을 넣을지 정하는 근거이며 특징 27개, 탐침 8,648건을 쓴다.
액티비티 에이전트(activity)
전용 학습은 team/role-activity 저장소 코드·문서를 검색한 범위 안에서 찾지 못했다. 공통 분류 모델의 의도 라벨에 activity 4종이 들어 있을 뿐이다.
요식업 에이전트(dining)
대체 식당 추천에서 「비슷한 곳」을 태그 규칙보다 잘 고르는지 시험한다. 같은 가게의 두 모습(상호+대표메뉴, 취급메뉴)을 짝으로 놓는 대조학습으로 문장 임베딩을 미세조정하며, 사람 판정은 별도 시트로 받는다.

그림 6. 첫 판의 과소적합을 가중·에폭·배치 조정으로 고친 효과(A.X 검증 정확도)
검증 정확도: 문제 코드 A.X 0.3333에서 0.7383, 요청 종류 A.X 0.7980에서 0.8344.
첫 판(빈도 역수 가중 상한 20, 4에폭)에서 문제 코드 인코더가 다수 라벨을 거의 예측하지 않아 검증 점수가 기준선보다 크게 낮았다. 학습 손실이 계속 내려간 점을 근거로 과소적합과 과한 가중을 원인으로 보고 제곱근 가중(상한 5)·8에폭·배치 16으로 조정했다.
weight decay 0.01과 기울기 절단 1.0은 학습 스크립트의 고정값이다. 교사 라벨의 오류가 그대로 학습되므로 사람 검수 표본으로 교사 라벨 정확도를 재는 것이 다음 과제이며, 09-28 기준 사람 검수 라벨은 0건이고 팀 브랜치의 홀드아웃 자료는 템플릿이다.
다음 과제: v3 지침(18종)으로 재라벨·재학습, 사람 정답 홀드아웃 확보, 로컬 모델의 제품 분류 연결 결정(현재 미연결), 여행 감정 학습 데이터 확보(미확보).
코어 · 계획 읽기
값 변조 3.4%(12/350)가 목표 0에 못 미쳤다. 전부 사진·스캔 받아쓰기의 글자 오독이며 반쪽 받아쓰기 검사는 빠진 줄만 잡고 바뀐 글자는 못 잡는다. 놓친 10개 중 6개가 한 이름(긴 가게 이름)이다.
후보는 전체·반쪽 받아쓰기가 서로 다른 줄을 확인 필요로 표시하는 것과 장소 조회로 고친 이름을 제목 옆에 보이는 것이며 해 보지 않았다. 사람 라벨 평가셋과 실제 사진 평가는 아직 없다.
이동 에이전트(mobility)
HGB가 지하철(0.992)은 잘 맞히지만 버스(0.405)는 못 맞힌다. 근거없음을 성립으로 잘못 바꾸는 오류가 남는 것이 미채택의 이유이며, 소요시간 추정에는 통계 프로파일을 썼다.
요식업 에이전트(dining)
분류 일치는 대리 지표다(분류도 같은 메뉴에서 규칙으로 뽑았다). 사람 판정 시트 237행(시험 가게 40곳마다 후보 5~6곳)은 비어 있어 방법별 적합률을 내지 않는다. 시험은 1회이고 제품에는 적용하지 않았으며 사람 판정을 채운 뒤 정한다.
