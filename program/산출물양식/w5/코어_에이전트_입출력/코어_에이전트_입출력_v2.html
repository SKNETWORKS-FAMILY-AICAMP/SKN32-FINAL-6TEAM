3. 에이전트별 입력 · 호출 · 출력

요식 dining

입력

  • 일감 dining.itinerary
  • trigger.item_id = 문제 식사 항목, trigger.at
  • 고객 신고면 report.type = delay(+분) · closed

호출

  • → DB trips · itinerary_items
  • → 외부 API 6종
  • → DB places · place_catalog
  • → DB dining.*(요식 원장)
  • → DB dining.*

출력

  • 그대로: answer 「영향이 없어요」 · decisions {"itinerary":"clear"}
  • 바꿈: itinerary.apply 제안(대신 갈 식당) + 알림 문구 · 다른 안
  • 못 함: fatal_source_failure · itinerary_unresolved
파일 app/modules/travel_ops/dining/team.py · 계산 plan_dining_disrupted · plan_delay · plan_closed

액티비티 activity

입력

  • 일감 activity.itinerary
  • trigger.item_id = 문제 활동 항목, trigger.at
  • 고객 신고면 report.type = stock_out(+상품)

호출

  • → DB trips · itinerary_items
  • → 외부 API 6종 (후보마다 재점검)
  • → DB places · place_catalog

출력

  • 그대로: answer 「영향이 없어요」
  • 바꿈: itinerary.apply 제안(같은 대분류 대체 활동)
  • 묻기: itinerary.apply + consent 「바꿀까요?」(실내 여부 모름 · 설문 미선택)
  • 품절: 근처 가게 답(일정은 그대로)
파일 app/modules/travel_ops/activity/team.py · 계산 plan_activity_adjustment

이동 mobility

입력

  • 일감 mobility.itinerary
  • trigger.item_id = 문제 이동 구간, trigger.at
  • 고객 신고는 처리하지 않음

호출

  • → DB trips · itinerary_items
  • → UTIC 교통 API
  • 시간표 판정기 → mobility_data_dir 시간표 파일
  • read.route · read.transit → 미구현

출력

  • 그대로: 계획 경로에 사건 없음
  • 바꿈: itinerary.apply 제안(다른 경로)
  • 못 함: unresolved · fatal_source_failure
파일 app/modules/travel_ops/mobility/team.py · 계산 plan_route_adjustment · 앞뒤 이동 재계산은 이동이 아니라 적용기(refresh_moves_around)가 함
