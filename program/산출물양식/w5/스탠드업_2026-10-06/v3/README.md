# 5주차 스탠드업 발표 v3 (2026-10-06, 디자인 스킬 적용판)

v2 는 디자인 스킬 없이 손으로 짜서 「겁나 구리다」는 지적을 받았다. v3 는 다음 순서로 다시 만들었다.
1. design-critique: v2 진단(같은 무게 상자 과다 · 기본 차트 · 작은 글자 · 빈 칸 · 엇갈린 선)
2. design-system: triPilot 사용자 웹 디자인 시스템 토큰(종이색 바탕 · 초록 하나 강조 · 경고/오류만 따뜻한 톤 · 큰 모서리 · 영어 대문자 눈썹 문구 · 브랜드 풍경 그림)
3. diagram-design: 흐름도 · 깔때기를 밀도 4/10 · 강조 1~2개 규칙으로 SVG 를 그려 PNG 로(`_assets/*.svg`)
4. 차트는 「하나만 초록, 나머지 회색」, 막대가 0 에서 시작하지 않는 비교는 점 그래프 + 축 시작값 표시
5. Opus 하위 작업으로 16장 검토(12가지 지적) → 모두 반영
