## 1. triPilot 이 하는 일 (아키텍처 한눈에 v26 그림 1 · 그림 4 에서)
- 자유여행자가 이미 짠 여행 계획을 올린다(글 · 사진 · 파일).
- 코드가 날짜 · 시각 · 장소를 읽고, 시간이 겹치는지 · 이동이 되는지 검사한다. 고객이 확인 화면에서 고치거나 등록한다.
- 등록되면 여행이 끝날 때까지 3분마다 일정 위험(휴관 · 마감 · 날씨 · 이동 문제)을 점검한다.
- 문제가 생기면 식당 담당 AI · 활동 담당 AI 가 바꿀 안(일정마다 최대 3개)을 만들고, 이동 판정기(공용 도구)가 앞뒤 이동이 되는지 본다. 바뀐 내용은 알림(디스코드 등)과 여행계획서 링크(로그인 없이 열림)로 알린다.
- 고객은 채팅이나 자기 AI 비서로도 묻고 고친다.

## 3. 모델이 푸는 문제 — 실제 예 (시험 세트 mix12, Claude 작성 합성)
일정표 일부: 금요일(2027-11-05) 13:30 「23번 대림미술관 전시 관람」 · 16:30 「25번 피크닉 전시 보기」.
- 고객 「금요일에 전시 뭐 봐?」 → 서비스 「금요일엔 13:30 대림미술관 전시 관람, 16:30 피크닉 전시 보기가 있어요.」 → 고객 「뒤에 거 예매해야 돼?」 → 정답 **25번(피크닉 전시 보기)**
- 고객 「남산타워 몇 시에 올라가?」 → 정답 **없음**(일정에 없는 곳)
- 고객 「대림창고 가는 날 언제야?」 → 정답 **없음**(대림미술관과 헷갈리게 만든 이름)
왜 필요한가: 어느 항목인지 알아야 그 장소의 영업시간 · 예약을 확인하고 바꿀 수 있다.
시험지: 일정 질문 835문제(mix8~12) 중 한 번에 두 항목을 묻는 66문제를 뺀 769문제. 헷갈리게 만든 유형 11가지 — 대명사(「거기」) · 같은 장소 두 번 · 비슷한 이름 · 두 가지 요청 · 「~말고」 · 오타 · 줄임말 · 일정과 무관한 말 · 이름 없이 설명 · 순서(「첫 번째」) · 변경 요청 · 그럴듯하지만 없는 일정.
작성: mix8~11 Codex · mix12 Claude. 처음 문제와 체크리스트는 사람이 직접 작성 · 제공했고, 사람이 일부를 직접 검수했다.

## 4. 한 줄로 이은 시험 — 단계별로 어디서 끝났나 (멀티 에이전트 보고서 4.4, 835문제)
- 규칙이 125문제를 바로 끝냄 → 710 남음 → ML 판별기가 36문제를 「일정과 무관」으로 끝냄 → 가르친 E4B 는 674번만 호출(혼자 다 하면 835번, 19% 감소).
- 점수(769문제 기준): 가르친 E4B 혼자 748 · 규칙 + ML 앞단 745 → 3 : 6, p=0.51 로 구분 안 됨.
- 보낼 곳 판정에 학습 없는 Winnow-E4B(Jev 계열)를 넣으면 697(사후 개선 판, 사전 등록 판 472). 가르친 모델과 학습 조건이 달라 공정한 비교 아님.
- 같은 방법으로 가르친 두 모델(E4B · Winnow-E4B)을 섞은 구조 747~752, 혼자와 구분 안 됨.

## 5. 섞은 흐름 2,735문제 (멀티 에이전트 보고서 4.5)
- 구성: 일정 질문 835 + 관광지 질문 600 + 일상 대화 1,000 + 구어체 300.
- 가르친 E4B 혼자: 정답 90.8%(2,424/2,669) · 일정과 무관한 말에 항목을 짚음 4.5%(80/1,786).
- 규칙 → ML → 가르친 E4B: 91.9%(2,453/2,669) · 3.2%(58/1,786) · 전문가 호출 2,735 → 2,117.
- 빈 답 85/2,735 = 3.1%(두 번 돌려도 같은 85건, 원인 미확인).

## 7. 규정 검색 — 실제 예 (독립 질문 B, 48문제)
「창덕궁 임시 휴관이면 일정 어쩌죠?」 → 정답 규정: 「관람 · 자연 갈래의 운영 중단과 통제」 문서의 「임시 휴관과 정기 휴관을 나눈다」 절.
색인 글 바꾸기: 규정을 찾을 때 쓰는 글을 「직원용 본문」에서 「문서 제목 + 절 제목 + 고객용 문장」으로 바꿈 → 정답을 보인 질문 21 → 31/48. 대가: 「일요일 08:44에 2명 예약해 주세요」 같은 규정이 아닌 여행 말에도 규정을 붙이는 비율 22.3% → 36.7%(라벨 없는 여행 대화 300건).

## 8. 남은 문제 — 한 줄 풀이
- 사람 평가 0건: 실제 사람이 답을 읽고 매긴 점수가 아직 없다(평가 시트 35행만 준비).
- 규정 검색 상위 3개 안 정답 30/48 = 62.5%(목표 90%).
- 빈 답 3.1%: 일정 항목 짚기 모델이 아무 답도 안 낸 경우.
- 엉뚱한 대상 1/172: 채팅 한 마디를 할 일로 바꿀 때 고치라는 것과 다른 일정 항목을 고른 경우 1건.
- 원 → 엔 1건: 알림을 일본어로 옮기며 「35,000원」을 「35,000円」으로 바꿨는데 숫자만 대조하는 보호 장치를 통과.
- 값 변조 12/350 = 3.4%: 계획을 읽을 때 원문에 없는 제목 · 예약번호를 지어 넣은 경우.
