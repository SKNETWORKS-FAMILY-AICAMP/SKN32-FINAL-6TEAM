# v12 — triPilot 멀티에이전트 플로우 (단계별 정의 → 적대 검토 → 그림)

v11 그림을 두고 「멀티에이전트 플로우로 안 보인다 · 흐름이 끊긴다」는 지적(외부 Claude 검토, 사용자 전달)을 받아
**처음부터 단계별로 다시 정의하고 코덱스와 적대 검토를 돌며** 만든 판이다. v10 · v11 은 건드리지 않았다.

## 다시 만들기

```
cd src
python build_v12.py
```

규칙 검사(겹침 · 교차 · 이름표 간격 · 글자 넘침 · 상자 수)가 하나라도 걸리면 내보내지 않는다. PNG 는 Playwright 로 그림만 2배로 찍는다.
덮어쓰기 전 판은 `_backup/`(그림 · 문서) · `src/_backup/`(스크립트)에 있다. ★`src/_backup/2026-10-03_0035_4차반영전_사본(…)` 은 4차 반영 전 사본이다 — 원래 3차 반영 전 **스크립트** 백업이 있던 폴더를 실수로 덮어써서 이름을 바꿨다(3차 반영 전 **그림 · 문서**는 `_backup/2026-10-03_3차반영전/` 에 남아 있다).
