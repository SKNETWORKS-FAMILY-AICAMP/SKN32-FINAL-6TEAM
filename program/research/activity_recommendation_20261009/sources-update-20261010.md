## 이번 시험에 반영한 원칙

한 곳 선택과 상위3 순위는 서로 다른 응답 계약으로 측정합니다. Choice 출력 분포는 선택 불확실성이고 후보별 만족 효용이 아닙니다. Score는 정의한 등급의 기대 위치이며, 단순 제공 여부와 산술이 명확하면 Noul로 제공 여부만 얻고 가중합은 코드가 할 수 있습니다.

같은 정보의 제시 순서가 바뀌었을 때의 일관성과 정답 적중을 별도로 봅니다. 같은 입력을 다시 호출한 결과도 있어야 생성 변동과 순서 변화가 섞였음을 파악할 수 있습니다. 이번 API 시험에는 순서 전용 인과 실험이나 InvariRank의 구조 변경을 적용하지 않았습니다.

서비스 선택은 품질·비용·지연·실패를 함께 봅니다. 모델을 두 번 부르는 방식은 첫 단계의 의미 판단 비용과 최고 후보 누락 위험을 추가합니다. 후보가 많을 때 이 비용을 입력 절감으로 상쇄하는지는16·64·256후보 문제를 나눠 관측하며, 큰 규모 문제는각1개이므로 일반 손익분기점으로 확정하지 않습니다.

실제 사람 선호·암묵적 요구·다양성과 일정 전체의 상호작용은 합성 산술 정답과 별도로 검수해야 합니다. 사람이 판정하지 않은 양식은 사람 검수 완료로 세지 않습니다.
