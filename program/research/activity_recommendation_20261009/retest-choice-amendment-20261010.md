# Choice 재시험 전 입력·검증 수정 기록

기록 시점: 본 평가 eval-v1 48/48 종료 후, 추가 Choice·ID Top3·Noul·반복 유료 호출 전.

1. 실제 확률은 소수 둘째 자리로 반올림된다. 합 0.99를 무조건 거부한 검증을 수정한다. 각 값의 ±0.005 반올림 구간에 합 1인 분포가 존재하고, 선택값이 최댓값과 반올림 오차 범위에서 일치하는지 검사한다. 반환값 자체는 바꾸지 않는다.
2. 공식 Jev 1.13 한도는 요청 합 64k, state+최장 질문 32k 토큰이다. 후보를 state와 criteria에 두 번 넣던 중복을 제거하고 한 묶음128개를64개로 줄인다. 후보 사실은 criteria에 모두 남는다. 기존 대규모 HTTP400의 원인이 문맥 한도였다는 것은 추정이며 오류 본문을 확보하지 못했다.
3. 전체48문제 Choice 재시험은 예상30호출(기존29에서1 증가), ID 전용 Top3 진단은20호출이다. 공유 추가비용 상한 $0.50, 600호출은 유지한다. 기존 실패·원자료·비용은 보존한다.
4. 이번 수정 후 결과는 같은 표본에 대한 탐색적 재시험이다. 이전 모델들과 동시·동일 시점 평가로 해석하지 않는다. 정답·고객 취향·가중치·모델 선택은 바꾸지 않는다.
