# ID 전용 선택 진단의 사전 기준 — 2026-10-10

원문 인용까지 생성하는 전체 경로와 후보 선택 자체를 구분하기 위해 새 진단을 실행합니다. 진행 중인 본 실험, 개발24개·평가48개 원본과 정답을 변경하지 않습니다. 이 문서는 진단 API 실행 전 고정하며, 본 실험의 개별 성능 결과를 읽어 프롬프트를 최적화하지 않습니다.

| 실제 사람 판정 | 미실시 | 0/48 = 0% |

## 대상과 출력

- Choice 단계: 동결 평가48개 전체에서 기존 `Providers.choice`로 Jev API(유료)의 1위 선택을 실행합니다. 상태가 준비되지 않았거나 후보가 하나면 코드로 반환하고 API를 부르지 않습니다. 실제 호출 예상은 계층 선택을 포함29회입니다. 확률은 효용이나 고객 만족 확률로 해석하지 않습니다. 루트가 본 평가 종료 후 응답 반올림 검증을 별도로 수정한 뒤 실행합니다. 진단 코드는 그 검증을 우회하거나 결과를 보정하지 않습니다.
- Rank 단계: 평가48개 중 코드 필수 조건을 통과한 후보가2개 이상인 ready 문제를 `case_id` 오름차순으로 정렬해 처음10개만 고릅니다. 모델 결과·정확도·비용을 선택 기준으로 사용하지 않습니다. nano/Luna 각각 reasoning=`none`, 최대 출력512토큰으로 한 번씩 호출하여 총20회입니다. 문제별 호출 순서는 nano→Luna, Luna→nano로 교대합니다.
- Rank 응답은 `{"ranking":["후보ID", ...]}`만 허용합니다. 두 모델에 동일한 스키마를 사용하며 엄격한 후보 ID enum·정확한 min(3,후보수) 개수·중복 금지·추가 필드 금지를 적용합니다. 중복 금지는 로컬 parser에서 검사합니다. 인용·이유·자유 사실 문장은 요청하지 않습니다. 기존 취향 등급, 동점, 유사도, 이동 점수와 최종 가중 합 규칙은 유지합니다.

새 독립 문제나 최종 미사용 평가셋이 아닙니다. 본 평가와 반복 변형의 표본 수에 진단10개를 더하지 않습니다. 인용을 포함한 본 Top3 결과는 전체 경로 결과이며, ID 전용10문제는 같은 선택 계약에 대한 제한된 진단입니다. 이 비교만으로 인용 실패가 어떤 의미 추론 오류에서 생겼는지 인과적으로 확정하지 않습니다.

## 지표와 실패 처리

기존 `root_metrics(case,result,choice=True/False)`를 재사용합니다. Choice는 top1·nDCG@1·동점 허용 recall@1, Rank는 top1·nDCG@3·동점 허용 recall@3를 구분합니다. 필수 조건·중복·미완성·개수·스키마 위반은 실패로 보존하고 품질0을 포함합니다. 정상 응답에 조건부인 결과는 별도로 표시할 수 있지만 실패를 분모에서 제외하지 않습니다. 코드 상태·단일 후보는 비자명한 품질·비용 비교에서 제외하고 전체 상태 판정 결과를 따로 보고합니다. 근거 회수와 사람 의미 검수는 수행하지 않습니다.

## 비용·원본 보존

기존 동일 `ledger.sqlite`의 Budget과 run_lock을 사용합니다. 이번 전체 재시험 공유 상한 US$0.50/600호출, 이전 실험 기준액 US$0.349834632를 그대로 적용합니다. 추가 예산은 만들지 않습니다. Choice29회+Rank20회 추가 시 전체 최대599회라는 예상이며 실제 예약 수와 비용 상한이 우선합니다. 금액 상한에 걸리면 중단하고 부분 결과를 보존합니다. 자동 재시도는0입니다.

출력은 자료 폴더의 새 `runs/id-choice-eval-v1` 및 `runs/id-rank-diag-v1`입니다. 기존 디렉터리가 있으면 실행을 거부합니다. 원시 응답, 모든 호출 ID, 원래 비용·지연, 사용량과 반환 모델명을 보존합니다. 계층 Choice는 마지막 응답 사용량만 전체 사용량처럼 해석하지 않고 모든 원시 응답 파일을 참조합니다. 실행 전 원본·설정·공유 소스·진단 소스·이 문서의 실제 바이트 해시를 저장하고 종료 때 변하지 않았는지 검사합니다.

실제 API와 환경 파일 접근은 CLI 유료 실행 경로에만 있습니다. 작성·단위시험과 `--plan-only`는 API를 부르거나 환경 파일을 읽지 않습니다. 실행기는 기존 동결 소스 영역 밖에 있으며 운영 앱·SDK 설치·기존 결과를 변경하지 않습니다.
