# Claude 의견 (1회차, Codex 호출 전에 적어 둠 — 나중에 고치지 않는다)

choice: C (혼합: 코드로 이어 붙인 대량판 + LLM 이 자연스럽게 섞어 쓴 소량판)

summary: 대량(약 2,000)은 「실제 잡담 문장 + 연결어 + 이미 라벨이 확실한 질문」을 코드로 이어 붙여 정답을 그대로 물려받게 하고, 자연스러움 점검용 소량(약 300)은 솔 6.1 이 쓰고 루나 6.0 이 따로 라벨해 합의한 것만 쓴다. 모든 섞인 문장에는 「질문만 있는 짝(대조)」을 붙여 섞임 때문에 생긴 손실만 짝지어 잰다.

reasons:
- 코드로 이어 붙이면 정답이 질문의 정답을 그대로 물려받아 라벨 오류가 0 이고, AI Hub · KoCulture 잡담을 외부 서비스로 보내지 않아도 된다(라이선스 걱정 없음).
- 이어 붙인 문장은 어색해 모델이 「앞에 잡담이 붙었다 = 없음」 같은 지름길을 배울 수 있다 → 자연스러움을 LLM 이 쓴 소량판으로 따로 확인한다.
- 짝지은 대조(같은 질문의 섞기 전 · 후)로 「섞임 효과」만 잴 수 있다 — McNemar 로 구분 가능.
- 잡담 문장의 출처를 섞는다(AI Hub · KoCulture · Claude 합성): 한 출처의 말투에만 강해지는지 본다.

risks:
- 코드 이어 붙이기는 문법이 어색해 현실 분포와 다르다.
- 솔 · 루나는 같은 Codex 계열이라 라벨이 같은 방향으로 틀릴 수 있다(사람 점검 없음).
- 「잡담 속 일정 낱말(요청 없음)」 유형은 사람도 의견이 갈린다 — 이견은 따로 두고 골든셋 후보로.
- 질문이 이미 어려운 문장이면 섞임 효과와 구분이 안 된다.

would_change_if:
- 이어 붙인 문장에서 모델 정답률이 짝(질문만)과 거의 같고 LLM 판에서만 떨어진다면 → 코드판은 쓸모없고 LLM 판을 키워야 한다.

confidence: medium
