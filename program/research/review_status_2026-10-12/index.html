DB 정리의 실제 확인 범위

로컬 개발 DB는 96→91표, x600 서버의 cs 프로젝트 DB는 92→87표입니다. 삭제 대상 5표는 양쪽에서 최종 0개입니다. 삭제 대상 밖의 표·열·제약·인덱스·트리거 구조는 전후 차이 0개이며 여행 핵심 6표의 내용 해시가 양쪽에서 유지됐습니다. 다른 이름의 같은 업무 자료·JSON 값 전체까지 모두 검사한 결과는 아닙니다.

관련 시험은 29/29 통과했습니다. 전체 시험 묶음이나 실제 고객 거래 시나리오를 실행했다는 뜻은 아닙니다. 로컬 실제 업무 DB의 추가 전체 SQL 재실행은 자동 승인 검토가 거절하여 실행하지 않았습니다. 복원한 격리 DB에서는 환경별 2회 재실행을 확인했습니다.

현재 DB 구조·이미지·검사 결과 · 환경별 실측 데이터

새 세션에서 시작한 추가 개선

SQL 실행 원자성·배포 안전장치 개선 — 실제 작업 시작을 확인했습니다. 결과는 새 세션에서 별도 보고합니다.

  1. SQL 실행 도중 실패했을 때 앞서 실행한 변경도 모두 취소되는지 검증하고 수정합니다.
  2. 다음 배포에서도 과거 표 재생성 방지 설정이 빠지지 않도록 검사·차단 장치를 보완합니다.
  3. 배포 전 사용할 이미지를 확인하고 시간 초과·부분 실패의 복구 절차를 보완합니다.

새 세션은 로컬 수정·격리 DB 시험·배포안 준비를 진행합니다. 현재 보고서 시점에는 추가 수정이나 배포가 완료된 상태가 아닙니다.

SQL 적용 계약과 알려진 한계

원본 검토 자료에는 이전 시점 설명이 함께 남아 있으므로 현재 DB 상태는 2026-10-12 실측 자료를 우선합니다. 새 파일로 저장하여 기존 검토 자료를 덮어쓰지 않았습니다.
