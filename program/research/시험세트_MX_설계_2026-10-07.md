# MX 시험 세트 — 잡담 속에 일정 질문 · 변경 요청이 섞인 입력 (설계 · 구성 · 위치, 2026-10-07)

사용자 요청: 「잡담에 우리가 답해야 하는 일정이나 변경이나 관련된 내용이 포함되는 경우 우리 모델들이 얼마나 잘 답하는지 알 수 있게 테스트셋을 만들어. 지금까지 모은 잡담 데이터셋에 DB 정보나 다른 정보를 섞어 놓고 보면 확실하게 알 수 있지 않을까? 자세한 방법은 코덱스랑 논의해서 완성하고 결과를 내놔」.

## 한눈에

- **MX = 잡담이 섞인 2,007문장(혼합) + 같은 요청만 있는 2,007문장(대조)** = 시험 입력 4,014개, 일정 59개. 모든 혼합 문장에 대조 짝이 있어 「잡담이 섞여서 생긴 손실」만 짝지어 잰다.
- 설계는 Claude 의견(먼저 적어 둠)과 Codex 솔 6.1 의견이 **1회차에 같은 선택(C: 코드로 이어 붙인 대량 + LLM 이 쓴 소량)** 으로 일치했다. 합의 방식: 1회차 일치. 기록 [program/research/_consensus/20261007_mixed_testset/](_consensus/20261007_mixed_testset/) (질문 `q.md` · Claude 의견 `claude_r1.md` · Codex 판정 `r1_main.json`).
- **파일 위치(저장소 루트, git 밖 — AI Hub · KoCulture 문장이 들어 있음)**: `datasets/core/pointing/legacy_runs/mx_testset/` — 아래 「파일」 절.
- 결과(가르친 E4B 시드 1·2·3 · oos1)는 서버 A 에서 재는 중이고, 끝나면 `program/scripts/plan_qa_bench/results/mx_report.md` 에 나온다.

## 설계 합의의 핵심(Codex 솔 6.1 제안 중 채택한 것 · 바꾼 것)

| 항목 | 내용 |
|---|---|
| 유형 · 규모 | Codex 제안 MX1 500 · MX2 450 · MX3 400 · MX4 500 · MX5 300 · MX6 150(약 2,300). 일정 수가 59개로 정해져 있어 생성량으로 맞췄고 실제 값은 위 표 |
| 라벨 규칙 | 정보 질문 · 변경 요청이 일정의 한 항목을 특정하면 그 번호, 일정 밖 장소 · 일반 규정 · 새 항목 추가 · 전체 변경이면 null. **같은 장소가 일정에 여러 번 나오면 날짜 · 순서 · 시각으로 방문을 특정하거나 쓰지 않게** 생성 지시(D 의 오답 86개 중 74개가 방문 모호였다는 사실 반영) |
| 대조 짝 | 같은 요청만 남긴 문장. 짝지은 McNemar · 일정 단위 군집 부트스트랩으로 구간 |
| 두 사람이 한 라벨 | 요청 문장은 솔 6.1 이 쓰고 루나 6.0 이 따로 라벨, 둘이 맞은 것만(이견 558개 제외). LLM 자연 혼합은 혼합 문장과 요청만 문장을 둘 다 루나가 라벨해 의도와 같을 때만 |
| 외부 전송 | AI Hub · KoCulture 문장은 Codex 에 보내지 않고 로컬 코드로만 이어 붙였다. 솔 · 루나에는 우리가 합성한 일정과 모델이 만든 문장, 말투 힌트는 Claude 가 쓴 합성 잡담(D3)만 보냄 |
| DB 정보 | 답변 지식을 시험하지 않고 **참조 대상을 통제**하는 데 쓴다 — 일정 안 장소와 일정 밖 비슷한 장소를 짝지어 같은 주차 · 영업시간 질문도 대상만 바꾸면 번호 ↔ null 이 바뀌게 한다(MX1 대 MX3). 이번 판은 일정의 항목 이름과 일정 밖 장소 질문을 솔이 쓰게 했고 `place_catalog` 행을 직접 쓰지는 않았다 `[이번 판에서 안 한 것]` |
| 성공 기준(시험 전에 고정, Codex 제안 채택) | 항목 선택률 ≥ 95% · 정답 없음 유형 오지목 ≤ 1%(MX3 · MX4 · MX5a 는 각각 ≤ 3%) · 섞임에 따른 선택률 손실 ≤ 2%p · 오지목 증가 ≤ 1%p. 달성 가능성이 입증된 기준이 아니다 |
| 오염 방지 | 일정 59개는 학습에 쓰지 않았고 H 시험이 쓴 30개도 뺐다. 요청 문장이 H 시험 · H 학습 문장과 3-gram 자카드 0.6 이상 겹치면 쌍을 격리(31쌍). 이 세트는 시험 전용이라 학습에 넣으면 회귀 시험으로 바뀐다 |
| 사람 점검 | 층화 표본 158개(유형 × 생성 방식, `mx_human_check_sample.csv`) + 이견 558개 + 도전 59개는 사람 판정 후보. **사람 점검은 아직 0건** |

## 한계

- 혼합 문장의 약 88%(1,768/2,007)는 **코드로 이어 붙인 것**이라 어색하고 연결어 · 위치가 지름길이 될 수 있다. LLM 이 자연스럽게 쓴 239쌍과 나눠 봐야 한다(`SRC=code` · `SRC=llm`).
- 혼합이 대조보다 약 2배 길어서 「잡담이 섞인 효과」와 「문장이 길어진 효과」가 섞인다. 일정 낱말 없는 잡담만 있는 대조는 이번 판에 없다 `[안 한 것]`.
- 솔 · 루나는 같은 Codex 계열이라 같은 방향으로 틀릴 수 있고 합의분만 남겨 어려운 사례(MX4)가 빠졌다.
- 일정 59개 · 모델당 1회. 일정 하나의 문장이 서로 닮아 독립 표본이 아니므로 구간은 일정 단위로 낸다.
