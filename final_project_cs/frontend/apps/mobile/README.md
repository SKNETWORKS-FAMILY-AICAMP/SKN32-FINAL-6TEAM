# 모바일 앱 — 3순위 보류

기존 Expo + React Native + TypeScript 앱 구상을 보존하는 예약 위치다. 현재는 폴더만 준비했으며 실행 가능한 앱은 아직 없다.

**2026-09-14 사용자 결정:** 웹 1순위 → Personal Agent / MCP 2순위 → 앱 3순위다. 앱은 배포 시 개발자 등록 문제로 이번 초기화·개발·스토어 배포 범위에서 제외한다. 프로젝트 종료까지 적용하지 않을 가능성이 높으며, 웹·agent 완료 후에도 자동으로 착수하지 않는다. 재개 여부·시점은 미정이다.

앱 전용 화면·자격증명 저장·푸시·딥링크·오프라인 조회는 보류한다. 재개할 경우 웹과 같은 계정·여행·채팅 API를 사용한다는 기존 구상을 기준으로 상세 범위를 다시 정한다. 모바일 브라우저 지원은 [사용자 웹](../web/README.md)의 반응형 화면에서 다룬다.
