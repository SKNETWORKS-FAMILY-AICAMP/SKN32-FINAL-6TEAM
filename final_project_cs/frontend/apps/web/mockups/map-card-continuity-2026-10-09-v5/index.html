지도 정보와 카드 도구, 아래로 이어지는 수정안

실제 프론트 화면을 새로 촬영했습니다. 이미지를 누르면 원본 크기로 볼 수 있습니다.

일정 응답은 mock 서버 시험 데이터, 지도 배경은 OpenStreetMap입니다. 공개 서비스 배포 전 화면입니다.

  • 장소·종류 → ! 개수 → 변경 아이콘·개수 → 전체 되돌리기 순서입니다.
  • 카드 제목 옆에는 자동 추천·수정·삭제 아이콘만 한 줄로 둡니다.
  • 거리 버튼에 포함된 일정의 일반 마커는 숨기고, 지도 안으로 돌아오면 복구합니다.
  • 하단 안내를 더 내리거나 누르면 저장 전 권장 수정안을 볼 수 있습니다.
