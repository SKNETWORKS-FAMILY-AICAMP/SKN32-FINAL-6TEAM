계획 확인 C안 — 고른 뒤 다시 확인하는 방식 (지금 목업 · 바꿀 모습)

작성 2026-10-20 · 검토용 비교 목업 · 전제: 「새 흐름(멈추고 고르기)」 + 「카드 안」 + 이동 확인은 C안(장소 카드에서 함께)(2026-10-20 확정) · 이동 줄은 한 번에 그림(확정) · 기준 SKN32 role-eval-ui 31bc404d · 실제 API 미연결 · 장소 · 시각 · 거리 · 후보는 예시 값

같은 일정을 두 화면에서 동시에 재생한다. 왼쪽은 지금 목업 방식 — 고르면 카드가 「확인하는 중」 모양으로 돌아가 「다시 확인하는 중…」 줄이 생기고 검사 줄을 처음부터 다시 켠다. 오른쪽은 바꿀 모습 — 고르면 선택 칸만 접히고, 카드는 색 · 테두리 · 위치를 그대로 둔 채 검사 줄 표시만 그 자리에서 다시 돌아 새 값으로 바뀐다. 「자동 진행」을 켜면 매번 첫 선택지를 골라 두 화면을 나란히 볼 수 있다.

광화문 근처 한식 카드에서 장소를 고르면 → 검사 줄이 다시 돌고 → 같은 카드에 「오는 길」 질문이 이어진다(C안). 차이는 그 「다시 도는」 순간에 보인다.

무엇이 다른가 — 고른 직후

지금 목업바꿀 모습
선택 칸바로 사라짐(카드 아래가 통째로 다시 그려짐)접히며 사라짐(0.26초) — 무엇을 골랐는지 알림으로
카드 색 · 테두리「확인하는 중」 모양(회색 테두리 · 흰 바탕)으로 돌아감 — 카드가 처음 나온 것처럼 보인다그대로(확인 필요 테두리 · 바탕) — 다 통과하면 그때 초록으로 바뀐다
「다시 확인하는 중…」 줄카드 안 맨 위에 한 줄 생김없음 — 줄마다의 돌기 표시가 같은 뜻을 한다(아래 고정 칸 · 위 띠에 「다시 확인하는 중이에요 · 잠시만요」)
검사 줄모두 「확인하는 중…」으로 지워졌다가 처음부터 하나씩 다시 켜짐 — 앞 값이 사라져 무엇이 바뀌는지 안 보인다표시(✓ · ! · ✕)만 도는 표시로 바뀌고 앞 문장은 흐리게 남은 채, 위에서부터 하나씩 새 값으로 바뀜 — 바뀐 줄이 보인다
카드 제목 · 원문둘 다 고른 순간 바뀐다(「광화문미진 본점」 + 원문 「광화문 근처 한식」, 「바뀜 · 이전 …」은 접힌 뒤)
다른 카드흐림이 풀렸다가 다음 질문에서 다시 흐려짐통과할 때까지 흐린 채 — 이 카드에 머문다는 것이 이어진다
같은 카드의 다음 질문(C안)둘 다 다시 확인 뒤 오는 길이 늦으면 같은 카드에 「오는 길」 질문이 이어진다 — 바꿀 모습은 카드가 그대로라 「같은 카드의 다음 질문」으로 읽힌다

화면 · 서버

  • 화면만서버 요청 · 응답은 같다 — 고르면 POST …/edits(또는 수단 바꾸기) → 새 판의 전체 검사. 다른 것은 화면이 그 카드의 새 검사 줄을 어떻게 다시 보여 주나뿐이다.
  • 화면만구현 메모: 멈춘 카드는 판정(verdict)을 「확인 필요」로 둔 채 검사 줄만 한 줄씩 새 값으로 바꾸고(지금 재생의 줄 단위 advance(…, "rows")를 그 카드에만), 마지막 줄 뒤에 판정을 바꾼다. 줄 수가 바뀌면(운영시간 · 휴무 줄이 생기거나 없어짐) 새 줄은 도는 표시로 들어와 같은 순서로 바뀐다.
  • 지금 계약서버가 검사하는 동안(status: reading) 고치기는 409 — 멈추고 고르기의 「서버 확인이 늦을 때」(고른 값을 들고 기다렸다 보냄)와 같이 쓴다. 기다리는 동안도 선택 칸만 접힌 채 줄 표시가 돈다.

결정할 것

  1. 다시 도는 줄 — 그 카드의 검사 줄 전부(목업) / 값이 바뀐 줄만(안 바뀐 줄은 그대로).
  2. 다시 확인하는 동안 알림 — 위 띠 · 아래 고정 칸의 「다시 확인하는 중이에요 · 잠시만요」(목업) / 줄 표시만.
  3. 다 통과한 뒤 — 초록으로 바뀌고 잠깐 뒤 접힘(목업) / 바로 접힘.
  4. 다시 확인해도 문제가 남을 때 — 같은 카드에 질문이 다시 나오고 위에 「고른 뒤에도 확인이 필요해요 · 다시 골라 주세요」(목업).

문구

앱 문구 그대로 — 「다시 확인하는 중이에요 · 잠시만요」 · 「다시 확인하는 중…」(지금 목업 쪽) · 「확인하는 중…」 · 「고친 내용을 다시 확인했어요」 · 「바뀐 장소와 앞뒤 이동을 다시 확인해요」 · 「택시로 바꿨어요」 · 「이 구간만 다시 계산했어요」 · 「바뀜 · 이전 ○○」 · 「확인 필요」 · 「모두 확인했어요」 · 「여행 등록」 · 서버 검사 줄 문장 틀.

새로 지은 문구새 문구 — 바꿀 모습에 새 문구는 없다. 질문 · 선택지 · 멈춤 띠는 이동 확인 순서 비교 목업(C안)과 같다.
