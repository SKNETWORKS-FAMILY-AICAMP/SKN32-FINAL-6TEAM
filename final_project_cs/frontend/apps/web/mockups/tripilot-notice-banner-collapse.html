2026-10-17 사용자 결정: 넣지 않음(검토 후 보류 — 기록). 공지를 다시 찾을 길이 이미 있고 화면마다 예외 규칙이 일곱 가지 필요해서다. 대신 지금 배너의 「공지 닫기」를 새 공지가 올 때까지 기억하게 고친다. ST4F-607 · 사용자 안: 새 공지는 맨 위에 카드로 뜨고, 시간이 지나면 작게 줄어 공지가 있다는 것만 보인다. 줄어든 것을 누르면 다시 카드가 되고, 카드에는 「접기」(작은 모양으로 돌아가 그대로 유지)와 「끄기」(새 공지가 올 때까지 그 공지는 안 보임)가 있다. 휴대폰 아래 단추로 「처음부터」 · 「새 공지 오기」를 눌러 볼 수 있다. 공지는 예시다.

다른 화면에 적용 — 실제 화면 위에 (2026-10-17 시험용 가짜 서버로 찍은 화면 · 예시 자료)

배너는 앱 전체 틀(`layout.tsx`)에 있어 모든 화면에 뜬다. 머리 구성 · 지도 · 입력칸 · 덮는 창이 서로 다른 화면 여덟 곳을 골라 같은 안을 얹었다. 아래에서 안(A~E)을 고르면 여덟 화면이 함께 바뀐다. 지도 자리의 분홍색은 시험용 지도 타일이다(실제 지도 아님).

정할 것 · 작성자 제안

  • 줄어든 모양: A~E 중 하나. 작성자 제안은 E(장애는 내용이 보이는 한 줄 띠 · 끄기 막음, 나머지는 칩) — 장애는 놓치면 곤란하고, 안내 · 점검 예고는 자리를 덜 차지하는 게 낫다. 단순하게 가려면 A.
  • 줄어드는 시간: 8초(제안) 또는 10초. 카드에 손을 대거나 초점이 있는 동안은 멈춘다.
  • 「끄기」 기억: 이 브라우저에 공지 id 로 기억하고, 새 id 가 오면 카드부터 다시 띄운다(운영 앱이 같은 공지를 고쳐도 id 가 같으면 다시 안 뜬다 — 다시 띄우려면 새로 올려야 함). 「접기」도 같은 기억 — 새로고침해도 작은 모양 그대로.
  • 알림 센터 「공지」 탭 · 공지사항 게시판은 지금처럼 그대로 — 끈 공지도 거기서는 보인다.
  • 화면별 규칙(아래 「다른 화면에 적용」): 입력 중(계획 담기 · 채팅)에는 카드 대신 바로 작은 모양, 지도 화면은 한 줄 띠를 지도 위에 얹고(밀지 않음) 계획 확인 안내 아래로, 알림 센터가 열린 동안은 작은 모양을 숨기고, 공지사항 화면은 카드 없이 작은 모양만(제안).
  • 새로 지은 문구: 「접기」 · 「끄기」(사용자 지시), 「외 n」, 「장애가 풀리면 저절로 사라져요」, 끈 뒤 안내 문장. 「문의하기」는 지금 배너 문구 그대로.
