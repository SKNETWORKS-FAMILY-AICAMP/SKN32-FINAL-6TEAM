되돌리기는 이 흐름에 넣지 않아요 2026-10-20 결정

C안 카드 안의 선택 · 다시 확인 뒤에 「되돌리기」를 붙이지 않았습니다. 지금 앱에는 되돌리기가 네 곳에 있습니다. 적용할 때 이 네 곳을 없앨지, 결과 화면에만 남길지는 아직 정하지 않았습니다. 실수로 지우지 않도록 목록만 둡니다.

  1. 바꾼 뒤 알림의 「되돌리기」 — 방금 바꾼 것 되돌리기(POST …/edits로 반대 변경)
  2. 카드 아래 「바뀜 · 이전 …」 옆 「되돌리기」 — 이 일정만 되돌리기(POST …/restore + item)
  3. 머리의 「전체 되돌리기」 아이콘 — 처음 판으로(POST …/restore)
  4. 바꾼 시간의 「되돌리기」 · 「바꾼 시간 모두 되돌리기」

정할 것

  • 재생 방식 바꾸기의 범위 — 이 목업의 재생(첫 판 속도 · 위로 고정)은 지금 앱의 재생 규칙을 바꿉니다. 문제가 없는 계획의 재생과 「애니메이션 건너뛰기」 설정에도 같이 적용할지 정해야 합니다.
  • 자동 등록 시간 — 지금 목업은 읽는 중 화면과 같은 5초. 등록은 되돌리기 어렵습니다(등록 뒤에는 「일정 수정」 모드로 고침).
  • 결과 화면에 처음 뜨던 알림 「계획 확인 화면이에요 · 일정을 수정하거나 권장 수정안을 확인해 주세요」 — 자동 등록 막대와 겹쳐 이 목업에서는 띄우지 않았습니다. 없앨지, 막대를 닫았을 때만 띄울지 정해야 합니다.
  • 자동 등록 막대의 첫 줄 — 앱에 이미 있는 「모두 확인했어요」(지금은 화면 읽기 프로그램에만 읽히는 문장)를 썼습니다.
  • 알림(토스트) 원칙(2026-10-20 결정) — ① C안 카드 안에서 고른 뒤의 성공 알림은 띄우지 않는다. ② 저장 실패 알림은 남긴다: 고른 것이 저장되지 않았다는 것은 꼭 보여야 하므로 지금 앱처럼 닫을 때까지 남는 경고(stay · role=alert)로. ③ 화면 읽기용 안내는 남긴다: 같은 문장(「○○을 △△로 바꿨어요 · 바뀐 장소와 앞뒤 이동을 다시 확인해요」 등)을 화면에 보이지 않는 상태 문장(sr-only · role=status)으로 읽어 준다 — 목업도 그렇게 바꿨다. ④ C안 밖의 변경(결과 화면의 고치기 · 삭제 · 이름 바꾸기 · 시간 · 이동 수단 등 「되돌리기」가 붙는 알림)은 지금 앱 그대로 — 바꿀지는 따로 정한다.

C안 목업(c-recheck)에서 바로잡은 것

실제 화면 · 코드와 대조해 앞 목업의 글과 모양을 앱 · 서버 기준으로 고쳤습니다. 앞 목업 파일은 그대로 두었습니다.

  • 「그대로」로 정한 뒤 장소 줄: 「확인한 곳이에요」(코드에 없음) → 서버 문장 「직접 고른 곳이에요 · 카카오 지도에서 찾았어요」
  • 광장시장 운영시간 줄: 「시장 안 점포마다 …」(코드에 없음) → 서버 문장 「운영시간 정보를 아직 못 찾았어요」 · 「휴무 정보가 없어요」
  • 바꾼 뒤 안내 문장: 「확인했어요」 · 「고친 내용을 다시 확인했어요」 → 앱 문장 「○○을 △△로 바꿨어요」 · 「바뀐 장소와 앞뒤 이동을 다시 확인해요」. 지금은 알림으로 띄우지 않고 화면 읽기용 안내로만 씁니다(위 「정할 것」의 알림 원칙).
  • 검사 줄마다 앱에 있는 「날씨·도로」 줄을 넣었습니다(앞 목업에는 없었음).
  • 거리: 「1.0km」 → 앱처럼 「1km」
  • 멈춤 표시: 머리 진행 막대에 「멈춤 · …」을 넣던 것을 빼고 앱 그대로(「정리 완료 100%」) 둔 뒤, 목록 위 안내로만 알립니다.
  • 앱 · 서버에 같은 틀이 있음을 확인한 글: 「○○에서 오는 길 · 도보 n분」 · 「○○까지 가는 길 · … · n분 여유」(place-change.tsx), 「창덕궁과 같은 중분류(관광공사 분류)의 곳이에요」(candidates.py), 「후원은 따로 예약해야 들어갈 수 있어요」(대표 장소 표의 방문 안내 값), 「다시 확인하는 중이에요 · 잠시만요」(plan-check.tsx)

목업의 한계

  • 지도 바탕(타일)은 뺐습니다. 핀 · 칩 · 경로선은 실제 앱이 그린 위치 그대로입니다. 계획 확인 중 지도는 장소마다 앱이 그린 모습으로 바꿔 끼웠고, 고른 장소로 핀을 옮기지는 않습니다.
  • 결과 화면은 고친 계획을 새로 불러온 화면을 떴습니다. 그래서 바꾼 카드의 「✓ · 바뀜 · 이전 …」 표시가 없습니다(실제로는 같은 화면에서 이어지면 붙을 수 있음).
  • 설문 답 고르기 · 메뉴 · 지도 단추 · 카드 펼치기 등은 눌러도 동작하지 않습니다. C안 질문은 첫 번째 선택지로만 이어집니다(둘째 선택지 · 직접 수정은 C안 목업 tripilot-plan-check-c-recheck.html에서 봅니다).
  • 모방 서버의 알림 기록(「오늘 첫 일정은 08:00 아침 식당이에요」 등)은 여행 화면 채팅 칸 안에 남아 있습니다 — 시험용 자료입니다.
