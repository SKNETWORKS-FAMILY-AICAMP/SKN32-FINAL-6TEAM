  2. 「끝났어요」를 누르면 카드 안에 「다음 일정을 바로 진행할까요?」. 앞당긴 시각은 서버가 이동 시간을 계산해야 나오므로 미리 적지 않는다(「인사동 원래 12:00 · 지금 출발로 이동 시간을 서버가 다시 계산해 앞당겨요」 / 「인사동 12:00 시작 그대로 · 끝난 시각만 기록」). 「아직 진행 중」을 다시 누르면 접힌다(서버에 아무것도 안 보냄).
  3. 「바로 진행」 → 서버가 지금 출발 기준으로 이동 시간을 다시 계산하고, 바뀐 일정을 검사한 뒤 저장한다(막 「서버로 전송중입니다.」 — 보통 1초 안팎, 지하철 깊은 탐색이면 7~8초). 통과하면 북촌한옥마을은 ~10:50 지난 줄, 이동 줄은 10:50 출발, 인사동은 도착 뒤로 앞당겨진다(머무는 시간 그대로, 그 뒤 일정은 원래 시각). 검사에 걸리거나 계산을 못 하면 끝난 시각만 기록하고 시각은 그대로 — 위 「서버 답(흉내)」로 바꿔 본다.
  4. 「그대로 유지」 → 서버가 끝난 시각(10:50)만 기록하고 나머지 시각은 그대로.
  5. 시각을 11:20 으로 옮기면 앞당긴 인사동이 녹색이 된다. 14:30 은 그날 마지막 일정 — 「끝났어요」는 묻지 않고 끝난 시각만 보낸다. 토스트는 모두 서버가 돌려주는 문장 그대로다.
