# triPilot 운영자 웹앱

기본 모드는 실제 운영 연결입니다. 고객 웹앱과 다른 프로세스·포트로 실행하며 운영자 계정만 접근합니다.
`NEXT_PUBLIC_ADMIN_DATA_MODE=demo`를 명시한 경우에만 시연 자료를 사용합니다. 연결 실패가 데모로 바뀌지는 않습니다.

## 실행

- 운영 앱: 프로젝트 루트에서 `python -m app.ops_entrypoint`. 루프백 전용입니다.
- 운영자 웹앱: 이 폴더에서 `npm run build`, `npm run start`. 기본 포트 3300, 루프백 전용입니다.
- 운영용 API 주소 설정: `ADMIN_OPS_API_URL`(비공개 환경 변수). 브라우저에 노출하지 않으며 루프백 주소만 허용합니다.
- 운영자 계정·권한은 기존 운영 앱의 `ACOP_UI_OPERATORS`에 등록합니다. 설정이 비어 있으면 로그인하지 못합니다.
- 승인·위임·발송 해소·기존 서비스 설정은 `ACOP_OPS_API_KEYS`의 해당 권한 키를 재사용합니다. 스스로 키를 만들지 않습니다.
- 고객 데이터베이스에 마이그레이션 226이 필요합니다. 고객 자료는 실제 삭제하지 않고 기존 보관 정리 경로에 종속시킵니다.

로그인은 PBKDF2 비밀번호 확인과 서명된 HttpOnly 쿠키, 로그인·쓰기 CSRF 검사를 사용합니다.
고객 로그인 쿠키와 고객 키는 운영자 인증에 사용하지 않습니다. 운영자 권한을 거두면 다음 요청부터 적용됩니다.

## 실제 연결

사용자 차단·일일 채팅 한도·예외 한도·문의 답변·템플릿·공지·점검 모드는 DB에 저장하고 변경 이력을 남깁니다.
승인·위임·발송 확인은 기존 서비스 경로를 통과합니다. 관리자 화면이 접수 상태를 직접 수정하지 않습니다.
운영 설정·보관 기간 탭은 기존 설정 API를, 접수·처리 근거 탭은 기존 접수 조회를 재사용합니다.
안전 감시 주기는 예산이나 기계 자원 여유로 바꾸지 않습니다. 자동 유료 영업 조회 주기는 이 화면에서 켜지 않습니다.

CPU·메모리·HTTP 응답 지연처럼 아직 계측하지 않은 값은 미계측입니다.
LLM 수치는 현재 테넌트의 접수와 연결된 호출만 집계하며 귀속되지 않은 호출을 0건처럼 포함하지 않습니다.
외부 API 예산은 제공처의 UTC/한국 시각 기준으로 나눠 읽습니다. API 상한 변경은 원래 보호 상한을 높이지 못합니다.

## 검증

`npm run typecheck`, `npm run lint`, `npm test`, `npm run build`.
실제 연결 화면의 mock 서버 시험: `npx playwright test --config playwright.live.config.ts`.
mock 서버 시험은 실제 고객 데이터베이스·외부 제공처 확인과 구분합니다.
