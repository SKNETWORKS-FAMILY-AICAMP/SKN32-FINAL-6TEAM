# 서비스 관리자 웹

Next.js + React + TypeScript로 개발할 서비스 운영자 웹의 위치다. 현재는 폴더만 준비했으며 실행 가능한 앱은 아직 없다.

여행·Case 조회, 승인, 사용자 관리, Trace·Evidence·감사 기록 등 운영 업무를 다룬다. API는 백엔드에서 운영 권한을 확인한다.

기존 개발자 콘솔은 저장소 루트의 `final_project_ui`에 유지한다. Composer와 개발·평가 도구를 이 앱에 자동으로 복제하지 않는다. HTML-in-Canvas를 실험할 경우 이 앱의 `/labs`에서 별도로 구현한다.
