## 쓰는 법과 한계

- 법령 · 고시 원문을 통째로 옮기지 않고 **판단 단위(절)** 로 풀어 썼다. 절마다 근거 조항 · 별표 위치를 본문에 달았다.
- **표준약관은 여행사와 여행자의 패키지 여행 계약**이다. 개별 활동 예약에는 **참고 기준**이며 업체 약관이 확인되면 그쪽이 우선한다 — `t_ext_01` 첫 절에 명시했다.
- 소비자분쟁해결기준은 **합의 · 권고의 기준**이다(계약에 별도 약정이 있으면 약정 우선). 장소별 · 업체별 약관은 담지 않았다(추후 확장).
- 활동 에이전트 검색 범위: `travel_cancellation`(공유) · `travel_activity`. 식당 · 이동 · 예약 인계 팀도 `travel_cancellation` 을 같이 검색한다.
