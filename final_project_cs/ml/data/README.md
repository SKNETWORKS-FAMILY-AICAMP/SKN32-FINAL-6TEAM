# 여행 도메인 감정 평가셋 — `travel_sentiment_eval.jsonl`

★**무엇인가.** 감정 모델은 **쇼핑 리뷰**(네이버쇼핑 20만 건)로 학습한다. 제품이
실제로 받는 글은 **여행 CS 메시지**다. 둘이 얼마나 다른지를 재려고 만든 작은 조각이다.

| | |
|---|---|
| 건수 | 41 (중립 15 · 긍정 12 · 부정 14) |
| 라벨을 붙인 사람 | **Claude(이 저장소 작업 세션)** — 사람 검수 안 받았다 |
| `source: scenario` | 팀 확정 시나리오·시험 코드에 실제로 들어 있는 문장 6건 |
| `source: author` | 같은 성격으로 지어 쓴 문장 35건 |

★**이 조각으로 「성능」을 말하지 않는다.** 41건은 **방향**만 본다 — 신뢰구간이
넓고, 라벨이 한 사람 판단이라 사람 간 일치도를 모른다. 모집단을 대표하지 않는다.

★**학습에 쓰지 않는다.** 시험 전용이다. 여기에 맞춰 모델을 고치면 시험이 아니게 된다.

★**중립이 절반 가까이다.** 학습 데이터(리뷰)에는 중립이 아예 없다 — 별점 3점이
원 말뭉치에 없다. 그래서 중립은 **모델이 물러서는 것**(확신이 낮으면 중립)으로만
낼 수 있고, 그 임계값이 맞는지를 이 조각으로 본다.
