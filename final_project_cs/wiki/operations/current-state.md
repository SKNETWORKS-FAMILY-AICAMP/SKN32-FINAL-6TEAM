[실측 2026-10-12 00:58~01:09 KST] Oracle ARM의 구성과 실제 기능을 새로 점검했습니다. 핵심 구성은 가동하지만 장소 오연결·일부 자료 미구축·외부 연결 누락·채팅 지연이 남아 있습니다. 세부 수치와 확인 범위는 [기능 점검 보고서](../records/reports/2026-10-12_0110_arm-stack-functional-audit.md)를 따릅니다. 다른 환경의 과거 행은 이번 원격 확인으로 갱신하지 않습니다.

**2026-10-11 문서 정리에서는 원격 프로세스·배포·실서비스를 새로 점검하지 않았습니다.** 아래는 로컬 코드와 날짜가 있는 실행 기록을 대조한 결과입니다. 과거 관측은 현재 정상 가동 보장이 아닙니다. 새 직접 관측을 하지 않은 행은 과거 관측으로 취급하고 현재 정상 상태로 표시하지 않습니다. 실제 점검 주기·자료 나이 상한은 서비스 위험과 측정으로 따로 정하며 임의의 공식 권장 시간으로 꾸미지 않습니다. 새 관측을 할 때 환경·KST 시각·코드 SHA/이미지·검사 범위·성공/실패·원본 기록을 함께 갱신합니다.

## 상태를 갱신할 때

각 환경에서 API·웹·DB·자동 감시·알림 배달·모델 연결을 별도 행으로 기록합니다. 미배치·기동 실패·준비 실패·기능 실패·관측하지 않음을 구분합니다. 설정 파일의 restart·healthcheck·타이머 존재를 실제 적용 증거로 쓰지 않습니다. 코드 SHA·이미지 ID가 기록돼 있지 않으면 값을 지어내지 않고 미확보라고 씁니다.

공개 배포 worker는 현재 heartbeat 경로가 로컬 스케줄러와 다릅니다. 계측·준비 검사 개선은 [상시 운영 절차](always-on.md)의 남은 구현 항목을 따릅니다. 문서 수정 완료와 운영 개선 완료를 구분합니다.
