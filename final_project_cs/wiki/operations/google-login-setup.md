# 구글 로그인 켜기

서버 코드는 있다([REST 명세 「소셜 로그인」](../external/rest-endpoints.md)). **구글 콘솔에서 앱을 만들고 그 값을 서버 환경 파일에 넣는 일은 사람이 해야 한다** — 값이 없으면 `GET /v1/web/auth/providers` 가
빈 목록이고 웹은 「설정된 로그인 방법이 없어요」라고 말한다(가짜 단추를 두지 않는다).

## 1. 구글 콘솔에서 (사람)

1. Google Cloud 콘솔에서 프로젝트를 고르거나 만든다 → **OAuth 동의 화면**을 설정한다(앱 이름 · 지원 이메일. 우리는 `openid` 범위만 쓰므로 민감한 범위가 없다).
2. **사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 애플리케이션 유형 「웹 애플리케이션」.**
3. **승인된 리디렉션 URI** 에 서버의 콜백 주소를 **정확히** 넣는다: `<서버 공개 주소>/v1/web/auth/google/callback`.
   - `<서버 공개 주소>` 는 서버 설정 `ACOP_PUBLIC_BASE_URL` 과 같아야 한다(서버가 이 값으로 콜백 주소를 만들어 구글에 보낸다 — 한 글자라도 다르면 구글이 거절한다).
   - 구글은 리디렉션 주소를 HTTPS 로 받는다. 로컬(`127.0.0.1` · `localhost`)은 예외라 개발 PC 에서는 로컬 주소 그대로 등록할 수 있다.
   - **개발용(로컬)과 운영용은 클라이언트를 따로** 만든다.
4. 만들어진 **클라이언트 ID 와 클라이언트 보안 비밀**을 받아 둔다.

## 2. 서버 환경 파일에 (git 밖)

서버가 읽는 환경 파일(`.env` — 저장소에 올리지 않는 파일)에 넣는다. 템플릿은 [`.env.example`](../../.env.example) 의 「소셜 로그인」 절.

| 이름 | 값 |
|---|---|
| `ACOP_GOOGLE_CLIENT_ID` | 위에서 받은 클라이언트 ID |
| `ACOP_GOOGLE_CLIENT_SECRET` | 위에서 받은 클라이언트 보안 비밀 |
| `ACOP_PUBLIC_BASE_URL` | 서버의 공개 주소(콜백 주소의 앞부분 — 1-3 과 같아야 한다) |
| `ACOP_WEB_ORIGIN` | 로그인이 끝나면 브라우저를 돌려보낼 **웹 화면의 출처** (비우면 `ACOP_WEB_ALLOWED_ORIGINS` 의 첫 값) |

★**둘 다 있어야 켜진다**(ID 만 · 비밀값만 있으면 목록에서 빠진다). 공개 서버(`deploy/`)의 환경 파일 생성기는 이 PC 의 개발용 값을 서버로 **옮기지 않는다** — 운영용 클라이언트 값은 서버의 환경 파일에 직접 넣는다(`ACOP_PUBLIC_BASE_URL` 과 `ACOP_WEB_ALLOWED_ORIGINS` 는 생성기가 이미 서버 공개 주소로 채운다). ★비밀값은 저장소 · 문서 · 커밋 메시지 · 채팅에 적지 않는다.
서버를 다시 시작하면 반영된다(설정은 기동 때 읽는다).

## 3. 확인

1. `GET /v1/web/auth/providers` → `{"providers": [{"id": "google"}]}` 이면 켜진 것이다.
2. 웹 마이페이지 → 「소셜 계정」 → Google 연결 → 구글 화면에서 계정을 고르면 웹의 마무리 화면으로 돌아와 「연결됐어요」가 보여야 한다.
3. 다른 브라우저(키 없음)에서 「Google로 로그인」 → 같은 계정이 붙은 사용자의 여행이 열려야 한다(이 브라우저용 새 키가 발급된다 — 다른 기기의 키는 그대로).

## 되돌리기

환경 파일에서 두 값 중 하나를 비우고 서버를 다시 시작하면 구글이 목록에서 빠진다(이미 붙은 계정 연결은 DB 에 남는다 — 지우려면 사용자가 마이페이지에서 해제한다).

## 지금 확인하지 못한 것

- 실제 구글과 이어 본 기록 — 시험은 가짜 업체로 한 바퀴를 돌리고, ID 토큰 확인(서명 · 발급자 · 대상 · 만료 · nonce)은 생성한 키로 따로 시험한다. 첫 실제 로그인은 위 3 으로 확인한다.
- 운영 서버의 공개 주소가 정해지면 위 1-3 의 운영용 클라이언트에 그 주소의 콜백을 등록해야 한다.
