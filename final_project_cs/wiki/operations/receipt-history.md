# 재난 수신·API 점검 기록 조회

2026-10-17 사용자 지시: 모의 입력 화면과 수신 기록 화면을 분리한다. 기록 화면은 모의/실제/둘 다, 달력 시작일·종료일, 50건 페이지 번호로 조회한다. 기본 기간은 한국 시각 오늘을 포함한 최근 7일이다.

변경 담당: 현재 UI·API 작업 세션. 매니저 검토·통합: `git commit push` 세션에 인계 예정이며 아직 검토 완료로 표시하지 않는다.

## 내부 운영 API 확장

`GET /admin/api/simulations/receipts`는 기존 운영자 인증과 `ops:introspect` 권한·테넌트 격리를 유지한다. 외부 공공 API를 다시 호출하거나 고객 일정·알림을 변경하지 않는다.

- `mode`: `actual`(기본), `simulation`, `all`.
- `date_from`, `date_to`: 한국 시각 달력 날짜, 양 끝 날짜 포함. 생략하면 최근 7일.
- `page`: 1 이상. 한 페이지는 50건으로 고정한다.
- `as_of`: 첫 페이지가 반환한 시간대 포함 시각. 다음 페이지에서 같은 값을 보내 새 기록으로 페이지가 밀리지 않게 한다.
- 기존 문자·수신 상태·최근 회차 필드는 유지하고, `history`에 필터·전체 수·페이지·기록을 추가한다.

## 일정 영향 표시·필터 — 2026-10-17 추가 요청

변경 담당은 현재 UI·API 작업 세션이며 매니저 통합 검토는 기존 커밋·푸시 세션이 맡는다. 기존 고객 판정·정지·알림 정책은 바꾸지 않는 운영자 조회 기능이다.

입력 구분 아래에 `전체일정정지`·`일일일정정지`·`해당일정정지`·`영향없음` 체크박스를 둔다. 여러 선택은 OR이며 입력 구분·한국 시각 기간과는 AND로 결합한다. 아무것도 선택하지 않으면 미판정까지 전체 기록을 표시한다. 선택을 바꾸면 첫 페이지로 돌아가고 조회 기준 시각을 새로 잡는다. 필터는 전체 기록에 먼저 적용한 뒤 전체 수와 50건 페이지를 계산한다.

`impact` 쿼리를 반복해서 보낸다(`trip`, `day`, `item`, `none`; 최대 4개). 응답 `history.impacts`에는 선택값, 각 기록 `impact`에는 `scope`, `label`, `summary`, `affects_itinerary`, `target_mode`를 추가한다. `scope=unassessed`는 수신만 했거나 조회 실패·일부 응답으로 판정하지 못한 기록이며 `none`에 포함하지 않는다. 기존 요청은 영향 조건 없이 동작한다.

범위는 기록에 보관된 해당 소스의 disruptions·advisories만 사용한다. 전체·일일 정지는 기존 순수 안전 판정기와 현재 공통 설정을 재사용하고, 그 외 중단·변경 사유와 예보 주의는 해당 일정 범위로 표시한다. 다른 소스의 사건을 이 기록의 영향으로 붙이지 않는다. 원문 문자 수신만으로 여행 영향이나 실제 정지 완료를 추정하지 않는다. 과거 정책 버전을 보관하지 않은 기록은 현재 기준 재분류임을 화면에 명시한다.

이 범위는 정지·변경 검토 기준이며 실제 적용 완료를 뜻하지 않는다. 실제 소스이며 여행에 연결된 영향 기록은 색과 `실제 일정 영향 가능` 문구로 강조한다. 모의 입력·모의 시험 대상은 별도 문구로 구별한다. 소스 명칭과 영향 설명은 펼치지 않아도 읽을 수 있게 한다. 고객 앱 응답·알림·디스코드에는 이 운영자 표시나 후보 탈락 사유를 추가하지 않는다.

이번 변경의 로컬 시험·실서버 확인·배포 여부는 [작업 기록](../records/reports/2026-10-17_receipt-impact.md)에서 구분한다.

기록은 실제 수신 문자, 실제 재난문자 API 수신 상태 이력, 감시 회차의 6종 API 점검, 감사 이력에 남은 모의 입력이다. 모의/실제는 각 입력 소스의 표시로 가른다. 모의 여행 점검에서 선택하지 않은 실제 소스 응답은 실제 API 점검으로 표시한다. 호출 횟수와 점검 기록 수는 같다고 주장하지 않는다.

API 값은 기존 점검 결과의 허용 필드와 주소·비밀값 가림을 거쳐 표시한다. 과거에 보관하지 않은 응답값은 재구성하지 않는다. 현재 수신 상태와 현재 검사 대상은 기간별 기록과 구별해 표시한다.

## 검사 대상 표시

현재 진행 중인 방문 또는 90분 안에 시작하는 방문만 실제 검사 대상으로 표시한다. 유효한 관리자 시험으로 시간 범위를 벗어나 포함된 방문은 모의 시험 대상에 따로 표시한다. 감시 일꾼의 시험 실행·안전정지·고객 승인 규칙은 바꾸지 않는다.
