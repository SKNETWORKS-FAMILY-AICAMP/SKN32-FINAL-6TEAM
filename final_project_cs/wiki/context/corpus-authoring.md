# 여행 코퍼스 작성 규칙

현재 사용하는 지식의 범위·출처는 [여행 코퍼스](travel-corpus.md)가 소유합니다. 여행 자료를 신규 작성하며 과거 상품 주문·배송·반품 문서를 이름만 바꿔 재사용하지 않습니다.

## 작성·검사 순서

1. 해당 여행 업무의 질문·적용 범위·정책 출처를 정합니다. 정책 설명과 장소·시각·가격 같은 사실 조회를 구분합니다.
2. 출처·문서 식별자·적용 범위를 남기고, 미확보 값이나 규정을 만들어 채우지 않습니다. 동일 규칙은 한 문서에서 관리합니다.
3. 문서마다 질문에 필요한 내용을 독립적으로 씁니다. 제목만 바꾸거나 무작위 토큰·무의미한 꼬리문장으로 중복 검사를 피하지 않습니다.
4. cs 폴더에서 `python -m scripts.check_corpus`를 실행합니다. 현재 검사기의 길이·중복·표현·필수 항목을 확인하고 실패 원인을 고칩니다. 통과시키려고 기준을 느슨하게 바꾸지 않습니다.
5. 적재·검색 검증은 [RAG 안내](rag-retrieval.md)와 여행 검색 시험으로 별도 확인합니다. 파일 검사 통과를 DB 적재 완료로 쓰지 않습니다.

원문 PII·비밀값·접속 정보는 넣지 않습니다. 자료 변경은 버전·해시·검사 결과를 기록하며, 이전 평가 점수와 새로운 자료의 결과를 섞지 않습니다.

## 과거 기록

[수정 전 문서](../records/commerce_2026-10-11/wiki--context--corpus-authoring.md)는 당시 기록입니다. 현재 여행 제품의 사양·평가·시연·완료 증거로 사용하지 않습니다. 원문 바이트는 같은 폴더의 백업에도 보존했습니다.
