# 현재 여행 정책 코퍼스

현재 입력은 [여행 manifest](../../knowledge/travel/manifest.json)와 그 파일이 참조하는 여행 문서입니다. 실제 자료 개수·청크 수·검사 결과는 현재 manifest와 실행 결과로 확인하며 과거 수치를 재사용하지 않습니다. D-023 이후 쇼핑몰 코퍼스와 공존한다는 안내는 현재 사실이 아닙니다.

## 담는 내용과 조회 사실

여행 활동·날씨·식사·이동·취소 절차·동행 조건의 **판단 기준**을 `travel_` 접두 scope로 분리합니다. 지금의 영업시간·운행·가격·가용성 같은 값은 외부 조회와 구조화 데이터가 담당합니다. 업체별 취소 기한·위약금 수치를 산문에서 임의로 추출하거나 법령을 확인 없이 만들어 넣지 않습니다.

여행지 쇼핑 활동을 금지하지 않습니다. 백화점·시장 등의 장소 정보와 과거 상품 주문·배송 데이터는 다릅니다. 존재하지 않는 쇼핑 규정을 RAG 문서로 꾸며 넣지 않습니다.

## 검사와 적재

cs 폴더에서 `python -m scripts.check_corpus`로 파일·scope·중복·표현·필수 항목을 확인합니다. [적재기](../../scripts/ingest_corpus_local.py)는 현재 여행 manifest로만 실행하며 DB·모델 호출 전제와 대상 환경을 확인합니다. 파일 검사 통과와 DB 적재 완료는 별도입니다.

[여행 검색 통합 시험](../../tests/integration/rag/test_travel_corpus_retrieval.py)은 여행 문서 검색과 과거 scope 재유입 방지를 확인합니다. 실제 DB 상태는 실행한 환경·날짜를 붙여 보고하며 다른 환경의 적재 상태로 확대하지 않습니다. [작성 규칙](corpus-authoring.md)을 함께 따릅니다.

## 과거 기록

[수정 전 문서](../records/commerce_2026-10-11/wiki--context--travel-corpus.md)는 당시 기록입니다. 현재 여행 제품의 사양·평가·시연·완료 증거로 사용하지 않습니다. 원문 바이트는 같은 폴더의 백업에도 보존했습니다.
