# 소형·대형 모델 비교와 추가 학습 기준

우리 자료로 추가 학습하지 않은 원본을 먼저 비교하고, 상위권 소형 모델은 별도 학습판으로 시험한다. 모델을 학습 후보로 고르는 것과 서비스 모델로 채택하는 것은 서로 다른 판정이다.

이 페이지는 지속해서 따를 평가 절차의 정본이다. [후보 목록](../../../program/research/daily_rag_slm/model_release_watchlist.json)은 버전별 실제 실행 상태를 관리하고, [날짜별 기록](../../../program/research/daily_rag_slm/index.md)은 근거를 보관한다. 판정 규칙을 변경할 때 실행기의 조건과 함께 확인한다.

`[실측 2026-10-09]` E는 혼합 평문과 대조 짝을 통한 참조 인식 진단을 고도화했지만, 사람 검수와 독립 최종 검증까지 완성된 상용화 관문은 아니다. [구성·검수 감사](../records/reports/2026-10-09_0214_e-testset-maturity-audit.md).

## 판본표와 독립 보고서

[사용자 결정 2026-10-11] [모델 판본·보고서 표](model-version-reports.md)에서 필요한 실험을 바로 엽니다. 상세 실험은 각각 독립 보고서로 보존합니다. 새 중앙 모델 등록 서비스를 도입하지 않습니다.

## 매일 확인할 것

공식 개발사 발표·모델 카드·저자 저장소에서 마지막 확인 이후의 새 출시와 가중치 수정판을 확인합니다. 단순 파일·문서 수정 시각을 신모델 출시일로 삼지 않습니다. 이름·출시일·검증일·버전·커밋·전체/활성 매개변수·메모리·학습 가능 여부·라이선스·다운로드 크기·추론 방식·지원 언어를 기록합니다. 이전에 확인한 동일 커밋은 중복 다운로드·시험하지 않습니다. 기존 모델과 역할이 같은 유망 후보부터 자원을 배정합니다.

소형 모델의 작업상 기본 범위는 언어 부분 약 8B 이하입니다. 이는 보편적인 정의가 아니라 현재 GPU 자원에 맞춘 선별 기준입니다. 비전 모듈이나 전문가 혼합 구조는 언어 부분·전체·활성 매개변수를 따로 적고 실제 메모리로 판단합니다. 활성 수가 작다는 이유로 전체 가중치가 거대한 모델을 자동으로 소형 학습 후보로 넣지 않습니다.

## 비교와 상위권 판단

‘우리 학습 없음’은 배포된 원본에 우리가 추가 학습을 하지 않았다는 뜻입니다. 개발사가 지시·코딩·결정 학습을 한 모델은 그 사실도 적습니다. 완전히 사전학습만 한 Base 모델과 Instruct 모델은 구분합니다. 원본 모델 순위와 우리 학습 모델 순위는 별도 표에 둡니다.

원본 비교는 같은 여행 질의 ID·정답·프롬프트 계약·판정 규칙·양자화 조건으로 맞춥니다. 형식 적응이 필요한 결정 모델은 동일 정보와 선택지를 받고, 적응 방법과 출력 범위를 고정합니다. 실행기가 다르면 정확도 비교 조건은 명시하되 속도의 직접 우열은 별도 측정 전 확정하지 않습니다. 정상 요청·잡담·어려운 문장·혼합 요청·복합 요청을 구분해 정답 수와 전체 수를 보고합니다. 오류·미완료·해석 실패를 분모에서 빼지 않습니다.

매일 후보를 다운로드하기 전에 기존 GPU 서버 A/B의 대기열·프로세스·공간을 확인합니다. 본문·소스·가중치의 실제 사용 조건을 읽고 기존 저장공간 안에서만 받습니다. 기존 작업을 중단하거나 기존 모델을 삭제하지 않습니다. 대형 모델은 기존 접근권·인증·승인된 자원으로 가능한 경우 시험합니다. 새로운 결제·임대는 하지 않습니다.

상위권의 기본 기준은 동일 시험을 완료한 원본 비교군에서 정상 요청 정답률과 요청 없음 정답률을 각각 절반씩 반영한 균형 정확도가 상위 3개에 드는 것입니다. 여러 평가 세트는 세트별 균형 정확도를 먼저 낸 뒤 같은 비중으로 평균합니다. 요청 없음 전용 세트는 해당 정답률을 사용합니다. 각 세트의 점수와 분자·분모를 함께 공개해 합산 점수만으로 회귀를 숨기지 않습니다. 동률·차이가 불분명한 모델은 상위권 후보로 남기고 반복 시드·짝지은 차이와 구간을 추가 확인합니다. 비교군이 작으면 ‘확인한 n개 중 순위’라고만 적고 시장 전체 순위로 쓰지 않습니다.

학습 전 선별은 서비스 채택 기준과 다릅니다. 원본의 잡담 오지목이 목표를 넘더라도 상위권 소형 모델이라면 개선 목적의 추가 학습을 시험할 수 있습니다. 다만 정상 요청을 거의 모두 거절해 부정 점수만 좋아지는 판을 상위권으로 처리하지 않습니다. 일부 시험만 끝난 후보를 최종 상위권으로 확정하거나 곧바로 본 학습으로 넘기지 않습니다. 초기 스모크 뒤 동일 역할의 일반·직접 선택·어려운·혼합 시험을 완료한 비교군에서 판정합니다. 범위가 다른 옛 결과는 연결할 수 있는 세트만 사용하고 부족한 시험은 보충합니다.

## 자동으로 이어갈 학습과 재평가

상위권이며 소형이고 기존 자원에서 학습 가능한 후보는 사용자의 이번 승인에 따라 별도 확인 질문 없이 파인튜닝 대기열에 넣습니다. 먼저 정답 토큰만 학습하는 짧은 검증으로 구조·메모리·학습 가능성을 확인합니다. 검증 후 여행 도메인 학습 자료와 검증된 레시피를 사용하고 원본을 보존합니다. 자료·시드·레시피·어댑터·가중치 해시·시간·최대 메모리를 기록합니다.

학습한 판은 같은 원본, 기존 학습 없는 비교군, 기존 우리 학습 모델과 각각 비교합니다. 기존 시험은 개발·회귀 진단에 사용하고 최종 채택에는 학습과 일정·문구를 분리해 고정한 보류 자료를 씁니다. 선택률·오지목·말투 변경·복합 요청·확신도·지연·메모리와 학습 부작용을 함께 확인합니다. 혼합 평가의 사전 기준은 정답 선택 ≥95%, 오지목 ≤1%, 선택 손실 ≤2%p, 오지목 증가 ≤1%p이며 지정한 부류도 ≤3%인지 확인합니다. 반복 시드의 차이와 편차를 확인한 뒤 검증된 개선을 작업 폴더에 적용합니다. 학습을 했다는 이유로 제품 모델을 자동 교체하지 않습니다.


## 결과에 필요한 근거

실행마다 입력·정답 ID와 해시, 자료·프롬프트·시드·문턱, 모델 revision·양자화·엔진 버전, 답안 원본·오류·누락, 유형별 분자/분모, 반복 횟수·구간, 지연·메모리를 보관한다. 말로 답한 확신도와 토큰 확률은 같은 확률로 취급하지 않는다. 정확도와 같은 모델의 엔진 속도 비교를 분리한다.

새 독립 보류 자료는 작성·정답 검수·중복 검사 후 해시를 고정하고 최종 검증 전에 학습에 사용하지 않는다. 누적 개발 시험 결과만으로 채택하지 않는다.
