# 재난 수신 영향 필터 통합 검토

2026-10-17 한국 시각 기준. 사용자 추가 요구는 원본 수신 내역의 영향 카드와 네 종류 다중 체크박스다. 고객 일정 정지 정책이나 고객 알림은 바꾸지 않는다.

숙소·예약·고객 웹의 양쪽 매니저 11196399 반영과 운영 배포를 먼저 완료했다. 그 트리 위에 재난 추가 13파일을 통합했다. 공유 wiki와 인계 목록의 추가 줄 충돌은 각각 두 기록을 모두 보존했다. 원본 작업 폴더의 자료는 읽기 외에 건드리지 않았다.

후보 API는 현재 운영 API 위에 조회용 Python 3파일만, 관리자 이미지는 현재 관리자 운영판 위에 같은 Python 3파일과 화면 2파일만 더한다. 첫 빌드는 Docker가 sha256을 저장소 이름으로 해석해 실패했으며 같은 ID의 별도 복구 태그로 재시도 중이다. 기존 운영 컨테이너는 변경하지 않았다.

제공자 검사 714/714·완료 기준 26/26·mock 서버 화면 4/4와 실제 저장 기록 읽기 전용 조회 6조건을 전달받았다. 이는 이 통합판의 새 HTTP·로그인 화면 검증이 아니며 이 세션에서 통합 후 검사와 배포를 이어간다. 아직 추가분 푸시·배포·실제 관리자 화면 검증은 미완료다.


## 통합 후 검사 결과

완전 격리 실행기 8/8 단계 exit 0. 필수 시험 7741건 중 7603 통과·138 건너뜀, 예약 추가 221/221, 관련 DB·보안·숙소 회귀 264/264, 완료 기준 26/26 통과했다. 시험 DB는 정지했고 운영 컨테이너 ID는 그대로다. 관리자 기본 Turbopack 빌드·정적 검사·단위 시험 22/22 및 운영판 기반 컴파일 결과의 mock 서버 화면 시험 1280px/375px 2/2 통과, 쓰기 요청 0건이었다. 각 API/관리자 후보 Python 변경 3파일은 Git과 같고 그 외 Python 451개씩은 각자의 기존 운영판과 같다. 관리자 패키지 검사 기존 취약점 3건(높음 2·치명 1)은 의존성 버전을 바꾸지 않아 남는다.

숙소 배포 뒤 다른 담당 채팅의 신규 실제 예시에서 예약·재질문 보호는 정상이었으나 최초 숙소 자동 채움은 두 호텔 모두 실패했다. 수동 전체 추천에서는 공통 호텔이 제시되어 최초 계산 경로를 숙소 담당이 추적 중이다. 새 필터는 읽기 전용 기능이며 그 미완료 숙소 수정과 별도다. 현재 이 추가분의 푸시·실제 HTTP·로그인 화면 확인은 아직 남았다.
