# 지도 도구 왼쪽 내 위치 버튼 복구

위치 동의 전 버튼이 숨겨지고 첫 위치를 못 읽으면 비활성화되는 조건을 고쳤다. 현재 브라우저에서 위치를 읽을 수 없다고 확인한 결과는 아니다. 사용자가 지적한 페이지의 정적인 이미지로는 실제 위치 권한 상태를 판단할 수 없다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| Chrome mock 서버 시험 | 통과 | 39/39 = 100% |
| 위치·동의 단위 시험 | 통과 | 58/58 = 100% |
| native 화면 촬영 | 완료 | 5/5 = 100% |

## 변경

- 펼친 가로 도구의 맨 왼쪽에 내 위치 진입을 제공한다. 세로에서는 기존 마지막 도구 자리를 사용한다. 거리·접기 버튼의 오른쪽 자리와 화살표 방향, 마커가 이 버튼 하나만 피하는 규칙을 유지한다. 도구 누름 영역과 배치 계산을44px로 맞췄다.
- 위치 동의가 없으면 기존 선택 동의를 그 자리에서 받는다. 전문을 볼 때 안내 창을 교체해 창을 겹치지 않고, 취소·Esc 후 버튼으로 초점을 돌려준다. 동의 창을 오래 읽는 동안 도구가 접히지 않게 했다. 다른 선택 동의 호출부의 동작은 유지한다.
- 기존 브라우저 위치 조회·파란 점·정확도 원·카메라 이동을 연결한다. 실패는 기존 알림 토스트로 안내하고 버튼에서 다시 시도한다. 거절했던 권한을 허용한 뒤 다시 찾으면 추적도 다시 연결한다. 동의 철회 중 도착하는 위치를 버리고, 권한 확인 중 철회되면 위치 조회를 시작하지 않는다. 전체 일정 보기에는 사용자 위치를 포함하지 않는다.

## 검증

기준은 팀 매니저 `d4895eefdaf39db6efd02b24bbda2edd231dbeb3`다. 해당 기준에서 만든 별도 웹 사본에 이번 변경만 적용해 Next webpack 생산 빌드로 확인했다. 작업 루트의 기존 CSS 차이는 되돌리지 않았고, 이번 크기 변경 두 곳만 팀 기준 CSS에 적용한 결과를 검사했다. 변경 소스·시험13개의 해시와 패킷 적용 확인은 [실행 근거](../evidence/2026-10-11_location-entry/)에 있다.

- 최종 `verified.json`: expected39·unexpected0·skipped0·flaky0. 새 위치 진입9, 기존 지도 단추7, 직접 좌표 지정4, 기존 내 위치16, 지도 포함 촬영3이다.
- `unit-verified.log`: 지도 배치·위치 API·위치 전송·동의 동기화58/58.
- `static-final.json`: 최종 ESLint와 TypeScript의 종료 코드를 기록한다. 생산 빌드는 최종 Chrome 실행이 사용하는 빌드다.
- 촬영은 준비된 브라우저 좌표와 기존에 저장된 OpenStreetMap 타일을 사용한다. 촬영 중 외부 타일 요청은 하지 않았고 캐시 누락도 검사했다. 위치 이동 애니메이션과 날짜 복귀가 끝난 화면을 [목업](../../../frontend/apps/web/mockups/location-entry-2026-10-11-v4/index.html)으로 제공한다.
- 최초6건은4통과·키보드 시험2실패였다. 실제 Tab 이동으로 시험을 바로잡았고, 다음8건에서 발견한 동의 창의 초점 복귀·순환 결함3건을 수정했다. 중간32건의31통과·1실패는 자동 종료 중인 소개 토스트를 누르려던 시험 경합으로, 소개 안내가 끝난 뒤 검사하도록 고쳤다. 최초 단위 실행의 임시 파일 접근 오류와 중간 형 검사의 오래된 Next 증분 파일 오류도 원문 로그에 보존했다. 최종 검사는 정상 임시 폴더와 증분 기록을 사용하지 않는 형 검사로 확인했다.

재현은 시험 사본에서 `STUB_PORT`·`LIVE_PORT`·`PLAYWRIGHT_CHANNEL=chrome`을 정하고 `playwright.location.config.ts`로 위치 진입·지도 도구·내 위치·직접 좌표·촬영의 다섯 spec을 실행한다. 촬영에는 `LOCATION_TILE_CACHE`로 기존 타일 폴더를 지정한다. 위치·동의 단위 시험은 `vitest run src/features/map/map-geometry.test.ts src/lib/location.test.ts src/lib/live/location-samples.test.ts src/features/consent/consent-sync.test.ts`다.
