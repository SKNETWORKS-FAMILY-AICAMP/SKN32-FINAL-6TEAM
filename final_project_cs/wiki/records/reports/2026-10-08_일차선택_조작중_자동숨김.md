# 일차 선택 줄 — 조작 중 자동 숨김

전체·일차 선택 줄을 스크롤·지도·목록 조작 중에는 부드럽게 숨기고, 조작이 끝나면 같은 위치에 다시 표시한다. 사용자 브라우저 댓글의 ‘일차 고르기’ 선택 요소에 대한 수정이다. 공개 서비스에는 아직 배포하지 않았다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| mock 서버 화면 시험 | 통과 | 6/6 = 100% |
| 실제 화면 촬영 | 완료 | 4/4 = 100% |
| 수정 파일 ESLint·타입 검사 | 통과 | 2/2 = 100% |

## 동작

- 일차 줄 자체를 선택하는 동작을 제외하고, 목록 스크롤·휠·화면 안의 포인터 조작이 시작되면 숨긴다. 누르고 있는 동안에는 계속 숨긴다. 손을 놓은 뒤 마지막 스크롤로부터 800ms 지나면 복귀한다. 스크롤 관성 중에는 숨김을 유지한다.
- 숨김은 150ms ease-in, 복귀는 200ms ease-out이다. 투명도와 위로 4px 이동만 사용한다. 요소의 높이·목록 여백을 바꾸지 않으므로 숨김·복귀가 스크롤 위치를 밀지 않는다. ‘동작 줄이기’에서는 위치 이동과 전환을 끈다.
- 일차 버튼을 누르거나 방향키로 고를 때, 일차 줄에 키보드 초점이 있을 때는 유지한다. 숨은 줄은 임시로 클릭·초점 대상에서 제외한다. Tab을 누르면 상단 헤더에서도 곧바로 복귀시켜 브라우저가 다음 초점을 계산하기 전에 접근을 되살린다. 손을 화면 밖에서 놓거나 포인터가 취소·창이 비활성화되어도 복귀 타이머를 정리한다.
- 기존 날짜 줄 아래로 일정 맞추기와 검증 중 일정 중앙 정렬은 그대로 유지한다.

## 검증

mock 서버 시험 6/6 (화면 반응): 새 동작 4건과 기존 일정 위치 2건. 실제 Chrome, 휴대폰 375×812 및 PC 1280×720 화면 촬영. 목록을 스크롤한 뒤 복귀 전후 스크롤 위치 차이 3px 미만을 확인했다. 지도에서 누르고 1.1초가 지나도 숨김이 유지되며 손을 놓은 뒤 복귀한다. 상단 메뉴 초점에서 Tab을 누르면 300ms 안에 숨김 상태가 해제됨을 확인한다. 동작 줄이기에서는 숨은 줄의 transform이 none이다.

실서버 확인 (서버 응답): 안 했음. 이 변경은 화면 동작이며 공개 서비스 배포 전이다.

실제 화면 빌드 성공, 수정 파일 ESLint와 타입 검사 통과. [실행 로그](../evidence/2026-10-08_일차선택_자동숨김/), [실제 화면 모음](../../../frontend/apps/web/mockups/day-strip-auto-hide-2026-10-08-v1/index.html). 지도 타일·여행 자료는 mock 서버 시험용이고 실제 프론트를 촬영했다.

키보드 접근은 초기 구현의 화면 안 이벤트만으로 제한하지 않고, 화면 밖 상단 헤더의 Tab도 받도록 보완했다. 시험은 조작을 멈춘 뒤 자동 복귀를 기다려 통과하지 못하도록, Tab 직후 300ms 안의 상태를 검사한다. 모션·전환·키보드·동작 줄이기 스킬을 적용했다.
