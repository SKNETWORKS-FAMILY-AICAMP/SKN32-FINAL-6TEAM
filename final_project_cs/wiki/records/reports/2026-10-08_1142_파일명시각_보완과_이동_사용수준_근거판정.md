# 파일명 시각 보완과 이동 사용 수준 근거 판정

2026-10-08 기준, 제한된 시연·참고 안내에는 활용할 수 있지만 이동 기능 전체를 실제 여행의 자동 조정에 적용하는 출시 준비가 끝났다는 근거는 부족하다. 파일명 누락 시각 3건은 생성 시각으로 보완했고, 대조 결과를 저장 원자료로 다시 계산했다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 파일명 작성 시각 보완 | 완료 | 3/3 = 100% |
| 새 100쌍 집계 재현 | 일치 | 100/100 = 100% |
| 네이버·구글 웹 값 재해석 | 일치 | 60/60 = 100% |
| 주요 통계 독립 검산 | 일치 | 6/6 = 100% |

## 목표·실제 변경

사용자가 승인한 파일명 시각 보완과 지도 대조의 사용 가능 수준 판단이다. v11 §5 Mobility 및 §0-4 결정 15의 값 확보 원칙, `RULE.md` §2·§3.4·§4.2를 적용했다. 새 기능 구현·요율 보정·지도 제공자 전환·배포·push는 수행하지 않았다.

정확한 보고서 작성 시각을 내부 본문에서 확인하지 못해 Windows 생성 시각을 사용했다. 웹 관측 시각을 작성 시각으로 혼동하지 않았다. 파일명 접두에 02:45·05:03·09:54를 추가했다. 문서·도구의 연결 7개 파일은 기존 파일명을 새 파일명으로 바꾸고 모두 수정 전 백업을 만들었다. [이름 대응표와 백업 위치](../evidence/assets/2026-10-08_1142_mobility_readiness/rename-manifest.json), [재검산 증거](../evidence/2026-10-08_1142_지도대조_사용수준_재검산.md)를 보관했다. 기존 점검 보고서의 2/5는 당시 관측이며 현재 최근 다섯 보고서는 5/5가 시각 접두를 갖는다.

## 실제로 확보한 대조군

- **다음/카카오**: 기존 200쌍과 겹치지 않는 새 100쌍의 자동차·대중교통 및 도보·자전거 각 30쌍. 개발자 지도 API 대신 웹 관측값을 사용했다. [새 100쌍 보고서](2026-10-08_0503_이동_새100쌍_카카오웹_성능조사.md), [집계·입력 해시](assets/2026-10-08_mobility_fresh_100/summary.json).
- **네이버**: 카카오 새 100쌍 중 사전에 고른 동일 12쌍의 자동차·대중교통·도보·자전거 48건.
- **구글**: 같은 12쌍의 대중교통 12건. 자동차·도보·자전거 대조까지 완료한 것으로 세지 않는다. [12쌍 보고서](2026-10-08_0954_이동_네이버_구글_웹_12쌍_대조.md), [집계](assets/2026-10-08_mobility_multi_provider_12/summary.json).

같은 12쌍을 제공사별로 관측한 것이므로 새 경로 24쌍이나 독립 검증 표본 124쌍으로 합산하지 않는다. 네이버·구글은 오전, 카카오는 새벽 관측이다. 추천 경로·역 출입구·교통 상태가 완전히 같지 않다. 지도 서비스 간 정확도 순위를 판정하지 않는다.

## 주장별 근거 판정

| 확인할 주장 | 판정 | 근거·반증 확인 |
|---|---|---|
| 파일명 시각은 보완할 수 있다 | 맞음, 이번 3개 범위 | 파일 생성 메타데이터와 본문 날짜·실험 순서가 모순되지 않음. 복사 이력으로 시각이 달라질 수 있어 생성 시각을 실제 집필 시각이라고 단정하지 않음 |
| 구글·네이버·카카오 전 수단을 다 검증했다 | 틀림 | 구글 유효 대조는 대중교통 12건. 나머지 수단·실시간 사건·혼잡·따릉이 가용성 등은 이 대조로 검증하지 않음 |
| 택시 여유가 예산 부족을 줄였다 | 맞음, 표본 범위 | 같은 카카오 100쌍에서 10% 여유 67/100, 고정 37% 여유 96/100. 네이버는 11/12. 실제 결제액 영수증 검증은 아님 |
| 대중교통 12쌍 결과가 전체 정확도를 보장한다 | 틀림 | 카카오 100쌍의 추천안 ±5분 비율은 대기 포함 66/100·제외 68/100. 두 12쌍 결과와 일괄 일반화할 수 없음 |
| 버스·요금 기능은 출시 준비가 끝났다 | 틀림, 이번 측정 상태 | 버스 비교 가능 경로 52/100, 지하철 요금 24/95 누락. 경로별 비용 비교도 동일 승차 경로의 요율 정답률이 아님 |
| 도보·자전거 도착시각은 정확하다 | 일부 맞음 | 중앙 차이만 작은 항목도 개별 차이가 큼. 카카오 도보 ±5분 15/30, 네이버 4/12. 자전거 시간 중앙 차이 카카오 −17.9%, 네이버 −20.4% |

숫자는 저장 자료 재검산과 공개 집계 두 형태로 대조했다. 서로 독립된 외부 실제 운행 자료 두 개를 확보했다는 뜻은 아니다. 사용 수준은 위 결과에서 내린 판단이며 사전에 승인된 신규 서비스 합격 기준은 아니다.

## 기능별 사용 수준

**택시 예산 안내는 조건부 활용 가능**: 카카오 예상액 이상 96/100 = 96%, 네이버 11/12 = 91.7%. 같은 계산의 예산은 비교 지도 예상액보다 구간별 비율 중앙으로 각각 +27.4%, +36.0% 높다. 37%는 공식 요율이 아니라 자료로 산정한 예산 가정이며 실제 결제 상한을 보장하지 않는다. 미터 예상액과 별도 여유를 표시하고 경로·저속 시간 추정을 개선해야 한다. 미터 계산 자체의 ±1,000원 이내는 카카오 55/100, 네이버 9/12라 '정확한 택시비'로 설명할 근거도 부족하다.

**대중교통 소요는 제한된 참고·시연에 활용 가능**: 아래는 각 지도 첫 추천안과의 비교다. 카카오가 더 큰 표본이고 네이버·구글은 같은 목적 표본 12쌍이다. 대기 제거값을 실제 일정 소요로 대신 사용하지 않는다.

| 기준 | 표본 | 우리 대기 포함 ±5분 | 우리 대기 제외 ±5분 | 대기 포함/제외 비율 차이 중앙 |
|---|---|---|---|---|
| 카카오 추천 | 100쌍 | 66/100 = 66% | 68/100 = 68% | 0.0% / −4.7% |
| 네이버 추천 | 12쌍 | 11/12 = 91.7% | 12/12 = 100% | +15.6% / +9.9% |
| 구글 추천 | 12쌍 | 12/12 = 100% | 12/12 = 100% | +4.3% / 0.0% |

카카오 추천 대기 포함 평균 절대 차이는 5.35분, 제외 4.97분이다. 네이버는 각각 3.58·2.92분, 구글은 2.17·1.83분이다. 12쌍에서 모두 맞았어도 관측은 경로·수단별 한 번이고 시간대별 재현성·실제 도착 오차는 측정하지 않았다. 12쌍의 구간 수와 조건을 숨기고 '정확도 100%'라고 표현하지 않는다.

**버스와 요금은 실제 자동 적용 전 보완 필요**: 버스만 허용한 비교 가능 경로 52/100 = 52%, 지하철 경로 비교 가능 95/96 = 99.0%와 달리 요금 값은 71/95 = 74.7% 제공했다. 지하철 24/95 = 25.3%, 버스 1/52 = 1.9% 요금 누락은 대체 소스로 값 확보가 필요한 결함이다. '미확인' 문구로 서비스 완성을 대신하지 않는다.

**도보·자전거는 도착시각 안내 전 보완 필요**: 카카오 도보 30쌍 평균 절대 차이 7.04분, 네이버 12쌍 10.85분이다. 자전거는 카카오 중앙 −17.9%, 네이버 −20.4%로 짧게 계산한 결과이며, 네이버의 강변 경로 등 선택 도로 차이도 섞인다. 자전거 전 구간이 항상 빠르게 계산된다고 단정하지 않는다.

## 편차와 공식 근거

고정 표본에서 2,000회 재표집한 예산 비율 차이 중앙의 95% 구간은 카카오 +23.9~+29.4%, 네이버 +31.8~+38.4%다. 카카오 자전거 시간 중앙 차이 구간은 −22.0~−13.9%, 네이버는 −31.6~+6.9%로 0을 포함한다. 목적·거리층 표본의 재표집 범위이며 서울 전체 대표성이나 반복 운행 오차 범위가 아니다.

- [서울시 택시 공식 요율](https://sftc.seoul.go.kr/seoul/mulga/main/contents.do?menuNo=200023): 2026-10-08 재확인. 중형 2023-02-01 적용 요율은 오래된 적용일이지만 현재 공식 페이지에 그대로 공표돼 있다. 법정 요율의 근거이며 우리 경로·저속 시간·여유율 정확도의 근거가 아니다.
- [Google 공식 길찾기 도움말](https://support.google.com/maps/answer/144339?hl=ko): 2026-10-08 확인, 페이지 갱신일 표시 미확보. 지역별 수단 가용성, 출발/도착 시각 변경, 소요·거리·요금 등의 추천 순위 기준을 안내한다. 지도 첫 추천안을 동일 경로 정답으로 볼 수 없다는 해석의 보조 근거다.
- [다음 지도 주소](https://map.daum.net/): 2026-10-08 도구에서 카카오맵으로 리디렉션 확인. 본문 캐시는 오래된 자료로 표시돼 서비스 세부 기능 판단에 사용하지 않았다.

권장 다음 작업은 버스 경로 미산출·지하철 요금 누락 해결, 도로 경로·저속 시간·자전거 지연 원인 개선이다. 개선 후 같은 장소·시각 조건을 맞춘 미사용 표본과 실제 탑승 자료로 확인해야 한다. 이번 결론으로 제품 기능을 끄거나 데이터를 삭제하지 않았다.
