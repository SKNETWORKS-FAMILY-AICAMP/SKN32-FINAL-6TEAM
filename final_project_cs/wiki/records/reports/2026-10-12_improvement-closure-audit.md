## 이번 코드 회귀

`python -m pytest tests/unit/travel/test_decision_target_guard.py tests/unit/travel/test_intake_transcription_differs.py tests/unit/travel/test_read_requests.py -q`를 cs 프로젝트에서 실행했습니다. **63/63 = 100% 통과**, 5.78초, 프로세스 종료 코드는 0입니다. 종료 시 pyreadline3의 Console 정리 예외가 stderr에 남았지만 pytest 실패는 없습니다. 이는 DB 없는 로컬 회귀이며 실제 모델 172문장·OCR 350값·공개 웹 흐름을 새로 측정한 결과가 아닙니다.

실서버 확인(서버 응답): 이번 감사에서 Oracle ARM 앱 HTTP 질의를 새로 실행하지 않았습니다. 10월12일 04:53까지 보관된 실제 진단을 대조했습니다. 그 네 질문은 모델 상주 중에도 59.80~68.53초이며 응답 속도 해결로 표시하지 않습니다. mock 서버 화면 시험은 이번 범위에 없습니다.

## GPU 이전과 모델 작업

2026-10-12 11:11 KST SSH 원본: GPU 서버 A는 NVIDIA RTX 2000 Ada Generation이며 등록 196항목 전체가 종료 상태입니다(157 completed·37 completed_with_errors·2 failed). 실행 0개·미실행 0개입니다. 실패·오류가 있는 종료 39개를 품질 통과에 합치지 않습니다. GPU 서버 B는 NVIDIA RTX A4000이며 현재 FINCH 두 번째 시드의 앱 완성도 비교를 실행 중입니다. 모델 메모리 9,989MiB·GPU 24%는 순간값이며 풀가동 지속 비율이 아닙니다.

사용자 지시는 ADA2000 작업을 A4000 하나로 통합하는 것입니다. 이번 감사는 모델 파일·실행 도구 이전과 RunPod 정지를 완료하지 않았습니다. A4000 현재 남은 공간은 5,499,613,184바이트, ADA2000는 3,623,124,992바이트입니다. 이전 전에 필요 파일·기존 보관본·해시·용량을 대조하고 이미 종료된 시험을 재실행하지 않아야 합니다. 새 결제·임대·모델 삭제를 승인받은 것으로 해석하지 않습니다.
