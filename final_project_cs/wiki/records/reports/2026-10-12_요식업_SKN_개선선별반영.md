## 검토와 보완

검토 모델은 Claude Sonnet 5.5(실제 응답 modelUsage claude-sonnet-5-5), 읽기 전용 2회다. 실행 검증이나 DB 검증을 모델 검토가 대신하지 않는다.

- 검수 시트 upgrade 시 기존 수기 행이 빠지는 문제: 기존 검수 행/직접 만든 가게를 유지하고, 출력마다 덮기 전 백업한다. 영업 상태로 기존 행을 제외할 때 경고한다.
- 같은 상호의 여러 지점이 영업시간을 서로 덮는 문제: 중복 상호는 명확한 오류로 중단한다. 지점 구분 없이 임의 합치지 않는다. 데이터 원본 확보 뒤 이 오류가 실제 발생하는지 확인해야 한다.
- 설문 타입 가드: 실제 추천 경로와 dining 설문 읽기에 입력 검사를 더했다. components에서 instances를 직접 import하지 않는다.
- 배지 이름은 짧게 유지하며 상세에 별도 출처를 표시한다.
- 브레이크타임이 개점/폐점 경계와 겹칠 때도 실제 영업 구간에서 차감한다. 회귀시험을 더했다.
- SQL 제약 검색을 dining.dn_attribute 표로 한정했다.
- --dry는 만든 가게 목록을 기록하지 않는다. 노포 원본 누락은 rebuild --check에서 사전에 막는다.

재검토의 식사 줄 필터 지적은 이번 변경 이전부터 존재하던 코드이므로 이번 수정 결함으로 확정하지 않았다. 팀 보고서의 근처 메뉴 검색 기준 좌표 누락은 별도 후속 확인 대상으로 남는다. 이름 유사도와 30m로 Google 연결하는 신규 규칙은 검수된 정확 일치와 동일한 신뢰도로 일반화할 수 없다.
