# 후보 세 단 · 모델 이유 문장 · 임베딩 · 약관 보관 기간 — 인계

세션 이름 「triPilot : cs project 구축」이 2026-10-07 에 한 일을 닫으며 남깁니다. 사용자 결정은 화면 담당(uiux) 세션이 사용자 채팅 원문 요지로 전한 것이고, 코드는 모두 로컬 작업 폴더에서 만들고 로컬 개발 DB 로 시험했습니다.

네 건 모두 코드가 `role-manager` · `develop` 에 들어가 있습니다(통합 커밋 `0bf4331e`에 취향 3단 · 모델 이유 · 임베딩 · 분류 채우기가 함께 실렸고, 호텔 `90d9e403` · 보관 기간 `3330766a` · 후보 단 `c0ca7054` 는 따로 만든 커밋). **x600 서버의 cs 프로젝트 서버에서 확인한 것은 하나도 없고, 실제 모델(채팅 · 임베딩)로 돌려 본 것도 없습니다.**

## 검증 범위

- **로컬 개발 서버(이 PC의 DB)** 에서 통과: 후보 묶음(세 단 · 같은 종류 · 호텔 · 이유 문장 · 임베딩) · 보관 기간 22건 · 삭제 · 게스트 정리 · 동의 · 웹 방어 · 웹 계정 · 구조 시험. 숫자는 실행 때마다 늘 수 있어 이 문서에 고정하지 않습니다 — 시험 지도의 [해당 행](../../quality/test-map.md)에서 다시 돌립니다.
- 이 PC 메모리 부족으로 `tests/unit/travel/mobility/test_check_scripts.py::test_check_runtime_on_real_timetable` 한 건이 실패합니다(큰 시간표 배열을 못 만듦). 이번 변경과 무관한 환경 문제입니다.
- 개발 DB 는 시험 묶음을 겹쳐 돌리면 복구 모드로 들어갑니다 — 나눠서 돌리고 `ERROR` 가 쏟아지면 DB 부터 확인합니다.
- **하지 않은 것**: mock 서버가 아닌 실제 모델(채팅 · 임베딩) 호출 · x600 서버에서의 확인(마이그레이션 056 · 057 · 058 적용 포함) · 화면 실제 확인.

## 아직 안 한 것 · 결정이 필요한 것

1. **실모델 확인** — 채팅 모델이 쓴 이유 문장이 검사(`guard`)를 얼마나 넘는지, 임베딩 투표 기준(`KNN_K` 7 · `MIN_SIMILARITY` 0.55 · `MIN_SHARE` 0.6)이 맞는지는 모릅니다. 모델 서버가 있는 곳에서 `scripts.embed_place_catalog`(dry-run 먼저) → `scripts.fill_place_classes`(dry-run 먼저) 순서로 돌려 건수와 표본을 보고 정합니다.
2. **회원 자료 정리를 `on` 으로 켜는 일** — 지우는 일은 되돌릴 수 없습니다. 기본은 `dry_run` 이고 건수는 `retention_runs`(관리 화면 `GET /admin/retention` 의 `purge.runs`)에 쌓입니다. 사용자가 건수를 보고 승인한 뒤 `/admin/limits` 의 `retention.purge_mode` 를 `on` 으로 바꿉니다.
3. **채팅 · 활동 기록을 우리 데이터로 남길지** — 사용자가 「활동 기록은 운영을 위해 기록해야 한다」고 했는데, 확정한 보관 기간(회원 1년 뒤 파기 · 처리 기록 함께 파기)은 그 기록을 지웁니다. 선택 값만 비식별로 남기는 안(추천)과 요청서 그대로 파기하는 안 중 사용자가 아직 고르지 않았습니다.
4. **`case_events` 추가만 규칙의 예외** — 처리 기록 파기가 이 규칙의 유일한 예외입니다([메모리 문서](../../context/memory.md)에 적음). 프로젝트 `CLAUDE.md` · `AGENTS.md` 의 「`case_events`는 추가만 합니다」 문장은 다른 세션이 편집 중이라 고치지 않았습니다 — 두 파일을 같이 고쳐야 합니다.
5. 접수 원문 `intake_sources.keep_until`(30일)을 읽는 정리 · 위치 점 · 위치 확인자료 파기(위치 저장 기능이 없음) · 회원 탈퇴 기능은 범위 밖입니다.
6. 약관 버전 `2026-10-07.1` 은 웹 `TERMS_VERSION` 과 **같은 배포**에 올려야 합니다(한쪽만 올리면 모든 동의가 409). 운영자가 보관 기간 값을 바꾸면 서버 버전이 `…+ret{N}` 이 되므로 웹은 상수 대신 `GET /v1/web/legal/retention` 의 `terms_version` 을 읽습니다(화면 담당이 반영했다고 알려 옴 — 실제 화면은 확인하지 못했습니다).
