# 상세 보기 「변경됨」 되살리기 · 지도 가장자리 칩과 번호 핀의 다크 색 (2026-10-21)

가지 `fix/web-detail-changed-mark-20261021` (role-eval-ui `9f6c145d` 에서 땀). 18:1x 사용자 결정(「한 세션만 쓴다」)으로 두 일을 이 세션에서 한 커밋으로 묶었다(19:0x 사용자 「다른 세션에서의 작업을 여기서 반영해서 한번에 커밋」).

## 1. 상세 보기 「변경됨」 (ST4F-704 후속)

- **무엇이 사라졌나**: `b4384da8`(ST4F-704)이 상세 보기의 「입력한 메모」 줄을 뺐다(사용자 지시 — 적는 칸도 서버 값도 없음). 그 줄은 웹이 서버 값으로 지어 붙인 두 조각이었다(`gateway.ts` `notes`): 「장소: ○○」(장소 이름이 제목과 다를 때) · **「지켜보다 바뀐 일정이에요.」(서버 `changed`)**. 앞 조각은 ST4F-706 의 장소 줄(📍)이 대신하지만, 뒤 조각은 상세 카드에서 바뀐 일정을 알리는 유일한 자리였다 — 같은 날 「일정 장소 상세보기 메모칸 확인」 세션이 「메모 줄을 빼려면 바뀐 일정 표시를 위 표시 줄로 옮기라」고 짚어 둔 것을 이 세션이 확인하지 않고 지웠다.
- **고침**: 서버 `changed`(= 이 일정이 앞 일정을 대신함 — `trip_api._item_view` `replaces_item_id is not None`, 채팅 · 감시 · 수정 모드 모두)를 `TripStop.changed` 로 받고, 상세 카드의 「n일차 시각」 표시 줄에 `pc.pill[data-state="changed"]` 「변경됨」(서버 공유 계획서 배지와 같은 말). `notes` 칸은 지금 화면에서 읽는 곳이 없지만 모델 · 시험 자료 10곳이 쓰는 칸이라 이번에 지우지 않았다(정리는 따로).
- **확인**: `gateway.test` 에 `changed` 단언 · 웹 단위 1022/1022 · 타입 · lint. 로컬 실서버(웹 3120 = 이 가지 · API 8062)에서 시험 여행 `ad81261f…`(경복궁을 대안 「학고재」로 고른 판 2) 상세 보기 — 「학고재 관람」 카드에만 「변경됨」, 7장 모두 「입력한 메모」 없음.

## 2. 지도 가장자리 칩 · 번호 핀 다크 색 (목업 결정 B안)

- **출처**: 「지도 핀 다크모드 색상 목업」 세션(18:2x ~ 18:4x)이 목업 [tripilot-map-edge-chip-dark.html](../../../frontend/apps/web/mockups/tripilot-map-edge-chip-dark.html)으로 정한 것 — 사용자 결정 「번호는 B안(밝은 글자) · 지도 위 번호 핀(물방울)의 흰 테두리도 초록」. 그 세션은 다른 세션의 브라우저 시험이 끝난 뒤 앱에 넣기로 하고 목업 · README 줄만 이 세션의 다른 작업 폴더(`SKN32-time-wheel-20261021`)에 미커밋으로 두었다 — 이 커밋으로 옮겼다(원래 자리의 미커밋 파일은 그대로 둠).
- **문제**: 가장자리 칩(화면 밖 일정 「2.4km | 1 · 2 ↑」)의 번호 배지가 두 테마에서 같은 `--color-map-stack #202020` 바탕에 `--color-on-primary` 글자 — 다크에서 #0d1712 글자라 대비 1.1 : 1 로 안 읽혔다. 칩 · 번호 핀 테두리는 `--color-text`(다크에서 흰색).
- **고침**: `map.module.css` `.edgeChip` 테두리 → `--color-selected` · `.edgeNumbers` 바탕 투명 · 글자 `--color-text`, `providers/pin.ts` 번호 핀 기본 테두리(두 곳) → `--color-selected`. 후보 · 주의 · 흐린 핀 테두리와 밀린 핀의 점선은 그대로. `--color-map-stack` 은 쓰는 곳이 없어져 `tokens.css` 두 테마에서 지웠다. 역할(토큰)만 바꿔 라이트에도 같이 적용된다(라이트 `--color-selected` = 앱 초록 #2e6047).
- **확인**: 다크(브라우저 다크 선호 · 앱 `data-theme=dark`)로 시험 여행 지도를 확대해 칩이 생긴 상태에서 계산된 값 — 번호 핀 테두리 `rgb(124,189,150)`(#7cbd96) · 칩 테두리 같은 색 · 칩 번호 글자 `rgb(228,236,231)` · 번호 바탕 투명. 지도 색을 읽는 단위 · 화면 시험은 없다.
