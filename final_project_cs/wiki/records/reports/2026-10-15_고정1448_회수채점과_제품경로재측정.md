# 고정 1,448문장 회귀 — 회수·채점·제품 경로 재측정 (2026-10-15)

## 결론 (위층)

- 두 문제 모두 **아직 해결이 아닙니다.** 제품 경로(학습 E4B + 최신 코드)로 다시 재니, 일정과 무관한 말에 항목을 짚는 비율은 5주차 5.3% → **3.85%** 로 내려갔지만 목표(0.3~0.4%대)에는 멀고, 규정 질문 놓침은 5주차 26% → **약 41%** 로 오히려 나빠졌습니다.
- 「채점 결과를 못 찾음」은 오해였습니다. 10-12 회귀의 채점 결과(`summary.json`)와 답안 1,448줄이 GPU 서버 B 에 그대로 있어 회수했고 사전 등록 채점기로 다시 확인했습니다. 단 그 값은 학습 없는 모델 · 구 코드 · 출력 400토큰이라 제품 값이 아닙니다.
- 이번에 고친 것은 코드 한 곳(잡담 100건이 「해석 실패」로 버려지던 것)이고, 나머지 둘(잡담 오지목 · 요청 말투 규정 질문)은 **모델 쪽 원인**이라 모델 교체 또는 추가 학습 결정이 필요합니다. 모델 교체는 승인 전에 하지 않았습니다.
