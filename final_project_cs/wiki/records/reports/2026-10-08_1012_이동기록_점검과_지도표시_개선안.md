# 이동 기록 점검과 지도 표시 개선안

최근 이동 조사 결과는 보관·연결돼 있지만 기록 규칙을 완전히 지키지는 못했다. 지도 연동 설명의 오래된 내용을 코드에 맞춰 바로잡고, 추가 길찾기 API 호출 없이 가능한 표시 개선을 정리했다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 최근 보고서 보관·요약 연결 | 확인 | 5/5 = 100% |
| 보고서 내부 파일 링크 | 확인 | 29/29 = 100% |
| 보고서 파일명 시각 규칙 | 미준수 3개 | 2/5 = 40% |

## 목표와 범위

사용자의 기록 준수 확인 및 지도 표시 개선 방법 요청에 대한 점검이다. v11 §5의 Mobility와 여행계획서 웹 표시 범위, `RULE.md` §2·§3.4·§4.2를 적용했다. 새 기능 구현·제공자 전환·요금 설정 변경·배포·develop 병합·push는 수행하지 않았다. 전체 저장소의 모든 문서를 감사한 결과로 해석하지 않는다.

## 최근 기록 점검

| 보고서 | 보관·요약 링크 | 파일명 시각 | 근거 형태 |
|---|---|---|---|
| [중단작업·200쌍](2026-10-08_0245_이동_중단작업_재개와_200쌍_대조.md) | 확인 | 누락 | 본문 시험 기록·원자료 경로 |
| [택시 보정](2026-10-08_0343_택시_예산여유_보정과_시각일치_검증.md) | 확인 | 준수 | 본문 시험 기록·입력 해시·재현 명령 |

| [공식 요율·지도 대조](2026-10-08_0924_택시_공식요율과_네이버_구글_대조.md) | 확인 | 준수 | 독립 증거 문서 링크 |
| [네이버·구글 12쌍](2026-10-08_0954_이동_네이버_구글_웹_12쌍_대조.md) | 확인 | 누락 | 독립 증거 문서·집계·도구 링크 |

확인 분모는 위에 적은 최근 보고서 5개다. 내부 로컬 링크 29개는 전부 존재하며 초기 대조·보정 원자료로 명시한 네 JSON도 존재한다. 이 확인만으로 모든 기록의 수치가 재검증됐다고 주장하지 않는다. 원래 보고서 5개는 작성 당시 기록과 연결을 보존했다. 파일명 시각 누락 3건은 남아 있는 미준수로 기록하며, 이후 작성 기록은 시각 접두와 별도 증거 링크를 붙인다. 이번 점검 증거는 현재 요약 문서에서 찾아갈 수 있다.

## 현재 지도와 개선 방법

지도 화면은 지도 바탕, 우리 경로 좌표, 선·핀·정보 표시가 합쳐져 만들어진다. 네이버 지도 바탕을 붙이는 어댑터는 이미 있지만 실제 인증·배포 설정은 이번에 검증하지 않았다. 기본 설정은 OSM이며 배포 환경의 실제 제공자는 이번 확인 범위가 아니다.

현재 수단별 선 색상·핀 겹침 배치·확대 시 상세 경로 좌표 요청이 구현돼 있다. OSM에는 선택한 선을 굵게 올리는 처리가 있다. 네이버 어댑터에는 동일한 선택 선 ID 처리가 없어 실제 전환 전에 기능 동등성을 보완해야 한다. 보기 좋은 지도 제공자로 바꾸는 것만으로 네이버 웹의 경로 검색 화면 전체가 생기지는 않는다.

추천하는 첫 작업은 현재 지도에서 선택 경로의 테두리·강조, 나머지 선의 낮은 강조, 겹치지 않는 출발·도착 핀, 선택 구간의 소요·거리·예상 요금 카드 연동이다. 실제 표시 수치만 사용하며 미터 예상액과 별도 예산 여유를 구분한다. 이미 있는 기능은 재구현하지 않고 화면에서 연결·대비·배치를 다듬는다. 우리 경로 좌표와 결과를 사용하므로 외부 길찾기 API를 추가할 필요가 없다.

도보·자전거·택시는 로컬 도로 그래프 선을 그리지만 지하철은 역 좌표 연결, 버스는 직선이다. 버스 정류장·노선 좌표를 보강해야 실제 길을 따라 보이게 할 수 있다. 근거 없이 곡선을 꾸며 실제 경로처럼 표시하지 않는다. 현재 OSM 바탕은 이미지 타일이므로 선·핀 디자인과 달리 바탕의 도로색·글자 배치를 CSS만으로 전면 변경할 수는 없다.

네이버 지도 바탕을 쓰는 두 번째 방법도 가능하다. [공식 Maps 개요](https://guide.ncloud-docs.com/docs/maps-overview)는 지도 표시와 Directions 길찾기를 별도 서비스로 구분하며, 지도 표시에도 대표 계정 조건에 따른 무료 이용량·과금 정책이 있다. [Map Style Editor](https://guide.ncloud-docs.com/docs/application-maps-styleeditor-screen-vpc)는 밝은/어두운 스타일과 요소별 편집을 제공한다. 기존 어댑터에서 새 서비스·스타일 ID를 지원하는지는 별도 확인·개발이 필요하다. 이번에 키·도메인·서비스 활성화·과금 설정을 바꾸거나 SDK를 로드하지 않았다. 요금 페이지 조회가 시간 초과돼 최신 단가를 확인했다고 주장하지 않는다.
