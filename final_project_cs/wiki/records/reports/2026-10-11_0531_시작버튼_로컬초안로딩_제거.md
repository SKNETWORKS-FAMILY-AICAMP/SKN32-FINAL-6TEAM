## 원인과 변경

홈 버튼 경로는 원래 `/trips/new`였다. 설문으로 돌아간 것이 아니라, sessionStorage의 여행 글 초안을 async React Query로 읽으면서 초기 pending 상태에 「여행 정보를 불러오고 있어요」를 그렸다. 변경 전 Chrome 375px·1280px 각 1회 모두 DOM 삽입을 기록했다. 기록은 짧게 삽입된 DOM을 관찰한 것이며 실제 표시 시간은 측정하지 않았다.

초안은 `useSyncExternalStore`로 서버 렌더/최초 hydration 때 빈 문자열을 사용하고, 브라우저에서는 동기 읽기로 복원한다. 입력·임시 저장 경고·로그인 뒤 복원은 유지한다. React Query의 이 초안 전용 조회·캐시·전체 로딩 분기를 제거했다. 다른 API의 React Query 사용은 유지한다.

## 화면과 cs 프로젝트 API의 관계

필수 약관에 이미 동의한 방문자의 일정 입력 폼 자체는 cs 프로젝트 API 응답을 기다리지 않는다. 프런트엔드 경로·코드·이미지 다운로드는 필요하므로 인터넷 완전 단절에서도 첫 화면을 새로 내려받는다는 뜻은 아니다.

「계획 확인하기」를 누르면 기존 진행 화면을 먼저 표시한다. 접수 번호를 받은 뒤 기존 SSE 구독으로 읽기·검증 진행을 따라간다. 실제 오류를 숨기거나 성공으로 표시하지 않는다. 기존 필수 약관의 재확인·SSE 단계·403 차단·새 버전 안내는 별개로 유지한다. 모든 HTTP 요청을 SSE로 바꾸지 않았다.
