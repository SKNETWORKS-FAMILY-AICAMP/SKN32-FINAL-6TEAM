# 날짜 탭 아래 여백

날짜 탭과 전체 자동 추천 버튼 사이에도 실제14px 간격을 확보했다. 날짜 제자리 그림자와 손잡이 간격·가로선 중앙 +는 유지했다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 간격 조정 | 완료 | 1/1 = 100% |
| mock 서버 화면 시험 | 통과 | 4/4 = 100% |
| 정적 검사·표준 생산 빌드 | 통과 | 3/3 = 100% |
| 화면 촬영·확인 | 완료 | 6/6 = 100% |

직전 변경에서 날짜 머리말을10px 내리고 아래 목록 첫머리 패딩64px는 그대로 두어 전체 자동 추천 버튼이 날짜 탭에 붙었다. 목록 첫머리와 스크롤 맞춤 여백을64px에서80px로 함께 늘렸다. 다른 제품 CSS·JS·API는 변경하지 않았다. 초기76px 조정은 Chrome 실측에서 간격10px로 나와 목표12px 검사2개가 실패했고 시각 회귀2개가 통과했다. 이를80px로 보정한 표준 생산 빌드의 최종 실행은4/4 통과했다. 실패 JSON·촬영과 첫 수정 CSS를 [수정 전 백업](../../../_backup/2026-10-11_0349_날짜탭아래여백_수정전/)에 보존했다.

375px·1280px 각각 날짜 그림자4초 전체 주기17시점, 총34시점에서 버튼 간격14~14px·탭/목록 위치 고정·상단 손잡이 가림 없음·초점·스크롤 숨김/복귀·움직임 줄이기·가로선 +·추가 검색/취소 복귀를 확인했다. 목록 시작 패딩의 영향을 받는 펼침/검토/되돌리기 시각 따라오기 회귀도 두 너비에서 통과했다. 변경 시험 TypeScript·ESLint와 최종 표준 Next.js 생산 빌드3/3 통과했다. CSS는 ESLint 대상이 아니다. 기존 목업은 유지하고 새 이름으로 두 너비 각3상태, 총6장을 촬영해 직접 확인했다.
