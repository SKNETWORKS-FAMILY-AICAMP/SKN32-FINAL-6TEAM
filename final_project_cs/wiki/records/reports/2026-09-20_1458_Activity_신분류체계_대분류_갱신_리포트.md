# Activity 대분류 — 관광공사 신분류체계로 갱신

## 1. 작업 목표

`wiki/teams/activity.md`의 "범위 — 관광 분류체계로 못박는다" 절이 근거로 삼던 한국관광공사 관광정보 API **구(舊)분류체계**(A01~A04)를, 사용자가 제공한 팀 스프레드시트의 **신분류체계**(2023년 개편, 대분류 10종)로 갱신한다.

## 2. 실제 수행 내용

- 소스: [팀 스프레드시트](https://docs.google.com/spreadsheets/d/1lCXbot4Ro0BUSnNHp7tVqn5ZXwW0A_xg/edit?gid=1765698897#gid=1765698897) — `신분류체계정보 관광타입정보 연계 정의서` 시트(gid=1765698897). CSV export로 전체 244행(대분류 10종·중분류·소분류) 확보.
- 변경 파일: `wiki/teams/activity.md`
  1. "범위 — 관광 분류체계로 못박는다" 절에 신분류체계 대분류 10종(AC·EV·EX·FD·HS·LS·NA·SH·VE·C01) 대조표를 추가하고, 각 대분류의 Activity 담당 여부와 근거를 적었다. 구분류(A01~A04) 표는 매핑 참고용으로 남겼다.
  2. "걸리는 것" 표의 "쇼핑 분류의 제외 목록"(`[미확보]`, 생활밀착형 21종 제외 목록에 대형마트가 걸려 있던 문제)을 **닫힘**으로 정정 — 신분류체계에서 대형마트(SH03)는 쇼핑 대분류의 정식 소분류이므로 애초에 제외 목록 설계가 잘못됐었다.

## 4. 검증 방법과 결과

문서 수정 작업이라 코드 실행 검증은 해당 없음. 소스 데이터 확보는 다음 명령으로 재현 가능하다.

```bash
curl -s -L "https://docs.google.com/spreadsheets/d/1lCXbot4Ro0BUSnNHp7tVqn5ZXwW0A_xg/export?format=csv&gid=1765698897" -o activity_sheet.csv
```

HTTP 200, 13530 bytes, 244줄 확인.

## 5. 미해결 이슈·다음 작업 제안

- `accepted_case_types`·`knowledge_scope`(manifest 절, `activity.py`)는 여전히 구분류 축 어휘로 남아 있다. 신분류체계로 코드까지 맞출지, 문서만 대조표로 병기할지는 정해지지 않았다 — 코드를 고치기 전에 결정이 먼저다(RULE.md §3.5, Contract-first).
- C01(추천코스)을 Activity가 다룰지 별도 판단 필요.
