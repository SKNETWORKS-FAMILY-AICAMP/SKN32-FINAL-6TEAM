# 손잡이 불투명 가림과 접근 페이드

목록 내용은 손잡이 아래32px 구간에서 위로 갈수록 서서히 사라지며 손잡이 영역에서는 완전히 가려진다. 손잡이 배경과 막대는 선명하게 유지한다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 요청 수정 | 완료 | 1/1 = 100% |
| mock 서버 화면 시험 | 통과 | 8/8 = 100% |
| 정적 검사·표준 생산 빌드 | 통과 | 3/3 = 100% |
| 화면 촬영 | 완료 | 8/8 = 100% |

손잡이에 공통 표면 색과 위쪽 모서리 반경을 주고 목록/날짜 머리보다 위에서 그린다. 기존 목록 마스크는0~32px에서 곧바로 보이기 시작했으므로 손잡이 내부22px에도 내용이 비쳤다. 날짜 머리가 떠 있는 목록의 완전 투명 구간을22px까지, 페이드 끝을54px까지 넓혔다. 날짜 머리가 없는 완료 목록에도 몸체와 손잡이의4px 겹침을 가리는 규칙을 적용한다. 마스크의 불투명 끝은 공통 글자 색 토큰의 알파를 쓰므로 별도 고정 색을 추가하지 않는다. 손잡이 자체와 날짜 탭에는 마스크를 걸지 않는다.

실제 전체 자동 추천을 위로 스크롤하여 접근/페이드/완전 가림 상태를 찍었다. 실제 스크롤 레이어의 배경에 시험용 색을 잠깐 넣고 Chrome이 그린 PNG 픽셀을 읽어 손잡이 영역에서는 완전히 차단되고 아래로 갈수록 점진적으로 보이는지 검사했다. 색상 계측 후 배경을 원래대로 돌리고 펼친 카드도 촬영했다.375px·1280px의 가로 넘침, 키보드 손잡이, 최소 접힘/드래그 복원, 날짜 유휴 표시, 시각 고정 시작점은 유지됐다. 첫10개 시험은 모두 통과했지만 날짜 없음 변형이 변환 과정에서 무시돼 같은 화면을 중복 확인했다. 그 변형을 제거하고 최종8개를 새 빌드에서 재실행했다. 날짜 없는 긴 목록은 실화면 회귀 확인 범위가 아니다.
