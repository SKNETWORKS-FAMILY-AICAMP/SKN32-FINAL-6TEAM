## 적용한 동작

- 지도 거리 단추는 가로·세로 모두 메뉴와 같은 폭 44px이다. 기존 높이 40px와 배경 불투명도 92%를 유지했다. 아래로 펼칠 때 거리 아래에 화살표를 둔다. 가로 배치 공간 계산도 실제 44px를 쓴다.
- 잠금은 아이콘 내부만 연하게 채운다. 버튼 배경·테두리 강조와 잠금 때문에 생기던 카드 배경·선택 후광은 제거했다. 키보드 초점은 아이콘 선 두께·색과 도움말로 보인다. 잠금 기능·재확인 경고는 유지했다.
- ‘고정 풀기’ 상자는 마우스·키보드 초점에서만 나오는 도움말이므로 유지했다. 평소에는 숨긴다.
- 전체 자동 추천은 스크롤 목록 첫머리의 일반 요소다. 목록을 내리면 위로 사라지고 최상단으로 돌아오면 다시 보인다. 기존 위치가 이 구조여서 위치를 옮기지 않고 일반 배치를 명시하고 동작을 시험했다.

## 검증 범위

mock 서버 시험 고유 20/20 (화면 반응). 첫 실행 17/20, 보완 실행 3/3으로 20개를 확인했고, 최신 약관 원본으로 다시 빌드해 추가 요청 6/6을 재확인했다. 거리 숫자는 글자의 실제 영역이 버튼 안에 있는지도 2/2로 확인했다. 고유 집계에서 반복 실행을 중복 계산하지 않았다.

실서버 확인 (서버 응답): 안 했음. 공개 cs 프로젝트 서버의 응답 확인과 배포는 이번 작업 범위에서 수행하지 않았다.

지도 계산 17/17, TypeScript·ESLint·Next 생산 빌드 통과. Chrome에서 375px와 1280px 화면을 촬영했다. 제품 변경 파일은 지도 제어 TSX·지도 CSS·일정 CSS 세 개다.

첫 시험의 세 실패 중 하나는 디스크 공간 부족으로 추적 파일을 쓸 수 없었던 것이고, 둘은 시험 자료에서 확인 필요 항목을 없애 공통 대기 조건에 맞지 않았던 것이다. 본인 시험 빌드 캐시만 정리하고 시험 자료에 확인 필요 항목을 유지해 재확인했다. 새 촬영 중 공유 약관 원본과 mock 자료가 갱신돼 기존 빌드와 불일치한 실행은 중단했고, 현재 원본으로 재빌드했다. 관련 약관 제품 코드는 이 변경 묶음에 포함하지 않는다.
