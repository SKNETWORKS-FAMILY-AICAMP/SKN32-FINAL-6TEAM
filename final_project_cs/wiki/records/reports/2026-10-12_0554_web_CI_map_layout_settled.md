# 지도 도구 배치 반영 뒤 화면 너비 검증

세 번째 팀 develop 전체 화면 실행은 649개 통과·1개 실패·기존 조건부 제외13개였다. 실패는 375px 위치 지정 취소 뒤 목록 높이를 네 번 바꾸고 확장한 지도 도구의 너비 검사다. 펼침 aria-label은 반영됐지만 너비는44px로 세로 배치 값을 읽어 기존 조건인 접기 버튼 너비의 두 배 초과(88px 초과)를 만족하지 못했다.

목록 높이의 React 반영과 지도 ResizeObserver의 배치 계산은 다른 시점이다. 펼침 라벨 확인만으로 가로 배치 완료를 증명할 수 없었다. 제품 코드는 그대로 두고 시험이 `data-direction=row`를 확인한 뒤 같은 프레임에서 묶음/접기 버튼 너비 비율을 반복 측정하여 기존 두 배 초과 조건을 검사한다. 임의 sleep·재시도 횟수 증가·skip 추가·너비 조건 완화는 하지 않는다.

검증: mock 서버 화면 시험 20/20 통과(375px·1280px 각각10회), 린트·타입 검사 통과. 제품 빌드는 앞선 통과 빌드 그대로이며 변경은 이 시험과 보고서2파일뿐이다. 실서버 확인(서버 응답): 이 후속 수정에서는 하지 않았음. 전체 추적 파일의 인프라 검색 원문과 두 파일 검사 결과를 비공개 검증 폴더에 보존한다. 네 브랜치의 최종 전체 CI는 이 커밋에서 다시 확인한다.
