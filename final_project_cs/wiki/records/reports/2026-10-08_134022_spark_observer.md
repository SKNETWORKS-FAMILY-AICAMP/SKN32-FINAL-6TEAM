# GPU 서버 B의 새 학습 단계 관측 검증

[실측] 새 Spark 학습 단계와 다음 다운로드의 공간 대기를 로컬 관측 도구가 구분하도록 보완하고 실제 GPU 프로세스 관측1/1회로 확인했다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 실제 관측 도구 실행 | 통과 | 1/1회 = 100% |
| GPU 서버 A 대기 입력 확인 | 통과 | 8/8개 = 100% |

[수정한 도구](../../../../program/scripts/plan_qa_bench/record_gpu_routine_observation.py)는 일일 기록에서 감사한 모델·학습 또는 기본 평가 단계와 실제 프로세스가 일치할 때만 상태를 기록한다. 현재 단계가 바뀌거나 새 완료·실패가 있으면 결과 회수·재감사를 요구한다. 대기 작업 수는 저장한 현재 숫자로 읽어 완료된 이전 모델을 계속 학습 중으로 표시하지 않는다.

현재 Spark 임시 입력이 있는 동안 다음 모델 다운로드 공간은 충족으로 표시하지 않는다. 기존 B54의 현 학습·평가·임시 입력 정리 뒤22GB 기준을 재확인하는 준비 대기를 명시한다. 이후 단계는 자동으로 이 예외를 적용하지 않는다. 실행기·원격 학습 순서·삭제 동작은 수정하지 않았다.

[실제 관측 검증 결과](../../../../program/scripts/plan_qa_bench/results/gpu_backlog_20261008/routine_observation_1337.json): A 준비8개, B 기존 기반2개·다운로드 준비1개이며 새 완료·실패0이다. 모델 평가 원본 및 학습판 산출물은 [별도 완료 리포트](2026-10-08_133908_winnow_eval_queue.md)를 따른다.
