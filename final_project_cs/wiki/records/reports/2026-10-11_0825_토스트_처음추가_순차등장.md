# 상단 안내·처음 추가·일정 순차 등장 수정

계획 확인 화면의 상단 임의 문단을 없애고 기존 알림 토스트로 통합했다. 맨 위 추가는 첫 일정 앞에 표시한다. 질문 뒤 지도 목록과 마커는 순서대로 나오며 읽기 진행은 완료 상태를 유지한다.

## 변경과 원인

PlanCheck의 임의 ReactNode 안내 슬롯이 지도 머리와 겹쳤다. 이 슬롯을 토스트 데이터만 받게 바꿔 같은 위치에 임의 문단을 다시 끼우지 못하게 했다. 접수 전송·연결 지연·시험 계획·확인 실패·연도 가정·계획 생성 요청 안내를 기존 ToastView로 표시한다. 같은 문구는 반복해서 띄우지 않는다. 지도 화면에서 공통 토스트를 받을 때 머리줄·본문·상태·오류 유지·동작 속성을 그대로 전달한다.

추가 위치 선택에는 맨 아래 우선 규칙만 있었다. 이제 맨 위에서는 첫 일정 앞을 우선하며, 내려갔다가 맨 위로 돌아와도 즉시 복원한다. 중간에서는 기존 가까운 삽입선을 고르고, 맨 아래에서는 마지막 일정 뒤를 유지한다. 첫 삽입선에48px 높이를 확보하고 중앙에 선·44px 누름 영역을 둬 첫 카드와 겹치지 않게 했다. 첫 일정 앞 저장의 실제 순서와 시작 시각08:00 초안도 검사했다.

질문 해제 때 전체 완료 결과를 즉시 보여 주던 처리 때문에 첫 지도 목록까지 한 번에 표시됐다. 이제 질문에서 아직 보지 못한 지도 목록만 빈 checking 상태에서 시작한다. 완료된 원문 읽기·진행 막대는 재생하지 않는다. 지도 머리의 진행 표시는 실제 완료 응답을 사용해100%에서99%로 되돌아가지 않는다. 완료 접수 재열기, 저장 후 수정, 메뉴의 애니메이션 건너뛰기는 즉시 표시를 유지한다. 기존 동작 줄이기 설정은 계속 적용한다.

접힌 카드의 문제 항목은 사용자가 선택한 비교안처럼 확인 필요 바로 왼쪽에 모았다. 두 묶음 사이12px, 카드 내부12px를 확보하고 문제가 많으면 줄바꿈한다. 상태는 맨 아래 오른쪽에 남고 펼친 카드의 자세한 설명은 유지한다.
