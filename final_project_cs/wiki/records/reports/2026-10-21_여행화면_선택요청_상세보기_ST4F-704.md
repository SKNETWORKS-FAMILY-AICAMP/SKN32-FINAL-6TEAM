# 여행 화면 — 선택 요청 일정 표시 · 상세 보기에서 고르기 · 일정 수정 바로 열기 (ST4F-704)

작성 2026-10-21 · 티켓 ST4F-704 · 가지 `feat/web-trip-card-proposal-mark-20261021` (role-eval-ui `78a1689c` 에서 땀) · 목업 [tripilot-trip-card-proposal-mark.html](../../../frontend/apps/web/mockups/tripilot-trip-card-proposal-mark.html)

## 어디서 시작했나

사용자 질문 「수정 모드에 들어가면 로딩이 생긴다 — 이미 있는 일정을 다시 검사하나」(약 16초: 이동 재계산 약 11초 · 바깥 위험 재조회 약 5초 — 서버 쪽은 ST4F-705)에서 「서버가 확인이 필요하다고 보낸 일정이 카드에 뜨나」로 이어졌다. 확인 결과 감시의 「먼저 묻기」 제안(`proposal_request`)은 **카드에 표시한 적이 없다** — 10-07 이전엔 화면 위 「선택이 필요해요」 칸, C안(10-07~08)부터 종 뒤 알림 센터에만 있었다.

## 사용자 결정 (2026-10-21)

- 카드 표시는 **D안**: 계획 확인 「확인 필요」처럼 카드 전체 경고색 + 「선택이 필요해요 · 서버 문장」 줄(위험 「주의」 줄 모양).
- 카드의 단추는 알림 센터가 아니라 **「상세 보기」**로 — 고르기는 상세 보기 카드 안에서.
- 상세 보기에 **「직접 수정」** — 수정 모드를 그 일정의 바꾸기 화면으로, 「직접 고치기」를 펼친 채 연다.
- 상세 보기의 **모든 일정**에 수정 모드로 바로 가는 단추 — 카드의 「n일차 시각」 줄 오른쪽 끝 ✎ 「일정 수정」, 크기는 「전체」 일차 칩 모양(처음 판의 아래 단추 줄 「이 일정 수정」은 「크기가 너무 크다」로 바꿈).
- 날씨만 걸린 제안의 「바꿀까요?」 한 단계(②)는 **지금처럼 둔다**(9-29 결정 — 대안 찾기는 후보마다 바깥 점검 비용). 대신 서버가 대안을 찾는 동안 **일정 칸을 회색으로 잠그고 「서버로부터 대안을 받고 있습니다.」**(사용자 문구).
- 알림 센터 · 상단 알림은 그대로 둔다(같은 제안 — 어느 쪽에서 답해도 다른 쪽에서 빠진다).
- (17:4x 사용자 화면 확인 뒤) 카드 줄의 「상세 보기」 단추는 **뺀다** — 펼친 카드의 「상세 보기」와 겹쳤다. 대신 「상세 보기에서 확인하세요」 한 줄. 상세 보기의 **「입력한 메모」 줄도 뺀다** — 고객이 메모를 적는 칸이 없고 서버가 보내는 메모도 없어 「등록된 메모가 없어요」만 보였다.

## 확인하다 찾은 결함

- **「직접 수정」으로 열면 바꾸기 화면 후보 자리에 「그 일정은 이미 없어요」**(17:2x 로컬 실서버). 원인: 수정 모드 값이 처음 도착한 그 커밋에서 계획 확인의 열기 효과(자식)가 수정 화면 훅(부모)의 효과보다 먼저 돌아, 훅이 아직 받지 못한 판으로 후보를 물었다(`use-server-review.ts` 의 `plan()` → `item_gone`). 10-19 채팅 「직접 고르기」(같은 `opening.change`)도 같은 길이라 같은 결함이 있었을 것으로 본다(이번에 재현은 「직접 수정」으로만). 처음엔 훅의 판 넘기기를 `useLayoutEffect` 로 앞당겼으나 계획 확인 시험 3파일의 React 흉내와 맞지 않아 되돌리고, 열기 쪽에서 `requestAnimationFrame` 한 번 미뤘다 → 후보 1/4 정상.

## 남은 일 · 확인하지 않은 것

- 결과 막대 문구(고른 곳으로 바꿈 · 그대로 둠)는 서버 응답 200 까지 확인 — 막대 글자 자체는 사용자 화면에서만 봄(스크린숏 없음). 「이미 정해짐」 거절은 미확인.
- 상단 새 알림 막대는 선택 요청이어도 지금처럼 「알림 보기」(알림 센터)로 간다 — 상세 보기를 보고 있을 때 같은 일정 알림이 막대로도 뜬다(이번 범위 밖 · 사용자 판단 필요).
- 선택 칸의 서버 문장은 알림 센터와 같은 함수(`openChoices` — 그 제안의 첫 알림 문장)라, 대안을 받은 뒤에도 「「예보에 맞게 일정 변경」을 누르면…」 문장이 남는다(대안 알림 문장은 대안 목록을 다시 늘어놓는 긴 글). 바꿀지는 따로.
- 수정 모드 열기 기다림은 ST4F-705(서버). 오늘 로컬에서는 캐시가 따뜻할 때 3초 · 차가울 때 16~20초로 흔들렸다 — 705 에서 차가운 상태로 잰다.
