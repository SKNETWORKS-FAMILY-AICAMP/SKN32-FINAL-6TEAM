# 구구루트 여행 질의 모델 — SFT 지식 증류 학습·평가 계획 (2026-10-31)

작성: Claude Opus 5.5 하위 작업자(계획·준비 전용). **학습 0, 제품 모델 추론 0, 유료 API 0, 업로드 0, 배포·서버 변경 0, 다른 평가자 파일·DB·lease 쓰기 0.**

## 0. 결론

1. **지금은 학습을 시작할 수 없습니다.** readiness 점검 결과는 `NOT_READY`입니다(pass 6 · fail 1 · blocked 4, 아래 §11). 막는 조건은 다섯 가지입니다. 현행 모델 기준선이 없고(평가자 실측 0/47 답변), 학습 툴체인이 없고(0/7 모듈), GPU를 다른 작업이 쓰고 있고(사용률 90%), 커밋 메모리가 부족하고(8.2GB 여유, 필요 12GB), 학습 승인이 없습니다.
2. **방향은 RL 없는 SFT 시퀀스 증류입니다.** 교사 출력을 정답 토큰으로 학습합니다. 첫 대상(Track A)은 **구조화 결정**으로, 제품 스키마 enum JSON(할 일·대상 id·근거 인용)만 학습합니다. **사용자에게 보이는 자연어 답변(Track B)은 별도 adapter·별도 평가로 분리**하고 A의 결과를 본 뒤 시작합니다. 영업시간·가격 같은 현재 사실은 가중치에 넣지 않습니다. 이런 값은 검색·DB 근거에서만 가져옵니다.
3. **학생은 현재 서빙 E4B입니다.** 원본(`tripilot-pointer:e4b-ft`)은 바꾸지 않습니다. 후보는 새 이름의 격리 사본과 새 adapter로 만듭니다. 다른 학생 모델로 바꾸는 것은 서빙 변경이므로, 짝지은 근거가 생긴 다음에 따로 판단합니다.
4. 문헌(원문 확인 6편)은 이 방향을 지지합니다. 단, 각 논문의 실험 조건이 우리와 달라 **효과 크기는 가설**로만 둡니다(§13).

## 4. 범위

- **포함**: 시퀀스 증류 SFT(교사 출력을 고정 정답으로 쓰고 정답 토큰에만 손실). 2단계로 진행합니다. 합성 데이터로 먼저 학습한 뒤, 사람이 검수한 자료로 보정합니다(§6).
- **제외(사용자 지시)**: 강화학습, 보상 모델, 선호 최적화.
- **보류(근거)**: on-policy·로짓 KD(GKD 등). 같은 토크나이저를 쓰는 white-box 교사의 토큰 분포와 학습 스택이 필요한데, API 교사로는 할 수 없습니다(2606.22942 §3.2 `[문헌-원문]`).
- **분리**: Track A(구조화 결정 adapter)와 Track B(자연어 답변 adapter)를 한 학습 세트에 섞지 않습니다. 검사기에서 `E_TARGET_TYPE_MIX`로 실패 처리합니다.

## 6. 교사 선택과 합성 라벨 검증

- **교사는 교사 자체 점수로 고르지 않고 학생 개선량으로 고릅니다.** 근거는 GRACE 원문입니다. 교사 성능과 학생 결과의 상관은 0.11이었습니다(GSM8K·LLaMA-1B, 15 교사) `[문헌-원문]`. Capacity gap과 Polyglot Teachers도 같은 방향이지만 `[문헌-초록]`입니다. 절차는 다음과 같습니다. 교사 후보 2~3개 × 같은 입력 소규모 pilot × 같은 레시피로 학습하고, select 분할에서 학생 향상을 비교합니다.
- **교사 후보 종류**: ① 로컬 오픈 대형 모델(과거 769에서 26B-A4B 95.19%·Qwen3.8 97.4% `[기록]`, 다른 과제·다른 코드). 지금은 GPU·메모리 경합으로 적재할 수 있을지 확인되지 않았습니다. ② 유료·구독 API 교사. synthetic만 보내고 승인을 받아야 합니다. 비용은 개발 도구 장부에 따로 적습니다(참고: 오늘 Claude 네이티브 검색 명목 $0.739+$0.302, 구독 차감).
- **라벨 필터(순서대로)**: 제품 스키마로 제약한 생성 → 서버 검증기(`edit_intent.validate`, `guard_target`, 근거 인용이 원문에 있는지) 통과 → 다른 계열 검증자 일치 또는 사람 승인 → 거절률·유형 기록 → 층화 표본 사람 감사. 검사기에서 `E_LABEL_UNVALIDATED`·`E_VERIFIER_SAME_FAMILY`·`E_HOLDOUT_AUTHOR_TEACHER`로 확인합니다.
- **선별 대조**: 같은 토큰 예산으로 무작위 선택과 품질·다양성 선별을 비교합니다(Xia 2025 `[문헌-초록]`).
- **결함 기반 커리큘럼(선택)**: select 분할에서 학생 결함(M1~M6)을 진단하고 그 유형의 합성 데이터를 보충합니다. 2602.12172 원문의 Identifier도 seed 데이터의 validation 부분으로 진단합니다. 반복 진단은 select 분할에 과적합하므로 최종평가는 반드시 분리합니다. 이 논문의 「망각 없음」 주장은 수치 없이 관찰만 제시해서 우리 회귀 관문을 대신하지 못합니다.
