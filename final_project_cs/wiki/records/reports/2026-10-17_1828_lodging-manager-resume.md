- 같은 시각 실제 API 실행 파일에서도 공통 완료 조건과 날짜별 숙소 계산 보완을 확인하지 못했다. 웹 실행판은 기존 지도 경로 수정판이었다. 재난 관련 매니저 반영·배포는 다른 세션에서 끝난 것으로 확인해 반복하지 않는다.

## 같은 실행판에서의 추가 검증

숙소 app 5개 파일의 변경만 현재 운영 이미지 위에 3방향 병합했다. 다른 기능의 Python 448개는 후보 이미지에서도 현재 운영 이미지와 같은 해시였다. 운영 환경·이미지 해시·개별 파일 대조 결과와 실행 로그는 커밋 대상 밖 기록에 보관했다. 준비 담당은 후보 빌드까지만 수행했으며 실제 서비스 컨테이너·운영 DB 스키마·원본 로컬 자료는 변경하지 않았다.
