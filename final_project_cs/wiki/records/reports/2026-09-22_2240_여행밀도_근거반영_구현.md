# 여행 밀도 추가 조사 반영

2026-09-22 사용자 요청에 따라 [조사 보고서](2026-09-22_2230_여행밀도_근거조사.md)를 작성하고 API 계약 1.1과 계산기를 보강했다. 관련 테스트는 62/62(100%) 통과했다.

## 실제 반영

- `density.py`: level 대신 직접 `target_density`를 받을 수 있다. 둘을 동시에 지정하면 미측정 경고다. `policy_basis`로 사용자 선호/추정 프리셋/판정 불가를 구분한다.
- `density.py`: 일정·별도 이동·완충·이동 부분합·대기 부분합·대기 주석 누락 수·미배정 시간을 제공한다. `queue_minutes`는 항목 길이에 포함된 주석이므로 다시 더하지 않는다. 잘못된 대기 값은 미측정으로 처리한다.
- `guardrails.yaml`: 정책 식별자와 조사 기준일 추가. 프리셋은 실측 근거가 없으므로 [추정]을 유지한다.
- `travel-density.md`: 코드 수정 전에 선택 확장 1.1 계약과 해석 범위를 기록했다. `rest-api.md`, D-019, wiki 로그를 연결했다.
- 단위 테스트와 실제 DB API 테스트에서 직접 목표 및 기존 프리셋 등록/재전송/조회를 확인했다.

## 근거로 바뀐 판단

시간 점유율은 개인 선호다. 전체 가용시간에 들어온다는 사실만으로 피로·정시도착을 보장하지 않는다. 대기도 일정 비용이며 이미 예약 구간에 들어간 시간은 중복 합산하지 않는다. 총 완충시간이 남아 있어도 필요한 구간에 배정되어 있음을 보장하지 않으므로 `buffer_placement: unallocated`로 표시한다.

자료별 링크와 원문 확인 범위는 조사 보고서에만 집중했다. 새로 찾은 수치를 끼워 맞춰 기존 임계값을 검증된 값으로 바꾸지 않았다. 실제 관측을 이용한 이동 버퍼 보정·프리셋 검증 절차도 그 보고서에 있다.
