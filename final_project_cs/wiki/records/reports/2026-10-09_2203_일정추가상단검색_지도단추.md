# 일정 추가 상단 검색·취소와 지도 단추 수정

일정 추가에서도 기존 장소 수정과 같은 상단 검색을 사용하고, 뒤로가기와 왼쪽 빈 배경의 오른쪽 스와이프로 취소하도록 반영했다. 지도 눈금은 화살표·거리 버튼으로 합쳤으며 최신 프론트 화면만 새 목업으로 촬영했다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 변경 묶음 | 완료 | 3/3 = 100% |
| mock 서버 화면 고유 시험 | 통과 | 33/33 = 100% |
| 관련 단위 시험 | 통과 | 40/40 = 100% |
| 휴대폰·넓은 화면 촬영 | 완료 | 10/10 = 100% |

## 달라진 동작

1. **상단 검색·추가 취소**: 일정 사이 `+`를 누르면 해당 삽입 위치를 유지한 채 상단 로고·제목이 뒤로가기와 검색창으로 바뀐다. 하단에는 검색 결과만 표시하고, 장소를 고르면 날짜·시각·이름·종류 입력을 표시한다. 장소의 좌표·출처와 선택한 삽입 위치를 기존 추가 요청에 그대로 전달한다. 취소는 저장 요청을 보내지 않고 원래 `+`로 초점을 돌린다.
2. **스와이프 취소**: 왼쪽 빈 배경에서 시작한 오른쪽 가로 스와이프만 취소로 처리한다. 입력칸·버튼·지도에서 시작하거나 먼저 세로로 움직인 동작은 제외한다. 저장 중에는 뒤로가기와 스와이프 취소를 막고, 저장 거절 시 입력과 장소 선택을 보존한다. 기존 전날/다음날 전환과 같은 애니메이션 및 움직임 줄이기 처리를 공유한다.
3. **지도 표시**: 별도 눈금 막대를 없애고 접기 버튼에 화살표와 현재 거리(예: `500m`)를 넣었다. 아래 공간이 넓으면 아래로, 낮으면 옆으로 펼친다. 기본 접힘·5초 자동 접힘·지도 이동 중 숨김을 유지한다. 거리 칩은 실제 단추 영역만 피하며 해당 높이에 단추가 없으면 화면 오른쪽 끝에 붙인다. 일정 번호는 채운 배지, 거리는 구분선 뒤의 가벼운 글자로 나눴다. 장소·확인 수·변경 수·되돌리기는 독립 칩 디자인을 유지한다.

낮은 지도에서 선택 마커와 거리 칩이 겹치는 실제 사례도 발견해 마커 빈 칸 탐색의 상단 경계를 보완했다. [재현·보완 기록](debugs/2026-10-09_2154_낮은지도_마커거리칩겹침.md).

## 확인 범위와 근거

- mock 서버 시험 **33/33 = 100% (화면 반응)**: 새 사례 6, 기존 일정 삽입 4, 지도 도구 7, 지도·세부 수정 13, 자동 접힘·이동 숨김·40개 밀집 마커 3. 세 실행의 같은 사례는 최신 결과로 집계했다. 지도 도구 첫 사례는 기대 디자인 변경으로 이름이 바뀌어 같은 사례로 합쳤다. [집계 JSON](../evidence/2026-10-09_add-header-map/add-header-map-summary.json).
- 최종 수정 후 직접 재실행한 브라우저 시험은 **13/13**이다. 여기에는 375px/1280px 선택 마커·거리 칩·가로 도구 겹침 검사, 상단 검색·취소, 저장 중 취소 차단, 자동 접힘, 지도 이동 중 숨김, 밀집 마커가 포함된다. [최종 실행 JSON](../evidence/2026-10-09_add-header-map/add-header-map-run3.json).
- 관련 단위 시험 **40/40**, TypeScript 및 수정 파일 ESLint 통과. 단위 시험 대상은 지도 가장자리 배치·마커 배치·가시성·삽입 위치·새 일정 입력이다. [명령 출력](../evidence/2026-10-09_add-header-map/add-header-map-checks.txt).
- 이전 실패는 두 종류였다. 기존 눈금 위치 기대값·저장 중 비활성 버튼 클릭 방법을 새 계약에 맞춰 고쳤다. 선택 마커를 포함한 시험에서 발견한 실제 겹침은 구현을 보완했다. 실패 때문에 누락됐던 화면도 새 판에 모두 다시 촬영했다. 실행 원본 3개는 [근거 폴더](../evidence/2026-10-09_add-header-map/)에 보존했다.
- 실서버 확인 **(서버 응답): 안 했음**. 실제 cs 프로젝트 서버의 일정 추가 응답·외부 로그인·Google/Naver 지도 SDK 런타임은 이번 확인에 포함하지 않았다. x600 서버 배포·커밋·푸시는 하지 않았다.
