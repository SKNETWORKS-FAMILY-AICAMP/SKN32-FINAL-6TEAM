# 운영앱·관리자앱 화면과 업무 흐름 고도화

2026-10-03 · Codex · `role-eval-ui` · 기준 `1ec6111` + 미커밋 변경. 사용자 지시: 클로드는 사용자 웹을 계속 개발하고, Codex는 운영앱·관리자앱의 화면과 업무 흐름부터 개선한다. 이번 티켓은 생략한다.

## 목표와 범위

운영앱에서 상세 확인 후 원래 목록 작업을 이어가고, 관리자앱에서 오류를 찾아 발생 근거를 확인하는 첫 흐름을 제공한다. [운영앱 기획](../../../frontend/apps/admin/SCREEN_PLAN.md)의 기존 화면과 [관리앱 기획](../../../frontend/apps/dev-console/SCREEN_PLAN.md)의 M-01~M-03 범위다. 새 HTTP 계약·실제 운영 정책을 확정하지 않는다.

## 변경 내용

- 운영앱: 사용자 검색·필터·정렬과 문의 검색·상태·담당 필터를 화면 이동 동안 유지한다. 새로고침·데모 초기화는 조건을 비운다. 차단·해제 성공 후 확인창을 닫고 사유를 비우며 실패하면 입력을 보존한다. 같은 앱 소스로 단일 HTML을 재생성한다.
- 관리자앱: 관리 홈 → 오류 검색·상태/심각도/출처 필터 → 발생 상세를 읽기 데모로 제공한다. 검색 조건과 선택한 발생은 URL에 보존한다. 잘못된 식별자는 찾을 수 없음으로 표시한다. 총 발생과 예시 개수, 영향 사용자 0과 미수집을 구분한다. 기존 팀·코어 테스트와 사례 비교를 유지한다.
- 문서: 관리앱 화면 기획과 API 협의 진입점을 추가하고 기존 테스트 계약과 연결한다. API·인증·상태 변경은 협의 필요로 남긴다.

## 검수와 검증

운영앱 단위 23/23·브라우저 22/22, 관리자앱 단위 55/55·브라우저 12/12로 합계 **112/112 = 100%**다. 두 앱의 린트·타입 검사·빌드, 운영앱 단일 HTML 재생성 일치 검사도 통과했다. PC·모바일 캡처를 부모가 직접 확인했다. 최초 시험 선택자 실패와 수정·최종 결과는 [실행 근거](../evidence/2026-10-03_0238_운영앱_관리자앱_검증.md)에 구분해 기록했다.

독립 정적 리뷰에서 서버 대표 오류 묶음에 속한 상시 작업 발생이 출처 필터에서 누락되는 문제를 찾아 관련 출처 합집합으로 고쳤다. 부모 리뷰에서는 부분 검색과 상세 발생 선택의 일치 기준 차이를 찾아 함께 고쳤다. 두 수정의 회귀를 추가했다. 사용자·문의 목록 맥락과 차단 확인의 [발견 결함](debugs/2026-10-03_0238_admin_목록맥락과_차단확인.md)도 별도로 기록했다.

마지막 부모 검토에서 관리자앱의 미제출 검색어를 입력한 뒤 동일 URL로 초기화하면 입력값이 남는 경로를 발견했다. 검색 폼 초기화와 URL 초기화를 함께 수행하도록 보완하고 최종 브라우저 회귀에서 확인했다.

## 남은 범위

실제 오류 수집·관리 API와 개발자 인증, 운영앱 live 연결, 실제 서버·브라우저 통합은 미완료다. 이 작업의 데모 성공을 실서버 연결 완료로 표시하지 않는다. M-04 이후 요청 추적·상시 작업·연결 점검과 오류 상태 변경은 후속 범위다. 전체 앱 고도화 완료율은 분모 미정이다.

기존 사용자 웹 변경과 미커밋 관리 시나리오 목업을 보존했다. 새 디렉터리·공통 규칙 변경·백엔드 수정은 없다. 커밋·push·배포를 수행하지 않았다. TeamFlow는 조회 실패/자동 승인 거절 뒤 사용자가 생략을 선택하여 발행하지 않았다.
