# UIUX 매니저 반영 준비 — 2026-10-10

UIUX 완료 인계 두 묶음을 원격 매니저 기준 위에 격리 통합했다. 추가 사용자 화면 수정의 새 완료 연락을 기다리는 중이며 아직 이번 변경을 커밋·푸시하지 않았다.

## 범위와 기준

기준 커밋은 `bd0239b09bb5891d39d3aaf78fdc3f6b189e79b1`이다. 기존 LLM 키 전환 수정은 보존했다. 설문 자유입력, 일정 직접 추가·편집·복원, 게스트 계정 이관, 약관 실시간 진행, 지도·카드·계정 화면과 선택 항목 시각 표시를 통합했다. 공유 작업본 대신 별도 격리본만 변경했다. 다른 이동 계산·시뮬레이션·GPU·RAG 작업은 포함하지 않았다. 대상은 팀 저장소 `role-manager`뿐이다.

## 검증과 발견한 결함

- 웹 단위 613/613, ESLint, 생산 빌드 통과. 변경 백엔드 ruff 통과.
- 관련·계약·보안·API 시험 첫 실행은 402/403 통과. 설문의 bus/subway 연결 누락을 최소 두 매핑으로 복원했고 후속 집중 시험 80/80 통과. 403개 전체를 수정 후 한 번에 다시 실행한 수치는 아니다.
- 첫 통합본 완료 기준 26/26, MVP18/18 통과. 이후 집중 수정에는 해당 기능 시험을 적용했다.
- mock 서버 시험 28/28 (화면 반응): 앞선 27개 통과에 디스크 기록 실패 1개 재시험 통과를 합쳤다. 마지막 시험의 최초 기록 실패를 제품 동작 실패로 세지 않았다.
- 추가 화면 회귀 첫 실행은 48/55 통과, 5개 실패, 촬영 HTML 변수 미설정 2개 건너뜀. 실패 항목 수정과 갤러리 읽기 시험은 후속 검증 중이다.
- 실서버 확인 (서버 응답): 했음 — 로컬 개발 전용 DB와 TestClient의 설문·약관·일정 잠금·복원. 안 했음 — 공개 cs 프로젝트 서버의 변경 후 응답, 실제 외부 소셜 로그인, x600 서버 배포 확인.

신규 화면의 색상 직접 지정 19줄은 기존 색상 규칙 시험과 충돌해 역할 변수로 옮겼다. 이 변환 중 작업자가 `white-space` 속성26개와 브랜드 흰색 참조4개를 잘못 바꿨으며 푸시 전에 원복했다. 줄바꿈 복원 후 모바일 정렬 4건이 통과했다. 정의되지 않은 색상 역할 전수 검사 결과는 0건이다. guardian tooltip 선택자에 지역 클래스를 추가했고 CSS composes 대상 선언 순서를 바로잡았다.

생산 빌드의 CSS 클래스 이름을 고정 접미어로 찾던 화면 시험에는 안정된 DeviceFrame 속성과 실제 요소 선택자를 적용했다. 화면의 검사 기준은 유지했다. 같은 문제를 해결한 화면 담당 브랜치의 최소 접근을 참고했으며 브랜치 전체는 병합하지 않았다.

## 보안과 보존

텍스트 3787개·바이너리 제외186개의 검사에서 차단 항목은 없었다. 이후 추가된 보고·시험 파일과 최종 stage는 푸시 전에 다시 확인해야 한다. git grep 원문은 개인 검증 폴더에 보존했다. 백업은 변경 파일 옆 `_backup/`의 `.bak`로 보존하며 커밋 목록에서 제외했다. 디스크 부족 시 이번 격리본의 재생성 가능한 Next 캐시만 정리했다. 원본·증거·백업은 보존했다.

## 근거와 남은 작업

실행 원문은 [검증 증거](../evidence/2026-10-10_uiux-release/)에 있다. 현재 파일 목록은 같은 폴더의 별도 manifest로 확정한다. 새 UIUX 완료 인계를 통합한 뒤 영향 범위 재검증과 최종 보안 검사, 매니저 커밋·푸시를 수행한다. develop과 main에는 푸시하지 않는다.
