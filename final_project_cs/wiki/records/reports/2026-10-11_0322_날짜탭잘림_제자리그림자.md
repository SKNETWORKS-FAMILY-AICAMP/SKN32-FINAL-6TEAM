# 날짜 탭 잘림·제자리 그림자

날짜 탭의 반복 상하 이동을 없애고 제자리 그림자 불투명도 변화로 교체했다. 손잡이 아래10px 간격과 스크롤 영역 내부12px 그림자·초점 테두리 여백을 확보했다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 원인 확인·교체 | 완료 | 2/2 = 100% |
| mock 서버 시험 | 통과 | 6/6 = 100% |
| 정적 검사·표준 생산 빌드 | 통과 | 3/3 = 100% |
| 화면·영상 | 완료 | 7/7 = 100% |

수정 전 Chrome 실측에서 날짜 줄은 상하 여백0px이고 overflow-y:auto였다. 탭 상단이 손잡이 끝에 붙어 있으며 -2px 이동 때 손잡이 뒤로 들어간다. 외부 그림자도 스크롤 영역에서 잘린다. 이전 시험은 이동량만 확인하여 실제 가림을 놓쳤다. [디버그 기록](debugs/2026-10-11_날짜탭부유_손잡이가림.md)에 원인과 재발 방지 범위를 남겼다.

4초 주기로 그림자 가상 요소의 opacity .2~.65만 변화시킨다. 탭·글자·선택 배경·목록은 이동하지 않는다. 상하12px 패딩과 음수 여백으로 탭 스크롤 영역의 그림자 공간을 확보하고 가로 정렬을 유지했다. 손잡이와 날짜 사이10px를 추가하여 손잡이와 그림자가 겹치지 않게 했다. 마우스·키보드 초점·드래그에서 효과를 멈추고 움직임 줄이기에서는 정적 그림자를 쓴다. 기존 스크롤·지도 조작 중 숨김과 복귀를 유지한다. 사용자 선택 가로선 중앙 +와 선 애니메이션은 변경하지 않았다.

375px·1280px에서4초 전체 주기를250ms 간격으로17회씩 계측했다. 탭·선택 배경·목록 위치 고정, 손잡이 간격10px 이상, 상하 그림자 여백12px 이상, 실제 화면 상하단 버튼 hit test를 검사했다. 포인터/초점 정지·스크롤 숨김/inert/복귀·움직임 줄이기·선 밝기/중심/44px영역·추가 검색 초점/취소 복귀·쓰기 요청 없음·가로 넘침 없음을 검증했다. 새 시험과 기존 날짜·폼 회귀를 합쳐6/6 통과했다. TypeScript·변경 시험 ESLint·표준 Next.js 생산 빌드3/3 통과했다. CSS는 ESLint 대상이 아니다.

새 화면6장과 실제 Chrome60프레임의12초 영상을 새 이름으로 보존했다. 두 화면 너비와 영상 시작/그림자 최대/후반 프레임을 직접 확인했다. 전체 시점의 위치·잘림은 자동 계측으로 확인했다. 기존 목업·영상은 덮어쓰지 않았다. 수정 전 CSS·시험·계약·실측JSON·PNG는 [백업](../../../_backup/2026-10-11_0322_날짜탭잘림_수정전/)에 있다.
