# 신규 버스 응답의 조회 완료 시각 누락

## 해결됨 (2026-10-09, 부분) — 조회 완료 시각·접근 재검증

seoul_bus.boardable_arrival는 조회 시작 now를 그대로 선택 함수에 넘깁니다. TravelSource는 정상 응답을 받은 뒤 confirmed_at을 찍으므로 지연이 있는 새 응답은 confirmation_in_future로 거절될 수 있습니다. departure_observer도 confirmed_at<=조회 시작 now만 허용합니다. 실제 응답 대기 시간을 출발/접근/마감 판정에 포함하는 통제 재현이 필요합니다. 실제 API 호출 없이 시계를 진행시킨 주입 transport로 먼저 확인합니다.
