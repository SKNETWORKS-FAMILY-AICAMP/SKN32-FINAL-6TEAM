# 약관 확인 동안 화면이 비고 진행을 알 수 없다
## 미해결

- 위치: `frontend/apps/web/src/features/consent/consent-gate.tsx` 마지막 반환. 동의 사본이 없고 조회 중이면 앱 전체를 문장 하나의 main으로 교체한다. 첫 수화 전에는 null을 반환한다.
- 재현: 동의 기록이 있는 로그인 세션에서 브라우저 동의 사본을 비운 뒤 `/mypage`를 열고 동의 조회 응답을 지연한다.
- 실측: 해당 분기 1곳과 GET 동의 기록의 JSON 전용 응답 1곳을 코드로 확인했다. 사용자 제보이며 시간은 측정 전이다.
- 위험: 화면이 사라져 어디까지 처리했는지 알 수 없다. 조회 실패를 미동의로 취급하면 불필요하게 다시 약관으로 보낼 수 있다.
- 수정 계획: 현재 화면/화면 틀을 유지하고 작은 진행 카드 표시. 실제 SSE 단계·완료 수·대기 시간·연결 상태 표시. 실패는 같은 자리에서 재시도. 확인 전 보호 API를 호출하거나 새 게스트를 만들지 않는다.

## 해결 — 2026-10-08 최종 상태

기존 화면 또는 같은 화면 틀을 유지하고 실제 SSE 진행 카드를 추가했다. 오류를 미동의로 바꿔 경로를 이동하던 조건도 제외했다. 느린 조회·오류 후 재시도를 포함한 mock 서버 화면 시험 39/39, 로컬 개발 DB 통합·계약 33/33, 약관·연결 단위 시험 35/35 통과. [구현과 검증](../2026-10-08_약관확인_실시간진행_화면유지.md). 위 미해결 기록은 발견 당시 상태를 보존한 것이다.
