# 손잡이 영역에 목록 내용이 비침

## 해결됨 (2026-10-10)

손잡이를 불투명 표면으로 덮고 목록의 투명 구간을 손잡이 전체 높이까지 넓혔다.375px와1280px의 실제 Chrome 색상 계측·촬영, 최소 접힘/복원, 시각이 가려질 때부터 고정하는 기존 동작을 mock 서버 시험8/8로 확인했다. 공개 cs 프로젝트 서버 응답은 확인하지 않았다.

## 발견 당시 기록

사용자는 일정 추가·시각 목업의 펼친 일정 화면에서 전체 자동 추천이 드로워 손잡이 뒤에 흐리게 남는 문제를 지적했다. 목록은 가까워질수록 사라지고 손잡이 영역에서는 완전히 가려져야 한다.

현행 CSS에서 손잡이 배경은 none이고, 날짜 탭을 띄운 목록의 mask는 목록 위 0px에서만 완전 투명하고 32px에서 완전히 보인다. 따라서 손잡이가 차지하는 22px 영역 내부에도 부분적으로 목록이 보일 수 있다. 날짜 탭이 없는 목록에는 이 mask가 적용되지 않는다. 변경 전 CSS·기존 시험·계약을 _backup/2026-10-10_1333_손잡이불투명_수정전/에 보존했다.

375px와1280px에서 실제 목록 스크롤·손잡이 가림·완만한 페이드·날짜 표시·최소 접힘·시각 고정 시작점을 확인한다. 공개 cs 프로젝트 서버 응답 확인이나 x600 서버 배포는 이번 확인에 포함하지 않는다.
