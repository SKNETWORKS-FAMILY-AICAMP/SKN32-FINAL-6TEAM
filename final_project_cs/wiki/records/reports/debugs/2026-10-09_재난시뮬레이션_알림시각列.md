# 재난 시뮬레이션 알림 조회의 시각 열 오류

## 해결됨 (2026-10-09)

조회 열을 실제 DB의 `outbox.available_at`으로 바꾸고 시험 헬퍼의 중복 인자를 수정했다. 관리자 API 조회·저장, 인증·CSRF, 여행 범위 격리 시험을 포함한 [최종 백엔드 검증](../../evidence/2026-10-09_watch_simulation/final-boundaries.txt)은 195/195 통과했다.

같은 작업 중 발견한 도구 시험의 `connection_factory=None` 호환 문제는 연결이 있을 때만 여행 맥락을 읽도록 고쳤다([126/126 통과](../../evidence/2026-10-09_watch_simulation/backend-verified.txt)). 계층 방향 검사 실패는 관리자 인증 의존성을 실행 진입점에서 주입하도록 고쳐 상한을 늘리지 않고 해결했다(위 최종 195/195). 관리자 화면 시험의 중복 알림 요소 선택 오류는 안내 문구로 대상을 좁혀 고쳤다([2/2 통과](../../evidence/2026-10-09_watch_simulation/admin-browser-final.txt)).

아래는 발견 당시 기록이다.

관리자 API 통합 시험에서 알림 조회에 사용한 `outbox.created_at` 열이 실제 DB에 없어 응답이 실패했다. 실제 표의 안내 시각인 `available_at`으로 맞추고 API 시험을 다시 실행한다. 첫 실행은 관련 시험 112개 중 109개 통과, 3개 실패였다. 나머지 2개 실패는 시험 헬퍼에 같은 인자를 중복 전달한 오류다.
