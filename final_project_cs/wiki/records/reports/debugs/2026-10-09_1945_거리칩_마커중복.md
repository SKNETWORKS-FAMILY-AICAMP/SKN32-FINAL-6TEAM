# 화면 밖 거리 칩과 일반 마커의 중복 표시
## 해결 — 2026-10-09 19:56

- 발견: `frontend/apps/web/src/features/map/live-map.tsx`에서 거리 칩만 따로 계산하여 그렸고 지도 어댑터에는 칩 대상 일정의 마커를 숨기는 경로가 없었다.
- 재현: 검증 화면 지도 확대 또는 이동으로 일정 좌표를 화면 가장자리/상단 가림 영역으로 옮긴다. 거리 칩이 표시되어도 `layoutPins`로 화면 안쪽에 배치된 일반 마커가 함께 남을 수 있다.
- 확인 범위: LiveMap과 OSM·Google·Naver 어댑터 3개를 코드로 대조했다. 수정 전 공개 배포의 고객 접수를 조작하지 않았다.
- 위험: 같은 일정의 지도 표시가 중복되어 거리·방향 안내를 혼동하게 한다. 일정 좌표나 저장 데이터의 문제는 아니다.
- 변경: 칩 계산 결과를 마커 가시성과 공유하고 브라우저 표시 전에 교대한다. OSM의 별도 연결선과 접근성·키보드 진입도 함께 숨긴다. 네이버는 같은 마커의 SDK 연결만 토글하여 투명 클릭 영역도 함께 숨긴다. 좌표·경로선·선택 기능과 마커 객체는 유지한다.
- 보완: `bottomInset`을 어댑터로 전달하고 세 지도 어댑터의 전체 맞춤 하단 여백에 반영했다. 전체 일정으로 돌아왔을 때 하단 정보 막대에 걸린 장소가 거리 칩으로 남는 상황을 방지한다.
- 검증: 지도 단위시험 60/60 통과, 타입검사·ESLint·공백 검사 통과. 루트 최신 통합 UI 빌드의 mock 서버 브라우저 시험 2/2 통과(375px·1280px, 19.8초). 세 마커와 분리 연결선 전체 숨김, 칩 선택 후 마커 복구, 전체 맞춤 후 칩 제거, 동일 마커 DOM·경로선 보존을 확인했다.
- 실서버 확인 (서버 응답): 안 했음. 공개 cs 프로젝트 서버나 Google·Naver 실 SDK는 이번 시험에서 호출하지 않았다.
