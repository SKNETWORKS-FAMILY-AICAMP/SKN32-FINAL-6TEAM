# 먼 마커·잠금 도구·일정 추가 배치

## 해결됨 (2026-10-10)

사용자가 지도 조작 중에도 먼 일정 마커 거리로 가로 공간을 차지하는 문제와 카드 경계의 원형 추가 단추 혼동을 지적했다. 위치는 map-controls.tsx EdgeChipButton, plan-check.tsx renderInsertion과 plan-check.module.css insertPoint/insertButton이다. 기존 지도 moving 상태는 도구만 숨기므로 마커 거리에는 적용되지 않았다.

재현: mock 서버 화면에서 지도 확대·드래그, 잠근 일정 상세와 목록 중간 추가 단추를 확인한다. 기존 버튼 중심은 카드 위 테두리에 걸려 카드 펼침 도구처럼 보일 수 있다. 위험은 조작 중 지도 가림과 잘못된 추가 위치 선택이다. 결제·승인 동작은 해당하지 않는다.

원본은 `_backup/2026-10-10_전체잠금_먼마커_수정전/`에 보존했다. 거리만 조작 중 숨기고, 전체 잠금 해제를 목록 맨 위 자동 추천 옆에 제공하며 기존 API 잠금 필드만 한 요청으로 해제한다. 추가 단추 새 배치는 목업으로 함께 제시한다. 기존 판 전체를 바꾸거나 예약 보호를 해제하지 않는다.

지도 moving 상태를 거리 표시·실제 폭 재측정에 연결했다. 전체 해제는 잠금 필드만 단일 수정 요청으로 보내며, 추가 단추는 독립 간격 왼쪽에 이름을 붙여 배치했다. mock 서버 화면 고유26/26, 계산·훅30/30, TypeScript·ESLint·표준 생산 빌드 통과. [실행 근거](../2026-10-10_0413_먼마커_전체잠금_추가배치.md).
