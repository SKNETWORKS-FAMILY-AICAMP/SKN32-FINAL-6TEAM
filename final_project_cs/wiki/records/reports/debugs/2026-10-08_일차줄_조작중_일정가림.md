# 일차 선택 줄이 조작 중 일정을 가림

## 해결됨 (2026-10-08)

- 사용자 요청: 전체·1일차·2일차 선택 줄을 스크롤하거나 화면을 조작하는 동안 숨기고 자연스럽게 다시 나타나게 한다.
- 위치: `frontend/apps/web/src/features/plan-check/plan-check.tsx`의 `dayStrip`, `plan-check.module.css`의 떠 있는 일차 줄.
- 재현: 여러 날짜의 접수에서 일정 목록을 스크롤한다. 선택 줄은 목록 위에 그대로 떠 있어 아래 일정과 겹친다.
- 수정: 조작 시작부터 숨기고 손을 놓은 뒤 마지막 스크롤로부터 800ms 후 복귀. 숨김 150ms, 복귀 200ms. 일차 버튼 선택과 키보드 초점은 유지하며 Tab으로 다시 접근 가능. 동작 줄이기에서는 이동 효과를 끈다.
- 위험도: 일정 읽기·조작을 방해하는 화면 결함. 일정 저장·CS 판정·과금에는 관여하지 않는다.
- 검증 계획: mock 서버 화면 시험 `tests/live/day-strip-quiet.spec.ts`에서 목록·지도·키보드·동작 줄이기를 확인하고 실제 화면을 촬영한다.


확인: 새 동작 4건과 기존 일정 위치 2건의 mock 서버 화면 시험 6/6 통과. 실제 Chrome에서 목록 위치 유지·지도를 누른 동안 숨김 유지·상단 헤더의 Tab 즉시 접근·동작 줄이기를 확인했다. [결과·실행 로그](../2026-10-08_일차선택_조작중_자동숨김.md).
