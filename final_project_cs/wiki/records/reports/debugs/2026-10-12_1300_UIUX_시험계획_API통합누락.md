# UIUX 시험 계획 API 통합 누락

## 해결됨 (2026-10-12)

완료된 API 자료·설정 설명·관련 시험 네 파일과 현재 계약을 통합했습니다. 새 전용 DB의 실제 접수 HTTP 경로와 보안 시험 128/128이 통과했습니다. 자료는 15개이며 일곱 목적 분류와 접수 메타데이터를 보존합니다. [실행 결과](../../evidence/2026-10-12_uiux-catalog-api/result.json) · [전체 JUnit](../../evidence/2026-10-12_uiux-catalog-api/junit.xml).

공개 서비스 새 코드 배포는 확인하지 않았습니다. 시험의 장소·이동 응답은 mock 제공자이며 공개 cs 프로젝트 서버의 외부 조회를 검증한 결과가 아닙니다.

2026-10-12 공개 화면 인계 후 통합본을 대조했습니다. 고객 웹은 분류별 선택 목록인데 `app/domains/travel_ops/components/intake/test_plans.py`는 이전 12개 자료와 분류 없는 API 응답을 유지하고 있었습니다. 2026-10-11 완료된 기본안 세 개·분류별 표시 작업에서 고객 웹만 통합하고 연결된 API 자료·시험을 가져오지 않은 것이 원인입니다. 정상 기본안을 선택할 수 없고 모든 항목이 일반 흐름으로 표시되는 위험이 있습니다.

재현: 기존 통합본의 `catalog()`는 12개를 반환하고 `prepared()` 결과에 `category`가 없습니다. 원본 완료 변경은 15개와 일곱 시험 목적 분류를 제공합니다. API 활성화·인증·고객별 접수 저장·실제 장소 검증 경계는 바꾸지 않고 완료된 네 파일만 통합합니다. 공개 배포 버전과 Git 통합 누락은 별도 문제로 확인합니다.
