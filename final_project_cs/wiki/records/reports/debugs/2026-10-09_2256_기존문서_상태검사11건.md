# 기존 결함 문서 11건의 상태 표기 검사 실패

## 미해결

API 한도 기능 작업을 마감하면서 전체 결함 문서 상태 검사도 실행했다. `tests/unit/core/test_debug_report_status.py` 결과는 105 passed / 11 failed다. 실패한 11개 파일은 이번 기능에서 만든 결함 문서 3개와 이름이 겹치지 않으며 이번 작업에서 수정하지 않은 문서다. 해당 문서의 실제 해결 여부를 새로 확인하지 않고 상태를 추정해 고치지 않았다.

영향: 결함 문서 전체 상태 검사가 통과하지 않는다. API 한도 조회 기능·권한·읽기 전용·기간 경계 검증 127개와 관리자 화면·중계 7개는 통과했다.

근거: [전체 상태 검사 원문](../../evidence/2026-10-09_api_environment_limits/report-status.txt). 개별 실패 파일 이름은 원문 마지막 FAILED 목록에 있다. 이 기록은 실제 결함들의 해결 여부를 판정하지 않는다.

다음 작업: 해당 문서 소유 작업의 구현·검증 근거를 확인한 뒤 각 문서에 해결/미해결 상태를 명시한다.
