# API 한도 조회의 DB 연결 의존성

## 해결됨 (2026-10-09)

DB 연결 구현체 import를 응용 조회에서 제거하고 운영 API가 연결 팩토리를 전달하도록 수정했다. 계층 검사 상한은 변경하지 않았다. 근거: [최종 검증 127/127](../../evidence/2026-10-09_api_environment_limits/backend-complete.txt), `tests/architecture/test_basement_layers.py::test_layer_directions_do_not_get_worse`.

첫 검증에서 기능 시험은 통과했지만 계층 검사에서 application → infrastructure import가 기존 상한 3개에서 4개로 증가해 실패했다. 새 조회 모듈이 DB 연결 구현체를 직접 가져오는 것이 원인이다.

수정 예정: 연결 팩토리를 필수 인자로 받아 API 진입점에서 전달한다. 계층 검사 상한을 올리지 않고 같은 검증을 다시 실행한다.
