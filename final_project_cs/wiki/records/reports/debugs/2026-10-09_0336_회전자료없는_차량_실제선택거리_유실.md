# 회전자료 없는 차량 경로의 실제 선택 거리가 유실된다

## 해결됨 (2026-10-09) — 실제 선택 거리·근거 유실

일반 GraphRouter.route의 경로 복원은 다른 시작/끝 간선을 사용해도 snap_m 및 quality를 가장 가까운 Ss[0]/Ts[0]로 표시한다. 실제 나란한 합성 도로와 두 후보를 주입한 A*/Dijkstra·직행/연결 네 조건 모두 geometry는 두번째 후보를 사용하지만 거리 표시는0m/0m다(실제8.8m/8.8m). 회전자료가 없는 응답은 선택 근거도 전달하지 않는다.

위치: app/domains/travel_ops/instances/mobility/engine/graph_router.py:512~560 일반 경로 복원·요약. 위험: 회전자료가 빠진 환경에서 다른 도로 접근을 정확한 위치처럼 표시한다. 회전 미적용은 별도 미가용 상태다.

재현: python -m pytest tests/unit/travel/mobility/test_car_legacy_selected_snap_v1.py -q. 수정 전4/4실패는 car-legacy-snap-before-v1.log/xml에 보존했다. 도보/자전거는 기본 후보1개이므로 다른 후보 거리 유실의 일반 사례라고 주장하지 않는다. 실제 웹 경로 정확도와 물리적 접근 가능성은 별도다.


일반 경로 복원에서 실제 시작/끝 후보를 사용하고 회전 적용/미가용 경로가 같은 선택 근거를 만든다. 자료 없음 상태는 유지한다. 수정전4/4실패, 수정후 확대695/695 및 포함 관련57/57통과. [보고서](../2026-10-09_0347_차량_대체경로_선택거리와_좌표이동_통제실험.md)·[최종 실행 명령](../../evidence/2026-10-09_0336_회전자료없는_선택도로_거리/car-legacy-regression-v1-commands.json). 도로 진입의 물리적 가능성은 미해결이다.
