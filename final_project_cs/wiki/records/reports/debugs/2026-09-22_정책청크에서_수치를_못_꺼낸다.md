# 정책 청크에서 수치를 못 꺼낸다 — 취소 기한·위약금율이 항상 「모름」

## 미해결 (2026-09-22 실행으로 확인)

- 상태: **미해결.** 원인은 확정했고(아래 §실측) 고치는 방법은 **아직 안 정해졌다** —
  `program/plan/A-COP_여행RAG_필요대상_재점검_2026-09-10.md` §3 의 ①②③ 가운데 고르는 결정이 먼저다.
- 이 세션(여행 RAG 코퍼스 작성)은 **고치지 않았다.** 코퍼스를 넣어도 이 자리는 안 채워진다는
  사실을 확인해 남기는 것이 여기까지의 일이다.

## 1. 위치

```
app/modules/travel_ops/activity.py  _policy_hours()     — 취소 기한 cancel_deadline_hours
app/modules/travel_ops/activity.py  _penalty_rate()     — 구간별 위약금율 penalty_by_hours
app/core/context.py                 PolicyChunk         — RAG 가 실제로 주는 모양
```

```python
# activity.py — 코드가 기대하는 모양
for chunk in policy if isinstance(policy, list) else []:
    if isinstance(chunk, dict) and chunk.get(key) is not None:   # ← dict 를 본다
```

```python
# app/core/context.py — RAG 가 주는 모양
@dataclass(frozen=True)
class PolicyChunk:
    document_id: str; chunk_no: int; content: str; score: float; scope: str
```

`PolicyChunk` 는 `dict` 가 아니다. `isinstance(chunk, dict)` 가 **항상 거짓**이다.

is dict? False

## 3. 실측 — 무엇이 몇 건인가

- 영향받는 자리 **2곳**(위 §1). 둘 다 `None` → `activity.check_cancelable` 이
  `_unknown("취소 기한")` 으로 끝난다. 즉 **취소 가능 여부 판정 자체를 못 한다.**
- 어떤 코퍼스를 넣어도 같다. 2026-09-22 에 여행 코퍼스 12문서·130청크를 넣고도 그대로다.
- ★**앞 판정의 `[미확보]` 를 닫는다.** `A-COP_여행RAG_필요대상_재점검_2026-09-10.md` §3 이
  「실행으로 재현하지는 않았다. 코드 세션이 한 번 돌려 확인해야 한다」로 남겨 둔 것을
  위 재현으로 확인했다 — **읽어 낸 결론이 맞았다.**

## 4. 위험도

**중간.** 거짓 확정은 만들지 않는다 — `None` 이면 「모름」으로 답하므로 잘못된 금액을 말하지는
않는다. 다만 **제품이 약속한 판정을 못 한다**: 「지금 취소하면 위약금이 얼마인가」에 답하지 못하고
전부 사람에게 간다.

★커머스 쪽 같은 모양은 더 위험하다 — `return_refund._policy_days` 는 같은 `isinstance(value, dict)`
로 거른 뒤 `90 if reason == "defective" else 7` 로 **떨어진다**(폴백이 있다). 여행 쪽은 `None` 이라
그 점은 낫다.

## 5. 내가 잘못 보고했던 수치의 정정

없음. 다만 **「여행 코퍼스를 넣으면 취소 기한·위약금이 답해진다」고 읽히지 않게** 못박는다 —
이 세션이 넣은 코퍼스는 **근거 문장**을 대지 수치를 대지 않는다.

## 6. 고치는 길 (아직 안 정해졌다)

| 안 | 무엇 | 대가 |
|---|---|---|
| ① 구조화 정책을 따로 둔다 | 수치는 전용 표/설정에서 읽고 RAG 는 문장 근거만 | 수치와 문장이 두 곳 — 개정 때 갈릴 수 있다. **어디 둘지 미정** |
| ② front matter 수치를 청크에 싣는다 | `PolicyChunk` 에 `attributes` 한 칸 추가 | **계약 변경.** Context Broker·Evidence 까지 번진다 |

재점검 문서는 ①을 권했다. **결정이 나기 전에는 이 자리를 고치지 않는다** — 고치면 그 구현이
결정을 대신하게 된다.
