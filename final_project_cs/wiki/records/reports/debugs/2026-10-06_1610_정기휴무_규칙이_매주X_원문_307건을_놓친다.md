## 1. 위치

`app/modules/travel_ops/activity/feasibility.py` 의 `FeasibilityMixin._weekday_closure_match`

```python
day_names = re.findall(r"매주\s+(\S+?)\s*(?:휴무|휴관)", restdate_text)
if not day_names:
    return False
```

정규식이 **요일 뒤에 「휴무」·「휴관」이 붙어 있어야만** 요일을 뽑는다. 패턴이 없으면 `False`(휴무 아님)다. 그런데 TourAPI 휴무 원문(`restdate`)은 대부분 「매주 월요일」처럼 그 낱말이 없다. 「매주 토요일~일요일」 같은 요일 범위도 읽지 못한다.

## 2. 재현

```bash
cd final_project_cs
.venv/bin/python - <<'EOF'
import csv, re
from datetime import datetime
from app.modules.travel_ops.activity.feasibility import FeasibilityMixin
rows = list(csv.DictReader(open("app/modules/travel_ops/activity/data_processing/activity_total_data.csv", encoding="utf-8-sig")))
texts = [(r.get("closed_days") or "").strip() for r in rows]
weekly = [t for t in texts if re.search(r"매주\s*[월화수목금토일]", t)]
days = [datetime(2026, 10, 12 + i) for i in range(7)]        # 월~일 한 주
missed = [t for t in weekly if not any(FeasibilityMixin._weekday_closure_match(t, d) for d in days)]
print(len(rows), sum(bool(t) for t in texts), len(weekly), len(missed))
EOF
```

### 시제품 측정 (scratchpad, 저장소 밖)

| 대상 | 지금 규칙 | `closed_on` | 시제품 |

- ★골든셋 16/16 은 **골든셋을 본 뒤 만든 시제품**의 수치라 낙관적이다. 골든셋과 무관한 확인은 CSV 쪽 수치다.
- 시제품이 아직 놓치는 모양
  - 「월요일, 1월 1일, 설날, 추석날」: 한 절에 요일·날짜·명절이 섞이면 날짜 패턴만 보고 끝난다.
  - 「매년 3월, 6월, 9월, 12월 첫 번째 월요일」: 「첫 번째」 표기를 못 읽는다.
  - 본 구현에서는 **절 안의 모든 패턴을 다 보고 하나라도 맞으면 휴무**, 못 읽은 조각이 남으면 모름으로 해야 한다.

### 읽는 규칙

| 원문 모양 | 판정 |
|---|---|
| 비었음 · 「상이」·「참조」·「확인」·「문의」·「공연별」 | 모름 |
| 「연중무휴」·「연중 개방」·「휴무 없음」 | 아님 |
| 「매주 월요일」·「토요일~일요일」·「월, 화」·「주말」 | 요일이 맞으면 휴무 (`place_hours.days_in` 재사용) |
| 「매월 둘째·넷째 주 X요일」·「마지막 주」 | 그 달의 몇째 요일인지 코드가 계산 |
| 「1월 1일」 같은 날짜 | 월·일이 맞으면 휴무 |
| 「법정공휴일」·「공휴일」 | `read.holiday` — 공휴일이면 휴무, 아니면 아님, 모르면 모름 |
| 「명절·설·추석 당일 / 연휴 / 전일~익일」 | `read.holiday` 로 그날과 앞뒤 하루의 이름을 본다. 모르면 모름 |
| 「(단, 공휴일이면 개방)」 예외 | 요일이 맞아도 공휴일이면 아님, 공휴일 여부를 모르면 모름 |
| 「다음 첫 번째 비공휴일 휴관」 같은 이월 규칙 | 전날이 공휴일인지 모르면 모름(드물다 — CSV 4건) |
| 그 밖에 못 읽은 조각 | 모름 (★지금은 「아님」) |

절과 절은 「하나라도 휴무 → 휴무, 아니면 하나라도 모름 → 모름, 다 아니면 아님」으로 합친다.

### 바뀌는 곳

- 새 공용 함수(예: `app/modules/travel_ops/activity/closure_rules.py`) — `read_closure(text, at, holiday) → (휴무/아님/모름, 맞은 구절, 이유)`
- `feasibility._feasible_operating` 과 `judge/rule.py` 의 휴무 판정, `alternatives.closed_on` 이 이 함수를 쓴다.
- `ActivityTeam.manifest.allowed_tools` 에 `read.holiday` 를 더한다. 공휴일이 걸린 원문일 때만 부른다.
- 답변 문구
  - 휴무: 맞은 구절을 함께 보인다(「휴무 안내 중 「매월 둘째 주 화요일」에 해당합니다」).
  - 모름: 「휴무 원문 일부를 읽지 못해 휴무 여부는 확정하지 않았습니다」 + 경고. 지금처럼 사람에게 넘기지 않고 원문을 전한다.

### 영향

- 정기휴무일 예약이 이제 「불가」로 나가고 대체 장소를 찾는다. 맞는 답이 늘지만, 대체 후보 조회가 늘어난다.

- 섀도 모드의 비교 기준(규칙)이 바뀐다. 섀도 표에 바뀐 시점을 남기고, 5단계 평가의 규칙 쪽을 다시 잰다(LLM 비용 없음).
