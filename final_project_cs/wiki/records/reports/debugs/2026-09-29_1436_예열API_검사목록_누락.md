# 예열 API의 OpenAPI 검사 목록 누락

## 미해결

- 발견: 2026-09-29 · Codex · `develop` `fc1ac0a` · API 문서 정리 `ST4F-172` 중 정적 대조.
- 위치: `app/modules/travel_ops/trip_api.py:1027`에 `POST /v1/web/warmup`이 있고, `tests/integration/api/test_openapi_surface.py:28`의 `CONTRACT_V1_PATHS`에는 없다. 같은 검사 파일의 `test_v1_surface_is_documented_when_it_grows`는 실제 경로와 목록의 차이가 비어 있어야 한다고 단언한다.
- 재현(아래 프로젝트 폴더에서):

```powershell
rg -n 'warmup|CONTRACT_V1_PATHS|extra == ' app/modules/travel_ops/trip_api.py tests/integration/api/test_openapi_surface.py
python -m pytest tests/integration/api/test_openapi_surface.py -q
```

- 실측: 코드 대조에서 예열 경로의 추가와 검사 목록 누락을 확인했다. 이 OpenAPI 검사는 이번 작업에서 실행하지 않았다. 별도 웹 계약 검사 시도도 Python 환경 문제로 실행하지 못했다([출력](../../evidence/2026-09-29_1436_웹API_협업문서_정리.md)). CI의 실제 최신 결과는 조회하지 않았다.
- 영향: 예열 라우터가 포함된 구성에서 위 검사의 추가 경로 판정이 실패할 조건이다. 인증 우회나 고객 기능 장애가 관측됐다는 뜻은 아니다.
- 처리: API 명세에는 예열 계약을 반영했다. 검사 코드 변경은 이번 문서 작업에서 하지 않았다. 다음 구현 작업에서 경로 목록과 필요한 검증을 함께 확인해야 한다.
- 닫는 기준: 계약 경로 목록과 실제 라우터를 맞추고 OpenAPI 표면 검사를 실행해 결과를 기록한다.
