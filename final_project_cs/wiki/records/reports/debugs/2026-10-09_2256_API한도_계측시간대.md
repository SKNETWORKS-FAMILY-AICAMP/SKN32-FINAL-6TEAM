# API 한도 조회 초안의 장애 대체 계측 시간대

## 해결됨 (2026-10-09)

API 행별로 계측 시간대를 구분해 조회하도록 수정했다. 한국 시각 2099-11-01 01시(UTC는 전월) 입력으로 ITS의 11월·OpenAI 장애 대체의 10월 줄을 각각 조회하는 로컬 개발 DB 시험이 통과했다. 근거: [127개 최종 검증](../../evidence/2026-10-09_api_environment_limits/backend-complete.txt), `tests/integration/test_api_environment_limits.py::test_actual_db_usage_last_cap_override_and_kst_utc_boundary_are_distinct`.

검토 중 조회 초안이 모든 DB 계측을 한국 시각으로 조회하는 것을 발견했다. 공공 소스는 한국 시각이지만 OpenAI 장애 대체 호출은 CallBudget 기본 UTC로 기록한다. 한국 시각 자정~09시 또는 월초에 다른 기간 줄을 읽을 수 있다. 공개·배포 전 발견했다.

근거: `app/composition.py::_llm_failover_budget`는 tz를 전달하지 않고 `app/domains/travel_ops/ports/data_sources/call_budget.py::CallBudget` 기본값은 UTC다.

수정 예정: 각 행에 계측 시간대를 명시하고 실제 기록 기준으로 기간을 선택한다. 한국/UTC 날짜·월이 다른 시각의 통합 시험으로 검증한다.
