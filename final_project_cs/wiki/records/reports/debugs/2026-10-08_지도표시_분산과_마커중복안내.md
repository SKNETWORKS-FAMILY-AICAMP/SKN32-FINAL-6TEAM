# 지도 표시 분산과 마커 중복 안내

## 해결됨 (2026-10-08) — 상태 막대·경로 이름·마커 선택

확인·변경·위치 안내를 같은 막대에 붙이고, 별도의 수단 범례 대신 확대된 경로선에 이름을 표시한다. 마커 선택의 `stopToast` 호출은 제거했다. 실제 Chrome의 최종 묶음 26/26 중 새 상태 표시 시험 4/4와 기존 지도 상세 시험 13/13으로 확인했다. 원문 실행 로그는 [최종 화면 시험](../../evidence/2026-10-08_1750_지도상태와_경로표시/map-status-ui-complete.log), 세부 변경은 [작업 리포트](../2026-10-08_1753_지도상태와_경로표시_정리.md). 공개 서비스 배포·응답 검증을 뜻하지 않는다.

### 발견 당시 기록

- 상태: 조사 중
- 사용자 관찰: 변경 개수가 확인 필요 표시와 떨어져 있고, 위치 미정과 이동 수단 표시는 별개의 태그로 흩어져 보임. 마커 선택 때 일정 정보가 알림으로 중복 표시됨.
- 로컬 확인: 변경 버튼과 시간 되돌리기는 앞선 수정에서 이미 지도 쪽으로 이동했으나 위치 표시는 별개의 태그이고 경로 범례가 남아 있음. 마커 선택은 `stopToast`를 호출함.
- 수정 범위: 상태 표시 공통 막대, 확대된 경로선 위 수단 이름, 마커 설명 알림 제거. 경로 선택 설명과 일정 목록 연결은 유지.
- 검증: 수정 후 기록 예정.
