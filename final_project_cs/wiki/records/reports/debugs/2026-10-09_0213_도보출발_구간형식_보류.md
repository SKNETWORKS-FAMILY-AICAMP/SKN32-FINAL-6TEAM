# 직접 도보가 출발 재검증에서 보류된다

## 해결됨 (2026-10-09, 부분) — 새 직접 도보 문맥의 안내 보류 원인

위치: 이동 계산기의 departure_context.capture와 departure_observer.observe.
계획 목표: v11 출발 시점의 현재 이동 값으로 안내하기.
원인: 직접 도보는 legs=[]와 check=None으로 저장되지만 관측기는 차량 구간만 허용한다. 빈 구간만으로 도보라고 판단하면 택시·자전거를 잘못 걷기로 바꾸므로 명시적 종류를 저장해야 한다.
재현: 새 tests/unit/travel/mobility/test_departure_walk_v1.py로 새 생성 문맥과 현재 도보 계산·안내를 연결한다. 아직 실행 전이므로 통과 수치는 쓰지 않는다.
위험: 정상 도보 안내가 보류된다. 저장된 ETA를 그대로 사용하는 우회는 현재 경로 단절·지각을 숨긴다.
수정 범위: 새 문맥에 direct_walk 종류를 추가하고 기존 보행 경로 계산을 재사용하여 출발·도착·운영 여유를 검사한다. 대체 거리 식은 모델 근거로 남긴다. 옛 문맥 누락·종류 미확인은 보류로 유지하며 다음 개선 단위로 남긴다.

검증: 관련55/55·확대671/671, 실제 보행 그래프 단위와 로컬 DB 도보2/2. [보고서](../2026-10-09_0223_도보출발_현재경로_재검증.md). 옛 문맥 복구와 실제 경로 오차는 미해결입니다.
