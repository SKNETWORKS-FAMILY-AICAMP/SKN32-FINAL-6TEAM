# 관리자웹앱 중계 경로와 조회 조건 누락

## 해결됨 (2026-10-09)

API 한도·감시·시뮬레이션 경로를 명시적으로 허용하고 조회 조건을 전달했다. Next.js 중계 뒤 mock 서버에서 경로·필터·쿠키·PATCH 본문을 검증했고 임의 경로와 잘못된 UUID는 404로 유지했다. 근거: [브라우저·중계 최종 7/7](../../evidence/2026-10-09_api_environment_limits/admin-browser-ux.txt), `frontend/apps/admin/tests/live/api-limits-proxy.spec.ts`.

ENV 한도 조회를 연결하며 중계 코드를 직접 읽어, 새 API를 허용 목록에 추가해야 한다는 것을 확인했다. 이전에 추가한 재난 시뮬레이션·감시 현황 경로 역시 허용 목록에 빠져 404가 되며, 중계가 URL 검색 조건도 전달하지 않는다. 기존 브라우저 시험은 화면 요청을 직접 목업하여 이 구간을 지나지 않았다.

수정 예정: 명시적인 경로·UUID 허용 규칙을 유지하면서 api-limits, simulations, watch-runs를 등록하고 query string을 전달한다. 실제 Next.js 중계를 통과해 mock 서버에 도착한 경로·조건·쿠키를 확인하는 시험을 추가한다.

범위: 관리자웹앱 중계. 운영 API 자체의 권한·CSRF·대상 검증은 기존 구현을 유지한다.
