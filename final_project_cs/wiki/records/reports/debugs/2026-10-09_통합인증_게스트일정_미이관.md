# 통합 인증 시 게스트 일정 미이관

## 해결됨 (2026-10-09, 부분) — 게스트 여행·접수 이관과 고객 통합 진입

기존 회원끼리 합치지 않는 경계와 nonce·CSRF를 포함한 HTTP·로컬 개발 DB 시험 51/51 확인. [실행 근거](../../evidence/2026-10-09_1719_통합인증_게스트이관.md). 실제 외부 소셜 왕복, 기존 Case 소유권과 백그라운드 접수 경계는 루트 통합 검증에 남긴다.

- 위치: `modules/web_account/web_auth.py:complete`, `web_auth_api.py:auth_start`, 웹 `features/account/social-accounts.tsx`.
- 재현: 게스트 여행이 있는 브라우저에서 기존 소셜 계정 연결을 선택한다.
- 코드 확인: 다른 소셜 소유자가 있으면 `already_linked_elsewhere`로 거절하며, 로그인 경로에는 출처 게스트 기록과 여행 이관이 없다. 기존 화면도 로그인하면 게스트 여행이 사라진다고 안내한다.
- 위험: 작성·검증 접수와 등록 여행이 기존 회원 계정에서 보이지 않는다. 타 회원끼리 자동 병합하면 계정 경계가 무너지므로 게스트만 허용해야 한다.
- 확인 전 상태: 코드 경로 확인. 재현 실행과 회귀 시험은 수정 후 기록한다.
