# 변경 버튼 분산·선택 일정 가림·검증 중 목록 초점

## 해결됨 (2026-10-08)

- 사용자 관찰: 확인 필요 개수와 변경 개수가 서로 떨어져 있고 시간 초기화의 위치가 애매하다. 지도 마커를 누르면 선택 일정 제목이 전체·일차 선택 줄에 가린다. 검증 중인 일정은 목록 맨 아래에 나타나 위 지도 마커와 함께 보기 어렵다.
- 원인: 변경 개수·일괄 초기화가 목록 머리에 분산되어 있었다. 마커의 목록 이동은 떠 있는 날짜 줄의 아래 경계를 고려하지 않았다. 마지막 일정은 스크롤 끝에서 멈춰 위로 올릴 여유가 없었다. 검증 줄은 가까운 가장자리까지만 따라갔다.
- 수정: 지도 아래 확인·변경 그룹과 변경 메뉴의 시간 일괄 되돌리기. 마커로 선택한 행을 날짜 줄 아래에 정렬하고 필요한 끝 여유를 추가. 검증 행을 목록 가운데로 따라감.
- 재현·확인: `tests/live/plan-focus.spec.ts` 두 시험과 `tests/live/plan-check-redesign.spec.ts`의 일괄 되돌리기 시험. 실제 Chrome 3/3 통과. 여러 날짜가 있는 계획의 마지막 일정이 날짜 줄 바로 아래(10~20px)에 도달함을 측정한다. 검증 중 마지막 행과 목록 가운데의 차이가 22px 미만이고 지도 마커가 보임을 확인한다.
- 위험도: 계획을 읽고 수정하기 어려워지는 화면 결함. 비용·업체 예약에는 관여하지 않는다. 시간 되돌리기는 기존 일괄 요청으로 한 번만 전송된다.
