분야별 시험 묶음은 서로 중복되므로 수를 더하지 않습니다. 확대 검증1484개는 별도 JUnit의 같은 시험 식별자를 중복 제거한 수입니다. 기본 검증에서 제외한 전체층3개는132 분모에 포함하지 않았고 아래의 확대 검증 제외 수도 별도로 남깁니다.

## 바뀐 동작

택시 안내는 같은 계산 결과의 미터 추정·예산 여유·통행료를 나눠 표시하고 호출·옵션료 미포함을 밝힙니다. 요금식이나37% 여유율을 골든셋에 맞춰 바꾸지 않았습니다. [택시 상세 보고](2026-10-11_2335_택시예산_구성금액과옵션료_안내검증.md).

출발 안내는 저장 경로가 목록인지, 각 버스·지하철 구간에 필수 노선·승하차 이름이 있는지 공급자 조회 전에 검사합니다. 손상 안내는 보류하고 다음 정상 안내를 처리합니다. 승인된 Sonnet5.5 검토 지적을 실제 호출로 재현해 필수키 누락 결함을 확인했습니다. Sonnet이 추측한 예외 위치와 실제 판정기에서 확인한 위치는 구분했습니다. 기존 저장 시험1개의 대역 주입 위치도 현재 조립 계약에 맞췄습니다. [217개 검증 기록](../evidence/2026-10-12_001640_mobility_private_and_fixes/transit/result-final-v3.md).

따릉이 재고는 손상 JSON 구조·음수·분수·bool을 거절하고 다음 정상 응답으로 회복합니다. 자전거와 도보가 공유하는 경로는 손상 구조·bool·NaN·무한대를 정상 거리/시간으로 저장하지 않습니다. 수정 전 신규32개에서21실패·11통과, 수정 후32개와 관련100개가 통과했습니다. 처음 관련52개 실행에서는47통과·5실패가 나왔습니다. 자전거 전용 후보도 혼합 대중교통 운임 규칙을 먼저 읽는 문제였고, 적용 수단 확인을 규칙 조회 앞으로 옮긴 뒤 기존5개를 포함한132개가 통과했습니다. [수정 전](../evidence/2026-10-12_001640_mobility_private_and_fixes/bike-before-v1.log), [처음 관련 실패](../evidence/2026-10-12_001640_mobility_private_and_fixes/bike-after-v1.log), [최종132개](../evidence/2026-10-12_001640_mobility_private_and_fixes/bike-after-v2.log).

서울시 [따릉이 공식 명세](https://data.seoul.go.kr/dataList/OA-15493/A/1/datasetView.do)는 대여소별 실시간 대여가능 건수와 자전거주차총건수를 제공합니다(2026-10-11 확인). 개수의 비음수 정수 검사와 구조 검사는 해당 출력 의미를 지키기 위한 입력 경계이며 실제 재고 정확도 관측이 아닙니다.

무정차 공지의 ‘혜화, 한성대입구역’에서 이제 앞쪽 혜화도 탐지합니다. 역명 일부·관련 없는 문장·종료·시간·호선 경계는 유지합니다. 신규37개는 수정 전21실패→수정 후37통과, 관련85개가 통과했습니다. 실제 과거 공급자 원응답은 이번 검색으로 확보하지 못해 과거 조사 문구·통제 공지 검증으로만 기록합니다. [무정차 검증](../evidence/2026-10-12_001640_mobility_private_and_fixes/subway_notice/REPORT.md).

## 검증 범위와 남은 관문

최종 중복 제거 검증은 1484/1484 = 100% 통과, 실패 0, 건너뜀 0입니다. 초기 확대 실행과 원인 수정 후 관련 재실행의 같은 classname/name을 최신 결과로 교체한 합계이며, 한 번에 전건 재실행한 수치가 아닙니다. 초기 확대 실행에서 mobility_full 220개는 제외됐으며 별도 하네스 정책4개는 제품 시험 분모에서 뺐습니다.

확대 검증의 첫 실행은 샌드박스 임시 폴더 권한 오류로 수집 중 종료2였습니다. 시험용 TEMP/TMP를 작업 폴더에 지정한 v4는1059통과·5실패·4건너뜀에서 조기 중단됐습니다. 실패3개는 asyncio의 내부 통신을 외부 연결로 막은 검사 장치, 실패2개와 건너뜀4개는 오프라인 시험 초기화가 환경의 외부 라우터 상태를 먼저 조회한 문제였습니다. 기존 기대값은 그대로 두고 해당 파일 전체를 각각8/8·11/11·5/5로 재검증했습니다.
