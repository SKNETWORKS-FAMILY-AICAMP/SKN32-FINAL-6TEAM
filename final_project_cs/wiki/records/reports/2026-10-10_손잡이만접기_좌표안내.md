# 손잡이만 남기는 접힘과 좌표 안내

목록을 끝까지 내리면 높이44px의 손잡이만 남고 보내기·등록 버튼도 숨긴다. 다시 올리면 목록·날짜·버튼이 복원된다. 좌표0개 안내는 메뉴 아래에 놓고 지도 공간이136px보다 작으면 목록 머리말에서 표시한다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 화면 수정 | 완료 | 2/2 = 100% |
| mock 서버 화면 시험 | 통과 | 16/16 = 100% |
| 정적 검사·생산 빌드 | 통과 | 3/3 = 100% |
| 화면 촬영 | 완료 | 10/10 = 100% |

드래그 하한과 클릭 peek를104px에서44px로 맞췄다. 실제 렌더 높이로 최소 접힘을 판정하여 유휴 복원 후에도 보내기를 숨기고 inert/aria-hidden을 유지한다. 첫 시험에서 Tab 복원이 inert를 직접 해제하는 충돌을 발견하여 useQuietDayStrip의 suppressed 옵션으로 최소 접힘 중 해당 복원을 막았다. 짧은 목록의 기존190px 내용 숨김은 유지하며 페이지 점도 숨긴다.

좌표 안내는 topInset과 오른쪽 지도 도구 공간을 반영한다. 목록을 크게 펼친 경우 안내를 머리말로 옮기고 날짜의 최소 높이와 목록 시작 위치를 함께 보정했다. 머리말과 손잡이 아래로 스크롤 내용이 비치지 않는다. 현재 지도 범위에 좌표가 생기면 안내가 사라진다. role=status를 사용하고 토스트는 추가하지 않는다. 지도 좌표나 일정 데이터는 만들어 넣지 않았다.

mock 서버 시험16/16 (화면 반응). 분모는 새 접힘4·좌표 안내2와 기존 날짜4·목록 높이2·일차 전환1·움직임 줄이기 재생1·제출 숨김2의 고유 시험이다. 최종 전체16개가 통과했고, 손잡이 배경 마무리 후 영향을 받는 좌표 안내2개만 재확인했다. 실패 기록은 시험 근거에 실행별로 보존했다. mock 응답의 최초 세션 쓰기를 UI 수정 쓰기로 오인한 시험 기준과 스크롤 길이·토스트 종료 대기도 바로잡았다.
