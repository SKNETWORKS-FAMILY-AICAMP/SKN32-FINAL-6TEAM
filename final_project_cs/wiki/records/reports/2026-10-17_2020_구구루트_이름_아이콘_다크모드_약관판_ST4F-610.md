## 바꾸지 않은 것 · 남은 일

1. **서버와 웹을 같이 배포**해야 한다 — 판이 다르면 동의 저장이 거절된다(웹만 먼저 나가면 서버가 409 `terms_version_changed`, 서버만 먼저면 웹이 「새 약관」 안내).
2. 채팅 판단 프롬프트(`decision_unit.py` — 「answer_service: triPilot 자체의 기능…」 · 대화 기록의 말한 이 「triPilot」)는 모델 입력이라 그대로 뒀다. 고객이 「구구루트」라고 물어도 사용법 질문 낱말로 분류되지만, 바꾸려면 백엔드 담당과 평가를 같이 해야 한다.
3. 채팅 기능 안내 본문(검색어 「triPilot은 …」)에 「구구루트」를 넣으려면 지식 다시 적재(`scripts.ingest_corpus_local`)가 필요하다 — 백엔드 담당.
4. 구글 · 네이버 지도는 다크에서도 밝은 그대로(무료 지도만 반전). 구글은 지도 만들 때 색 체계를 정해야 한다.
5. 저장소 문서(루트 `CLAUDE.md` · `AGENTS.md` 「이름」 행, README · wiki 의 제품 이름)는 팀 규칙 · 공유 문서라 이 작업에서 고치지 않았다. 결정 기록(wiki `decisions/`)도 아직 없다.
6. 로컬 실서버(웹 3100 → 서버 8042, 이 작업 폴더 코드)는 첫 화면 · 탭 아이콘 · 홈 화면 아이콘 · 밤 그림 파일(모두 200) · 기기 밝음/어두움 테마 · 새 방문자 → 약관 화면까지 확인했다. 서버의 약관 판(2026-10-17.1)과 동의 항목 여섯은 설정 · 코드 읽기로 확인했고, 실서버에서 브라우저로 동의를 저장하는 왕복은 하지 않았다(mock 서버 시험과 서버 e2e `test_consents` 로 확인). 실기기(iOS 홈 화면 아이콘 · 기기 다크 전환)는 미확인.
