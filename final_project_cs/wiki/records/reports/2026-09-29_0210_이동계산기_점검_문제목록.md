## 요약

찾은 문제는 **66건**이고, 그중 먼저 막아야 할 **치명 문제는 5건**이다(#1·#24·#26·#35·#37).
심각도 분포는 **치명 5 · 높음 27 · 중간 24 · 낮음 10**이다.
교차 검수에서 틀린 것으로 나온 항목은 0건이다. 설명을 고친 것은 11건, 새로 찾은 문제는 3건(#65~#67)이다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 찾은 문제 전부 표로 정리 | 끝 | 66/66건 = 100% |
| 코덱스 교차 검수 | 끝 | 64/64건 = 100% |
| 교차 검수 판정 — 맞음 | | 51/64건 = 80% |
| 교차 검수 판정 — 일부 맞음(설명 고침) | | 11/64건 = 17% |
| 교차 검수 판정 — 확인 못 함(문서 수치) | | 2/64건 = 3% |
| 교차 검수 판정 — 틀림 | | 0/64건 = 0% |

**누가 고치나:** 대부분은 이동 계산기 쪽 수정 요청이다. 아래 번호는 **우리 쪽(코어·여행 공용 코드) 몫이라 우리가 고친다** — 22·23·27·34·35·36·37·42·43·44·46. 39·40·45는 연결 방식을 같이 정해야 한다. #41은 교차 검수에서 「문제 아님」으로 정리됐다.

**「확인」 칸의 뜻**

- 직접: 검토자가 코드에서 다시 봤다.
- 재현: 코덱스가 실제로 돌려서 확인했다.

- 추정: 코덱스의 짐작이라 실제로 일어나는지는 아직 모른다.
