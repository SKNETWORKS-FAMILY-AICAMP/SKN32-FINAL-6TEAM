# 지도 정보·카드 도구·하단 연결 구현 및 검증

요청한 정보 순서, 카드 아이콘 한 줄, 하단 안내 연결, 거리 칩과 마커의 단일 표시를 로컬 코드에 반영했다. 전체 되돌리기도 실제 복원 API에 연결했다. 공개 서비스에는 배포하지 않았다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 요청 화면 변경 | 구현 완료 | 4/4 = 100% |
| mock 서버 시험 — 화면 반응 | 통과 | 53/53 = 100% |
| 지도·복원 상태 단위 시험 | 통과 | 73/73 = 100% |
| 로컬 개발 DB 복원 시험 | 통과 | 11/11 = 100% |

실서버 확인(서버 응답): x600 서버의 cs 프로젝트 서버는 이번 변경으로 확인하지 않았다. 아래 DB 시험은 이 PC의 로컬 개발 DB를 사용한다. 배경 지도 타일을 실제로 받은 것은 운영 일정 API 확인과 별개다.

## 결과

- 지도 정보: 선택 일정 이름·종류 → 확인 필요 수 → 교체 화살표와 변경 수 → 전체 되돌리기. 표시용 `변경` 글자는 제거하고 접근 가능한 이름과 툴팁을 유지했다.
- 카드 도구: 자동 추천·수정·삭제 아이콘을 제목 옆 같은 줄에 배치했다. 아래 중복 버튼은 제거했다. 긴 제목은 두 줄까지 표시하며 변경 체크와 시간 되돌리기·확인 필요의 기존 위치를 유지한다.
- 하단 안내: 첨부 이미지의 초록색·곡선·화살표·점 표현을 적용했다. 안내와 하단 전체 자동 추천 영역이 틈 없이 이어진다. 밀기/클릭으로 수정안을 여는 기존 미리보기 동작은 유지한다.
- 거리 칩: 칩에 포함된 모든 일반 마커와 연결 꼬리를 같은 화면 갱신에서 숨긴다. 돌아오면 같은 마커를 복구한다. 경로선과 원좌표는 유지한다.

전체 되돌리기의 유효 판·잠금/예약 보호·실패 시 전체 취소 및 새로고침 경계는 [복원 계약](../../external/web-intake-restore.md)을 따른다. 최초 사용자 저장 성공 때 원판을 확정하며 복원 성공 뒤 재제출 대기 상태도 해제한다. 저장 전 삭제 대기만 있는 경우 API 호출 없이 삭제 대기만 취소한다.

## 검증 근거와 범위

최종 제품 빌드 성공 후 동일 빌드에서 Chrome 브라우저로 아래 다섯 시험 파일을 실행했다. 고유 시험 53개가 한 번의 종합 실행에서 모두 통과했다.

| 시험 | 수 | 확인 대상 |
|---|---:|---|
| `card-status-footer.spec.ts` | 5 | 카드 상태 위치·출처·긴 제목 |
| `map-card-continuity.spec.ts` | 4 | 정보 순서·아이콘·키보드 복원·하단 경계·미리보기 |
| `map-edge-visibility.spec.ts` | 2 | 375/1280px 묶인 거리 칩·모든 마커 숨김/복구·경로 유지 |
| `plan-check-map-detail.spec.ts` | 14 | 마커·경로·일차·지도 조작 |
| `plan-check-redesign.spec.ts` | 28 | 카드 수정·시간 조정·수정안 전환·잠금 |

별도 촬영 시험은 2/2 통과했다. 촬영 모음의 이미지 로딩·화면 크기 전환과 375px 가로 넘침도 별도 브라우저 조작으로 확인했다. 촬영 시험을 53개에 중복 합산하지 않았다.

지도 단위 시험과 `review-undo.test.ts`, `use-server-review-undo.test.ts`: 10개 파일 73/73 통과. 타입 검사와 변경한 프론트 파일의 ESLint 검사 모두 통과했다.

로컬 개발 DB의 [복원 시험](../../../tests/e2e/test_intake_restore.py): 11/11 통과. 본인 접수, 현재 판 충돌, 유효 원판, 정확한 시각 복원, 잠금/예약 보호, 검사 실패 롤백을 확인했다. 외부 Google·Naver 지도 서비스의 실제 접속과 공개 일정 API 응답은 이번 확인 범위에 포함하지 않았다. 지도 구현별 처리는 단위 시험, 실제 렌더링은 OpenStreetMap으로 확인했다.

기존 화면 시험은 새 변경 아이콘과 단추 이름, 이동 줄의 도착·체류 표시를 반영해 비교 대상을 수정했다. 작은 지도에서 펼친 조작 버튼 아래에 있는 마커를 고르는 시험은 전체 보기 후 조작 버튼을 접는 실제 사용자 순서로 실행했다. 강제 클릭으로 통과시키지 않았다.

## 화면 점검

- 375px·1280px에서 제목과 도구가 겹치지 않고 가로 넘침이 없다. 새 카드 아이콘 세 개는 각각 44px이다.
- 아이콘 설명은 포인터와 키보드 초점에서 보인다. 전체 되돌리기를 Tab/Shift+Tab으로 선택하고 Enter로 실행했다.
- 하단 안내와 고정 버튼 영역의 경계 간격은 2px 이하로 검증했다. 수정안은 `dry_run`으로만 받아 미리보기 중 저장 요청을 만들지 않는다.
- 새 움직임은 transform/opacity를 사용하며 움직임 줄이기 설정을 제공한다. 기존 출처의 일반/움직임 줄이기 전환 시험도 통과했다.
