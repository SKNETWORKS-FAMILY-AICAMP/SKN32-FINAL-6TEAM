## 실행 및 증거

실서버 확인 (cs 프로젝트 서버 응답): 안 했음. 실제 계정·실제 여행 변경·실제 GPS 장치·외부 공유 앱 전송을 확인한 결과가 아닙니다. 위치 검사는 Chrome의 지연·성공·철회 조건을 제어하여 확인했습니다.

- [최종 단위시험 652건](../evidence/2026-10-12_uiux-audit/unit-final.json), [최종 로그](../evidence/2026-10-12_uiux-audit/unit-final.log).

- [TypeScript 로그](../evidence/2026-10-12_uiux-audit/type-final.log), [수정 범위 ESLint 로그](../evidence/2026-10-12_uiux-audit/lint-final.log): 종료 코드 각각 0, 진단 출력 없는 빈 파일입니다.

최종 명령은 웹 작업 폴더에서 `node node_modules/typescript/bin/tsc --noEmit`, `node node_modules/vitest/vitest.mjs run --maxWorkers=1 --reporter=json`, 수정된 화면·시험 파일에 대한 ESLint였습니다. 단위시험은 Node 메모리 상한 768MB로 단독 실행했습니다. 격리 환경에서 임시파일 ENOENT로 일부 시험이 로드되지 않은 실행은 통과 집계에서 제외하고, 같은 최종 소스로 로컬 실행한 652/652만 집계했습니다.

생산 빌드는 분리된 작업 사본에서 webpack·CPU 1개·Node 메모리 상한 768MB로 통과했습니다. 이후 문의 캐시 보호 한 건이 추가되어 이 마지막 수정은 생산 빌드·화면 사본에 미포함입니다. 해당 수정은 최종 TypeScript·ESLint·단위시험과 문의 3조건 재현으로 확인했습니다. 문의 화면 일반 표시 검사는 보호 수정 전 빌드입니다.

화면 검사 대상은 시작 안내·약관/취향·여행 등록·여행 목록·등록 여행·기존 검증 주소 이동·기존 결과 주소 이동·접수 검증·전송 중 주소 재방문·마이페이지·프로필·문의·로그인 취소입니다. 가로 넘침·본문 존재·실행 오류·주소 이동·글꼴 및 실제 배치 확인을 포함합니다. 이 검사만으로 각 화면의 모든 상태가 정상이라고 일반화하지 않습니다.

## 전체 동작시험과 남은 항목

기존 711건의 전체 실행은 74건 결과(50 통과·20 실패·4 건너뜀)를 남기고 중단했습니다. [중단 실행 원본 로그](../evidence/2026-10-12_uiux-audit/full-run-interrupted.log)를 보존했습니다. 기록의 실패는 모두 제품 결함이 아닙니다. 현재 계약과 어긋난 시험 기대값 11건, 제품 결함 후보 2건, 시간 경계 계측 보류 2건, 환경·토스트 만료 경쟁 3건, 오류 기록 부족 2건으로 분류했습니다. 실패 20건을 수정 후 모두 재실행한 상태가 아닙니다. 후보 중 일정 추가 실패 안내 소실은 수정·재시험 통과했고 거리 버튼 높이는 남았습니다.

확인된 낡은 기대값 중 선택 동의 4개, 일정 추가 검색 자동 초점, 확장 지도 도구 겹침 허용, 촬영 제목의 정확한 선택자는 해당 시험 3개 파일에 반영했습니다. 시험 백업 사본이 재수집되지 않도록 Playwright에서 `_backup`을 제외했습니다. 나머지 기존 실패 시험은 변경된 계약과 개별 대조·재실행이 남습니다.

낡은 실패 시험 11건 중 수정된 사례는 4건이며 재실행 전입니다. 남은 7건은 거리 칩 좌우 선택 1건, 최상단 일정 추가 영역 높이 2건, 확장 지도 도구 겹침 허용 2건, 선택 약관 개수 2건입니다. 채팅 복구 시험은 실패 화면만 남아 오류 본문·추적이 부족하므로 원인을 확정하지 않았습니다.

미확정 항목은 다음과 같습니다.

1. 거리 접힘 버튼은 현재 CSS 높이 44px이며 [현재 화면 계약](../../external/web-flow-2026-10-09.md)은 40px입니다. 의미 없이 시험 기대값을 바꾸지 않았고, 후속 계약·실제 표시를 대조해야 합니다.
2. 시각 고정 경계 두 시험은 날짜 탭 상자 하단의 그림자 여백 12px 포함 여부 때문에 8.5px 차이가 났습니다. 실제 날짜 버튼 하단을 기준으로 재계측해야 합니다.
3. 전체 동작시험의 나머지 경우, 영문·긴 글·확대·다른 지도 제공자·실기기 조합은 이번 26개 경로 검사로 보증하지 않습니다.

PC에서 ENOSPC 및 메모리 부족이 발생했습니다. 당시 C 드라이브 여유 약 0.326GiB, Node 프로세스 64개·작업 집합 약 4.66GB를 확인했습니다. 이번 검사에서 만든 재생성 가능한 빌드 캐시만 경로 확인 후 정리했고, 소스·원본 백업·로그·스크린샷은 유지했습니다. 자원이 회복된 뒤 기존 빌드 재사용으로 남은 화면 7개는 마쳤으나 711건 전체 실행은 재개하지 않았습니다.

Claude CLI에서 요청한 실제 모델 `claude-sonnet-5-5`의 연결 응답은 확인했습니다. 소스 제공 없는 연결 시험만 수행했습니다. 화면 소스와 작업 규칙을 Anthropic에 제공하는 검토 실행은 자동 승인 검토가 구체적인 코드 제공 승인을 요구하며 거절했습니다. 사용자에게 제공 범위·제외 범위를 제시한 승인 질문은 대기 중이며, 이를 우회하거나 Claude 코드 검토를 완료했다고 표시하지 않습니다.
