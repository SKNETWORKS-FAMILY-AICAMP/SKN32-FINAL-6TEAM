## 처리와 검증

카드사 삼성만 새 픽셀로 남기고 결제 서비스명·카드 종류·카드 번호를 흰색으로 덮었습니다. 생성형 재작성이나 외부 이미지 전송 없이 로컬에서 처리했습니다. 마스킹 사본의 결제 영역 밖 픽셀은 원본과 일치합니다. 운임·옵션료·출발·도착·시각은 변경하지 않았습니다. 원본 7장과 이전 마스킹 판도 개인 보관소에 백업했습니다.

결제수단 영역 10칸을 모두 시각 확인했습니다. 최초 검사에서 사진3·7 하단의 글자 경계에 여유가 부족한 부분을 발견해 마스킹 범위를 넓힌 뒤 다시 확인했습니다. PNG 사본에는 원본 EXIF 메타데이터를 복사하지 않았습니다.

보관소는 Windows 로컬 AppData 아래이며 팀 Git·프로젝트 폴더 밖입니다. 현재 Windows 사용자·SYSTEM·Administrators만 허용하도록 권한을 설정하고 전체 파일을 검사했습니다. Windows 관리자는 접근할 수 있으므로 암호화 보관이나 관리자 접근 차단을 의미하지 않습니다. 출발·도착 같은 이동 정보는 남아 있어 외부 공유용 완전 익명 자료로 부르지 않습니다.

기존 평가 자료 39개의 파일별 SHA-256을 복사본과 모두 대조한 뒤 원래 작업 폴더를 개인 보관소의 백업으로 이동했습니다. 과거 작업 폴더 링크는 더 이상 유효하지 않으며 개인 보관소 경로는 팀 공유 문서에 싣지 않습니다. 별도 승인 없는 외부 전송은 하지 않았습니다.

## 보존 위치와 한계

개인 보관소에는 masked(마스킹7장), evaluation(기존 평가39파일), _backup(원본7장·이전 판·작업폴더 원본), verification(해시·픽셀·접근권한·시각검사)을 보존했습니다. 해당 경로는 사용자에게 개인 대화에서 직접 안내합니다. Codex가 받은 첨부 원본은 변경하지 않았습니다.

팀 작업 폴더에서는 `datasets/mobility/user_taxi_golden_20261011_v1`의 부재를 확인했습니다. `.tmp`의 관련 파일명·문구 검색에서 이번 처리 스크립트의 경로 참조만 확인됐습니다. 이 확인은 OS의 다른 개인 폴더·과거 다른 도메인 자료까지 삭제하거나 조사한 결과가 아닙니다.
