# 일정 경계의 장소 검색과 신규 추가 — 2026-10-09

기존 일정 사이에서 추가할 때 장소를 검색하고 결과를 선택하면, 고른 실제 장소의 좌표·출처·식별값을 그대로 추가 요청에 보낸다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 입력기·검색·저장 연결 | 완료 | 1/1 = 100% |
| 직접 관련 단위시험 | 통과 | 14/14 = 100% |
| 타입·ESLint 검사 | 통과 | 2/2 = 100% |

## 변경과 인터페이스

- [AddStop](../../../frontend/apps/web/src/features/plan-check/add-stop.tsx): `date`, `blocked`, `onSave` 유지. `initial?: {start,end}`, `onCancel?`, `search?: (query)=>Promise<AddStopPlace[]>` 추가. `onCancel`이 있으면 선택 경계 바로 아래에서 열린 form으로 제공한다. 최초 inline 진입의 초점은 부모의 callback 재생성으로 반복 이동하지 않는다.
- [PlaceSearch](../../../frontend/apps/web/src/features/plan-check/place-search.tsx)와 [별도 CSS](../../../frontend/apps/web/src/features/plan-check/add-stop.module.css): 두 글자부터 검색, 결과의 이름·종류·주소 표시, 정확한 장소 선택·다시 검색, 실패 안내·재시도. 새 검색 뒤 늦게 도착한 응답은 폐기한다. 좌표 없는 결과는 선택 불가로 설명한다.
- [NewStop·추가 요청](../../../frontend/apps/web/src/features/plan-check/new-stop.ts): `pickedPlace?: PickedPlace` 보존. 삭제 항목 번호까지 포함한 최대 번호+1에 기존 6개 필드로 append 저장한다. 검색 기준 일정이 없는 빈 계획에서는 기존 직접 이름 입력 계약을 유지하고 제한을 명시한다.
- [cs 프로젝트 서버 연결](../../../frontend/apps/web/src/features/plan-check/use-server-review.ts): `searchToAdd(anchorId,query)`가 기존 읽기 전용 검색 API를 재사용한다. 정확한 좌표·출처·관광 장소 식별값을 `pickedPlace`로 반환한다. 추가는 선택값을 이름 재검색으로 바꾸지 않는다. API 변경은 하지 않았다.

검색 결과의 기존 일정 시간 판정은 신규 일정의 방문 시각 판정으로 표시하지 않는다. 신규 추가 때 cs 프로젝트 서버가 앞뒤 이동시간과 제약을 재검사한다. 실패하면 입력·선택 장소를 유지하며 취소는 저장하지 않는다.

## 시간순 배치 확인

`review.py`는 `collect(...).rows`로 항목·이동을 생성한다. `assemble.py`의 `collect`는 시간 채움 후 날짜·시작 시각·원문 순으로 정렬한다. 따라서 새 원본 번호가 마지막이어도 실 응답의 검증 항목과 이동은 실제 시간순이다. 루트가 공통 mock 응답도 같은 순서로 맞추고 화면 삽입 위치를 담당한다.

## 검증과 남은 범위

새 시험 8/8 및 기존 전체 되돌리기 6/6, 총 14/14 통과했다. 정확한 선택값 저장, 삭제 번호 보존, 검색 중 쓰기 0건, 오래된 판 거절 후 재조회, 접수 전환 뒤 늦은 검색 거절, 추가 실패 원판 보존을 포함한다. 타입검사·변경 파일 ESLint·공백 검사를 통과했다. [재현 명령과 실제 출력](../evidence/2026-10-09_2030_일정추가_장소검색.md).

- mock 서버 시험 (화면 반응): 이 하위 작업에서는 안 했음. 최신 빌드·통합 브라우저 시험·촬영은 루트 담당이다.
- 실서버 확인 (서버 응답): 안 했음. 공개 배포나 실제 외부 검색은 수행하지 않았다.

루트가 맡은 공통 mock·plan-check·plan-rows·공통 CSS와 기존 place-change는 수정하지 않았다. 소유권 내 입력기·새 검색 컴포넌트·연결 hook·직접 시험만 수정했다.
