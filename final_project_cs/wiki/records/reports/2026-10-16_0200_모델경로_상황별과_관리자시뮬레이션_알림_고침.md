## 1. 모델 경로 — 상황별 설정과 「끔」 (사용자 지시 10-16)

> 「상황에 따른 모델 설정이 가능하게 해놔야 하는 거 아니야? 해당 옵션 그냥 env 파일 따라가게 off 로 해둘 수도 있어야겠고」

- 관리 콘솔 운영 설정에 칸이 셋이다: 채팅 해석 · 계획 읽기 · 번역(`llm.model_route`) / 일정 짚기(`llm.model_route.pointer`) / 공지 확인(`llm.model_route.notice`).
- 각 칸의 기본은 **끔** — 콘솔이 끼어들지 않고 환경 파일(`ACOP_MODEL_ROUTE_CHAT` · `_POINTER` · `_NOTICE`, 줄이 없으면 local)을 따른다. 그래서 배포해도 지금 동작과 같다.
- 일정 짚기 · 공지 확인에는 API 를 고를 수 없다(학습 모델이 API 에 없다).
- 채팅 칸 이름은 10-15 판 그대로라 이미 저장된 값이 이어진다.
- 안내: [모델 경로](../../external/llm-model-route.md)

## 2. 관리자 「재난 6종 시뮬레이션」이 실제 알림으로 이어지지 않던 문제 (사용자 보고 10-16)

> 「지금 모니터링 옵션 관리자웹앱에서 조정하는 거 실제 브라우저 알림으로 안 가고 적용이 안 되니까 해당 기능 수정해」

코드를 따라가 보니(하위 조사 + 직접 확인) 끊기는 곳이 셋이었다.

| 원인 | 결과 | 한 일 |
|---|---|---|
| 운영 앱이 「게스트 여행 빼기」 규칙을 꽂지 않아, 관리 화면 목록에 감시가 보지 않는 게스트 여행까지 나왔다 | 그 여행에 시험을 걸면 저장만 되고 감시 결과 · 알림이 영영 안 생김 | 운영 앱도 같은 규칙을 꽂는다(`composition.wire_trip_scope`). 시험 저장 때 게스트 여행은 422, 재난 정지 중 여행은 409 로 이유를 말하고 거절. 목록에 「재난 정지 중(감시 쉼)」 표시 |
| 시험이 켜진 일정에서도 **고르지 않은 실제 자료** 하나만 조회에 실패하면 판정 전체가 「조회 실패」 | 시험 사건 · 예보 안내가 고객에게 가지 않고 「확인 못 함」만 감 | 시험이 켜진 일정에서는 고르지 않은 자료의 실패가 시험 결과를 덮지 않게 했다(실패는 `simulation_ignored_failures` 에 남김). 시험 없는 실제 일정의 판정은 그대로 |
| 고객 웹에 「브라우저 알림」 기능이 없었다(화면 안 알림 막대뿐) | 탭을 보고 있지 않으면 알 길이 없음 | 아래 3 |

- 시험 알림이 디스코드 · 텔레그램으로 나가지 않는 것은 **설계**다(시험이 실제 고객 채널로 새지 않게) — 바꾸지 않았다.
- 「한도 · 감시 조절」 화면의 감시 단계는 실서비스 모드에서 일부러 저장하지 않는다(화면에도 그렇게 적혀 있다) — 바꾸지 않았다.

## 3. 고객 웹 브라우저(운영체제) 알림

- 여행 화면 「받은 알림」 탭 위에 「브라우저 알림 켜기」 단추가 있다. 누르면 브라우저가 권한을 묻는다(누르지 않으면 묻지 않는다).
- 켠 뒤에는 **여행 화면이 열려 있지만 그 탭을 보고 있지 않을 때** 새 알림이 운영체제 알림으로도 뜬다. 보고 있으면 지금처럼 화면 안 막대만 뜬다(두 번 띄우지 않는다). 누르면 그 탭의 받은 알림으로 온다.
- 탭을 닫으면 오지 않는다 — 닫혀 있을 때도 받으려면 서비스 워커 · 웹 푸시(VAPID 키)가 필요하고 범위가 커서 이번에는 하지 않았다.
- 막혀 있으면(denied) 「주소창 왼쪽 자물쇠 → 알림 → 허용」 안내를 보인다.
