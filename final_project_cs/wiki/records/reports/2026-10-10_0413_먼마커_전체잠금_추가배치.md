# 먼 마커·전체 잠금 해제·일정 추가 배치

사용자 요청 세 건을 구현하고 새 배치를 두 너비의 목업으로 촬영했다. 커밋·푸시는 기존 담당 세션의 팀 저장소 role-manager 통합 절차로 인계한다. 이 기록 시점에는 이번 추가분의 푸시·공개 배포를 확인하지 않았다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 사용자 요청 | 구현·목업 완료 | 3/3 = 100% |
| mock 서버 화면 시험 | 통과 | 26/26 = 100% |
| 잠금·추가·지도 계산 시험 | 통과 | 30/30 = 100% |
| TypeScript·ESLint·생산 빌드 | 통과 | 3/3 = 100% |
| 촬영 | 완료 | 12/12 = 100% |

지도 조작 중 먼 일정 마커는 거리 글자를 제거하여 방향과 일정 번호만 남긴다. 조작이 멈추고 기존 180ms 정착 지연이 끝나면 거리를 복원한다. 줄어든 실제 폭으로 가장자리 위치와 주변 레이블 가림을 다시 계산한다. 읽기용 이름에는 거리와 이동 동작을 유지한다. 폭 자체를 애니메이션하지 않는다.

전체 잠금 해제는 전체 자동 추천 오른쪽, 스크롤 목록 맨 위에만 둔다. 잠긴 일정이 없으면 숨긴다. 특정 카드나 필터·날짜에 한정하지 않고 현재 여행의 잠긴 일정 전부를 기존 수정 API 한 요청으로 해제한다. 잠금 필드만 보내므로 시각·장소·예약 여부와 되돌리기 대상은 유지한다. 실패하면 응답 전 화면을 바꾸지 않고 기존 오류 처리를 거친다. 성공 후에는 자동 추천 단추로 키보드 초점을 돌린다. 개별 잠금 재클릭도 유지한다.

일정 추가는 카드 경계에 걸친 원형 + 대신 일정 사이 왼쪽에 이름을 붙인 단추로 배치했다. 일정 추가와 이동 전 추가를 구분한다. 모든 추가 경계에 24px 간격을 두고, 현재 중심 근처 하나만 표시한다. 표시 전후 간격은 바뀌지 않으며 누르는 영역은 높이44px다. 입력·취소·키보드 복귀와 앞뒤 일정 기준은 유지한다. 새 배치는 목업에서 볼 수 있다.

화면 시험 분모26은 이번 신규6개와 기존 회귀20개의 고유 시험 수다. 첫 실행25개 통과·1개 실패는 넓은 화면에서 모두 지도 안에 들어와 화면 밖 마커가 없었던 시험 조건 문제였다. 두 너비 모두 지도 확대 후 조작하도록 보정한 재실행2/2이 통과했다. 제품을 바꾸어 시험 조건 문제를 숨기지 않았다. 지도 드래그를 누른 상태에서 거리 부재·폭20px 이상 축소와 종료 후 복귀를 직접 확인했다. 전체 해제 단일 요청·필드 두 개·초점 복귀와 스크롤 숨김, 추가 단추 왼쪽 정렬·검색 진입·취소 복귀도 확인했다.

계산·훅 시험30개에는 여러 원본의 잠금 전부를 한 판에서 해제, 잠금 없음 무요청, stale_revision 실패 시 기존 판 유지·재조회, 삽입 위치와 지도 배치가 포함된다. TypeScript·ESLint와 표준 Turbopack 생산 빌드는 통과했다. 기존 공개 cs 프로젝트 서버 API는 읽은 소스상 여러 잠금 필드의 묶음 수정을 지원하며 이번에는 API 코드를 바꾸지 않았다.
