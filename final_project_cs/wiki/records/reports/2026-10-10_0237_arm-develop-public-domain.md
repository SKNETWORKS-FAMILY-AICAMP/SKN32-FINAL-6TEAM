## 변경과 이유

기존 접속 확인용 정적 화면을 웹·고객 API 역방향 프록시로 교체했습니다. 기존 인증서 설정과 CDN 경유 접근 제한은 유지했습니다. API 문서와 내부 점검 경로는 404로 닫고 고객 API·계획 링크·개인 AI 입구만 API에 연결했습니다.

기존 웹 이미지는 방문자 PC의 루프백 API 주소를 번들에 넣고 있었습니다. 같은 develop 소스 `210b020067a1e42f2622262adeb60d1f3d371668`에서 API 기본 주소만 빈 값으로 다시 빌드하고 웹 컨테이너를 교체했습니다. 자동 배포 도구도 이후 웹 이미지를 같은 출처로 빌드하도록 수정했습니다. 배포된 JavaScript 파일 33개를 검사했으며 옛 루프백 API 문자열이 있는 파일은 0/33입니다.

공개 기본 주소·허용 출처는 기계 내부 환경 파일에 설정했습니다. 기존 질의 회차가 종료되어 배포 잠금을 확보한 뒤 API·상시 작업자를 교체했고 모델 프로세스·임베딩·DB·추론 시험은 재시작하지 않았습니다. 해당 실제 질의 회차는 교체 전에 요약을 저장했습니다. 이 조치는 모델 질의의 시간 초과 수정 후보를 함께 반영한 것이 아닙니다.

## 보존과 되돌리기
