- 날짜·시각·장소 동시 이동: 기존 독립 시험에서 새 날짜/시각 누락을 다시 확인했습니다. 동일 ID의 날짜 이동은 원본 ISO 날짜·전체 시각 범위·장소를 전후 값에 담습니다. 날짜만 변경·연도 경계도 보존합니다. 시간대 변환이나 날짜 추측을 추가하지 않았습니다.
- 새 ID 교체·종료 시각 변경: 기존 같은 날짜/시작 시각 교체 인식은 유지하고, 범위가 달라지면 양쪽 범위와 장소를 함께 담습니다. 시작/날짜도 다른 새 ID는 임의로 연결하지 않으며 서버 원문을 남깁니다.
- 로그아웃: 실제 회원 화면에서 탭 저장소의 이전/새 장소 잔존을 재현했습니다. 확정된 세션 종료(성공/이미 종료된 로그아웃·현재 세션 만료·미인증 조회)는 모든 여행의 diff 키만 제거합니다. 무관한 키는 보존합니다. 실패한 로그아웃·통신 실패·이전 세션의 늦은 거절을 확정 종료로 취급하지 않습니다. 채팅 성공 콜백은 요청 때의 세션 객체와 query 객체를 모두 확인해 종료 뒤 diff 재저장을 막습니다.

서버 API·요청/응답·DB·승인 정책·ChatDiff 저장 스키마는 그대로입니다. 기존 단독 시각/장소 표시·동일 서버 줄만 숨기는 규칙·20버전 보존도 유지합니다. 새로운 서버 계약이나 다른 718/731/732 후보를 합치지 않았습니다.
