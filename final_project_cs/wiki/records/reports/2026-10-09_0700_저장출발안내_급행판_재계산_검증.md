# 저장 출발 안내의 급행 입력 판 검증

급행표가 바뀌면 이전 출발 안내를 보류하고 다시 계산한 구간으로 안내하도록 연결했습니다. 변경 감지와 저장·재계산 흐름을 통제 시험에서 확인했으며 실제 탑승 정확도까지 검증한 결과는 아닙니다.

## 원인과 동작

저장 문맥과 출발 관측은 일반 시간표 생성 시각과 규칙 번호 두 값만 비교했습니다. 급행표 내용이 바뀌어도 두 값이 같으면 대조를 통과해 이전 구간의 안내를 계속 만들었습니다. 수정 전 두 조건 모두 실패했습니다. [최초 재현](../evidence/2026-10-09_0648_저장안내_급행판/express-context-before-v1.log).

계산에 사용한 런타임의 급행 입력 스냅샷에서 노선별 내용 SHA-256과 파일 부재 상태를 정렬해 공통 식별자를 만듭니다. 저장과 관측이 같은 함수를 쓰며 저장 문맥의 식별자가 다르거나 옛 문맥에 식별자가 빠져 있으면 외부 도착 조회 전에 needs_replan/basis_changed로 보류합니다. 이미 있는 감시→Case→재계산 흐름을 통해 새 일정과 새 문맥을 만들고 새 출발 안내를 한 번 적재합니다. 외부 채널로 배달한 것은 아닙니다.

파일 경로·수정 시각만 바뀌고 내용이 같으면 식별자를 유지합니다. 현재 파일을 다시 읽어 저장 판을 만들지 않고 실제 계산기가 가진 스냅샷을 씁니다. 따라서 이미 계산 중인 이전 판의 문맥이 새 파일 판으로 잘못 표시되지 않습니다. 로컬 경로나 메타데이터는 저장 문맥에 넣지 않습니다. 수동 Runtime에서 급행 추적 자체를 전달하지 않으면 기존 두 필드 호환을 유지합니다. 추적 상태가 있는데 내용 해시가 빠진 입력은 오류로 처리합니다.

## 검증 범위

새 단위8조건은 식별자 저장·내용 변경의 조회 전 보류·같은 내용의 경로/수정 시각 교체·옛 문맥 보류·추적 없는 수동 런타임 호환·파일 부재/생성과 정렬 순서·실제 임시 gzip 교체와 wiring 연결·내용 해시 없는 추적 입력 거부입니다. 임시 표의10:00 출발을10:05로 바꾸면 이전 저장 문맥은 보류되고 새 문맥은10:05 출발·10:09 도착으로 모델 재검증됩니다. 이전 런타임의 문맥은 이전 판을 유지합니다. 실제 운행 관측은 아닙니다.

신규 로컬 개발 DB2조건은 추적 식별자가 있는 문맥과 옛 문맥 각각을 사용합니다. 무작위 시험 테넌트의 통제 도보 구간에 급행 입력 판을 바꾸어 이전 안내가 보류되고, Case가 해결되어 일정 판2→3과 새 이동 항목·문맥이 저장되며, 추가9회 감시에서 사건이 더 열리지 않고 새 출발 안내가1회 적재되는 것을 확인했습니다. 도보 구간으로 저장 처리의 연결을 검증한 결과이며 실제 급행 열차에 탑승하거나 실시간 버스 응답을 수집한 결과가 아닙니다. fixture가 시험 여행을 정리합니다. [첫 DB 확인](../evidence/2026-10-09_0648_저장안내_급행판/express-context-db-v1.log).

관련43/43에 신규8이 포함되고 이동 기본층 565/565에도 포함됩니다. 출발 처리 통합 111/111에는 신규 DB2가 포함됩니다. 부분 묶음들을 중복 합산하지 않습니다. 기본층은 일반 묶음 552·택시 대체 5·계산기 연결 8로 나눴습니다. 연결과 통합은 Windows 비동기 로컬 통신 및 로컬 개발 DB가 허용되는 실행에서 확인했습니다. live·mobility_full 표시를 제외했으며 전체 cs 관문·배포 HTTP 확인까지 모두 재실행한 것은 아닙니다.

## 대가와 남은 범위

현재는 모든 저장 이동 구간에 공통 급행 판을 비교하므로 도보처럼 직접 영향이 없는 구간도 급행 내용 판이 바뀌면 한 번 재계산할 수 있습니다. 무변경 반복에서 사건을 새로 만드는 흐름은 두 DB 조건의 각9회 감시에서 없었습니다. 과도한 재계산의 실제 운영 빈도나 서비스 지연을 이번에 측정하지는 않았습니다.

관측을 마친 뒤 안내 저장 전 급행 입력이 또 바뀌는 경합은 이번 해결 범위 밖입니다. 기존 여행 조건 경합 시험이 통과해도 급행 파일의 저장 직전 최신성을 증명하는 것은 아닙니다. 이미 외부로 배달한 안내의 회수, 실제 현재 위치·탑승, 실시간 지하철 연결·첫차/막차의 실운행 정확도, 혼합 환승 운임·누락 경로,1.2km 안의 독립 웹 대조와 최초 자료 적재 지연은 남았습니다.
