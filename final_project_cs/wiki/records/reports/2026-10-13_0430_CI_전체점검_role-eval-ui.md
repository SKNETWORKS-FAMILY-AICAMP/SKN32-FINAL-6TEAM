## 1. 무엇을 어떻게 돌렸나

GitHub 의 CI 를 이 PC 에서 같은 명령으로 돌렸다. develop PR 이 열리면 도는 워크플로 넷이다.

| CI | 로컬에서 한 것 | CI 와 다른 점 |
|---|---|---|
| `ci-develop` · `ci-main` 백엔드 | 깨끗한 git worktree(로컬 `.env` 없음), 새 DB(`acop_ci_dev` · `acop_ci_main`), CI 의 환경값(가짜 키 · `PGTZ=Asia/Seoul`) | DB 는 Docker `acop-test-pg`(5433). Windows · Python 3.12 venv |
| ruff | `ruff==0.16.8 check .`(저장소 루트) | 없음 |
| Docker | `final_project_sample` 빌드(이 브랜치의 ci-main 규칙) | 없음 |
| `ci-web` | `npm run check`, `test:live`(`NEXT_PUBLIC_DATA_MODE=demo` · `TZ=Asia/Seoul`) | 브라우저는 설치된 Chrome(`PLAYWRIGHT_CHANNEL=chrome`) — 이 PC 에는 Playwright 의 chromium-1243 이 없다. `npm ci` 는 하지 않고 기존 `node_modules` |
| `ci-admin` | `check` · `export:html` 뒤 `git diff` · `test:e2e` · `test:unconfigured` | Chrome 채널 |

### 3-2. 오늘 변경이 만든 화면 결함 → 화면 수정 (`f2da364a` · `b2441a50`)

**하단 칸 위치(`f2da364a`).** 카드 높이 통일(④)로 카드가 내용보다 길어지면 하단 칸(확인 필요 · 되돌리기)이 내용 바로 아래에 떴다. 그래서 「카드 오른쪽 아래」 규칙(`card-status-footer` · `card-footer-exclusive`)이 깨졌다.

- 고친 방법: 늘린 카드에만 `data-even` 을 달고, 세로 flex + `margin-top: auto` 로 하단 칸을 바닥에 둔다.
- 변경 전 커밋(`18fe7610`)에서는 같은 시험이 통과해, 원인이 ④ 임을 확인했다.

**측정 되먹임(`b2441a50`).** 위 수정 뒤 다시 돌린 전체 실행에서 `card-status-group` 이 「element is not stable」로 실패했다.

- 원인: 다음 배치 때 바닥에 붙은 하단 칸 위치까지 「내용」으로 재어, 카드 높이가 배치마다 조금씩 계속 커졌다.
- 고친 방법: 잴 때만 `data-even` 을 떼어 하단 칸을 내용 바로 아래로 두고 잰다. `min-height` 는 그대로라 주변은 움직이지 않는다.
