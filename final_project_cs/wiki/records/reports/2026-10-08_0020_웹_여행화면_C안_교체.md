## 한눈에

- 등록한 여행 화면이 계획 확인 화면과 같은 **지도 위 시트**가 됐다. 그 위에 목업 C안의 우리 기능(종 · 알림 센터 · 재난 표시 · 제목 펼침과 공유 · 「상세 보기」 · 왼쪽 시각 고정 · 「일정 | 채팅」 · 채팅 막대)을 올렸다.
- 서버 호출은 새로 만들지 않았다. 여행 조회 · 경로선 · 채팅(SSE) · 제안/알림/이력 · 되돌리기 · 재난 정지/다시 시작/회복 · 항로 지킴이 · 위치는 **기존 연결을 그대로** 새 화면에 이었다.
- 서버에 없는 것은 화면에서 빼지 않고 **「준비 중」이라 말한다** — 등록한 여행 이름 바꾸기 · 장소 사진 · 카카오톡 공유(앱 키 없음). 알림 읽음은 서버에 없어 **이 브라우저에만** 기억한다.
- 시험하다 실제 결함 하나를 찾아 고쳤다: 여행 화면에서 메뉴로 언어를 바꾸면 메뉴 서랍이 닫혔다(언어별로 여행을 다시 읽는 동안 화면 틀이 바뀜).
- 검증은 **mock 서버 시험과 단위 시험**에, 2026-10-08 **로컬 실서버 확인**(2·3단계 — 아래 「실서버 확인」)을 더했다. 재난 정지 · 새 알림 막대 · 선택 요청 · 되돌리기는 서버가 그 상황을 만들어 주지 않아 실서버로 보지 못했다.
- 실서버 확인에서 찾아 고친 것: 상세 카드에 출처가 두 번 나옴 · 알림 문장 속 https 주소를 누를 수 없음. 같은 날 사용자 지시로 일정 카드 머리를 바꿨다(「상세 보기」는 펼쳤을 때만 · ＋/－ 는 맨 오른쪽).

## 서버에 없어 「준비 중」으로 둔 것(백엔드 협의 전)

| 화면 | 지금 | 서버에 필요한 것 |
|---|---|---|
| 이름 바꾸기 | 입력칸은 열리고, 저장하면 「이름 바꾸기는 준비 중이에요 … 저장하지 않았어요」 — 서버로 아무것도 보내지 않는다 | 등록한 여행의 이름 바꾸기(지금 `/v1/web/trips/{id}` 는 GET 만) |
| 알림 읽음 | 이 브라우저의 저장소에만 기억 — 다른 기기에서는 다시 새 알림 | 알림 읽음 상태 |
| 상세 보기의 사진 | 「등록된 사진이 없어요 · 장소 사진은 준비 중이에요」 | 장소 사진 · 설명 |
| 이동 줄의 수단 · 여유 | 서버가 이동 항목도 경로선도 주지 않은 구간은 「지도 앱에서 길찾기」만 | 등록 뒤에도 이동 항목 또는 경로선 — 로컬 실서버로 등록한 여행은 둘 다 비어 있었다 |
| 카카오톡 공유 | 「카카오톡 공유는 준비 중이에요 · 카카오 앱 키가 아직 없어요」 | 운영 설정: 카카오 JavaScript 앱 키(백엔드가 아니라 배포 설정) |

## 실서버 확인(2026-10-08)

로컬 실서버(웹 3100 = 이 코드 · 서버 8042 · 로컬 테스트 DB · Ollama). 새 여행 등록은 서버가 「게스트는 여행 1개까지」(`guest_trip_limit`)로 거절해, 이 브라우저 세션의 여행 하나(10/14~15 · 일정 7개 · 알림 1 · 살펴볼 점 3 · 이력 v1)로 봤다. 그 여행의 서버 값을 바꾸는 동작은 하지 않았다(등록 시도로 계획 읽기 접수 하나가 로컬 DB에 생겼다).

| 확인한 것 | 결과 |
|---|---|
| 종의 안 읽은 수 · 읽음 | 서버 알림 1개 → 종 「1」. 센터를 열면 받은 알림 탭부터 · 점 · 읽음 기록 · 종의 수 사라짐. 새로고침 뒤에도 읽음 유지(다시 열면 첫 탭 · 점 없음). Esc 로 닫으면 종으로 초점 |
| 탭 · 목록 | 살펴볼 점 3 · 받은 알림 1 · 변경 이력 1 — 서버 값과 같고 문장도 그대로 |
| 제목 펼침 · 여행계획서 열기 | ▴ · 연필 · 아래 줄. 바깥 누름으로 접힘. 계획서 링크는 서버가 200 HTML |
| 공유 창 | 「10.14 – 10.15 · 2일 · 7개 일정」, 텔레그램 · 메시지 주소에 실제 계획서 링크, 카카오톡은 「준비 중」(창 유지), 링크 복사는 클립보드 + 창 · 제목 줄 닫힘, Esc 는 「공유하기」로 초점. 「파일로 내려받기」 주소는 같은 경로 + `download=1` 이고 200 — 파일로 내려보내는 헤더는 브라우저가 다른 출처라 읽지 못해 **확인하지 못했다** |
| 이름 바꾸기 | 「준비 중 · 저장하지 않았어요」, 이름 그대로, 서버로 간 쓰기 요청 0건 |
| 상세 보기 | 실제 장소 정보(주소 · 출처 ⓒ한국관광공사 · 다음 일정), 「1일차 · 1/3」, 점으로 넘기면 카드 · 머리줄 · 핀이 함께 바뀜, 채팅 막대 · 경로선 숨김, 사진 준비 중, ← 로 돌아오면 그 일정이 펼쳐지고 초점 |

## 남은 일

- `role-eval-ui` 는 **매니저 브랜치가 가져가 적용한 뒤 매니저에서 `develop` 으로 병합**한다(2026-10-08 사용자 결정 — 우리는 `develop` 에 PR 하지 않는다).
- 위 「준비 중」 다섯 가지의 협의(백엔드 · 배포 설정). 특히 등록 뒤 경로선 · 이동 항목은 접수에는 있는데 여행으로 넘어오지 않는다.
- 실서버로 못 본 것(재난 · 새 알림 막대 · 선택 요청 · 되돌리기)은 서버가 그 상황을 만들 수 있을 때 확인.
- 언어 전환 직후 게스트 세션이 끊긴 일의 원인 확인.
