# 화면 밖 거리 칩과 마커 표시 교대 — 2026-10-09

거리 칩이 표시하는 일정은 일반 마커와 좌표 연결선을 함께 숨기고, 정상 가시범위로 돌아오면 원래 마커를 복원한다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 지도 어댑터 적용 | 완료 | 3/3 = 100% |
| 지도 단위시험 | 통과 | 60/60 = 100% |
| mock 서버 화면 시험 | 통과 | 2/2 = 100% |

## 변경

- LiveMap이 거리 칩 계산 결과를 렌더링과 마커 가시성에 공동 사용한다. 브라우저 표시 전에 교대하고, 묶인 칩에 속한 모든 일정 id를 처리한다.
- OSM은 같은 Leaflet 마커·분리 연결선 요소의 표시와 접근성·키보드 진입을 함께 전환한다. Google은 같은 AdvancedMarkerElement의 표시를 전환한다. Naver는 같은 마커 객체를 지도에서 분리/복귀하여 SDK의 투명 클릭 영역도 숨긴다.
- 마커를 지도 이동마다 재생성하거나 카메라를 다시 맞추지 않는다. 좌표·경로선·선택 동작은 유지한다.
- 전체 일정 맞춤에 하단 정보 막대 여백을 반영한다. `bottomInset` 전달 누락도 보완했다.

## 검증과 한계

- mock 서버 시험 2/2 (화면 반응): 실제 Chrome·Leaflet 렌더링의 375px/1280px 화면, 19.8초. 묶음의 세 마커·세 연결선 숨김, 기존 DOM 유지, 경로선 유지, 칩 선택, 전체 맞춤 후 칩 0개·모든 마커 복원을 검사했다.
- 실서버 확인 (서버 응답): 안 했음. 공개 cs 프로젝트 서버 응답과 Google·Naver 실 SDK의 화면 동작은 이 결과가 확인하지 않는다.
- `npm run test -- src/features/map`: 8개 시험 파일, 60/60 통과.
- `npm run typecheck`, 변경 파일 ESLint, `git diff --check` 통과.
- 루트가 만든 최신 `.next-live` 빌드를 `LIVE_SKIP_BUILD=1`로 사용했다. 공통 mock·plan-check·공통 시험 도구는 수정하지 않았다. 공개 배포는 수행하지 않았다.
