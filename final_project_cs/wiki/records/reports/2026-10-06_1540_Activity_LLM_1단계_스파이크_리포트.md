# Activity LLM 1단계 — 결정 문서 초안 · 스파이크 실측 리포트

## 결론

gpt-5.4-nano + `web_search` 로 활동 판정을 할 수 있다. 다만 실측에서 설계를 세 군데 바꿔야 했다.
1. json_schema 를 강제하면 `url_citation` 이 오지 않는다 → 출처 검증을 `web_search_call.action.sources` 대조로 바꿨다.
2. `seed` 를 쓸 수 없고 판정이 회차마다 갈린다 → 평가를 반복 측정으로 한다.
3. 지연이 가드레일 20초를 넘는 일이 있다 → 섀도 판정을 고객 응답 경로에서 분리한다.

결정 문서 D-CS-008(draft)을 올렸다. 코드 변경은 없다.

## 실측 요약

실행 조건: 2026-10-06 15:23 KST, 커밋 `662485c`, `openai==2.44.0`, 모델 `gpt-5.4-nano`. 상세와 원문은 evidence 문서에 있다.

- `temperature` 는 effort=none 에서만 받고, `seed` 는 400 오류(Unknown parameter)를 낸다.
- `web_search` 는 effort=none·low 모두 json_schema 와 함께 동작한다.
- json_schema 를 강제하면 `url_citation` 이 0건이다(effort none 1회, low 6회). 스키마 없이 부르면 2건이 왔다.
- `action.sources` 대조: 모델이 적은 URL 5/5건이 출처 목록에 정확히 있었다(3회).
- 지연(effort=low + web_search + schema, n=5): 6.92 / 7.60 / 9.27 / 20.10 / 27.99초. p50 9.27초이고, 2/5회가 20초를 넘었다.
- 판정 일관성: 같은 질의 8회 중 `open` 6/8, `unknown` 2/8.
- 비용: 웹 검색 $10.00/1k calls + 검색 내용 토큰(OpenAI 가격 문서). 건당 약 $0.02~0.04로 추정한다.
