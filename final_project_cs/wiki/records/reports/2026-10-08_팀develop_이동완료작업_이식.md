# 완료된 이동 작업의 팀 develop 이식

중단 세션의 완료된 이동 보정과 대조 자료를 팀 develop 1b196654의 기존 폴더 구조에 이식한다. 다른 세션의 미완성 변경과 전체 폴더 구조 변경은 제외한다.

## 내용과 검증

중형택시 저속 병산, 예산 여유율 37%, 대기 분해, 택시 선택과 실행 런타임 연결을 추가한다. 대조 도구와 새 100쌍 집계·그림을 포함한다. 전체 엔진 교체 검토판은 채택하지 않고 기존 팀 코드에 필요한 변경만 적용했다.

변경 관련 시험: 30 passed, 3 deselected in 10.77s. 자료 의존 시험 3건은 live 범위로 분리했으며 통과에 포함하지 않는다. 도구 5개 Ruff All checks passed, compileall 통과. 계약·보안 시험은 처음 환경·자료 경로 때문에 수집에 실패했다. 경로 보정 후 재실행 결과와 전체 이동 시험의 환경 의존 결과를 커밋 본문에 기록한다. 전체 릴리스 완료를 선언하지 않는다.

mock 서버 시험: 이번 커밋 검증에서 실행 안 함(화면 변경 제외).

실서버 확인(서버 응답): 안 했음. 배포된 cs 프로젝트 서버와 실제 운행은 확인하지 않았다.

## 보안과 제외

데이터 원값·백업·환경 파일은 추가하지 않는다. PDF 바이너리 문자열 오탐과 추출 본문 검사를 구분했다. 기존 버스 정류장 데이터의 숫자 표기 14행은 station_nm 필드이고 이번 수정 대상이 아니다. 선택 파일과 전체 Git 텍스트를 커밋 전 다시 검사한다.
