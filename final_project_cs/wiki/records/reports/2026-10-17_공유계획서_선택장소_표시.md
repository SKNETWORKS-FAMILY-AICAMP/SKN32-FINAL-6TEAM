# 공유 계획서의 선택 장소 이름 표시 보완

QA 계정에 기본 예시를 실제 등록하고 공개 계획서를 열자 양일 제목이 원문 「호텔」로만 보였다. 실제 API의 place에는 트레블로지 명동을지로호텔이 정상 저장돼 있었다. 광장시장·인사동도 제목만 보이고 선택한 가게 이름은 빠졌다. 여행 저장 결함과 HTML 표시 결함을 구분한다.

구현 전 [선택 장소 표시 계약](../../external/public-plan-place-display.md)을 작성했다. 제목은 유지하고 제목과 다른 실제 장소를 기존 보조 글 모양으로 함께 표시한다. 중복 이름·장소 없는 이동은 추가하지 않고 외부 문자열을 HTML 이스케이프한다. DB·여행 버전·JSON 응답은 바꾸지 않았다.

실제 운영 앱 이미지의 네트워크 없는 같은 검사 3개: 수정 전 2실패·1통과 → 수정 후 **3/3 = 100%**(0.50초). 변경 Python 2파일 ruff F·E9 통과. 코드·검사는 별도 격리 사본에서 수행했고 원본 코드를 덮어쓰지 않았다. 매니저 검토·배포·같은 공개 계획서의 변경 후 화면은 아직 대기다.
