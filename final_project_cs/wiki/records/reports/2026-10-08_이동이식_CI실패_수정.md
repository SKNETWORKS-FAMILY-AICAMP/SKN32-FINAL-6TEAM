# 이동 이식 커밋의 자동 검사 실패 수정

## 해결됨 (2026-10-08, 코드 수정) — 원격 자동 검사 최종 상태는 해당 수정 커밋의 Actions에서 확인

직전 develop 커밋 ab533cc6의 CI develop·main이 전체 Ruff 검사에서 실패했다. 웹·관리 화면 검사와 develop 시험 작업은 통과했지만 린트는 통과하지 않았다. 이전 로컬 보고의 321개 시험 통과가 GitHub 자동 검사 전체 통과를 뜻하지는 않았다.

## 원인과 수정

runtime.py의 _LazyCar를 이식하면서 속도 그래프 공유 사전 _CAR_GRAPHS 선언을 빠뜨렸다. 그 결과 두 사용 지점에서 F821이 났다. 사용하지 않는 router_kind와 시험의 paths 가져오기도 각각 F841·F401로 실패했다. 공유 사전을 원래 구현대로 선언하고 미사용 이름 둘을 제거한다. 검사 설정이나 문턱을 낮추지 않는다.
