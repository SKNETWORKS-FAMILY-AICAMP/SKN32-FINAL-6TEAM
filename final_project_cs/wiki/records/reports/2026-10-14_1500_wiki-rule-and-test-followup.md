`[원인]` 「용량 부족」은 디스크가 아니라 **가상 메모리 한도**였다. 디스크 여유는 8~12GB 였지만 가상 메모리 여유가 0.2~3.3GB 사이를 오갔다. 개발 DB 로그(`pgdata/server_5433.log`)에 커밋 한도 초과 `0xC000012D` · 페이지 파일 부족 `1455` 가 찍힌다(10-12 14:12 에도 같음). Claude 창 20여 개 약 6.7GB · ChatGPT 앱 약 2.5GB · 여러 세션의 시험 python 이 나눠 쓴다. 세션이 끊기면 그 세션이 띄운 시험이 고아로 남아 메모리를 계속 먹는다 — 이 세션의 고아 7개는 정리했다.

**파이썬 전체 시험(ci-main 순서)은 이 PC 에서 끝내지 못했다.** 「전체 통과」라고 말할 근거가 없다. 남은 묶음은 GitHub develop · main 검사(CI)나 메모리 여유가 있을 때 다시 돌린다. 시험 DB `acop_ci_full_1014` 는 로컬 개발 DB 서버 안에 남아 있다 — 15:10 에 지우려 했으나 개발 DB 가 꺼져 있어 못 했다. 다음에 DB 가 켜져 있을 때 `DROP DATABASE "acop_ci_full_1014" WITH (FORCE)` 로 지운다(이 세션이 만든 시험 전용 DB, 업무 자료 없음).
