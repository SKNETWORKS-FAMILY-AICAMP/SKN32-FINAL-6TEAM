# 읽기 화면 주소 교체 뒤 안내·되돌리기 유지 검증

## 원인과 수정
영어 화면 반복 시험에서 40회 중 1회 안내가 사라졌다. 접수 요청의 응답을 보류한 재현 시험에서는 시작 화면에서 안내를 확인한 뒤 응답을 풀면 새 접수 주소로 이동하며 안내가 사라졌다(수정 전 1/1 실패). 기존 처리는 같은 화면 안의 단계 변경만 다뤘으며 주소 교체로 화면 자체가 해제되는 경우를 놓쳤다.

읽기 화면이 해제될 때 남아 있는 조작 가능한 안내를 다음 화면에 전달한다. 되돌리기 동작과 남은 표시 시간을 보존하며, 이미 닫은 안내와 완료된 요청의 단순 진행 안내는 전달하지 않는다. 주소 교체를 강제하는 브라우저 회귀 시험과 단위 회귀 시험 3개를 추가했다. 재시도·시험 생략·판정 기준 완화 없이 수정했다.

## 검증
- 최종 제품 빌드·타입 검사·린트 통과.
- 매니저 웹 단위 시험 660/660 통과.
- mock 서버 시험 40/40 (화면 반응): 영어 안내 20회, 응답 보류 후 주소 교체·되돌리기 20회. 최종 제품 빌드 사용.
- 실서버 확인 (서버 응답): 안 했음. 이 기록의 브라우저 검증은 mock 서버 대상이다.
- 기존 조건부 생략 13개는 유지하며, 새 회귀 시험으로 원격 웹 활성 시험은 651개다. 원격 전체 CI 결과는 해당 커밋의 실행 기록으로 확인한다.

## 반영 범위
위 수정 3개 파일과 이 기록만 팀·개인 매니저 및 develop에 반영한다. 다른 작업과 기존 이력을 보존하며 main은 변경하지 않는다.
