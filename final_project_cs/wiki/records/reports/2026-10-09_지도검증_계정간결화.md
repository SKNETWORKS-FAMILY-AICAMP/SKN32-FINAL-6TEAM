## 변경

계정 화면은 Kakao 버튼을 흰 배경과 테두리로 바꾸고 공식 말풍선 아이콘을 유지했다. Google 버튼은 둥근 모서리로 바꿨다. 마이페이지 약관 영역에는 `약관 전문 확인`과 `선택 약관 동의` 두 버튼만 둔다. 선택 동의 창에서는 세 선택 항목의 설명·동의·철회·오류 재시도와 전문 펼침을 제공한다. 전문은 같은 창 안에서 펼쳐 대화창 중첩을 피했다. 최초 필수 동의와 기존 인증 요청 경로는 유지한다.

지도는 마커·거리 칩·지도 단추가 서로 피하도록 화면 배치를 계산한다. 거리 칩에 포함된 일반 마커는 숨긴다. 밀집해서 표시 공간이 차면 일반 마커를 번호와 추가 개수로 묶고 일정 목록에는 모두 남긴다. 선택 마커를 우선 배치하고 실제 장소 좌표와 경로는 바꾸지 않는다. 겹치는 경로 설명은 숨긴다. 지도 단추는 기본 접힘이며 거리 눈금은 남는다. 펼친 단추는 마지막 조작 후 5초에 접히며 포인터가 올라가 있거나 키보드 초점이 있으면 유지한다. 지도 이동·확대 중에는 정보칩과 단추가 사라지고 정지 후 복귀한다.

검증 화면은 작은 독립 정보칩, 간격을 줄인 카드 도구, 스크롤을 따라오는 시각 표시를 사용한다. 상시 제목 대신 최초 진입 토스트를 보여준다. 출처 글자와 위/아래 전환 안내를 줄이고 전환 안내는 같은 컴포넌트를 공유한다. 전체 자동 추천은 첫 목록 상단, 제출은 서비스 채팅 단추와 같은 56px 우하단 플로팅 단추로 배치했다.

## 시험

mock 서버 시험 **41/41 (화면 반응)**. 최종 실행 기록 세 묶음에서 같은 파일·시험 이름의 마지막 결과를 세었다. 지도 드래그 시험은 이름이 바뀌어도 같은 사례로 셌다. 재실행을 합산하지 않았다.

| 시험 묶음 | 통과 |
|---|---:|
| 계정 디자인·동의 진입 | 4/4 |
| 기존 동의 관리 | 18/18 |
| 지도 단추 | 7/7 |
| 이번 지도·계정·촬영 HTML | 9/9 |
| 기존 검증 화면 회귀 | 3/3 |
| 합계 | 41/41 = 100% |

최종 촬영 실행은 11/12였으며 남은 자동 접힘 시험은 실제 Tab 키 입력으로 수정한 뒤 1/1 통과했다. 프로그램으로 초점만 옮기면 마우스 입력 모드가 유지되어 키보드 초점 조건을 시험하지 못했다. 지도 조작 중 숨김, 정지 후 복귀, 같은 좌표 일정 40개, 카드 시각 고정, 선택 동의 저장·전문·Escape·초점 복귀, 375px 가로 넘침 방지를 확인했다.

지도 배치·마커·가시성·일정 행 단위 시험 **29/29**, TypeScript 검사와 변경 파일 ESLint 검사 통과. 375px와 1280px 촬영 **14/14**를 생성하고 비교 HTML의 전환과 모든 이미지 경로를 확인했다. 흰 소셜 버튼과 약관 두 버튼, 선택 동의 창, 지도 정보칩과 작은 하단 안내는 촬영 이미지로 확인했다.

실서버 확인 (서버 응답): **안 했음**. 이번 시험은 mock 서버를 사용했다. 실제 외부 OAuth 로그인, Google/Naver SDK 실행, x600 서버 배포는 이번 확인 범위에 포함하지 않는다. 지도 UI 실행 시험은 OSM 어댑터이며 Google/Naver 변경은 정적 검사 범위다.

## 자동 접힘 시간의 근거

지도 단추의 공통 최적 시간이 5초라는 자료는 확보하지 않았다. Android의 일시적 미디어 조작 UI는 기본 5초를 사용하고, 2GIS의 지도 조작 UI는 다른 기본값을 사용한다. 따라서 이번 5초는 지도 가림을 줄이려는 제품 시작값으로 정했다. 읽거나 조작하는 중에는 유지하며 실제 사용 관찰 후 조정할 수 있다.

- [Android PlayerControlView 기본 시간](https://developer.android.com/reference/kotlin/androidx/media3/ui/PlayerControlView), [공식 구현](https://github.com/androidx/media/blob/release/libraries/ui/src/main/java/androidx/media3/ui/PlayerControlView.java).
- [2GIS 지도 단추 설정](https://2gis.github.io/android-compose-docs/compose-navigation/ru.dgis.sdk.compose.navigation.controls.defaultcontrols.navigation/-default-navigation-controls-view-model/index.html).
- [W3C 포인터·초점 중 표시 유지 기준](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html).
