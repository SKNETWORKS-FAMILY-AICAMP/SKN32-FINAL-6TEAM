인계 패치 13개 파일과 최신판의 차이는 수동 통합했다. 기존 여러 여행 상태 일괄 조회와 재난 정지 표시를 보존했다. 이전의 게스트 시험 금지 검사는 새 요구사항에 맞춰 시작 전 제외·명시적 시험 중 포함·중지 후 제외를 검사하도록 변경했다. 새 DB 마이그레이션은 없다.

mock 서버 시험 4/4 (화면 반응). 처음 데모 설정 빌드로 실행한 화면 시험은 4건 실패했으며, API 연결 설정으로 별도 빌드한 뒤 4건 모두 통과했다. 실패한 실행을 성공 근거에 포함하지 않았다.
실서버 확인 (운영 cs 프로젝트 서버 응답): 이 기록 작성 시 아직 안 했음. 운영 배포·읽기 확인은 별도 실행 기록으로 확인한다. 실제 고객 여행에 재난 입력을 켜는 시험은 하지 않는다.

운영판에는 매니저판에 아직 없는 알림 수신 패널·발송 상태·등록 호출 등 후속 변경이 있다. 이를 덮어쓰지 않도록 운영 현재 이미지 위에 이번 기능 차이만 통합한 별도 패치를 준비했다. 이 패치는 저장소 전체 커밋을 통째로 배포한 것과 구분해 기반 이미지와 패치 판본을 기록한다. 다른 세션의 미커밋 변경을 이번 Git 커밋에 포함하지 않는다.
