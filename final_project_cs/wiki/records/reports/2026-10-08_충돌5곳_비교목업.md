# 충돌 5곳 비교 목업

사용자 요청에 따라 이전 충돌 확인에서 나온 다섯 경로만 우리 쪽·화면 담당 쪽·결합 제안으로 비교하는 독립 HTML을 만들었다. 실제 앱 소스는 변경하지 않았고 병합하지 않았다.

- 결과: [비교 HTML](../../../frontend/apps/web/mockups/merge-conflicts-2026-10-08-v1/index.html). 메뉴·화면 틀·저장 설정·메뉴 시험·개발 기록 탭 다섯 개.
- 메뉴와 화면 틀은 원문 소스에서 재구성한 목업이며 실제 앱 캡처가 아니다. 지도·여행 데이터는 설명용 예시다. 나머지 세 탭은 설정·시험·기록의 시각적 비교다.
- 각 탭 하단에 실제 Git diff를 HTML 안에 포함했다. 로컬 기준 `bc750713`, 담당 기준 `8fd211fb`, 담당 최신 `6ab6f10e`, 우리 쪽은 현재 작업 사본의 미커밋 변경 포함.
- 목업 생성 도구 `prepare.py`, 렌더링·검사 도구 `render.mjs`. 이미지: `menu.png`, `frame.png`, `settings.png`, `tests.png`, `records.png`, `mobile.png`. 검사 결과: 같은 폴더 `verification.json`.
- 실행: 결과 폴더에서 `python prepare.py`로 원문 포함, `node render.mjs`로 Chrome 렌더링 및 검사. 준비 스크립트는 기존 HTML을 교체하기 전 `_backup/`에 복사한다. 재실행에는 원본 템플릿의 `SOURCE_DATA` 자리표시자가 필요하다.
- 검증: 5/5 탭 전환·이미지 생성, 실제 diff 표시, 항로 지킴이 위치 안내, 화살표 키 탭 전환, 375px에서 5/5 탭 페이지 가로 넘침 없음, 페이지 JavaScript 오류 0. 메뉴·화면 틀 이미지 직접 확인.
- mock 서버 시험 (화면 반응): 실행하지 않음. 이번 검증은 비교 산출물만 대상으로 했다.
- 실서버 확인 (서버 응답): 안 했음.
- 백업: [산출물 백업 폴더](../../../frontend/apps/web/mockups/merge-conflicts-2026-10-08-v1/_backup/). 원문 연결 경로를 수정하기 전 생성 스크립트와 첫 이미지들도 보존했다.
