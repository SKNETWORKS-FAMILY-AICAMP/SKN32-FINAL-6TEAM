# 날짜 탭과 일정 추가 가로선 모션 독립 통합

날짜 탭 부유와 일정 추가 가로선 효과를 사용자 선택에 따라 최소 CSS 패치로 통합했다. 기존 검색 초점·토스트 시험 보완은 유지했다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 독립 화면 시험 | 통과 | 6/6 = 100% |
| 타입·시험 코드 lint·생산 빌드 | 통과 | 3/3 = 100% |

mock 서버 시험 6/6 (화면 반응), skip 0. 375px·1280px에서 일반/움직임 줄이기 설정, hover/키보드 초점 정지, 44px 누름 영역, 날짜 숨김·복귀와 검색 초점을 확인했다. CSS lint 통과를 주장하지 않는다. 사용자 명시 요청인 반복 장식과 3/4초 주기는 화면 계약의 예외를 따른다.
실서버 확인 (서버 응답): 안 했음 — 공개 cs 프로젝트 서버의 이번 수정본 응답과 배포는 확인하지 않았다.

독립 실행 증거는 [검증 기록](../evidence/2026-10-10_date-divider-independent/)에 보존했다. 팀 role-manager만 반영 대상으로 삼았다.
