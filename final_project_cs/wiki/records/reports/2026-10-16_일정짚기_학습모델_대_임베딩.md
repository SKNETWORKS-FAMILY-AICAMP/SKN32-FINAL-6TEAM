# 일정 항목 짚기 — 학습 모델 2개 대 임베딩

## 결론

- 고객 질문이 일정의 어느 항목을 가리키는지 고르는 일에서, **우리 데이터로 가르친 두 모델이 임베딩보다 확실히 높다.** 판정용 90문제에서 학습 E4B 86/90 = 96%, 학습 Winnow-E4B(Jev 계열) 84/90 = 93% 이다. 임베딩은 규칙으로 후보를 좁힌 뒤에도 가장 좋은 Qwen3-Embedding-8B 가 69/90 = 77%, 지금 쓰는 bge-m3 는 52/90 = 58% 다.
- 엉뚱한 항목을 짚은 수(고객에게 틀린 정보가 나가는 경우)도 학습 모델은 4건, 임베딩은 20~32건이다. 임베딩은 「이 일정에 없는 질문」을 가려내지 못한다(2026-09-29 결론 그대로).
- 두 학습 모델끼리는 **구분되지 않는다**(학습 E4B 4승 2패, p=0.69). 학습 없는 Gemma 4 26B(87/90) · gemma4:12b(83/90)와도 구분되지 않는다.

## 결과 (판정용 90문제 = test50 + hard40, 각 1회)

| 방식 | test50 | hard40 | 합계 | 엉뚱한 답 | 못 찾음 | 질문당 |
|---|---:|---:|---:|---:|---:|---:|
| **학습 E4B** (`tripilot-pointer:e4b-ft`, x600 과 같은 기반 + 덧붙임) | 48 | 38 | **86/90 = 96%** | 4 | 0 | 1.3초 |
| **학습 Winnow-E4B** (Jev 계열, `oos2_cosine_s20261019` 덧붙임) | 49 | 35 | **84/90 = 93%** | 4 | 2 | 0.3초 |
| (참고) 학습 없는 Gemma 4 26B — 2026-09-29 | 49 | 38 | 87/90 = 97% | 2 | 1 | 8.7초 |
| (참고) 학습 없는 gemma4:12b — 2026-09-29 | 50 | 33 | 83/90 = 92% | 6 | 1 | 3.1초 |
| 임베딩 Qwen3-Embedding-8B + 규칙 — 2026-09-29 | | | 69/90 = 77% | 20 | | |
| 임베딩 arctic-embed-l-v2.0-ko + 규칙 — 2026-10-16 | | | 60/90 = 67% | 30 | 0 | |
| 임베딩 bge-m3(지금 씀) + 규칙 — 2026-10-16 | | | 52/90 = 58% | 20 | 18 | |

- 엉뚱한 답 = 틀린 항목을 고름 + 일정에 없는 질문에 항목을 고름. 못 찾음 = 항목이 있는데 「없음」.
- 짝 검정(McNemar 정확, 같은 90문제): 학습 E4B 대 학습 Winnow 4승 2패 p=0.69 · 학습 E4B 대 12B 6승 3패 p=0.51 · 대 26B 1승 2패 p=1.00 · 학습 Winnow 대 12B 5승 4패 p=1.00 · 대 26B 1승 4패 p=0.38.
- 임베딩 줄은 앞선 측정값을 옮긴 것이다(같은 문제 · 같은 정답). 문제별 짝 검정은 하지 않았다 — 차이가 17~34문제라 결론은 바뀌지 않는다고 본다 `[추정]`.
- 질문당 시간은 실행 프로그램이 달라 비교하지 않는다(학습 E4B 는 Ollama 0.31.1 Q4_K_M, Winnow 는 llama.cpp `bed0a85` Q8_0, 참고 줄은 2026-09-29 다른 GPU).

## 한계

- 질문은 Codex 가 쓴 것이고 일정은 가상이다. 사람이 쓴 채팅 질의로는 재지 않았다.
- 90문제라 2~3문제 차이는 구분되지 않는다. 두 학습 모델의 우열은 이 결과로 말하지 않는다.
- 두 모델은 압축 방식이 다르다(E4B 4비트 · Winnow 8비트).
