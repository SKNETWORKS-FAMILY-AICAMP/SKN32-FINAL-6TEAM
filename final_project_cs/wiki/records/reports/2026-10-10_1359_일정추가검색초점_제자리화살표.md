# 일정 추가 검색 초점·제자리 화살표

일정 추가를 열면 상단 장소 검색창에 초점이 간다. 빈 검색어에서는 입력 폼을 유지하고, 지도 화살표는 기존 자리에서 접힘 <·펼침 >를 표시한다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 검색 초점 수정 | 완료 | 1/1 = 100% |
| mock 서버 화면 시험 | 통과 | 6/6 = 100% |
| 정적 검사·표준 생산 빌드 | 통과 | 3/3 = 100% |
| 화면 촬영 | 완료 | 8/8 = 100% |

추가 전용 검색창 호출에 autoFocus 속성 하나를 켰다. 기존 빈 검색어 폼 우선 표시와 장소 선택 후 일정 이름 초점, 초안 보존, 취소 후 추가 버튼 초점 복귀는 유지한다. 지도 CSS는 이미 적용된 제자리 회전을 그대로 사용하며 이번 추가분에서는 변경하지 않았다. 사용자가 보고 있던 이전 목업은 보존하고 새 갤러리를 만들었다.

375px와1280px의 Chrome에서 초기 검색 초점, 빈 검색어 검색 요청 없음, 검색·지우기·선택 과정의 초안 유지, 선택 장소 좌표와 수정한 이름 저장, 입력 검증 시 적절한 초점, 취소 복귀를 확인했다. 낮은 지도에서 접힘 <·펼침 >의 실제 SVG 방향과 화살표 중심 좌표 일치도 검증했다. 기존 메뉴 정렬·지도 펼침 방향 시험을 함께 실행했다. 두 너비의 초기·지도 도구 펼침 화면을 직접 확인했고 가로 넘침을 시험했다.

첫 실행은 시험 코드의 SVG 조회 타입 오류로 생산 빌드에서 중단됐다. SVGSVGElement 타입을 명시한 뒤 TypeScript·ESLint·표준 Next.js 생산 빌드와 최종 화면 시험을 통과했다.
