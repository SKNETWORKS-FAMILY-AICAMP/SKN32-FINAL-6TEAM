# 소셜 계정 버튼·약관 관리 화면 검수 보완

공식 회사 아이콘과 회사명을 함께 표시하도록 소셜 버튼을 정리하고, 약관 관리에서는 필수 전문 열람과 선택 동의 수정만 제공합니다. 최초 필수 동의 흐름과 기존 인증·철회 API는 유지합니다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 버튼·약관 관리 수정 | 완료 | 2/2 = 100% |
| 기존 약관 단위 시험 | 통과 | 26/26 = 100% |
| 보완 후 타입·린트 | 통과 | 2/2 = 100% |
| 신규 화면 시험 재확인 | 통과 | 4/4 = 100% |
| 계정·약관 전체 화면 시험 | 통과 | 36/36 = 100% |
| 계정·약관 화면 촬영 | 완료 | 6/6 = 100% |

## 첫 화면 시험에서 확인한 문제

루트 담당이 최신 빌드와 Chrome으로 실행한 신규 화면 시험은 2/4 = 50% 통과했습니다. 실패는 다음 두 가지였습니다.

1. 네 업체 버튼 표시 시험: mock 서버의 기본 `/v1/web/auth/providers` 응답은 Google과 Kakao 두 개입니다. 시험이 Naver와 Discord까지 기대하면서 실제로 제공되지 않은 버튼을 찾았습니다. 해당 시험에서 네 업체 응답을 명시적으로 주입하도록 수정했습니다. 공통 mock 서버의 기본값과 제품의 제공 업체 결정 방식은 유지했습니다.
2. 필수 전문 창의 키보드 시험: native `dialog.showModal()`은 배경 요소를 막지만 Chrome에서 마지막 요소 다음 Tab이 브라우저 영역으로 빠질 수 있었습니다. 전문 창에 Tab과 Shift+Tab의 첫·끝 초점 순환을 추가했습니다. 정방향 9회, 역방향 9회, 첫·끝 요소 직접 왕복을 확인하도록 화면 시험을 강화했습니다.

추가 수정 후 전체 TypeScript 검사와 변경된 전문 창·시험 파일의 ESLint는 통과했습니다. 루트 담당이 최신 빌드로 실행한 신규 전용 4개, 기존 약관 18개, 소셜 인증 12개, 통합 계정 2개도 모두 통과했습니다. 초기 실패 원인을 보완한 뒤의 결과입니다.

mock 서버 시험(화면 반응): 신규 4/4, 기존 약관 18/18, 소셜 인증 12/12, 통합 계정 2/2 — 고유 시험 총 36/36 = 100% 통과했습니다.

실서버 확인(서버 응답): 안 했음. 실제 외부 OAuth 인증, x600 서버 배포, 사용자 데이터 수정은 실행하지 않았습니다.

## 제품 변경과 자산 출처

- 소셜 버튼은 `Google/Kakao/Naver/Discord 계정으로 계속` 문구와 48px 높이·동일 정렬을 사용합니다. 업체별 공식 색상은 유지했습니다. 연결된 계정에도 공식 아이콘과 회사 이름이 표시되며 기존 연결 해제 동작을 유지합니다.
- 필수 두 항목의 요약·철회 버튼을 관리 목록에서 제거했습니다. `약관 전문 확인` 창에서 두 전문을 전환해 읽습니다. 선택 세 항목은 기존 동의·철회 기능을 유지합니다.
- 전문 창은 열 때 닫기 버튼으로 초점을 옮기고, Tab/Shift+Tab을 창 안에서 순환하며, Escape 또는 닫기 후 열었던 버튼으로 초점을 돌려줍니다.

공식 아이콘 출처:

| 회사 | 출처·사용 방식 |
|---|---|
| Google | [공식 브랜드 지침](https://developers.google.com/identity/branding-guidelines)의 기존 HTML 버튼·다색 G SVG 경로 재사용 |
| Kakao | [공식 제공 SVG](https://developers.kakao.com/tool/images/resource/preview/login-complete-en.svg)의 말풍선 경로·색을 그대로 사용하고 SVG 표시 영역만 심볼에 맞춤. [공식 디자인 지침](https://developers.kakao.com/docs/ko/kakaologin/design-guide) 확인 |
| Naver | [공식 자산 ZIP](https://developers.naver.com/inc/devcenter/downloads/bi/NAVER_login_EN.zip)의 `NAVER_login_EN/NAVER_login_Light_EN_green_icon_H48.png` 원본 바이트 재사용. [공식 BI 지침](https://developers.naver.com/docs/login/bi/bi.md) 확인 |
| Discord | [공식 브랜드 페이지](https://discord.com/branding)가 제공하는 [Symbol SVG](https://cdn.prod.website-files.com/6257adef93867e50d84d30e2/66e3d7f4ef6498ac018f2c55_Symbol.svg) 원본 바이트 재사용 |

원본 출처는 [자산 출처 코드](../../../frontend/apps/web/src/features/account/brand-assets/sources.ts)에도 기록했습니다. 기업 아이콘을 임의로 그리거나 제삼자 아이콘을 사용하지 않았습니다.
