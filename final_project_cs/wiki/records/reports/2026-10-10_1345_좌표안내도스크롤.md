# 좌표 안내도 목록과 함께 스크롤

목록을 크게 펼쳤을 때 좌표 없음 안내도 목록과 함께 위로 사라지고, 최상단으로 돌아오면 다시 보인다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 요청 수정 | 완료 | 1/1 = 100% |
| mock 서버 화면 시험 | 통과 | 8/8 = 100% |
| 정적 검사·표준 생산 빌드 | 통과 | 3/3 = 100% |
| 화면 촬영 | 완료 | 10/10 = 100% |

기존 좌표 안내는 고정 머리말에 들어 있어 스크롤해도 남았다. 안내를 스크롤 몸체의 첫 항목으로 옮겼고, 전용 머리말 배경·날짜 이동·126px 상단 예약 공간을 제거했다. 내부 상태 이름도 안내가 실제 들어가는 목록으로 맞췄다. 안내를 옮기는 지도 높이 조건136px, 지도와 목록 간 단일 표시, 상태 알림, 좌표 복원 시 제거는 유지했다. 날짜 탭은 기존 위치와 조작 중 숨김·유휴 복귀를 유지한다. 손잡이 접근 페이드도 안내에 그대로 적용된다.

375px와1280px의 실제 Chrome에서 안내가 목록과 같은 거리만큼 이동하고 화면 밖으로 사라지는 것을 검증했다. 최상단 복귀 시 원래 위치, 날짜 탭 위치, 최소 접힘 때 지도 안내 복귀, 좌표가 다시 생겼을 때 안내 제거, 쓰기 요청 증가 없음과 가로 넘침 없음을 확인했다. 기존 손잡이 색상 계측·시각 고정 시작점·드래그 복원 시험도 통과했다.
