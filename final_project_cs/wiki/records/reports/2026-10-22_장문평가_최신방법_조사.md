## 1. 붙여 주신 표 검토

| 표의 행 | 판정 | 근거와 지적 |
|---|---|---|
| ROUGE/BLEU: 빠름 · 긴 글에서 신뢰도 낮음 / 요약 · 번역에 적합 | **「긴 글에서 낮음」은 맞음. 「요약에 적합」은 의심스러움** | HelloBench 논문 표에서 요약 과제의 사람 평가와의 스피어만 상관이 ROUGE-L −5.61, BLEU −6.76(×100)로 **오히려 음수**였습니다. 요약에서도 긴 · 열린 글에는 맞지 않을 수 있다는 근거입니다. 단, 이 수치는 한 과제(요약)·한 논문 결과입니다. [외부-본문 앞 절반 확인] [HelloBench HTML](https://arxiv.org/html/2409.16191v1) |
| 인간 평가: 가장 정확 / 비용 높음 · 느림 | **대체로 맞음, 빠진 말이 있음** | 사람 판정도 사람끼리 어긋납니다. 「가장 정확」이 아니라 「기준점」으로 쓰려면 2명 이상이 같은 표본을 라벨해 사람끼리의 일치도를 먼저 재야 합니다. 표에는 이 단서가 없습니다. [추정 — 일반 방법론, 이번에 별도 출처 확인 안 함] |
| LLM-as-Judge: 빠름 · 세밀 / 편향 가능 · 신뢰성 변동 | **맞지만 너무 뭉뚱그림** | 편향 종류별로 근거가 있습니다: 위치 편향(15개 판정 모델 · 15만 건, 판정 모델 · 과제마다 크기가 크게 다름) [외부-초록](https://aclanthology.org/2025.ijcnlp-long.18/), 자기 선호(판정 모델이 자기 답을 높게 보는 경향, 크기 · 학습 데이터 · 글 문체가 영향) [외부-초록](https://aclanthology.org/2025.emnlp-main.86/), 2026년 20개 모델 비교에서 「성능이 높다고 자기 선호가 낮은 것은 아님」 [외부-초록](https://arxiv.org/abs/2604.22891). **「신뢰성 변동」이 핵심 문제이고 점수 하나로 쓰면 안 된다**는 쪽으로 최근 문헌이 모입니다(아래 2·3절). |
| ProxyQA / HelloBench: 자동화+정확성 / 설계 복잡 / 사실성 · 완전성 | **한 줄로 묶으면 오해됨, 그리고 낡음** | 둘은 다른 방식입니다. ProxyQA(ACL 2024)는 긴 글을 쓰게 한 뒤 **그 글만 보고 미리 답이 정해진 질문에 답하게 해서** 점수를 냅니다 [외부-초록](https://arxiv.org/abs/2401.15042). HelloBench(arXiv 2024-09, 학술지 · 학회 표기 없음)는 벤치마크이고, 평가법 HelloEval은 **지시마다 사람이 만든 예/아니오 질문 4~6개를 판정 모델(GPT-4o)이 한 번에 채점**하고 사람 점수에 맞춰 가중치를 회귀로 구합니다. 즉 HelloEval은 「LLM-as-Judge의 대안」이 아니라 **체크리스트형 LLM-as-Judge**입니다. 상관 수치(31.93)도 요약 과제 한 곳에서만 보고됐고, 저자들이 판정 모델 신뢰성을 한계로 적었습니다 [외부-본문 앞 절반 확인]. 둘 다 2024년 작업입니다. |
| (표에 없음) | **빠진 항목** | 체크리스트 · 루브릭 평가, 판정 모델 보정 통계, 판정 모델 여러 개 합의(패널), 쌍 비교, 추론형 판정 모델, 사실성 검증 도구(주장 단위). 아래 2절. |

**표 전체에 대한 한 줄:** 「긴 글 평가」 표인데 우리 문제는 긴 글 품질이 아니라 **「이 답이 이 기준 문장을 만족하나」라는 이진 판정의 신뢰도**라서, 표의 어느 행도 그대로 답이 되지 않습니다. 가장 가까운 것은 HelloEval · CheckEval 같은 체크리스트 평가입니다. [추정]

## 2. 2025~2026 방법 (우리 상황에 가까운 순서)

### 2-1. 판정 모델 보정 — 사람 표본으로 판정 모델의 오차를 재고 점수를 고친다 ★가장 중요

- **사람 라벨 소표본으로 판정 모델의 민감도 · 특이도를 재고, 통과율을 보정하고, 신뢰구간을 낸다.** Lee 외, 「How to Correctly Report LLM-as-a-Judge Evaluations」(2025-11, 최신판 2026-05-31): 판정 모델의 오차(민감도 · 특이도 부족)가 점수에 편향을 만든다고 보고, 사람 라벨 보정 표본으로 이를 고치고 **시험 데이터와 보정 데이터 양쪽의 불확실성을 반영한 구간**을 냅니다. 초록에는 구체적 표본 수가 없습니다. [외부-초록](https://arxiv.org/abs/2511.21140)
- **작은 표본(100 미만)의 함정.** Arawjo(2026-09-20): 판정 모델 점수 위에서 그대로 통계를 돌리면 위양성이 커지고, 사람과의 일치가 「거의 완벽」일 때도 위험이 높을 수 있다고 합니다. 사람 라벨 소표본으로 보정하는 PPI 계열 검정과 소표본용 구간 방법을 제안하고 `evalstats`(파이썬 패키지)를 냈습니다. 「실질적 일치(substantial agreement)로 검증된 판정 모델」이 가짜 발견으로 이어질 뻔한 사례를 듭니다. [외부-초록](https://arxiv.org/abs/2609.35815)
- **κ 하나를 보고하지 말고 규약을 고정하라.** Rao · Callison-Burch(2026-05, 개정 07-31): 이진 판정에서 피어슨 · 스피어만 · 켄달 · phi · MCC는 사실상 같은 통계라서 여러 개 적는 것은 한 숫자를 반복하는 것이고, κ는 판정 모델과 사람의 「통과 비율」이 다르면 값이 달라집니다. **판정 불가를 빼고 계산하면 정확도가 과장될 수 있어 제외 비율과 전체 기준 범위를 같이 적어야** 한다고 합니다. 한 벤치마크에서 계산 규약만 바꿔도 정확도가 0.551 → 0.899로 움직이고 κ의 부호가 바뀌었습니다(판정은 하나도 안 바꾸고). [외부-초록](https://arxiv.org/abs/2606.00093)
- **필요 표본 수.** 「κ≈0.6, 구간 폭 0.10 이하면 약 200쌍」이라는 말은 실무자 블로그 · 한 논문 예시 수준이고 일반 규칙으로 확인하지 못했습니다. 「보정 구간을 0.1 이하로 만들려면 한 예시에서 약 200개」라는 언급도 검색 요약에서만 봤습니다. [외부-검색요약, 참고용] [논문](https://arxiv.org/pdf/2511.21140) · [블로그](https://dev.to/maya_andersson_dev/your-llm-as-judge-eval-set-is-too-small-here-is-the-math-2iac)

### 2-2. 체크리스트 · 루브릭 평가 — 기준을 예/아니오로 쪼개 하나씩 판정

- **CheckEval**(EMNLP 2025): 기준을 이진 질문으로 쪼개 점수 변동을 줄였다고 합니다. 12개 판정 모델 · 여러 데이터셋에서 사람 판정과 높은 상관, **판정 모델 간 평균 일치도 +0.45**(비교 기준은 초록에 명시되지 않음). [외부-초록](https://aclanthology.org/2025.emnlp-main.796/)
- **RocketEval**(ICLR 2025): 지시마다 체크리스트를 만들고 작은 모델(Gemma-2-2B)이 채점한 뒤 사람 점수에 맞춰 가중치를 조정. MT-Bench · WildBench에서 사람 선호와 상관 0.965, 비용 50배 이상 절감이라고 보고. [외부-초록](https://arxiv.org/abs/2503.05142)
- **ResearchRubrics**(2025-11): 전문가가 쓴 세부 루브릭으로 딥리서치 에이전트를 채점, 최고 시스템도 루브릭 충족률 68% 미만. 「3단계 → 이진 판정으로 바꾸면 일치도 약 20%p 상승」은 **검색 요약에서만 봤고 초록에는 없습니다.** [외부-초록(본문 수치 미확인)](https://arxiv.org/abs/2511.07685)
- **주의 — 루브릭을 고치는 것이 능사가 아님.** Han · Kim(2026-10-09): 판정 모델들끼리 의견이 갈리는 하위 기준을 고쳐 쓰면 판정 모델 간 일치(Krippendorff α +0.069)는 올랐지만 **사람과의 일치는 변화가 검출되지 않았습니다**(SummEval, 켄달 τ 차이 −0.007). [외부-초록](https://arxiv.org/abs/2610.13303) → 판정 모델끼리 합의가 높아졌다는 것은 개선의 증거가 아닙니다.
- **TICK**(지시별 예/아니오 질문 생성)은 검색에서 2026년 논문의 한 줄 언급만 봤고 **원 논문은 확인하지 못했습니다.** [미확보]

### 2-3. 판정 모델 여러 개 합의(패널) — 효과는 있으나 기대보다 작을 수 있다

- **PoLL**(2024-04): 서로 다른 계열의 작은 모델 여러 개가 큰 모델 하나보다 낫고, 비용은 7배 이상 낮으며 같은 계열 편향이 적다고 보고. κ 수치는 초록에 없음. [외부-초록](https://arxiv.org/abs/2404.18796)
- **반론(2026)**: Kohli(2026-05-28): 7개 계열 9개 모델이 **실제로는 약 2표 분량의 정보**만 주었고(독립성의 약 3/4 손실), 가장 좋은 단일 판정 모델이 모든 조건에서 패널 이상이었으며, 집계 방법을 바꿔도 격차의 11%만 메웠습니다. NLI 3종 + RewardBench 쌍 비교 한정. [외부-초록](https://arxiv.org/abs/2605.29800) / CARE(ICML 2026): 판정 모델들의 오류가 verbosity · 문체 같은 공통 교란에 묶여 있으면 다수결 · 평균이 도움이 안 되거나 오류를 키울 수 있다며, 정답 없이 공통 교란을 분리하는 집계법을 제안(12개 벤치마크에서 오류 최대 26.8% 감소). [외부-초록](https://arxiv.org/abs/2603.00039)
- **해석:** PoLL은 「패널 vs 평균적 개별 판정 모델」, Kohli는 「패널 vs 최고 개별 판정 모델」 비교라 둘이 충돌하지 않는다고 Kohli 논문이 주장합니다(이 부분은 검색 요약으로 봄). 즉 **패널을 만들기 전에, 먼저 사람 표본으로 어느 판정 모델이 가장 좋은지 고르는 쪽이 앞섭니다.** [추정]

### 2-4. 자기 선호 · 위치 · 길이 편향 완화

- **자기 선호**: 20개 모델에서 측정, 「인지 부하 분해」(판정을 작은 조각으로 나눔)로 평균 31.5% 감소, 사람 정답 라벨 없이 품질이 거의 같은 쌍으로 측정하는 방식. [외부-초록](https://arxiv.org/abs/2604.22891) 기존 측정이 「품질 차이」와 「편향」을 섞는 문제를 지적하고 정답 판정을 기준으로 삼는 DBG 점수를 제안한 EMNLP 2025 논문도 있습니다. [외부-초록](https://aclanthology.org/2025.emnlp-main.86/)
- **위치 편향**: 순서를 바꿔 두 번 판정하고 **불일치를 따로 센다**는 것이 공통 실무입니다. 편향은 우연이 아니고 두 답의 품질 차가 작을 때 커집니다. [외부-초록](https://aclanthology.org/2025.ijcnlp-long.18/) (이 연구는 쌍 · 목록 비교용이라, 이진 기준 판정에는 직접 해당하지 않습니다 — [추정])
- **길이 편향**: 일차 문헌(2025~2026 논문)은 이번 검색에서 확인하지 못했고 **실무자 블로그 수준만 봤습니다**(기준을 하나씩 나눠 채점, 길이 구간별 보고, 같은 내용에 문장만 늘린 쌍으로 점검). [외부-검색요약, 낮은 신뢰] [예](https://oneuptime.com/blog/post/2026-08-31-control-llm-judge-verbosity-bias/view)
- **판정 모델 자체의 정확도 보강(참고)**: 2026-04 논문이 RewardBench 2에서 「과제별 기준 주입 + 앙상블」로 최대 85.8%(기준 대비 +13.5%p)를 보고. 초록 최신판 수치이며 검색 결과에 나온 이전 판 수치(83.6%)와 다릅니다. GPT·Claude 계열 유료 모델 대상이라 우리 환경(자체 모델)에 그대로 옮길 수 없습니다. [외부-초록](https://arxiv.org/abs/2604.13717)

### 2-5. 추론형 판정 모델 (생각하고 판정하도록 학습)

- **J1**(Meta, 8B · 32B · 70B, 강화학습으로 판정 전에 추론하게 함, 위치 편향 완화 주장). 초록은 「여러 벤치마크에서 최고 성능」이라고만 하고 벤치마크 이름은 없습니다. [외부-초록](https://arxiv.org/abs/2505.10320) JudgeLRM · RM-R1 · J4R도 같은 계열이라는 사실만 검색에서 확인했습니다. [외부-검색요약](https://arxiv.org/pdf/2504.00050)
- **우리에게는 지금 후순위입니다.** 판정 모델을 새로 학습해야 하고 학습 자원이 들며, 사람 표본이 없어 학습해도 개선을 잴 수 없습니다. [추정]

### 2-6. 쌍 비교

- 모델 A와 B 중 어느 쪽이 나은지 가릴 때는 적합하지만, **우리의 「기준 문장을 만족하나」 이진 판정에는 맞지 않습니다.** 판정 벤치마크로는 JudgeBench(정답이 객관적으로 정해진 어려운 쌍, GPT-4o가 무작위보다 조금 나은 수준) [외부-초록(검색 요약 기반)](https://arxiv.org/abs/2410.12784), RewardBench 2(기존보다 평균 약 20점 낮은 점수, 새 인간 프롬프트 기반) [외부-검색요약](https://arxiv.org/abs/2506.01937)이 있습니다. 판정 모델 후보를 고를 때 참고할 수는 있으나 우리 도메인 · 한국어 · 여행 대화를 대표한다는 확인은 없습니다. [추정]

### 2-7. 사실성 검증 도구 (주장 단위)

- **FActScore → OpenFActScore**(EMNLP 2025 시연): 글에서 낱개 주장을 뽑아 신뢰할 근거에 비춰 하나씩 검증, 공개 모델(Gemma가 최고)로 원본과 피어슨 0.99 재현을 보고. [외부-초록](https://arxiv.org/abs/2507.05965) VeriScore · VeriFastScore(8B 한 번에 처리, 6.6배 빠름, VeriScore와 상관 r=0.80)는 검색 요약만 봤습니다. [외부-검색요약](https://arxiv.org/pdf/2505.16973v2)
- **우리 적용 가능성은 [추정]**: 이 도구들은 위키 같은 외부 지식을 근거로 삼습니다. 우리 봇 답의 근거는 여행 데이터 · 도구 응답이라, 「근거 원문에 비춰 주장을 하나씩 확인한다」는 **발상**만 가져오고 도구는 그대로 쓰기 어렵습니다.

## 3. 추천 — 지금 할 일 3가지 (이 순서)

> 전제: 의뢰 글의 설명(판정 모델이 평가 대상과 같은 학습 모델, 사람 판정 표본 없음, 통과 131 → 33)이 맞다고 봅니다. 아래 수고 · 효과는 **[추정]**입니다.

| 순서 | 할 일 | 드는 수고 | 얻는 것 |
|---|---|---|---|
| 1 | **사람 판정 표본 만들기와 판정 모델 보정.** 기준 문장 × 봇 답 쌍을 통과 · 실패 · 판정 불가가 모두 들어가게 골라(옛 기준 · 새 기준 양쪽에서) **100~200쌍**을 사람이 라벨. 가능하면 2명이 같은 표본을 라벨해 사람끼리 일치도도 잼 | 사람 시간 수 시간~하루. 표본 수 근거는 2-1절의 약한 출처뿐이라, 100쌍으로 시작해 구간 폭을 보고 늘리는 방식이 현실적 | 131 → 33 줄어든 이유가 「새 기준이 엄격해서」인지 「판정이 빡빡해서」인지 **가를 수 있음**(판정 모델의 위양성 · 위음성을 따로 재므로). 보정된 통과율과 구간 |
| 2 | **보고 규약 고정.** 판정 불가 포함 전체 기준 정확도 · κ와 통과 비율 병기 · 기준 문장별 따로 보고 | 코드 몇 줄과 문서 한 장 | 지표 선택으로 결과가 뒤집히는 일 방지(2-1절 Rao · Callison-Burch). 1번과 같은 표본으로 바로 계산 |
| 3 | **자기 채점 점검 — 다른 계열 판정 모델을 하나 더 두고 1번 표본에서 비교.** 학습 전 원본 · 다른 계열 공개 모델 등을 같은 표본으로 판정시켜, 학습 모델 판정 · 다른 계열 판정 · 사람 판정을 비교. 합의(패널)는 **그다음** | 판정 모델을 로컬에서 돌릴 수 있다면 중간. 새 모델 준비가 필요하면 큼 | 자기 선호가 실제로 있는지 우리 데이터로 확인. 「더 많은 판정 모델」이 답이 아닐 수 있다는 2026년 근거(2-3절)를 감안해, **사람 표본 일치도가 가장 좋은 판정 모델 하나**를 고르는 게 목표 |

**지금 하지 않을 것:** 추론형 판정 모델 학습(2-5절) · 쌍 비교로 전환(2-6절) · 사실성 도구 도입(2-7절). 이유는 사람 표본이 먼저 있어야 어느 것이 도움이 되는지 잴 수 있기 때문입니다. [추정]

**이미 효과가 보고되어 가볍게 곁들일 수 있는 것(우선순위 4):** 기준 문장을 한 번에 하나씩 이진 판정시키는 구성과 순서 · 문장 길이를 바꾼 대조 쌍으로 판정 모델이 흔들리는지 점검(2-2 · 2-4절). 다만 **판정 모델끼리의 일치가 올라간 것을 개선으로 보면 안 됩니다**(2-2절의 Han · Kim 결과) — 개선 여부는 1번의 사람 표본으로만 잽니다.

## 4. 확인하지 못한 것 · 남은 일

| 확인하지 못한 것 | 비고 |
|---|---|
| 본문 수치(표본 수 · 세부 조건) | 대부분 초록만 확인. 논문을 인용할 때는 본문 확인이 필요 |
| TICK 원 논문 · CE-Judge · 길이 편향 일차 논문 | 검색에서 일차 출처가 나오지 않음. 「없다」는 뜻이 아님 |
| 한국어 · 한국어 대화 · 여행 도메인 판정 모델 사례 | 검색하지 않음 |
| 우리 저장소 평가 문서와의 대조 | 열어 보지 않음. 의뢰 설명이 정확하다는 전제 |
| 판정 불가 비율이 큰 경우의 처리 | Rao · Callison-Burch의 권고(전체 기준 범위 병기)를 따르면 되지만 우리 데이터 비율은 모름 |
| 2026년 논문의 재현 · 인용 검증 | 아직 이르다고 봐야 함 |
