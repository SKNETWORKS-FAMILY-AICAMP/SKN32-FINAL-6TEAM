# 2026-10-06 06:20 — 웹 계정이 필수 부품을 끌고 가지 않게 한다 (사용자 지시 (나))

## 해결됨 (2026-10-06) — 「필수 부품 → 끌 수 있는 기능」 4 → **0**, 「바꿔 끼우는 자리 → …」 2 → **0**

## 1. 무엇이 문제였나

[폴더 이동](2026-10-06_0300_업무도메인_폴더이동_리포트.md) 뒤 실측에서, **끌 수 있다고 적어 둔 기능**(웹 계정 ·
실시간 진행)을 **늘 있어야 하는 부품**이 직접 가져다 쓰고 있었다. 방향이 거꾸로다 — 기능을 끄거나
고치는 순간 부품이 같이 멈춘다.

가장 센 자리는 감시였다. 일정 저장 부품이 로그인 표(`web_social_links`)를 보는 규칙을 직접 import 해,
**로그인 쪽을 바꾸면 감시와 출발 안내가 통째로 멈추는 길**이 열려 있었다. 로그인과 아무 상관없는 기능인데도.

사용자 결정: **(나) — 틀린 방향을 바로잡는다**(끌 수 있다는 표시를 지우는 (가) 가 아니라).

## 2. 한 것

### 2-1. 끼움 자리 셋을 만들었다 (부품이 묻고, 기능이 조립 때 꽂는다)

| 끼움 자리 | 부품이 묻는 것 | 꽂는 쪽 | 아무도 안 꽂으면 |
|---|---|---|---|
| [components/itinerary/trip_scope.py](../../../app/domains/travel_ops/components/itinerary/trip_scope.py) | 감시 · 안내 대상을 좁힐 조건 | 웹 계정(게스트 제외) | `TRUE` — 아무도 빼지 않는다 |
| [components/settings_hook.py](../../../app/domains/travel_ops/components/settings_hook.py) | 운영자가 화면에서 바꾼 값 | 웹 남용 방어 설정 표 | `None` — 가드레일 기본값 |
| [components/progress_hook.py](../../../app/domains/travel_ops/components/progress_hook.py) | 진행 이벤트를 화면 모양으로 | 실시간 진행 | `[]` — 실시간 화면만 없다 |

★미등록일 때의 답은 **새로 만든 기본값이 아니다.** 세 자리 모두 그 기능이 없을 때 부품이 이미
가지고 있던 길이다(감시는 전부 대상, 설정은 가드레일 값, 진행은 화면 없음). **값을 지어내지 않는다.**

꽂는 곳은 조립 한 군데다 — [`app/composition.py`](../../../app/composition.py) `wire_optional_features()`.
컨트롤러를 만들 때와 HTTP 입구를 만들 때 양쪽에서 부른다(어느 쪽으로 기동해도 같은 조립).

### 2-2. 고객 연락처 · 동의는 「필수 부품」이 맞았다 — 칸을 옮겼다

알림 발송이 고객 연락처와 동의를 읽는 것은 끌 수 있는 기능이 아니다. 끄면 알림이 안 간다.
그래서 세 파일을 새 칸 [components/customer/](../../../app/domains/travel_ops/components/customer/) 로 옮겼다.

| 파일 | 무엇 |
|---|---|
| [profile.py](../../../app/domains/travel_ops/components/customer/profile.py) | 고객 연락처(알림 받는 곳 · 언어) |
| [consents.py](../../../app/domains/travel_ops/components/customer/consents.py) | 약관 동의(알림 보내도 되나) |
| [channels.py](../../../app/domains/travel_ops/components/customer/channels.py) | 텔레그램 · 디스코드 **저장값**(암복호 · 끊기) — 연결 흐름에서 떼어냈다 |

반대로 **연결하는 흐름**(디스코드 · 텔레그램 OAuth 창 · 일회용 코드)은 웹 화면이 있어야 성립하는
기능이라 [modules/web_account/](../../../app/domains/travel_ops/modules/web_account/) 로 옮겼다.
비게 된 포트 칸 `ports/notify_channels/` 는 지웠다(실제 발송 구현은 `app/infrastructure/notify/` 에 있다).
