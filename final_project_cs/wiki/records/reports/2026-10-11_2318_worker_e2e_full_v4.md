# 플러그인 전환 전체 E2E 4차와 건너뜀 경계 검증

전체 실행은 1,006건을 끝까지 실행했고 1,000건 통과, 실패 0건, 건너뜀 6건입니다. 별도 격리 합성 DB에서는 건너뜀 대상 6건을 각각 검증했습니다. 운영 배포·외부 API 실측 완료를 뜻하지 않습니다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 전체 수집 범위 실행 | 완료 | 1,006/1,006 = 100% |
| 전체 실행의 통과 | 6건 건너뜀 별도 | 1,000/1,006 = 99.40% |
| 건너뜀 대상 별도 실행 | 통과 | 6/6 = 100% |
| 정적 감사 후속 | 감시 재시도 확인 예정 | 0/1 = 0% |

## 원본 전체 결과

- [전체 로그](../evidence/2026-10-11_1936_team_plugin_implementation/e2e-full-v4.log), [JUnit XML](../evidence/2026-10-11_1936_team_plugin_implementation/e2e-full-v4.xml), [분류·시작 해시 대조](../evidence/2026-10-11_1936_team_plugin_implementation/e2e-full-v4-classification.json).
- 실행: `tests/e2e -vv --tb=short --maxfail=0`. 소요 1,930.58초. 수집 1,006, 실행 1,006, 통과 1,000, 실패 0, 건너뜀 6, 미실행 0. 경고 54.
- 시작 시 404개 소스 해시를 보존했습니다. 실행 중 다른 담당 변경 4개가 발견됐습니다: `conversation/decision_unit.py`, `conversation/trip_messages.py`, `intake/assemble.py`, `entry/trip_api.py`. 따라서 모든 시험이 동일한 최종 소스를 검증했다는 근거로 사용하지 않습니다. 각 담당자의 변경 후 영향 회귀가 별도로 필요합니다.
- 옛 999개 수집과 새 1,006개 수집은 단순 동일 분모가 아닙니다. 차이 목록에는 한국어 node id의 이전 인코딩 손실 5쌍, MCP 시험 이름 변경, 접수 시나리오 매개변수 변경도 포함됩니다. 원본별 분모를 유지합니다.

## 건너뜀과 별도 실행

개발 DB에 실제 식당 자료가 있어 합성 식당만을 요구하는 Dining 5건이 건너뛰어졌습니다. 별도 격리 합성 DB에서 실제 Dining 구현은 유지하고 Mobility에 명시 시험 제공자만 조립하여 [5/5 통과](../evidence/2026-10-11_1936_team_plugin_implementation/dining-ledger-isolated-db.log), 5.32초를 확인했습니다.

개발 DB에 실제 대피자료가 있어 빈 대피자료 경계 1건이 건너뛰어졌습니다. 자료를 지우지 않고 같은 별도 격리 합성 DB에서 [1/1 통과](../evidence/2026-10-11_1936_team_plugin_implementation/safety-empty-shelter-isolated-db.log), 20.25초를 확인했습니다. 자료가 없을 때 대피소를 지어내지 않고 해당 안내와 일시중지 상태를 남기는 기존 시험입니다.

별도 6건 결과를 전체 실행의 1,000 통과에 합쳐 같은 실행의 1,006 통과라고 적지 않습니다. 운영 DB와 기존 개발 자료는 수정하지 않았습니다. 시험 행은 격리 DB에 한정했습니다.

## 검증 범위

공유 API 소비 파일 49개와 앱 생성 28개를 감사했습니다([감사 목록](../evidence/2026-10-11_1936_team_plugin_implementation/e2e-app-construction-reviewed-v2.json)). CRUD·권한·멱등·상태 전환 시험의 계산 의존성은 명시 BindingTable 시험 제공자로 충족하며 운영 fallback을 복원하지 않았습니다. 엔진 부재 503과 실제 로컬 그래프 시험은 유지했습니다. 이 시험 통과는 실제 지도 경로·요금 정확도의 실측 근거가 아닙니다.

mock 서버 시험: 이 보고서에서 별도 실행하지 않았습니다.
실서버 확인(서버 응답): 로컬 개발 서버의 ASGI 앱과 로컬 DB로 위 제품 경로를 확인했습니다. x600 서버 배포·외부 API 연결은 수행하지 않았습니다.
