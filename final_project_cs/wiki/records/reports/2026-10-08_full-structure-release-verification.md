# 전체 구조·완료 패치 반영 전 검증

새 도메인 폴더 구조와 완료된 고객 화면·요식·이동·여행 접수 패치를 한 반영본으로 모았다. 팀 develop의 관리자 화면은 그대로 보존했다. 개인 저장소 전용 자료, program, CLAUDE.md, 데이터·키·빌드 캐시·백업은 조직 반영본에서 제외했다. 다른 진행 중인 시험의 후속 산출물은 이번 동결본에 추가하지 않았다.

## 확인한 오류와 조치

| 구분 | 원인 | 조치 |
|---|---|---|
| 이전 이동 이식 CI | 속도 그래프 공유 사전 선언 누락, 미사용 이름 | 원래 캐시 선언 복원, 첫 적재·재사용·자료 누락 회귀 시험 보존 |
| 전체 구조 CI 준비 | Ruff 61개 진단: 미사용 이름·Candidate 형식 이름 누락 | 실제 미사용 이름 정리, 형식 이름 명시 |
| 정리 중 발견 | 이동 검증기의 공개 연결 이름도 미사용 가져오기로 제거됨 | 런타임·CLI 공개 이름 복원, 이동 회귀 전체 재검증 |
| 일정 접수 시험 | 장소 미확정의 bad 판정을 warn으로 기대 | 차단 판정 유지와 두 해석 안내를 함께 검증, 회귀 추가 |
| 공개 API 목록 시험 | 새 경로 네 개가 확인 목록에 누락 | 이미 문서화된 네 경로를 목록에 명시 |
| 메뉴 화면 시험 | 삭제된 데스크톱 전환 항목을 찾음 | 현재 마지막 설정 항목으로 스크롤·화면 폭 검증 유지 |
| 시각 끌기 시험 | 손잡이가 화면 밖인 상태에서 좌표를 계산 | 손잡이를 화면 안으로 옮긴 후 실제 마우스 끌기 검증 |
| 로컬 시험 준비 | 새 시험 DB에 demo 자료·정책 문서 적재 누락 | demo는 CI와 동일하게 적재, 실제 임베딩 자료가 필요한 RAG 범위는 CI와 같이 구분 |

전체 첫 실행의 실패는 해당 파일 재검사로 해결 여부를 확인했다. 전체 장시간 시험을 수정 후 다시 전부 실행한 수치로 합쳐 쓰지 않는다. 실제 임베딩 정책 문서를 전제하는 RAG 통합 시험은 기존 CI에서도 제외되는 별도 수동 범위다. 바이너리 내용과 원격 최종 CI 결과는 이 텍스트 검사 수치에 포함하지 않는다.

mock 서버 시험(화면 반응): 고유 실행 항목 452/452 통과, 조건부 5건 건너뜀.
실서버 확인(서버 응답): 이 보고 시점에는 배포 전. 두 브랜치 동일 커밋과 실제 배포 응답은 푸시 이후 별도로 확인한다.

## 반영 방법

팀 role-manager와 develop을 두 부모로 둔 조직 반영 커밋을 만든다. role-manager를 먼저 일반 푸시하고 자동 배포 결과를 확인한 뒤 develop에 동일 커밋을 일반 푸시한다. 강제 푸시와 개인 저장소 이력 복제는 하지 않는다.
