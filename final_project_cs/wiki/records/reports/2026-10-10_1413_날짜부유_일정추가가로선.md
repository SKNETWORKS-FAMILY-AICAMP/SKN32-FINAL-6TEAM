# 날짜 탭 부유·일정 추가 가로선

날짜 탭에 잔잔한 부유 효과를 넣고, 사용자가 선택한 가로 구분선 중앙의 원형 +를 적용했다. 이전 버튼 위치 조정안은 취소한다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 요청 반영 | 완료 | 2/2 = 100% |
| mock 서버 화면 시험 | 통과 | 6/6 = 100% |
| 정적 검사·표준 생산 빌드 | 통과 | 3/3 = 100% |
| 화면·영상 | 완료 | 7/7 = 100% |

날짜 전체 줄과 선택 배경이 4초 주기로 최대2px 떠오르고 돌아온다. 현재 표시하는 삽입 경계에는1px 가로선과 중앙 원형 +를 표시한다. 선은3초 주기로 opacity .35~.85만 바뀌고 버튼 위치는 고정한다. 원형 표면은 비교 목업과 같은30px 지름이며 누름 영역은44×44px다. 기존 삽입 경계 선택과 목록 높이는 바꾸지 않았다. 지속 장식과3·4초 주기는 사용자가 이번에 명시한 요청에 따라 일반 motion 스킬의 반복 장식 금지·전환 시간 기준보다 우선하는 예외로 계약에 적었다.

hover·키보드 초점에서는 각 움직임을 멈추고, 날짜 스크롤 숨김·유휴 복귀와 기존 검색 초점·취소 복귀를 유지했다. prefers-reduced-motion:reduce에서는 반복 애니메이션을 완전히 제거한다. JavaScript와 API 계약은 바꾸지 않았다.

375px·1280px Chrome에서 실제 CSS 애니메이션 프레임을 계측했다. 날짜 이동량2px·선 밝기 차이·버튼/선 중심 일치·44px 영역 유지·목록 사각형 고정·선택 배경 정렬을 확인했다. 실제 포인터와 키보드 초점의 정지, 날짜 숨김과 inert·복귀, 움직임 줄이기, 초기 검색 초점과 취소 복귀, 쓰기 요청 없음·가로 넘침 없음을 시험했다. 두 너비 촬영을 직접 확인했다. 영상은 실제 Chrome의60프레임을5fps·12초로 인코딩했으며 영상 형식을 위해 오른쪽1px을 채웠다.

처음 세 실행은 각각 moving target의 hover 대기, 가상 요소 애니메이션 조회 범위, 숨겨진 role 요소 제외라는 시험 계측 문제로 새2개가 실패하고 기존4개가 통과했다. 제품 CSS를 추가 수정하지 않고 시험 도구를 바로잡은 최종 실행은6/6 통과했다. 실패 실행 JSON·시험 코드·촬영은 수정 전 백업 안에 보존했다. 표준 Next.js 생산 빌드는 첫 실행에서 통과했고 이후 CSS가 같아 재사용했으며 최종 시험 코드의 TypeScript·ESLint를 다시 통과했다. CSS는 ESLint 검사 대상이 아니므로 CSS lint 통과로 보고하지 않는다.
