## 고정 평가 결과

각 칸은 **정상 요청의 정답 / 정상 요청 전체**, **요청 없는 문장의 실제 오지목 / 요청 없음 전체**입니다. D의 복합 요청 66개는 모두 실행·보관했으며 아래 단일 선택 표에서만 별도 진단으로 분리했습니다. D2는 요청 없음 전용입니다. 실패·미완료를 분모에서 제외하지 않았습니다.

| 시험 | Saluki 배포 원본 | Gemma E4B Q4_K_M + cosine 학습 | Gemma E4B QAT Q4_0 + 같은 cosine 학습 |
|---|---|---|---|
| D 정상 / 오지목 | 771/883 · 76/1,786 | 765/883 · 14/1,786 | 768/883 · 22/1,786 |
| D2 오지목 | 68/1,000 | 8/1,000 | 8/1,000 |
| D3 정상 / 오지목 | 107/120 · 17/240 | 105/120 · 4/240 | 105/120 · 2/240 |
| H 정상 / 함정 오지목 | 434/461 · 305/855 | 446/461 · 3/855 | 444/461 · 7/855 |
| E 평문 혼합 정상 / 오지목 | 997/1,033 · 157/974 | 947/1,033 · 3/974 | 991/1,033 · 10/974 |
| E 합산 사전 기준 | 3/4 | 2/4 | 2/4 |

Saluki에는 우리 여행 자료를 추가 학습하지 않았습니다. 개발사 학습된 Qwen3.8-27B 기반 배포판을 발행자가 IQ2-mix로 변환한 원본입니다. cosine 두 칸은 **우리 여행 자료로 학습한 같은 어댑터**를 서로 다른 기반 양자화에 붙인 시험이며 원본 비교군으로 세지 않습니다. Base 사전학습 모델끼리의 비교도 아닙니다.

E는 내부 이름 MX이며 전체 **4,014문항 = 대조·평문 혼합 2,007쌍**입니다. 혼합 쪽만 보면 실제 요청 1,033개와 요청 없음 974개입니다. Saluki 정상 선택은 96.52%지만 요청 없음 오지목은 16.12%로 사전 상한 1%를 넘었습니다. 대조 대비 정상 손실은 11/1,033 = 1.06%p, 오지목 증가는 2/974 = 0.21%p입니다. cosine Q4_K_M은 정상 손실 71/1,033 = 6.87%p, QAT Q4_0은 30/1,033 = 2.90%p로 회귀했습니다.

모든 신규 완료 13세트에서 답안 27,555/27,555개, 호출·해석 실패 0개, 미완료 0개입니다. 원격·로컬 파일 SHA와 크기 **72/72**, 문항 ID 중복 0개, ID·정답·유형·세트·문항 순번 **27,555/27,555개 일치**, 입력 파일 전체 SHA 일치를 확인했습니다. E 집계는 실패 포함 도구를 사용했으며 Wilson 구간과 일정별 묶음 bootstrap 2,000회(seed 7), 같은 문항 정확검정을 원본 집계에 보관했습니다. 이는 1회 개발·회귀 시험이며 신규 독립 보류 자료 검증이나 최종 모델 순위·제품 채택이 아닙니다.

## FINCH 학습 완료와 후속 시험

첫 시드 20261012의 FINCH 학습은 train_oos2 고정 자료 2,613/2,613행, 2에폭·rank16·accum8·상한 5e-5로 optimizer 654/654회를 마쳤습니다. 학습 시간은 17,891.89초(298.20분), 앞선 초기 손실 측정은 2,187.70초로 분리합니다. 학습률 상한에 닿은 갱신은 **639/654 = 97.71%**, 연속 16~654번째입니다. 실제 학습률 범위는 3.83544e-5~5e-5이며 연결 검사나 학습 종료를 정확도 향상으로 해석하지 않습니다.

HF 어댑터·GGUF·레시피·소스·로그·기본 평가 17파일은 원격·로컬 SHA **17/17** 일치했습니다. 기본 평가 5파일은 **835/835문항**, 호출 오류 0개로 보관했습니다. 어댑터 가중치 SHA는 `0913cb609290a99f7cdc0b91f29cc6e4d0a303d4ac7375d6913c551b6cb6d2d4`, GGUF SHA는 `d96f5ce87bf3df7a0a7f7701389743642d47f02c79f5d7e389a6ae0e8fb062cd`입니다.

GPU 서버 A의 기존 worker에 FINCH × 두 기반 양자화 × D/D2/D3/H/E **10작업·18,850문항**을 추가했습니다. 어댑터 tensor 구조·기반 모델 전체 SHA·입력 SHA·기존 실행기의 LoRA 지원·잠금과 공간을 먼저 확인했고 manifest 원본을 백업한 뒤 원자적으로 교체했습니다. 새 worker를 띄우거나 진행 중인 작업을 중단하지 않았습니다.

막 완료된 FINCH D3 두 판도 720/720개 회수, 원격·로컬 SHA **8/8** 일치로 집계했습니다. Q4_K_M 기반은 정상 **105/120**, 오지목 **0/240**, QAT Q4_0 기반은 정상 **106/120**, 오지목 **0/240**이며 모두 실패·미완료 0개입니다. 나머지 평가와 독립 반복이 끝나기 전 우열을 확정하지 않습니다.

## Saluki 보관 실패와 복구

앞선 7.9GB 장시간 파이프 전송은 Windows 송수신 프로세스 실패로 중단됐고 GPU 서버 B 부분 파일 7,196,936,192바이트를 남겼습니다. 이 실패는 모델 추론의 실패가 아닙니다. 원래 프로세스가 종료된 것을 확인하고 기존 부분 파일과 GPU 서버 A의 같은 구간 SHA를 대조한 뒤, 남은 **701,432,960바이트만 별도 SCP**로 회수·전송했습니다. 부분 파일과 이전 실패 상태를 GPU 서버 B의 별도 백업에 보존한 뒤 덧붙였으며 전체 크기와 SHA를 확인하고 이름을 확정했습니다.

GPU 서버 B의 기존 디스크에는 전체 파일이 보관됐습니다. 전체 SHA `4a673518b11b1c4445f9b9a9d3c40356f5ba39f6a6260dcb25f3fbfd475d9efb`가 고정 원본과 일치하며 복구 후 공간은 **6,515,253,248바이트**입니다. 이는 GPU 기계 밖의 영구 아카이브가 아니고 기계 폐기 시 유지된다는 보장은 없습니다. GPU 서버 A의 원본 RAM 파일도 계속 보존했고 로컬 디스크에는 전체 모델 대신 검증한 꼬리 조각과 증거를 보관했습니다. 새 결제·임대·기존 모델 삭제는 없습니다.
