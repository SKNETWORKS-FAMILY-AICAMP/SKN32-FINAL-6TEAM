# 카드 하단 확인 필요·되돌리기 단일 표시

확인 필요와 시간 되돌리기를 카드 하단 오른쪽 한 자리에서 하나만 표시하도록 보완했다. 시간을 바꾼 동안에는 되돌리기만 표시하고, 되돌린 뒤 확인이 필요한 일정에는 확인 필요가 다시 나온다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 단일 표시 조건 | 완료 | 1/1 = 100% |
| mock 서버 화면 고유 시험 | 통과 | 4/4 = 100% |
| 촬영 | 완료 | 4/4 = 100% |

## 확인한 차이와 변경

사용자 첨부 공개 화면에서는 확인 필요가 제목 옆에 나왔다. 현재 로컬 `plan-rows.tsx`에는 이미 카드 하단 배치가 있었지만, 확인 필요·되돌리기를 독립 조건으로 렌더링해 둘이 함께 나타날 수 있었다. 하단 분기를 하나로 합쳐 되돌리기가 있으면 우선 표시하도록 했다. 제목 옆 확인 중·삭제 예정 상태와 삭제 복원 도구는 유지했다. 별도 CSS 변경이나 API 변경은 없다.

## 검증

- mock 서버 시험 **4/4 (화면 반응)**: 375px·1280px 각각 접힌/펼친 카드의 하단 위치, 제목 옆 확인 필요 0개, 하단 자식 1개, 시간 수정 후 되돌리기만 표시, 키보드 되돌림 후 원래 시간 요청과 확인 필요 복귀를 검사했다. 기존 하단 배치·시간 되돌리기 사례 2개도 통과했다.
- 첫 실행 4/4, 실제 지도 배경을 넣은 촬영 재실행 2/2. 동일한 두 신규 사례를 중복 집계하지 않아 고유 사례는 4개다. 타입 검사·수정 파일 ESLint 통과.
- 재현: 웹 작업 폴더에서 `STUB_PORT=8057`, `LIVE_PORT=3127`, `PLAYWRIGHT_CHANNEL=chrome`을 설정하고 `npx playwright test --config playwright.live.config.ts tests/live/card-footer-exclusive-20261009.spec.ts tests/live/card-status-footer.spec.ts --grep '확인 필요|시간 변경|한 자리' --reporter list,json`을 실행한다. 촬영은 `CARD_EXCLUSIVE_SHOTS`에 출력 폴더를 지정한다.
- [원본 실행 결과·형식 검사 출력](../evidence/2026-10-09_card-footer-status/).
- 실서버 확인 **(서버 응답): 안 했음**. 공개 페이지 확인 도구는 시작 단계에서 경로 오류로 실행하지 못했다. 공개 DOM·현재 배포 버전은 이번에 확인하지 않았으며, x600 서버 배포·커밋·푸시는 하지 않았다.
