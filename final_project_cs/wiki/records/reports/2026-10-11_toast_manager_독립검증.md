## 적용 범위

기준은 팀 role-manager의 5ded30ca입니다. 전달 patch 1개와 새 파일 34개의 SHA256이 일치했으며 변경 10개·새 파일 34개만 적용했습니다. 화면 안내를 공통 형식으로 표시하고, 목록 맨 위 추가 위치와 질문 완료 후 첫 지도 일정을 순차 표시하며, 접힌 카드의 문제와 상태를 함께 배치합니다. 기존 매니저 코드의 CSS 모듈 보정은 유지했습니다.

추가로 develop 180c56ae에서 검증한 CI 보완 네 파일만 가져왔습니다. 직접 색상값을 같은 색의 공통 역할값으로 교체하고, 이미 문서화된 공개 시험 목록 경로를 API 계약 검사 집합에 넣었습니다. 팀 develop의 다른 변경은 이식하지 않았습니다.

## 독립 검사에서 발견한 결함

최초 웹 단위 시험은 기존 색상 규칙 오류로 642개 통과·1개 실패했습니다. CI 보완 후 643개가 통과했습니다. 최초 Chrome 49개에서는 46개 통과·3개 실패했습니다. 전송 안내가 같은 화면에 두 번 생겨 정확한 문구 선택이 실패했습니다. 원인은 새 PlanCheck의 로컬 안내와 기존 공통 알림의 pending 전달 소비자가 같은 안내를 각각 표시한 것입니다. 전달 작업 폴더의 공통 알림 코드와 실제 매니저 기준 코드가 달라 원본 시험에서는 드러나지 않았습니다.

PlanCheck 읽기 안내를 한 곳에서 소유하도록 고쳤고, 읽기 중 공통 안내 수신을 안내 표시보다 먼저 연결했습니다. 지도 화면의 기존 수신과 공통 app-toast·toast-bus 구현은 유지했습니다. 전송 진행 안내는 이전 inline 안내처럼 해당 화면에서만 표시합니다. 기존 페이지 전환 전달·만료·닫기·되돌리기 행동은 공통 알림 단위 시험 6개로 확인했습니다. 실패한 세 시험에는 안내가 정확히 하나인지 검사를 추가했고 기존 진행·결과 검사는 유지했습니다.
