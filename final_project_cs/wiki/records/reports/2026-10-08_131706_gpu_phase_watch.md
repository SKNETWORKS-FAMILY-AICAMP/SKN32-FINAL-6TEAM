| 할 일 | 상태 | 진행 |
|---|---|---|
| 실제 계산 단계 확인 | 완료 | 2/2기계 = 100% |
| 변경 관측 도구 실행 | 통과 | 1/1회 = 100% |
| GPU 서버 A 즉시 준비 평가 | 대기 | 5/5개 입력 확인 = 100% |

변경은 [관측 기록 도구](../../../../program/scripts/plan_qa_bench/record_gpu_routine_observation.py)의 단계별 프로세스 확인이다. 이미 감사해 기록한 학습 또는 기본 평가 단계만 허용하며 다른 모델이나 다음 단계로 바뀌면 자동 기록을 멈추고 새 산출물을 회수하도록 한다. 원격 작업의 순서·프로세스·레시피를 바꾸지 않았다.

[GPU 서버 A 실제 관측](../../../../program/scripts/plan_qa_bench/results/gpu_backlog_20261008/A_snapshot_1316.json)과 [입력 확인](../../../../program/scripts/plan_qa_bench/results/gpu_backlog_20261008/A_conditions_1316.json), [GPU 서버 B 실제 관측](../../../../program/scripts/plan_qa_bench/results/gpu_backlog_20261008/B_snapshot_1316.json)과 [입력·공간 확인](../../../../program/scripts/plan_qa_bench/results/gpu_backlog_20261008/B_conditions_1316.json)을 사용해 [수정된 관측 도구를 실행](../../../../program/scripts/plan_qa_bench/results/gpu_backlog_20261008/routine_observation_1316.json)했다. 새 완료·실패 없이 통과했다.

GPU 서버 A는 Gemma12B 원본 D3 답안276/360개가 저장됐고 같은 실행기에서 남은 원본 평가5개가 기다린다. GPU 서버 B는 Winnow-E4B 우리 여행 자료 학습판의 기본 평가를 실행한다. 뒤 본 학습4개 중 기존 기반2개는 준비됐고2개는 기존 실행기가 기반을 다운로드해야 한다. 현재 공간과 다음 실행 시 공간은 같다고 가정하지 않으며 다운로드 직전 다시 확인한다. 새 결제·임대·삭제·실행기 추가·중복 호출은 하지 않았다.
