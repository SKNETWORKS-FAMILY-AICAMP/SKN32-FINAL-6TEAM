# 웹 CI 원격 전체 실행 후 추가 수정

원래 54개 실패 수정 뒤 원격 전체 실행에서 매니저 두 곳은 각각 649개 통과·1개 실패·기존 조건부 제외 13개였다. 팀 develop은 같은 코드로 전체 성공했다. 성공한 실행만 골라 재실행하지 않고 개인 develop은 648개 통과·2개 실패·기존 조건부 제외 13개였다. 확인된 원인 네 가지를 수정했다.

| 원인 | 수정 | 유지한 검증 |
|---|---|---|
| 지도 확대 시험의 촬영 도우미가 외부 지도 타일을 요청해 15초 응답 제한 초과 | 기본은 mock 서버 타일을 사용한다. 실제 지도 촬영은 UI_MAP_CAPTURE_REAL=1로 명시적으로 선택한다 | 지도 마커 이동 중 매 프레임의 노출·거리 칩 분리·타일 로딩 확인 |
| 목록 높이 변경 직후 버튼과 삽입 지점을 서로 다른 프레임에서 측정해 80px 차이 | 같은 프레임에서 모든 사각형을 측정하고 조건 성립을 기다린다 | 44×44px 버튼, 48px 첫 삽입 영역, 가로 오차 1px 미만·세로 오차 0.05px 미만, 취소 후 초점 복귀 |
| 개인 develop에서 읽기 판의 끄기 안내가 결과 판으로 전환하면서 사라짐 | 안내와 되돌리기 동작을 새 결과 판의 안내 소유자에게 넘긴다 | 실제 소유자 전환 회귀 단위 시험 및 영어 화면 다섯 번 반복 |
| 연결 종료 전 알림의 늦은 읽기로 제안이 먼저 표시되어 재접속 요청보다 앞서 개수를 검사 | 재접속 GET 요청을 기다린 뒤 제안 표시를 검사 | 재접속 2회 이상·변경 제안 표시 기준 유지 |

로컬 mock 서버 시험: 관련 두 파일 12개 시험을 각각 세 번 실행하여 36/36 통과. 린트와 타입 검사 통과. 실서버 확인(서버 응답): 안 했음. 실제 공개 지도 응답을 이 화면 검사의 성공 근거로 사용하지 않는다.
안내·재연결 경로는 새 제품 빌드로 각각 다섯 번 실행하여 10/10 통과했다. 단위 시험은 기존 654개와 신규 안내 전환 1개, 합계 655/655 통과했다.

원격 CI 최종 결과는 각 저장소의 해당 후속 커밋 Actions 실행으로 확인한다. 타임아웃·재시도 횟수·위치 오차를 넓히거나 시험을 제외하지 않았다. main 브랜치는 변경하지 않는다.
