## 도구 계약

| 도구 | 필수 입력 | 선택 입력 | 돌려주는 것 |
|---|---|---|---|
| `read.stay_search` | `keyword` `check_in` `check_out` | `adults` `children` `domestic` `size` `min_price` `max_price` `min_review_rating` | `stays[]`(gid · name · description · price_per_night · price_per_night_with_tax · rating · review_count · tags) · `total` · `has_next` |
| `read.stay_detail` | `gid` `check_in` `check_out` | `adults` `children` | name · latitude · longitude · address · link · price_per_night · total_price · rating · review_count · sold_out · no_rooms · rooms[](최대 5) |
| `read.flight_search` | `origin` `destination`(공항 코드 3글자) `depart_date` | `return_date` `domestic` `direct_only` `cabin` `max_results` `adults` `children` `infants` | `flights[]`(airline · legs · price_total · currency · seats · link · link_kind) · `cheapest_total` |

- 셋 다 `confirmed_at` · `source="myrealtrip"` 를 함께 준다.
- 필수 입력이 비면 바깥으로 나가지 않고 `None`(모름)이다. 날짜를 기본값으로 채워 부르지 않는다 — 되묻기는 팀이 한다.
- 못 가져온 갈래(시간 초과 · 연결 오류 · HTTP 오류 · 본문 오류 · 모양 다름)는 전부 `None` 이고 `misses` 에 센다. 0건은 빈 목록이다.
- 단위는 받은 그대로다: 평점 5점 만점, 목록 가격 1박, 상세 `total_price` 는 숙박 전체(세금 포함).
- 항공 링크는 `searchUrl` 만 싣는다. `reservationUrl` 은 열면 「가격 변동」 뒤 다시 검색으로 가서 쓰지 않는다(2026-10-07 사용자 확인).
- 서버가 연결 때 주는 안내문은 읽지도 넘기지도 않는다.
- 응답을 캐시에 담지 않는다.
