# 일정 추가 버튼을 카드와 이동 사이 중앙에 놓는 목업

기존 원형 추가 버튼은 이전 일정 카드 끝에 붙어 있어 카드에 속한 작업으로 보인다. 카드 끝과 다음 이동 행의 위쪽 사이 빈 공간 중앙에 놓는 안을 추천한다. 사용자가 요청한 것은 변경 목업 이미지이므로 제품 소스는 변경하지 않았다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 배치 검토 | 완료 | 1/1 = 100% |
| 목업 촬영 확인 | 통과 | 2/2 = 100% |
| 촬영 이미지 | 완료 | 4/4 = 100% |

design-critique와 spacing 스킬로 사용자가 표시한 + 버튼의 시각적 소속과 간격을 검토했다. 목록은 그대로 두고 원형 + 하나의 위치만 바꿨다. 실제 앱의 mock 서버 화면에 임시 스타일을 적용해375px·1280px를 촬영했다.375px에서는 접힘 전후 비교와 펼친 카드,1280px에서는 변경 배치를 확인했다. 카드 끝과 다음 이동 행의 실제 좌표를 읽어 중심을 계산했으므로 카드 높이에 따라 같은 간격 기준으로 이동한다.

실측375px 접힌 카드의 끝580px·이동 행 위619px에서 버튼 중심599.5px, 펼친 카드 끝430.1875px·이동 행 위469.1875px에서 버튼 중심449.6875px였다. 기존28px 원과44px 누름 영역을 유지했다. 첫 촬영 검사에서는 투명한44px 누름 영역 전체가39px 간격에 들어가야 한다고 기대해2개가 실패했다. 실제 보이는 원은 양쪽8px 안쪽이라는 기준으로 바로잡았고 최종 촬영2/2가 통과했다. 투명 누름 영역이 카드 아래 빈 패딩과2.5px 겹치는 점은 실제 제품 적용 시 간격 확보와 함께 조정해야 한다. 목업에는 저장 요청을 보내지 않았고 가로 넘침도 발생하지 않았다.
