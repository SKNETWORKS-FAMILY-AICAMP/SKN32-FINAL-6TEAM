# 완료 UIUX 변경의 매니저 통합 검증

2026-10-12. 완료된 고객 웹 수정과 지도 방향 보정, 목록 끝 등록·재제출 버튼 이름 표시를 기존 매니저 코드에 통합했습니다. 진행 중인 택시 요금 UI와 운영 관리 기능은 이 변경에 포함하지 않습니다. 공개 배포 완료 보고가 아닙니다.

## 변경 범위

- 읽는 동안 전체 일정 제목·시각을 먼저 표시하고 현재 검사 항목을 펼칩니다. 목록 이동·날짜 표시·수정안 왕복·마커 공개와 지도 경계 계산을 보완했습니다. 실제 좌표를 유지하면서 화면 밖 방향과 가장자리 표식을 계산합니다.
- 계정 전환 후 늦은 응답이 새 사용자 화면을 덮지 않게 하고, 위치 동의 철회·채팅 전송 중 중복 조작·이름 편집·문의 빈 화면·공유 실패의 처리를 보완했습니다.
- 목록 끝에서는 등록 또는 재제출 버튼의 이름을 즉시 표시합니다. 위로 스크롤하거나 최소 접힘·지도 조작 중에는 기존 숨김 조건을 유지합니다. 스크롤만으로 요청을 전송하지 않습니다.
- 기존 매니저의 로그인 조회 경쟁 방지와 화면 이동 시 알림·되돌리기 전달을 보존했습니다. 완료 UI 사본에서 두 기능이 빠진 것을 기존 회귀 시험이 검출하여 통합 때 복원했습니다. 시험을 삭제하거나 기대값을 완화하지 않았습니다.

## 출처와 경계

UIUX 완료 작업의 소스 340개를 완료 시점 해시와 대조했습니다. 그중 338개는 전체 점검 완료 해시, 지도 파일 2개는 후속 지도 방향 수정 완료 해시와 일치합니다. 후속 등록 버튼 수정은 검증된 소스 3개와 시험 1개를 대조하고, 목록 파일에서는 버튼 속성 한 줄만 합쳤습니다. 같은 파일에 있던 진행 중 택시 UI는 가져오지 않았습니다.

API·DB·권한 계약을 이 UI 변경에서 새로 바꾸지 않습니다. 다른 대화의 미완료 변경과 전체 wiki 개편·작업 흐름 변경·운영 관리 기능을 이번 UI 완료 범위로 간주하지 않습니다.

## 검증

통합 직후 기존 회귀 시험 16개가 로그인 보호·알림 유지 누락을 검출했습니다. 두 기능을 복원한 격리 통합본에서 단위 시험 712/712, TypeScript 검사와 ESLint 검사를 통과했습니다. 첫 실행의 추가 작업 프로세스 종료와 타입 검사 메모리 부족은 환경 오류로 구분하고 단일 작업 스레드·별도 메모리 한도로 다시 실행했습니다.

mock 서버 시험 (화면 반응): 완료 UIUX 작업에서 전체 경로 26/26, 집중 회귀 52/52와 문의 7/7, 후속 지도 방향 10/10, 등록 버튼 10/10을 확인했습니다. 이 수를 서로 더해 전체 시험 통과 수로 쓰지 않습니다. 초기 전수 실행의 실패 54개를 처리한 기록과 전체 최신 전수 실행 통과는 구분합니다. 통합 커밋 전체의 최종 관문은 해당 커밋의 CI 결과로 별도 확인합니다.

실서버 확인 (cs 프로젝트 서버 응답): 안 했음. 이번 검증은 로컬 격리 시험과 mock 서버 화면 검증이며, 공개 배포·외부 로그인·실제 여행 등록 확인을 대신하지 않습니다.
