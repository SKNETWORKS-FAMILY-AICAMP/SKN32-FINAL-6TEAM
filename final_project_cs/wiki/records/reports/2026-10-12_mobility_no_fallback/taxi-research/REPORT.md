# 서울 택시 초기 기본량 조사 — 2026-10-12

기본요금 단계 없이 저속 시간을 처음부터 이후요금으로 더하는 현재 계산은 공식 미터 구조와 맞지 않습니다. 다만 서울 미터의 인증된 초기 설정·증분 전환 경계까지 확보하지 못했으므로 특정 웹 예상액 4,800원에 맞춘 수정은 진행하지 않았습니다.

| 확인할 일 | 상태 | 진행 |
|---|---|---|
| 전기식·앱식 검정기준 전체 읽기 | 완료 | 2/2 = 100% |
| 서울 운임 결정 첨부 원본 전체 읽기 | 완료 | 2/2 = 100% |
| 서울 실제 초기 펄스 설정 확보 | 미확보 | 0/1 = 0% |
| 제품 코드 수정 | 요청대로 미수정 | 0/1 = 0% |

분모는 이번 조사 대상으로 지정한 문서와 실제 설정 확인 항목입니다. 기능 실사용 완료율이 아닙니다.

## 확정한 사실

1. 국토교통부 전기식 검정기준 별표 5는 기본시간·이후시간을 구별하고 기본 펄스 수와 이후 펄스 수를 별도로 검사합니다. 기본시간은 기본요금에 상당하는 대기시간입니다. §5.7.2의 제한적 동시병산은 한계속도 이하에서 시간과 거리 모두를 사용합니다. §8.3.6은 기본요금이 변경되고 이후요금이 1회·2회 변경될 때까지의 저속 시험에 V = 3.6 × L/T − U 식을 제시합니다. 첫 단계 자체가 없고 slow_s가 1초만 생겨도 100원을 더하는 현재 함수에는 이 단계가 표현되지 않습니다.
2. 서울시 2022-3177호 공고와 운임 결정 원본은 2023-02-01 04:00부터 중형 기본 4,800원/1,600m, 이후 131m당 100원·30초당 100원을 확인합니다. 원본 전체에 초기 기본시간·기본 펄스 수·거리와 시간의 잔량 이월 상세는 나오지 않았습니다. 서울 최신 웹 표의 부분 동시병산 15.72km/h와 단위는 일치합니다.
3. 앱식 별표 5의2는 지자체 운임 기준 적용, 부분 동시병산 조건, 초 단위 위치 기반 계산과 검정 허용차를 규정합니다. 서울 초기 시간값을 직접 명시하지는 않습니다.
4. 제조사 중앙산전 공식 제품 페이지와 회사 이력은 확인했습니다. 현재 공개 HTML 본문은 모델 소개이며 서울 요율 프로그램·기본시간값을 제공하지 않았습니다. 제조사가 모든 자료를 공개하지 않는다고 단정하지 않습니다.
5. 1999년 공개특허 KR19990010940A는 기본·이후 단계의 한계속도 구분, 시간/거리 펄스의 부분거리 환산, 단계별 기준거리 및 잔량 처리를 기술합니다. 현행 서울 인증 미터의 구현 증거로 사용할 수 없습니다. 2023년 KCI 앱미터 특허는 학습 보정 중심이므로 서울 기본 펄스 수치의 근거로 채택하지 않았습니다.

## 조건을 분리한 해결 설계

### 공식 시험식으로부터 유도 가능한 모형 — 아직 제품에 채택하지 않음

중형 시간·거리 단위의 환산계수 c = 131/30 = 4.366666… m/s입니다. 동일한 펄스 비례계수가 최초 단계까지 유지된다는 전제에서는 저속 구간의 거리 d와 시간 t가 d + c×t의 기본량을 함께 소진합니다. 정차 초기시간 1,600/c = 366.412…초는 이 전제에서 계산된 유도값입니다. 제조사의 서울 실설정 관측값이 아닙니다.

기본량은 거리와 시간이 공유하므로 '총 저속 시간에서 366초 공제'는 이 모형과도 맞지 않습니다. '물리 거리 1.6km 안이면 항상 시간요금 0'도 장시간 정차 조건을 놓칩니다. 함수의 독립 거리 올림 + 독립 시간 올림을 공동 펄스 잔량과 단계 전환으로 바꾸는 방향이 필요하며, 할증 시각·행정경계를 넘으면 각 구간의 정책 전환도 보존해야 합니다.

공개 비교의 제품 거리 862.7m라면 같은 모형의 기본량 잔여는 737.3m, 저속 시간으로 환산한 잔여는 168.847…초입니다. 전체 228초를 전부 저속으로 간주해서는 안 됩니다. 실제 slow_s가 이 잔여보다 크면 공동 펄스 모형에서도 기본요금을 초과할 수 있으므로, 지도 웹 4,800원과 일치시키려고 저속 시간을 지우면 안 됩니다.

### 실제 수정 전 필요한 확정값

- 현행 서울 중형 검정용 요율 프로그램의 기본 펄스 수/시간 펄스 비율 또는 기본 정차시간
- 기본량 정확 경계에서 첫 증분이 발생하는지, 경계 이후 첫 단위 소진 때 발생하는지
- 거리·시간 잔량을 합쳐 하나의 이후 펄스로 처리하는 규칙과 반올림 위치
- 중형(부분 동시병산)과 모범·대형(상호병산)의 구분, 최초·이후 단계 한계속도가 같다는 현재 서울 설정
- 운행 중 심야/시계외 정책 전환 시 미소진 잔량의 이월 규칙

최소 검증은 기본거리 전후, 정차 기본시간 전후, 저속·고속 교차, 부분 거리+부분 시간 조합, 15.72km/h 전후, 심야 전환, 시계외 전환을 포함해야 합니다. 임의 표본에 상수 보정하거나 미확인 값을 대체 소스로 채우는 변경은 하지 않습니다.
