# TMAP 보행자 경로 API 키 준비하기

**TMAP 무료체험 앱의 키 1개를 준비하시면 됩니다. 아직 제품에 연결하지 않았으며, 키를 준비하는 것만으로 도보 정확도가 개선되지는 않습니다.** 공개 Free 요금표에는 경로안내 1,000건/일이 표시됩니다. 가입·준비 시간은 미측정이고, 실제 계정의 제한과 사용량 확인 전에는 호출하지 않습니다. [공식 요금표](https://openapi.sk.com/products/calc?menuSeq=5&svcSeq=4)

| 할 일 | 상태 | 진행 |
|---|---|---|
| 공식 키 발급·요금·약관 안내 확인 | 완료 | 3/3 = 100% |
| 로컬 환경 파일 변수명 확인 | 완료 | 6/6 = 100% |
| 계정 실제 한도·갱신·공유 사용량 확인 | 미확인 | 0/3 = 0% |
| TMAP 제품 연결 | 아직 미연결 | 0/1 = 0% |

위 3개 공식 안내는 키 발급 경로, 요금표, TMAP 공개 약관입니다. 환경 파일 6개는 로컬 작업폴더와 cs 프로젝트 직하위 `.env*` 파일입니다. 계정 점검의 분모 3은 실제 한도·차감 단위, 일일 갱신 시각·시간대, 전체 공유 사용량입니다. 문서 준비율을 제품 완료율로 합산하지 않습니다.

[준비 흐름 그림 열기](TMAP-preparation-flow-20261012-v1.html)

## 1. 공식 사이트에서 앱을 확인하세요

[SK open API](https://openapi.sk.com/)에서 로그인한 뒤 [앱 목록 바로가기](https://openapi.sk.com/mypage/project/)를 여세요. 로그인 전에는 로그인 화면으로 이동할 수 있습니다. 아래는 공식 사용자 가이드의 메뉴 이름이며, 이번 작업에서 로그인 후 실제 계정 화면을 직접 조작하거나 확인하지 않았습니다.

| 순서 | 화면의 위치 | 할 일 | 끝나면 확인할 것 |
|---|---|---|---|
| 1 | 대시보드 → 앱 | 기존 triPilot용 앱이 있으면 선택합니다. | 앱 상세 화면 |
| 2 | 앱 만들기 | 기존 앱이 없을 때만 앱 이름을 입력하고 확인합니다. 예: `triPilot-study` | 앱 목록에 새 앱 |
| 3 | TMAP API 사용 요금 | 무료체험 Free의 사용하기에서 대상 앱에 상품 사용을 신청합니다. | 대상 앱 상품 관리에 TMAP이 활성화됨 |
| 4 | 선택한 앱 → 앱키(appKey) | 앱키(appKey) 항목을 확인합니다. | 키 1개 확인 |

앱 키는 앱 단위로 발급됩니다. 같은 서비스를 여러 앱·프로젝트로 나눠 한도를 우회하지 않습니다. 키를 새로 발급하기 전에 기존 앱·키를 사용할 수 있는지 확인하세요. [공식 앱 만들기·키 확인 가이드](https://openapi.sk.com/products/detail?menuSeq=126&svcSeq=60), [TMAP 요금제 선택](https://openapi.sk.com/products/calc?menuSeq=5&svcSeq=4)

보행자 API 공식 문서에는 키 위치를 **마이페이지 > 앱 > 앱키(appKey)**라고 적고, 포털 사용자 가이드는 **대시보드 > 앱**이라고 안내합니다. 두 표현 모두 위 앱 목록으로 이어집니다. [보행자 경로안내 공식 문서](https://tmap-skopenapi.readme.io/reference/%EB%B3%B4%ED%96%89%EC%9E%90-%EA%B2%BD%EB%A1%9C%EC%95%88%EB%82%B4)

## 2. 키는 로컬 환경 파일에 보관하세요

키를 채팅·문서·스크린샷에 붙이지 마세요. 저장 대상은 git이 무시하는 [로컬 cs 프로젝트 환경 파일](C:/Users/playdata2/Documents/final_workspace/final_project_cs/.env.apikeys)입니다. 아래 이름은 **새 연동에서 사용할 예정인 이름**이며 현재 제품이 읽는 설정으로 구현되어 있지 않습니다.

```dotenv
TMAP_APP_KEY=<앱키(appKey)에서 복사한 값>
```

기존 파일을 바꾸기 직전에 로컬 비공개 백업을 만들고, 기존 키·값을 지우거나 공개 템플릿에 넣지 않습니다. 이번 작업은 파일을 변경하지 않았습니다. 키 보관 뒤에도 제품 연결과 호출 예산 보호 장치를 먼저 구현·검증해야 합니다.

이번 점검에서 `.env.apikeys`를 포함한 로컬 환경 파일 6개와 검사 프로세스의 환경 변수명에서 `TMAP`을 포함한 이름은 발견되지 않았습니다. 다른 이름으로 보관된 키, 다른 프로세스, x600 서버 환경, 계정 콘솔은 확인하지 않았으므로 그곳의 키 부재는 단정하지 않습니다. 비밀값은 출력하거나 전송하지 않았습니다. [변수명 점검 근거](local-variable-presence-v1.json)

## 3. 실제 사용량 확인 후 호출 예산을 잠그세요

공식 요금표의 1,000건은 **경로안내 API그룹**에 표시된 무료 한도입니다. 보행자 호출마다 별도 1,000건을 쓸 수 있다고 가정하지 않습니다. 실제 계정·앱·키·엔드포인트의 제한 단위와 갱신 시간대를 확인한 뒤, 같은 단위를 쓰는 cs 프로젝트 서버·수집 도구·다른 예약 작업의 사용량을 합칩니다. [공식 요금표](https://openapi.sk.com/products/calc?menuSeq=5&svcSeq=4)

| 확인할 항목 | 확인하는 곳·필요한 근거 | 현재 상태 |
|---|---|---|
| 무료 요금제·실제 한도·차감 단위 | 선택 앱 상품 관리·적용 상품 조건. 공개 표와 다르면 계정 적용값 우선 | 계정 미확인 |
| 누적 사용량·오류 통계 | 선택 앱 통계에서 사용 통계·에러 통계와 조회 기간 확인 | 공유 누적 미확인 |
| 갱신 시각·시간대·실패 차감 | 적용 상품 문서·계정 표시·공식 문의 답변으로 확정 | 미확인 |

통계 메뉴는 공식 앱 가이드에서 확인했습니다. 화면에 당일 수치가 보이더라도 지연·다른 도구의 누락이 있으면 안전한 공유 사용량 근거로 쓰지 않습니다. [공식 통계 확인 안내](https://openapi.sk.com/products/detail?menuSeq=126&svcSeq=60)

사용자 지시에 따라 확인된 일일 한도 `L`의 최소 20%를 남깁니다. 예약 작업 상한은 `floor(L×0.80)`이며 기존 비용·월 무료 상한이 더 엄격하면 그 값을 따릅니다. 예를 들어 실제 적용 한도가 1,000단위로 확인됐으면 전체 공유 사용량 800단위까지만 허용하고 200단위를 남깁니다. 6시간마다 예산을 새로 만들지 않습니다.

호출 직전에 공유 기록에서 이번 차감 단위를 원자적으로 확보하도록 설계해야 합니다. 동시 작업 둘이 같은 잔여량을 중복 사용하는 것을 막는 절차입니다. 실패·재시도·페이지 조회도 보수적으로 차감하고, 예약 전후 누적량·잔여량·갱신 시각·이번 호출 수를 비밀값 없이 기록합니다. 사용량·차감 단위·갱신 시각을 확정하지 못하거나 예산 확보가 실패하면 **0회 호출**을 유지합니다. 80%에 도달하면 다음 공식 일일 갱신까지 멈추며 다른 키로 우회하지 않습니다. 이 보호 장치는 아직 구현하지 않았습니다.

## 4. 응답 재사용 기간을 제한한 뒤 연결하세요

[TMAP 공개 약관](https://tmapapi.tmapmobility.com/terms.html)은 얻은 데이터를 저장한 뒤 24시간 이상 사용하는 것을 제한합니다. 약관 페이지 전체 80줄을 확인했습니다. 따라서 추후 응답에 수집 시각과 만료 시각을 붙이고, 만료 응답을 제품 계산·영구 골든셋 재생·추천에 다시 쓰지 않도록 차단해야 합니다. 비교가 필요하면 유효기간 안에서 수행하고, 만료 후에도 어떤 감사 메타데이터를 남길 수 있는지는 별도로 확인합니다. 이 문서는 API 응답을 수집하거나 저장하지 않았습니다.

연동 검증에서는 같은 출발·도착 좌표, 좌표계, 관측 시각, 추천 유형을 고정합니다. 공식 TMAP 보행자 옵션에는 추천(0), 추천+대로우선(4), 최단(10), 최단거리+계단제외(30)가 있습니다. 카카오 최단거리와 대조할 때 추천(0)을 무조건 같은 조건으로 취급하지 않습니다. [보행자 API 입력·옵션](https://tmap-skopenapi.readme.io/reference/%EB%B3%B4%ED%96%89%EC%9E%90-%EA%B2%BD%EB%A1%9C%EC%95%88%EB%82%B4)
