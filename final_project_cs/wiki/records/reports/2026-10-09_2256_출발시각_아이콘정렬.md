# 출발 시각·아이콘·이동 설명 정렬

출발 시각에는 시각만 표시하고, 원형 점을 시작선에서 오른쪽으로 나가는 화살표로 바꿨다. 시각·아이콘·이동 설명 첫 줄의 세로 중심을 맞췄다. 로컬 완료이며 공개 배포하지 않았다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 표시·정렬 수정 | 완료 | 2/2 = 100% |
| mock 서버 화면 시험 | 통과 | 19/19 = 100% |
| 두 너비 촬영 | 완료 | 4/4 = 100% |

[최신 화면](../../../frontend/apps/web/mockups/departure-alignment-2026-10-09-v1/index.html)은 375px/1280px 두 크기로, 출발 시각이 있는 경우와 시각 누락·떠 있는 일차·스크롤 상태를 보여 준다. 점선 양끝의 일정 끝·도착 시각은 별도로 유지했다. 출발 시각이 없으면 대시를 같은 위치에 놓으며 시각을 지어내지 않는다. 경로를 펼쳐도 설명 첫 줄에 맞춘다.

mock 서버 시험 **19/19 (화면 반응)**: 새 정렬/누락/스크롤 사례 4, 새 화살표 드래그 저장 1, 기존 시간 조작 5, 점선 양끝·지도·하단 여백·제출 동작 7, 기존 정렬/간격 2. 두 실행을 고유 시험 이름으로 합산했고 중복 실행을 늘려 세지 않았다. 알려진 시각·없는 시각·펼친 경로에서 세로 중심 차이 1px 미만을 확인했다. 출발 화살표의 실제 포인터 드래그가 끝 시각 수정 요청을 한 번 보내며 시작 시각은 보내지 않는 것도 확인했다. [실행 근거](../evidence/2026-10-09_departure-alignment/).

TypeScript·변경 파일 ESLint·Next 빌드 통과. 실서버 확인 **(서버 응답): 안 했음**. 실제 cs 프로젝트 서버 응답·공개 배포는 이번 확인에 포함하지 않았다.
