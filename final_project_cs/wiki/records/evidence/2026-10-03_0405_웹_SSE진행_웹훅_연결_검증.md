## 1. 타입·린트·단위

```bash
npx tsc --noEmit
npx eslint . --ignore-pattern ".next-demo/**" --ignore-pattern ".next-dev-live/**" --ignore-pattern ".next-mock/**" --ignore-pattern ".next-live/**"
npx vitest run
```

```text
tsc=0
eslint=0
 Test Files  21 passed (21)
      Tests  175 passed (175)
```

중간 실행에서 `stream.test.ts`의 1개가 시간 초과로 실패했다.

```text
× tells a stopped reading (`stalled`), a missing intake, a server without the stream and a silent line apart 5003ms
Error: Test timed out in 5000ms.
```

조용한 줄에서 연결 감시가 요청만 끊고 읽기를 끝내지 않았다. 읽기도 끝내게 고친 뒤 9/9 통과했다.

## 2. live 빌드 (테스트용 모방 서버, 실서버 아님)

```bash
PLAYWRIGHT_CHANNEL=chrome npx playwright test -c playwright.live.config.ts
```

모방 서버를 SSE 기본으로 바꾼 직후의 기존 시험:

```text
  1) tests\live\flow.spec.ts:94:1 › 알림·복구 카드의 디스코드 웹훅은 등록까지 가도 서버로 보내지 않고 … — 저장 연결은 백엔드 몫
  1 failed
  64 passed (2.0m)
```

이 시험은 바꾸기로 한 옛 동작을 보는 시험이라 새 동작으로 다시 썼다. 새 시험 첫 실행에서는 웹훅 저장 요청이 두 번 나갔다.

```text
    + Received  + 6
    +   Array [
    +     "acop_u_stub_1",
    +     Object { "discord_webhook_url": "https://discord.com/api/webhooks/<아이디>/<토큰>" },
```

키 발급 신호 두 번이 같은 요청을 함께 기다리게 고쳤다. 같은 화면에서 마지막으로 보낸 값은 다시 보내지 않게도 고쳤다.

전체:

```text
  77 passed (2.6m)
```

카드 안내 문장을 모드별로 고친 뒤 다시 실행했다:

```text
  77 passed (2.6m)
```

## 4. 로컬 실서버

| 항목 | 내용 |
|---|---|
| 서버 | API 8042(작업 트리 `.env`, DB `acop_cs_manager`, 팀 알림 웹훅 설정 비어 있음), live 웹 3100(`NEXT_DIST_DIR=.next-dev-live`, OSM) |
| 조작 | 자유 문장 계획 올리기 → 「읽은 일정이 없어요 — 대신 짜 드릴까요?」 → 첫날 2026-10-20 · 1일 · 2명 → 「이 조건으로 짜서 등록」 → 여행 화면 → 채팅 「하루 요약」 → 마이페이지 웹훅 등록 → 지우기 |

일정 짜기 중 화면의 상태 줄(차례로 읽은 값):

```text
일정을 짜는 중이에요…
일정을 짜는 중이에요… (3초)
일정을 짜는 중이에요 · 응답이 느려요 (9초째)
→ /trips/82c86fb8-…  (등록 완료)
```

채팅:

```text
요청을 이해하는 중이에요…
요청을 이해하는 중이에요… (3초)
→ 답: 「10월 20일(화) 일정은 5곳이에요. · 08:00~09:00 [백년가게] 선천집(식사) …」
```

접수 읽기 스트림:
- 짧은 글 두 번은 첫 조회 때 이미 읽기가 끝나 있어 화면이 스트림을 열지 않았다(의도한 동작).
- 같은 요청을 브라우저에서 직접 보내 형식을 확인했다:

```text
200 text/event-stream; charset=utf-8
event: accepted
data: {"op": "intake", "state": {"status": "review", "stage": "review", "stage_label": "확인해 주세요", "revision": 1, …}, "at": "…"}

event: result
data: {"state": {"status": "review", …}}
```

웹훅(형식만 맞는 가짜 주소):

```text
저장 뒤 마이페이지: https://discord.com/api/webhooks/<앞 4자리>…/•••• · 아직 시험 메시지를 보내지 않았어요. · [시험 메시지 보내기]
브라우저 저장소에 토큰: false · 페이지 글에 토큰: false
지우기 뒤: 등록된 웹훅이 없어요.
```

API 서버 기록(사전 확인 `OPTIONS` 제외):

```text
"POST /v1/web/trip-intakes/{id}/plan HTTP/1.1" 200 OK
"POST /v1/web/trips/{id}/messages HTTP/1.1" 200 OK
"PUT /v1/web/profile HTTP/1.1" 200 OK
"PUT /v1/web/profile HTTP/1.1" 200 OK
```

- 「시험 메시지 보내기」는 누르지 않았다(디스코드로 바깥 요청이 나간다).
- 처음 쓰던 개발 서버(몇 시간째 켜져 있던 3100)는 내부 작업자가 죽어 `/intakes/…`가 리다이렉트 반복으로 열리지 않았다. 내리고 다른 빌드 폴더로 다시 띄웠다.
- 그때 Next.js가 `tsconfig.json`에 타입 경로를 자동으로 더했다. 이 변경은 되돌렸다.
