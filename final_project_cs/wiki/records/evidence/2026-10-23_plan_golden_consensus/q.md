# 질문: 「사람이 쓴 지저분한 여행 계획서 글 → 구조화 일정」 골든셋(사람 정답 시험 세트)을 어떻게 만들지

파일을 만들거나 고치지 마라. 명령은 읽기만. 이 파일 밖의 저장소를 읽지 마라. 한 번에 답하라. 사실표와 어긋나는 주장은 근거를 대라. 모르는 것은 모른다고 적어라.

## 정할 것 (한 문장)
고객이 자유롭게 쓴 여행 계획 글을 구조화 일정(일차·순서·시각·장소·종류)으로 바꾸는 모델의 **골든셋(학습에 쓰지 않는 사람 정답 시험 세트)** 을 아래 선택지 중 무엇으로 만들지, 그리고 그 설계를 구체화하라.

## 배경
- 제품: 고객이 질의(짧은 채팅) · 계획서(긴 자유 글) · 감시 루프(재난문자·공지) 어느 입구로 들어와도 한 모델이 같은 규약으로 처리한다(설계 D-026). 이 질문은 **계획서 입구**의 골든셋만 다룬다.
- 목표: 학습한 모델이 실제 사람 글에서 일정을 얼마나 잘 뽑는지, 원문에 없는 장소·시각을 지어내지 않는지 사람 정답으로 잰다.

## 선택지
- A: 실제 글 150~200개를 사람이 글 단위로 정답 확정(그중 50개는 AI 초안을 보여 주지 않는 블라인드), 2인 독립 + 불일치 제3자 판정.
- B: 실제 글 60~80개, 전부 블라인드 2인 독립(소규모 정밀).
- C: 기존 검수 화면의 항목 단위 정답(958개 중 101개 완료, 모두 AI 초안 확인 방식)을 끝까지 이어 가고 블라인드는 소량(20~30글).
- D: 2단계 — 먼저 약 60개로 블라인드/비블라인드를 나눠 앵커링 크기와 AI 초안 정확도를 잰 뒤, 결과를 보고 확대 여부를 정함.
- OTHER: 더 나은 안을 제안하라(id=OTHER, 설명).

## 확인된 사실표 (모두 저장소 파일에서 직접 확인, 2026-10-23)
- F1 학습 자료(실제 학습에 쓴 판 18,478행)의 계획서 입구 몫: 자유 글 일정 추출 215행(합성 카페 말투 글, 정답이 정확하도록 글을 정답에서 만든 것) + 기관 구조 정규화 664행. 합쳐서 879/18,478 = 4.8%. 모든 학습 라벨은 AI·합성·프로그램 생성이고 사람 확인 행은 학습에 없다(사람 확인은 평가에만 보존).
- F2 평가: 계획서 입구 평가는 합성 글 개발 25 · 테스트 60뿐이다. 실제 사람 글에 대한 정답 평가는 0개다.
- F3 원료: 실제 글 약 12만 건 수집(미라벨). 서울 + 일정 모양으로 자동 표시된 사람 글(Reddit + 블로그) 1,382 + 1,081 = 2,463개(규칙 표시, 사람 확인 아님). 그중 시각이 3개 이상 적힌 글 71 + 185 = 256. 일정 모양이 강한 글 171 + 235 = 406. 기관 코스 자료는 글을 구조에서 만든 것이라 추출 입력으로 쓰지 않는다는 규칙이 있다.
- F4 사람 확인 현황: 계획서 항목 958개(원문 192건) 중 101개를 검수자 1명(최연우)이 확인. 방식은 「AI 두 초안(Claude 초안·Codex 초안)을 보여 주고 고르거나 고침」(confirm_ai_shown). 항목 필드는 종류(식사/활동 등)·장소·범위(단일 장소/불특정 등). 글 단위 정답(일차·순서·시각)은 포함되지 않는다.
- F5 실제 글 196건은 Claude 초안만 있고 사람 확인 전이다(학습·평가 사용 금지로 보관). 정답 지침 GUIDE.md: 글 종류(계획·후기·섞임·일정 아님), 여행 일수, 서울 범위, 날마다 항목(순서·시각·장소·할 일·시각 근거), **원문에 없는 시각·장소는 쓰지 않는다**. 초안 196건의 글 종류: 계획 87 · 후기 75 · 섞임 2 · 일정 아님 32. 초안 작성자가 Claude라서 Claude 계열 모델 평가에는 출제자 편향이 있다.
- F6 규칙 기반 자동 추출을 Claude 초안과 맞대 보니 장소 겹침 평균 0.23(규칙은 정답 대용이 못 됨). 「일정 모양」 자동 판정은 초안과 171/196 = 87% 같음.
- F7 모든 사람 정답(772 + 55 + 101행)은 AI 답을 본 뒤 단일 검토자가 확인한 방식이다. 블라인드 일치도 근거는 없다.
- F8 이용 조건: 블로그·Reddit 원문은 개인 열람·내부 실험 한정(사용자 지시). 사이트 robots 가 AI 학습을 금지하거나 계약을 요구한다고 기록돼 있어 제품 투입·상업 전 폐기·재확인이 필요한 자료다.
- F9 일정: 최종발표 2026-10-26(3일 뒤). 검수자 확인된 인원은 1명. 추가 인력 가능 여부는 알 수 없다.

## 확인 못 한 것
- 기존 검수 화면(항목 단위)이 글 단위 정답(일차·순서·시각)을 받도록 확장되는지.
- 사람이 라벨에 쓸 수 있는 총 시간, 검수자 추가 가능성.
- 서울 일정형 2,463개 중 실제로 「계획」인 글의 비율(규칙 표시일 뿐).
- AI 초안(Claude·Codex)의 실제 정확도, 사람이 AI 답에 끌리는 정도(앵커링 크기).

## 제약
- 유료 모델 API 신규 호출 금지(보조 Codex 계정 사용은 사용자 승인됨). 평가 대상 모델(학습한 Gemma-4-E4B QAT · Winnow-E4B)과 같은 계열 모델을 라벨러로 쓰지 않는다.
- 골든셋은 학습에 쓰지 않는다. 같은 작성자·스레드의 글이 학습과 골든셋에 함께 들어가지 않게 한다.
- 원문에 없는 값을 지어내지 않는 것이 제품 규칙(되묻기·「확인 못 함」 허용).
