## 가짜 서버 live 브라우저

```powershell
$env:CI='1'
$env:PLAYWRIGHT_CHANNEL='chrome'
npm.cmd run test:live
```

첫 실행: **36/44 = 81.8%** 통과, 신규 검사 **8/44 = 18.2%** 실패. 기존 시나리오는 **36/36 = 100%** 통과했다. 실패 원인은 다음과 같았으며 시험 코드만 보정했다.

- 가상 시계를 완전히 멈추자 네트워크 응답 이후 Query의 비동기 화면 알림도 멈춤: 시계는 실행 상태로 두고 `fastForward`로 경과 시간만 이동.
- 채팅의 `role=alert` 선택자가 Next.js 경로 안내 요소까지 포함: `main` 안의 오류 요소로 한정.
- 초기화 중 언어별 조회가 발생할 수 있는데 첫 화면의 여행 GET 횟수를 항상 2회로 가정: 새 일정이 즉시 표시되는지와 재조회 발생을 검사.

수정 후 다음 명령으로 신규 시나리오를 재실행했다(종료 코드 0).
