# 계획 확인 화면 목업 전체 구현 검증 근거

| 항목 | 내용 |
|---|---|
| 실행 | 2026-10-03 · Claude |
| 기준 | `feat/web-manager-integration` `d1ce5da` 위 로컬 변경(SSE·웹훅 변경 포함) |
| 환경 | Windows 11 / Node.js 22 / 설치된 Chrome |
| 리포트 | [계획 확인 화면 — 목업 시나리오 1~7 전체 구현](../reports/2026-10-03_0501_계획확인화면_목업전체구현.md) |

출력은 발췌다. 아래 1~3은 마지막 전체 실행 한 번(단위 → demo 빌드 → demo 전체 → live 전체)의 출력이다.

## 1. 타입·린트·단위

```bash
npx tsc --noEmit
npx eslint . --ignore-pattern ".next-demo/**" --ignore-pattern ".next-dev-live/**" --ignore-pattern ".next-mock/**" --ignore-pattern ".next-live/**"
npx vitest run
```

```text
tsc=0
eslint=0
 Test Files  22 passed (22)
      Tests  185 passed (185)
```

## 2. demo 빌드·브라우저

```bash
NEXT_PUBLIC_DATA_MODE=demo NEXT_PUBLIC_MAP_PROVIDER=demo NEXT_PUBLIC_TURNSTILE_SITE_KEY= npx next build
PLAYWRIGHT_CHANNEL=chrome npx playwright test
```

```text
├ ○ /preview/plan-check
…
build exit=0

[80/80] tests\e2e\verification.spec.ts:97:1 › 결과 화면에서 언어를 바꾸면 같은 결과가 영어로 다시 표시된다
  3 skipped
  77 passed (3.1m)
demo exit=0
```

건너뜀 3개는 네이버 지도 SDK 전용 시험이다.

작업 중간 실행에서 `plan-check.spec.ts`가 실패한 원인과 처리(출력은 남기지 않았다):

| 실패 | 원인 | 처리 |
|---|---|---|
| 핀을 누르지 못함(다른 요소가 클릭을 가로챔) | 지도가 화면 맨 위부터 그려져 떠 있는 위 막대가 핀을 덮음 | 지도를 막대 아래(60px)에서 시작 |
| 꺼진 단추를 누르지 못함 | Playwright가 `aria-disabled` 단추를 누르지 않음 | 이유 알림을 보는 시험만 `click({ force: true })` |
| 자동 추천 뒤 개수 기대값 | 장소가 바뀌면 앞뒤 이동을 다시 재므로 「이동 1구간 확인 필요」가 남음(목업과 같음) | 기대값을 고침 |
| 시트를 전체로 올린 뒤 핀 누르기 | 시트가 지도를 덮은 상태에서 핀을 누름 | 시험 순서를 바꿈 |
| 판정 개수 | 처음 구현이 `warn`도 확인 필요로 셈 | 목업 규칙(`bad`만)으로 고침 — 화면 쪽 수정 |

## 3. live 빌드 (테스트용 모방 서버, 실서버 아님)

```bash
PLAYWRIGHT_CHANNEL=chrome npx playwright test -c playwright.live.config.ts
```

```text
Running 77 tests using 1 worker

  77 passed (2.7m)
live exit=0
```

결과 화면 시험 6개는 새 화면에 맞춰 다시 썼다(리포트 §5).

## 4. 로컬 실서버

| 항목 | 내용 |
|---|---|
| 서버 | API 8042(작업 트리 `.env`, DB `acop_cs_manager`), live 웹 3100(`NEXT_DIST_DIR=.next-dev-live`, OSM) |
| 조작 | 실제 접수 `/intakes/{id}` 열기 → 결과 화면 → 카드 「수정」 → 위 검색창에 「통인시장」 |

확인한 것:

- 지도가 칸을 채우고 위 막대가 떠 있으며 시트가 지도 위에 있다.
- 수정 화면 머리 「○○ 바꾸기」와 지금 일정 카드가 보인다.
- 검색창에 쓰면 「장소 검색은 준비 중이에요.」와 「「통인시장」으로 바꾸기」가 보인다.

「「통인시장」으로 바꾸기」는 누르지 않았다. 실서버 접수의 내용이 바뀐다. 이 단추가 보내는 본문(`items[0].place {name}`)은 3의 모방 서버 시험이 확인한다.
