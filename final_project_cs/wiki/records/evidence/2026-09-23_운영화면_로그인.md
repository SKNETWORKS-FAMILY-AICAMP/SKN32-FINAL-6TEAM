# 운영 화면(`/ui/*`) 로그인 — 실측 (2026-09-23)

결정 [D-CS-007](../../decisions/D-CS-007-ui-operator-login.md).

## 고치기 전에 본 것

- 승인·바깥함 해소 처리부가 `_development_key("action:approve", secret_key)` 로 **키를 스스로 만들어**
  API 를 불렀다(`app/presentation/ui/routes.py`). 위임은 `delegation:write` 를 같은 방식으로.
- 승인자·처리자는 `"ui-operator"` 로 고정이었다.
- 관문을 붙이자 **화면을 보던 기존 시험 21건이 로그인 화면으로 보내져 실패했다** — 그동안 이 시험들이
  인증 없이 화면·버튼을 쓰고 있었다는 뜻이다. 21건 모두 실제 로그인 경로(`POST /ui/login`)로 들어가게 고쳤다
  (쿠키를 손으로 만들지 않는다 — 그러면 로그인 경로가 깨져도 초록이다).

## ★작업 중 드러난 결함 둘

| | 무엇 | 고침 |
|---|---|---|
| 1 | 앱의 `HTTPException` 처리기가 **예외의 헤더를 버렸다**(`app/presentation/api/app.py`). 관문의 303 에 `Location` 이 빠져 브라우저가 로그인 화면으로 못 갔다 | 헤더를 그대로 싣는다. `WWW-Authenticate` 같은 다른 헤더도 이제 나간다 |
| 2 | 관문을 **동기** 함수로 썼더니 스레드풀에서 돌아, 거기서 정한 「지금 운영자」가 요청 처리로 **돌아오지 않았다** — 화면 머리에 운영자 이름이 안 나왔다 | 관문을 `async` 로 |

## 막히는가 — `tests/integration/api/test_ui_login.py` (24건)

| 보는 것 | 결과 |
|---|---|
| 로그인 안 하고 화면 7곳(`/ui/cases`·`approvals`·`delegations`·`admin`·`scenario`·`/ops/outbox`·`/ui/ops/outbox`) | 전부 **303 → `/ui/login?next=…`** |
| ★로그인 안 하고 승인 POST | 303, **`action_approvals` 0행** — 전에는 이 요청 하나로 승인이 났다 |
| 계정이 하나도 없을 때 | 로그인 화면이 「닫혀 있다」, 로그인 401 |
| 로그인하고 승인 | `action_approvals` 에 **`op-kim`** 으로 남는다(전에는 `ui-operator`) |
| scope 없는 운영자의 승인 | 보기는 되고(200), 누르면 **403 + 「아무것도 바뀌지 않았습니다」**, 0행 |
| 틀린 비밀번호 · 없는 id | 둘 다 401, **같은 문장** |
| 5회 틀린 뒤 맞는 비밀번호 | **429**, 쿠키 없음 |
| scope 를 손으로 늘린 쿠키 · 만료 쿠키 | 거절 |
| 계정에서 scope 를 빼거나 계정을 지운 뒤 옛 쿠키 | **다음 요청부터** 줄거나 무효 |
| 쿠키 속성 | `HttpOnly` · `SameSite=Strict` |
| `next=https://evil.example/ui` · `//evil…` · `/tripilot` · 빈 값 | 전부 `/ui/cases` 로 |
| 운영자 설정이 깨졌을 때 | 로그인 화면이 「설정이 잘못됐습니다」라고 말한다(「계정 없음」으로 숨기지 않는다) |

위임 화면(`test_ui_delegation_screen.py`)에 둘을 더했다 — `delegation:write` 없는 운영자는 **403 + 위임 0행**,
폼에 `actor_id=someone-else` 를 적어도 기록은 **로그인한 운영자(`op-1`)**.

## 쓰는 법

    python -m scripts.ui_operator --id <운영자 id>                 # 비밀번호를 두 번 입력
    python -m scripts.ui_operator --id <id> --scopes case:read     # 보기만 하는 계정

출력된 `ACOP_UI_OPERATORS=…` 한 줄을 `.env` 에 넣고 앱을 다시 띄운다. **계정이 없으면 운영 화면이 닫힌다.**

## 아직 막지 않는 것

`/scenario/*`(시연 경로 — `/ui` 밖) · CSRF 토큰 없음(`SameSite=Strict` 에 기댐) · 잠금이 프로세스 안 ·
로컬 http 라 `Secure` 없음. 자세한 것은 결정 문서 §「이 결정이 막지 않는 것」.
