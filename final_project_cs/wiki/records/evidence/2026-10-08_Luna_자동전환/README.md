# Luna 자동 전환 실측

운영 cs 프로젝트 서버에서 Ollama 연결 실패를 실제로 거친 JSON·채팅 질문 해석·문장 응답 3/3건이 API 경로로 성공했다. 시험용 여행 문장을 사용했고 고객 채팅·일정·Case는 생성하거나 바꾸지 않았다. 호출 상한 계수는 정상 호출 절차대로 반영했다.

서버용 키의 정확한 일치를 값 대신 내부 해시 비교로 확인했다. 이 파일에는 키·해시·접속 주소를 넣지 않았다. 모델 경로의 상세 주소는 저장 전에 제거했다.

- mock 서버 시험 57/57 (응답 모양·장애 전환·호출 상한·마스킹)
- 보안 시험 12/12. 저장소 루트 추적 텍스트 3,685개 검사 결과 인프라 누출 파일 0개. 바이너리·이미지와 옛 이력은 이 검사의 범위 밖이다.
- 실서버 확인 (서버 응답): 했음. 별도 서버용 API 키로 직접 연결 1/1, 실제 자동 전환 3/3. 브라우저에서 고객 메시지 제출은 하지 않았다.
- 운영 컨테이너 5/5 실행 중, 건강 검사 적용 대상 4/4 정상, 상시 일꾼은 건강 검사 비적용.

실측 세부는 [live-results.json](live-results.json)에 있다. 3건 응답 시간은 단회 실측으로 성능 보장이 아니다.
