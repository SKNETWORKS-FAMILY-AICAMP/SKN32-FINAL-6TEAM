# 보존 좌표의 도로 선택을 다시 계산하는 방법

같은 그래프 자료와 현재 코드를 사용해 두 좌표 조건을 각각 세 번 다시 계산했습니다. 기존 관측과 6/6회 일치했습니다. 추가 웹 표본이나 독립 검증으로 세지 않습니다.

워크스페이스 루트에서 다음 명령을 실행합니다. `.tmp/`에 새 이름으로 결과를 보존하며 기존 결과를 덮지 않습니다.

```powershell
$replayOutput = '.tmp/mobility-road-selection-' + (Get-Date -Format yyyyMMdd_HHmmss_ffff) + '.json'
python final_project_cs/wiki/records/evidence/2026-10-09_0336_회전자료없는_선택도로_거리/reproduce-road-selection-v1.py --output $replayOutput
```

현재 로컬 그래프 자료가 필요합니다. 데이터 파일은 저장소 밖 자료 폴더에서 읽으며, 코드·자료가 바뀌면 결과도 달라질 수 있습니다. [원래 계산](legacy-snap-real-probe-v1.json)과 [코드·자료 해시](verification-proof-v1.json)를 기준으로 비교합니다.

완료하면 `calls: 6`과 교대로 나타나는 출발 거리 `8.8m / 10.9m`가 출력됩니다. 이는 정적 경로 모델 계산이며 실제 차량 진입·탑승·결제 확인을 대신하지 않습니다. 지도 API 호출은 없습니다.

이 재현 도구는 이전 임시 작업 파일에 의존하지 않고 옆에 보존된 좌표 관측을 읽습니다. [재실행 결과와 검증](reproduction-proof-v1.json).
