## 1. 타입·린트·단위

```bash
npx tsc --noEmit
npx eslint . --ignore-pattern ".next-demo/**" --ignore-pattern ".next-dev-live/**" --ignore-pattern ".next-mock/**" --ignore-pattern ".next-live/**"
npx vitest run
```

```text
tsc exit=0
eslint exit=0

      Tests  158 passed (158)
```

중간 실행에서 단위 1개가 실패했다.

```text
× does not flag what the server only assumed (a year or a day it filled), nor what the customer set
```

이번 변경(고객이 고친 일정 = 조정)에 맞춰 기대값을 고쳤다.

## 4. 로컬 실서버 — 수정·삭제

| 항목 | 내용 |
|---|---|
| 서버 | API 8042(작업 트리 `.env`의 DB `acop_cs_manager`), live 웹 3100(OSM) |
| 대상 | 앞 단계에서 올린 시험 접수 |
| 조작 1 | 「광장시장 수정」 → 장소 이름 「창덕궁」 → 저장 |
| 조작 2 | 「북촌한옥마을 산책 삭제」 → 확인창 「삭제」 |

조작 1 뒤 그 카드의 글(줄을 「 | 」로 이음):

```text
광장시장 | 조정 | ✓ | 장소 | 창덕궁과 후원 [유네스코 세계유산] | 통과 | ✎ | 시간 | 끝 시각이 없어 60분으로 두었다 | 채움 | 자동 추천 | 준비 중 | 수정
```

- 수정 화면은 닫혔고 알림은 「저장했어요. 서버가 일정을 다시 확인했어요.」였다.

조작 2 뒤:

```text
{ "cards": ["경복궁 관람 조정", "광장시장 조정"], "count": "모두 확인했어요", "dialog": false, "register": false(꺼짐 아님), "toast": "「북촌한옥마을 산책」 일정을 삭제했어요." }
```

API 서버 로그(이 접수, 사전 확인 `OPTIONS` 제외):

```text
"POST /v1/web/trip-intakes/{id}/edits HTTP/1.1" 200 OK
"POST /v1/web/trip-intakes/{id}/edits HTTP/1.1" 200 OK
```

여행 등록은 누르지 않았다.
