# 이동 기록·지도 문서 점검 증거

최근 이동 조사 보고서 5개와 그 링크·원자료 일부를 확인했다. 저장소 전체 기록의 정합성이나 배포 화면 검증이 아니다.

## 실행 조건과 재현

- 날짜: 2026-10-08 한국 시각. 로컬 작업 트리 기준이며 다른 세션의 미커밋 변경도 있는 상태다.
- 읽기 전용 점검: [실행 스크립트](assets/2026-10-08_1012_records_map_audit/check.py), [실제 결과·파일 해시](assets/2026-10-08_1012_records_map_audit/result.json).
- 외부 길찾기 API·지도 표시 SDK 호출을 추가하지 않았다. 공식 문서 웹 조회만 수행했다.

재현 명령(저장소에서 실행):

```powershell
python wiki/records/evidence/assets/2026-10-08_1012_records_map_audit/check.py
```

실행 스크립트는 기존 결과를 덮어쓰지 않는다. 재실행 시 이 증거 폴더를 새 이름으로 복사한 뒤 복사본의 `check.py`를 실행한다. `result.json`이 이미 있으면 먼저 실패하므로, 새 사본에서 기존 결과를 별도 백업한 후 실행한다.

첫 실행 출력 원문:

```json
{"reports": 5, "wiki_links": 5, "timestamp_names": 2, "local_links_checked": 29, "broken_links": 0, "raw_files_exist": {"compare_resume_200_v5.json": true, "taxi_time_aligned_v1.json": true, "taxi_budget_calibration_v1.json": true, "taxi_time_aligned_v2.json": true}, "source_files_hashed": 8}
```

보고서 내부 파일 링크가 없는 부분의 원자료는 위의 네 파일 존재 확인으로 보완했다. 모든 원자료 내용·스크린샷·시험 결과를 이번에 다시 재현한 것은 아니다. 독립 증거 Markdown에 직접 연결된 보고서는 2개이며, 나머지는 본문 시험 기록 또는 집계·해시 JSON에 근거가 분산돼 있다.

## 문서 정정 후 확인

수정한 지도 연동 문서와 새 보고서·증거 문서의 로컬 링크를 정규식으로 추출하고 파일 존재를 확인했다. 최초 점검에서 저장한 SHA256과 기존 보고서 5개·제품 소스 8개를 다시 대조했다. 지도 문서에서 오래된 기본값·경로선 미구현 설명이 제거됐는지 문자열 검사했다. [실제 후속 출력](assets/2026-10-08_1012_records_map_audit/post-check.json)은 다음과 같다.

```json
{"new_and_updated_document_links_checked": 21, "broken_links": [], "original_reports_and_product_source_unchanged": "13/13", "outdated_default_and_no_route_statements_removed": true}
```

기존 보고서와 제품 소스는 13/13 = 100% 동일했다. 이 결과는 그 시점의 정정 문서·새 기록 링크 21개에 대한 존재 확인이며, 이후 이 결과 링크를 추가한 편집은 별도 링크 존재 확인을 했다. 결과를 추가하기 전의 증거 문서는 [백업](../evidence/_backup/2026-10-08_1012_점검결과추가전/)에 보존했다.
