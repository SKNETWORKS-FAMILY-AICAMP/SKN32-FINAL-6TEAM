## 0. 무엇을 메운 것인가

`[실측 2026-09-22 오전]` 같은 날 만든 위임 범위 게이트(`delegation.py` · 마이그레이션 019)에는
**주고 거두는 경로가 없었다.** 근거로 남은 두 문서가 그렇게 적고 있었다 —
[`DoD-v11-18-21_위임범위와_되돌림.md`](DoD-v11-18-21_위임범위와_되돌림.md) §6,
[`wiki/teams/booking-handoff.md`](../../teams/booking-handoff.md) 「걸리는 것」.

> 위임을 주고 거두는 화면·API 가 없다. 지금은 `delegation.grant()`·`revoke()` 모듈 함수뿐이다.

★**이것은 기능 누락 이상이다.** DoD-19 가 재는 것이 「위임을 **철회**하면 진행 중인 자동
실행이 멈춘다」인데, **철회할 방법이 사람 손에 없으면** 그 성질은 시험 안에서만 참이다.
제품이 약속하는 「언제든 철회할 수 있다」가 말뿐인 상태였다.

## 4. 화면을 **실제로 열어** 본 것

`acop-cs-ui-stable`(포트 8043, `--reload` 없음)로 띄우고 브라우저로 직접 눌렀다.
tenant `demo`, customer `edeb5e4a-…`(seed 의 `cust_01`).

| 무엇을 눌렀나 | 본 것 |
|---|---|
| `/ui/delegations` 열기 | `200`. 살아 있는 위임 0 · 맡기는 범위 6줄(건당 50,000원 · 누적 150,000원 · `activity · dining` · 2회 · 72시간 · 24시간) · 「위임 기록이 없습니다」 |
| 맡기기 → **확인 화면으로** | 확인 화면. 「지금 상태 기록 없음 · 이미 나간 금액 0원 · 남은 여유 150,000원」 + 열리는 범위 + 지금까지의 기록. **이 시점에 DB 는 안 바뀌었다**(행 0) |
| **확인 — 맡긴다** | `303` → 목록. 행이 `살아 있음`, 준 사람 `op-brow` |
| **거두기**(근거 입력) | `303` → 목록. 행이 `거둠`, 거둔 사람 `op-brow2`, 살아 있는 위임 0, 버튼이 `다시 주기` 로 바뀜 |
| **다시 주기** | 확인 화면에 **주고 거둔 기록 두 줄**이 그대로 보였다 — `revoked · op-brow2` / `granted · op-brow`. ★019 만 있었다면 이 두 줄이 없다 |
| 없는 고객 id 로 맡기기 | **실패 화면** — 「이 고객을 확인하지 못했습니다 / HTTP 404 / `{"error":{"code":"not_found",…}}`」 + 목록으로 돌아가는 링크 |

서버 로그(`preview_logs`)에 5xx·예외 **0건**. 확인한 요청은 `GET /ui/delegations 200`,
`POST /ui/delegations 303`(적용) · `200`(확인 화면·실패 화면)뿐이다.

### ★브라우저로 열어 보고 **결함 하나를 찾아 고쳤다**

시험은 전부 초록인데 화면이 읽히지 않았다 — 폼 입력이 표를 넓혀 **「근거」 칸이 한 줄에 한
글자씩**(`브/라/우/저/재/검/증`) 접혔고, 시각은 마이크로초까지 나와 세 줄로 접혔다.
운영자가 읽으라고 만든 칸이 읽히지 않으면 없는 것과 같다. `td.deleg-note` 최소 너비와
`white-space:nowrap`, 시각은 분까지만 보이고 **원값은 `title` 에** 남기도록 고쳤다
(`app/presentation/ui/routes.py` `_DELEG_CSS`·`_when`).

★**이것은 `200` 만 봐서는 못 찾는다.** 이 저장소가 승인 화면에서 배운 것과 같은 형태다.

### 남긴 상태

브라우저 시험으로 `demo` 테넌트에 만든 위임 1행·이력 2행은 **지우고 원래대로 돌렸다**
(`delegations` 0행 · `delegation_events` 0행 — 시작 시점과 같다).

## 5. 이 근거가 **말하지 않는 것** · 남은 구멍

- ★★**`/ui/*` 에는 로그인이 없다.** 이 앱의 운영 화면 전체가 그렇고 승인 화면도 같다.
  위임을 주는 버튼이 그 위에 올라갔으므로 **승인 버튼과 같은 크기의 구멍**이다. 이번 작업이
  만든 구멍은 아니지만 **넓힌 것은 맞다**. API 쪽은 scope 로 막힌다(`delegation:write`).
- **DoD-18(범위 밖 자동 실행 0건)을 다시 재지 않았다.** 이 작업은 위임을 **주고 거두는
  자리**를 만든 것이고, 판정 자체는 오전 작업 그대로다.
  `python -m scripts.measure_delegation_scope` 는 다시 돌리지 않았다.
- **거둔 뒤 자동 실행이 막히는지**는 판정기(`delegation.judge`)를 실제 예약 행에 대고 직접
  불러 확인했다(`test_revoking_closes_the_gate`). **Case 를 끝까지 흘려** 공급자 원장을
  조회하는 방식(오전의 측정 스크립트)으로는 다시 재지 않았다 — 그 경로는 판정기를 부르는
  쪽이 안 바뀌었다.
- 위임은 여전히 **고객 단위**다(Trip 단위 아님). 화면도 고객 단위로 보인다.
- 한계 값(`travel.delegation`)은 **여전히 우리가 고른 값**이다. 화면이 그 값을 보여 준다고
  해서 값이 옳다는 근거가 되지는 않는다.
