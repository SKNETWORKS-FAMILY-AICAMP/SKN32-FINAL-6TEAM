```bash

npx eslint . --ignore-pattern ".next-demo/**" --ignore-pattern ".next-dev-live/**" --ignore-pattern ".next-mock/**" --ignore-pattern ".next-live/**"
npx vitest run
```


```bash

PLAYWRIGHT_CHANNEL=chrome npx playwright test tests/e2e/menu.spec.ts
```


## 3. live 빌드 전체 (테스트용 모방 서버, 실서버 아님)

```bash
PLAYWRIGHT_CHANNEL=chrome npx playwright test -c playwright.live.config.ts
```

```text
  1) tests\live\flow.spec.ts:119:1 › 설문을 마친 뒤 새로고침해도 답이 남아, …
    Error: browserContext.close: ENOENT: no such file or directory, open '…\test-results\.playwright-artifacts-0\traces\…-recording25.trace'
  2) tests\live\flow.spec.ts:148:1 › 일정을 못 읽으면 일정 짜기 칸이 나오고, …
    Error: browserContext.close: ENOENT: no such file or directory, open '…\test-results\.playwright-artifacts-1\traces\…-recording4.trace'
  2 failed
  63 passed (2.0m)
```

live 전체가 도는 중에 위 2절의 `profile.spec.ts`를 따로 실행했고, 그 실행이 같은 `test-results` 폴더를 비웠다. 두 실패는 그 때문에 기록 파일이 없어진 것이다. 두 시험만 다시 실행했다:

```bash
PLAYWRIGHT_CHANNEL=chrome npx playwright test -c playwright.live.config.ts tests/live/flow.spec.ts:119 tests/live/flow.spec.ts:148
```

```text
  2 passed (21.2s)
```

## 4. 브라우저 눈 확인 (로컬 live 개발 서버 3100, 375×812)

| 확인 | 결과 |
|---|---|
| 메뉴 → 「화이트」 | `document.documentElement.dataset.theme` = `neutral`, `body` 바탕 `rgb(242, 242, 239)`, 프로필 이미지 바탕 `rgb(236, 236, 234)` |
| 새로고침 | 받은 HTML의 `<head>`에 테마 스크립트가 있고(`<html … data-theme="green">` 뒤 화이트로 바뀜), 화면은 화이트로 열림 |
| 홈 `/`·온보딩 `/start` | 화이트에서 풍경 그림 없이 바탕색만 보임. 그린에서는 온보딩 풍경 그림(`paper` 층 `opacity 1`)이 예전처럼 보임 |
| 계획 확인 미리보기 → 결과 → 1번 핀 선택 | 선택한 핀 `rgb(36, 87, 214)` 바탕·흰 글자, 다른 핀은 선택색 아님 |
