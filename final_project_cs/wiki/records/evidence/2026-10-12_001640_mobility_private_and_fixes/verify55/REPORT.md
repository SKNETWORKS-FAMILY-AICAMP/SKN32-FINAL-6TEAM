# 이전 이동 회귀의 오프라인 초기화 복구

확대 검증에서 실패한 두 시험은 실제 계산 비교에 도달하기 전 외부 라우터 상태 조회가 차단돼 실패했습니다. 시험 초기화에 오프라인 로컬 도로망과 실시간 키 비활성을 명시했습니다.

| 할 일 | 상태 | 진행 |
|---|---|---|
| 초기화 원인 확인·수정 | 완료 | 1/1 = 100% |
| 기존 실패 두 조건 | 통과 | 2/2 = 100% |
| 같은 파일 전체 회귀 | 실행 결과 | 11/11 = 100% |

원래 build_verifier(quiet=True)는 환경 설정의 GraphHopper /info를 조회했습니다. 네트워크 금지 검증에서 socket 연결 차단에 걸려 p90·동명이역 불변식을 검사하기 전에 실패했습니다. gh_url="", seoul_key="", local_router=True를 명시해 보유 자료만 사용합니다. 이는 제품 라우터 동작 변경이 아니라 시험의 자료·환경 고정입니다.

p90≥평균 ETA와 p90≤최악 ETA, 도보 포함 p90 후보 존재, 양평 동명이역 사이 환승 금지, 실제 이촌 환승 보존, 노선별 물리적 역·출구·동명이역 구간의 기존 기대는 수정하지 않았습니다. 통과만 위해 값을 낮추거나 기대를 삭제하지 않았습니다.

수정 전 두 실패는 부모 확대 실행의 원본 로그/JUnit에서 보존했습니다. before-two-targets.xml은 원본 두 testcase를 그대로 추출한 것이며 새 실행이라고 주장하지 않습니다. 수정 후 전체 파일 11조건 중 통과11·실패0·오류0·skip0입니다. [원본 확대 로그](before-full-gate-v4.log) · [수정 전 두 조건 XML](before-two-targets.xml) · [수정 후 로그](after.log) · [수정 후 JUnit](after.xml).

시험 전후 자료/규칙과 관련 코드 해시 40개를 비교했습니다. 실행 중 변경 항목은 []입니다. 이는 전체 저장소 해시 검증이 아니며 대상 자료는 기존 감사의35개 데이터/규칙과 현재 관련5파일입니다. [실행·해시](run.json) · [결과 요약](completion.json) · [수정 차이](source-change.diff).

원본 시험은 [백업](../../../final_project_cs/tests/unit/travel/mobility/_backup/2026-10-12_verify55_offline/test_verify55_v1.py)에 보존했습니다. 제품 소스와 데이터는 수정하지 않았습니다. Ruff 해당 시험1파일은 별도 실행에서 통과했습니다. 외부 연결 차단 아래 시도0회·API0회이며 개인자료 접근·외부 송신·커밋·wiki 변경을 하지 않았습니다.
