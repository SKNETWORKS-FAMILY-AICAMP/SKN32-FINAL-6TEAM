# 감시 소스가 실제 바깥 API 를 부르는가 — 지금 한 번 불러 본 기록

- 잰 때: 2026-09-22 · 운영 조립(`build_travel_sources(get_settings())`)으로 **재생이 아니라 진짜 호출**
- 왜 쟀나: 「지금 우리 DB 의 시나리오만 돌리고 있는 것 아니냐」는 물음에 **실행으로** 답하려고

## 1. 무엇이 붙어 있나 (조립 실측)

| 소스 | 붙음 | 구현 |
|---|---|---|
| 기상예보 | 있음 | `FallbackWeather`(기상청 → open-meteo) |
| 기상특보 | 있음 | `KmaWarningSource` |
| 대기질 | 있음 | `FallbackAir`(**에어코리아 → open-meteo**) |
| 재난문자 | 있음 | `DisasterMsgApi` |
| 도로 통제 | 있음 | `UticRouteEvents`(ITS 와 함께) |
| 장소·휴일·문화재 | 있음 | `TourApiPlace` · `HolidaySource` · `HeritageSource` |
| **대중교통 경로·운행** | **없음** | ODsay 를 쓰지 않기로 했다([D-CS-005](../../decisions/D-CS-005-odsay-not-used.md)) |
| 지진·항공편 | 없음(이 조립에서) | 키·어댑터 상태에 따라 붙는다 |

## 2. 실제 호출 결과 (경복궁 좌표 · 3시간 뒤 시작으로 판정)

```
판정: clear
  forecast         ok   open_meteo       precipitation_probability=0
  weather_warning  ok   kma_warning      in_effect=[{'kind': '강풍주의보', 'areas': ['전라남도(거문도…
  disaster_msg     ok   disaster_msg
  traffic_control  ok   its+utic
  air_quality      ok   open_meteo_air   (대체 거친 것: ['airkorea'])
  earthquake       ok   kma_earthquake
```

★**실제 특보가 들어왔다** — 전라남도 강풍주의보. 우리가 만든 값이 아니다.

## 3. 대체 소스가 실제로 받는가 — 실측

| 일 | 실측 |
|---|---|
| **도로 통제** | 경유 터널이 꺼져 있을 때 UTIC 이 `ConnectError(10061)` 로 실패 → **ITS 가 답했다**. 터널을 띄우자 `its+utic` 둘 다 답했다 |
| **대기질** | 한 번은 에어코리아가 **시간 초과**(상한 8초) → open-meteo 가 답했다. 그 뒤 같은 소스를 5회 직접 불러 보니 **5/5 응답**(0.3초 이하, 뒤 넷은 응답 재사용). **일시적 실패였다** |

★**둘 다 결정 15 대로다** — 1차가 안 되면 대체로 값을 내고, 무엇을 거쳐 왔는지(`fell_back_from`)를 남긴다. 조용한 대체가 아니다.

## 4. 그래서 어디까지가 실제인가

| | 실제 API | 우리 DB |
|---|---|---|
| **일정을 바꿀 사유 찾기**(기상·특보·대기질·재난문자·도로통제·장소·휴일) | **그렇다** | — |
| 업체 예약(공급자 원장) | 아니다 — 실제 업체 API 경로가 없다 | `supplier_bookings`(Mock, 등급 `simulated`) |
| 대중교통 경로·소요 | 아니다 — 안 쓰기로 했다 | 일정이 들고 오는 `route_def` |
| 시험·시나리오 모드 | 아니다 — **재생**이다(같은 하루를 똑같이 재현하려고) | `scenarios/seoul_day_taiwan_friends.json` |

## 5. 이 기록이 말하지 못하는 것

- **한 번씩 부른 것이다.** 하루 한도·오랜 시간의 실패율·응답 품질은 재지 않았다.
- 판정이 `clear` 였다 — **사건이 있는 날 어떻게 되는지는 이 호출로 보지 못한다**(그건 재생 시나리오가 본다).
- UTIC 은 **등록 IP 경유**가 필요하다. 경유가 꺼져 있으면 매번 ITS 만 답한다 — 운영에서는 경유를 상시로 두어야 한다.
