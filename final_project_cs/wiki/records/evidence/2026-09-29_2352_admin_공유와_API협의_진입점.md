## 전체 Python 시험 — 미완료

실행 위치 `final_project_cs`, 인터프리터 `.venv/Scripts/python.exe`, 대상 명령 `python -m pytest -q`. 동일 인터프리터의 `subprocess.run`으로 stdout/stderr를 캡처하고 timeout을 60초로 설정했다. 전체 시험이 오래 정체되었던 앞선 점검을 고려해 제한을 두었다.

최초 샌드박스 실행은 가상환경의 Python 프로세스를 생성하지 못했다. 권한 확보 후 재시도한 실제 출력(162 bytes, 제어문자 정규화):

```text

```
