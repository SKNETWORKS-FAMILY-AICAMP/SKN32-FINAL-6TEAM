## 실제 API·브라우저 확인

로컬 테스트용 DB를 사용하는 서버와 live 웹에서 기존 사용자 계획과 별개의 테스트 접수를 생성했다. 입력은 미래 날짜의 경복궁·광장시장·북촌한옥마을 세 항목이다. 외부 알림 연결은 비활성인 로컬 시험 환경이다.

- 카드 제목·종료 시각 저장 및 재조회.
- 전체 지도에서 창덕궁 조회·저장 → 실제 조회 이름 표시.
- 장소 없음 저장 → 경복궁 조회로 복구.
- 북촌 항목 제외 → 목록 2개로 변경.
- 여행 등록 → 서버 HTTP 200 → 여행 관리 화면에 일정 2개 표시.
- 기존 사용자 계획의 일차별 카드와 실제 OSM 지도 확인. 해당 계획에는 저장 요청을 보내지 않았다.

API 원본 로그를 해당 테스트 접수로 한정하고 식별자·접속 주소를 제거해 집계한 출력:

```text
Name                                     Count
GET /trip-intakes/{test-id}/ 200               6
POST /trip-intakes/{test-id}/edits 200         7
POST /trip-intakes/{test-id}/confirm 200       1
```

실패·충돌 응답과 320·390px 편집기/지도 창은 위 자동 시험에서 확인했다. 실제 휴대폰 및 Naver/Google 인증, 외부 API 한도 소진은 이번에 시험하지 않았다.
