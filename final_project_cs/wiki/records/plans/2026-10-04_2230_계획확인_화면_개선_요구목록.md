# 계획 확인 화면 개선 요구 목록 (2026-10-04 사용자 지시 — 웹 세션 uiux)

화면: `final_project_cs/frontend/apps/web` 의 `/intakes/[id]` (계획을 올린 뒤의 「계획 확인」). 코드는 `src/features/plan-check/`.
사용자가 화면을 직접 보며 한꺼번에 낸 요구를 번호로 적고, 한 건 끝날 때마다 상태를 고친다. (상태: 하는 중 · 끝 · 서버 요청 · 보류)

## 서버 담당에게 보낼 것
- (3) 원문 「호텔」(9시)이 식사 일정으로 읽혀 「식당의 이름이 적혀 있지 않아요」가 나오고, 「전체 자동 추천」이 호텔 줄을 식당(무구옥)으로 바꿨다. 호텔 줄은 숙소로 읽거나, 식사로 읽었으면 화면 문장·제목에 그 이유(조식 등)가 보여야 한다.
- (10) 접수 단계(`/v1/web/trip-intakes/{id}`)에도 이동 경로선(`route-shapes` 와 같은 모양, 일정 id 는 확인 화면의 id) 읽기 경로.
