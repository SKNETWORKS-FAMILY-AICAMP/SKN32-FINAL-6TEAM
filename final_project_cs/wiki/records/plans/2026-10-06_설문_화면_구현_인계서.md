## 3. 화면 · 레이아웃 (`mockups/tripilot-survey-loading-v10.html` 의 `screenPlan()` · `gkPanelHTML()`)

### 3-1. ① 계획 담기 (Pattern 3 — Form, 단계 1)
- 실제 화면 `features/trip-registration/trip-registration.tsx` 의 입력 패널 아래에 「읽는 기준」 패널 추가: 제목 · 한 줄 안내 · 「하루 일정의 여유」 라디오 3개(`role="radiogroup"`, 방향키 이동) · 보조 글 「「적당히」는 「여유롭게」보다 하루에 한 곳쯤 더 담아요.」.
- 오른쪽 안내 카드(원래 「여행 취향」 설문 안내)는 **기존 그대로 둔다**(설문은 따로 진행하는 기존 화면이 있으므로).
- 「계획 확인하기」는 **비활성으로 두지 않는다.** 계획이 비면 눌렀을 때 입력칸 아래 오류(「여행 계획을 적거나 파일을 올려 주세요.」)와 초점 이동, 쓰기 시작하면 오류 제거(기존 동작과 맞는지 확인할 것).
- 이 단추를 누르면 읽기 시작 **전에** 항로 지킴이 카드(§3-2)가 뜬다. 고르면 그 다음에 기존대로 계획 확인으로 넘어간다.

### 3-2. 항로 지킴이 카드 `GuardianCard` (두 변형 `start` · `notice`, 같은 HTML)
구조: 머리(추천 머리글 · 제목 · 영어 이름 · 닫기) → 본문(핵심 약속 · 「먼저 물어보는 경우」 묶음) → 바닥(단추 둘 · 켜진 아이콘 모형 + 안내 한 줄).

| 요소 | 값 |
|---|---|
| 그릇(넓은 곳 ≥768) | `position:absolute→fixed`, 오른쪽·위 16px, 폭 `min(440px, 100% − 32px)`, 높이=내용(최대 `100% − 32px`), 모서리 24px, 1px 테두리, 그림자 없음 |
| 그릇(좁은 곳 <768) | 아래 시트: 전체 폭, 위 모서리만 24px, `max-height: 100% − 48px`, 바닥 안전 영역 반영 |
| 그릇(중간 폭 600~767) | 시트를 꽉 채우지 않고 **폭 560 가운데 · 바닥에서 16px 띄운 네 모서리 24px 카드**(넓은 카드와 같은 모양) — 꽉 찬 시트는 폭이 늘어나 단추와 상자가 지나치게 넓어졌다 |
| 그릇(아주 좁은 폭 <480) | 머리가 작아진다(제목 24px · 아이콘 칸 48px) **그리고 핵심 약속 글이 16px** — 375 에서 20px 약속 글이 3줄로 꺾여 제목보다 무거워졌다 |
| 세로가 낮을 때(층 높이 <560) | 카드 전체가 스크롤되고 본문이 접히지 않는다(가로로 든 휴대폰 · 400% 확대에서 둘째 단추가 잘리던 것). 층을 CSS container `size` 로 묶어 높이도 잰다 |
| 폭 판단 | 화면이 아니라 **층의 폭**(CSS container `so`) — 목업 휴대폰 틀 안에서도, 제품 전체 화면에서도 같은 규칙 |
| 머리 | **방패 아이콘 칸 48px(좁은 곳 40px · 연한 초록 바탕 · 모서리 12px)이 제목 왼쪽에 있다** — cs 가 확정한 구성(모드 카드 = 아이콘 + 「추천」 + 한 줄 설명)이다. v7 에서 Opus 재검토의 「장식」 지적을 따라 뺐다가 이 구성을 어긴 것이라 v8 에서 되살렸다. 아이콘 칸은 **제목 + 영어 이름 덩어리의 높이에 맞춰 아래 맞춤**(칸 위 ≈ 제목 글자 위, 칸 아래 = 영어 이름 줄 아래)하고 「추천」은 그 위 꼬리표다. 「추천」(12px · 600 · 초록 · **글자간격 0** — .08em 은 영어 대문자용이라 한글이 「추 천」으로 벌어졌다) 제목 위 · 제목 32px(좁은 곳 24px · 600) · 영어 이름 14px · 닫기 아이콘 단추 44px(도구 설명 「닫기」 + `Esc`) |
| 본문 | 핵심 약속 20px · 500(16×1.25 단계, 「되돌릴 수 있어요.」는 줄을 바꿔 한 단계 옅게) · 묶음 칸(**14px / 줄 높이 20px**, 모서리 12px, 1px 테두리, 줄 사이 구분선 — 칸이 무겁지 않게). 간격: 머리→약속 24 · **약속→조건 칸 16 · 조건 칸→단추 32**(24 로 모두 같으면 묶음이 안 보인다). `start` 변형은 두 줄, `notice` 변형은 「켜 두어도…」 한 줄 |
| 바닥 | 단추 둘 **같은 높이 48px · 같은 너비**, 위가 주 단추. 아래 안내 줄 앞에 켜진 위쪽 아이콘 모형(32px 연초록 칸 + 점 + 방패 선 아이콘, `aria-hidden`, 누를 수 없음) |
| 본문 넘침 | 본문만 스크롤(`overscroll-behavior:contain`), 단추는 항상 보임 |
| 줄바꿈 | 「재난·지진이」는 쪼개지 않는다(`white-space:nowrap`), 약속 문장은 `text-wrap:balance` |

문구(그대로): 「문제가 생기면 알아서 바꾸고 알려요. / 되돌릴 수 있어요.」 · 「끄고 진행하면 문제가 생길 때 먼저 물어봐요.」 · 「켜 두어도 고정한 일정은 먼저 물어봐요.」 · 「재난·지진이 나면 일정을 멈추고 안전 안내를 보내요.」(★v10 — v9 는 「켜 두어도 고정한 일정과 재난·지진은 먼저 물어봐요」였다) · 단추 `start`: 「켜고 진행」 / 「건너뛰기 — 끄고 진행」, `notice`: 「켜기」 / 「그대로 두기」 · 바닥 「켠 뒤에도 언제든 화면 위 아이콘에서 끌 수 있어요.」

### 3-3. 상단 아이콘 `GuardianToggle` (켜짐 · 꺼짐)
- 44×44 아이콘 단추, 머리줄 오른쪽(메뉴 단추 왼쪽 / 휴대폰 머리줄은 「여행 계획」 글자 왼쪽).
- 켜짐: 연초록 원 배경 + 점(6px) + 초록 방패 아이콘. 꺼짐: 배경 없이 옅은 외곽선(흐린 글자색). 색만으로 구분하지 않는다(원 + 점).
- 이름은 동작을 말한다(「항로 지킴이 끄기」 / 「항로 지킴이 켜기」), 현재 상태는 숨은 글(「지금 켜져 있어요」)로 읽힌다. 도구 설명(마우스 올림 · 키보드 초점)에 같은 이름.
- 켜짐일 때 누르면 **한 번에 꺼지고** 알림줄(「항로 지킴이를 껐어요. 문제가 생기면 물어볼게요. [되돌리기] ✕」), 꺼짐일 때 누르면 `notice` 변형 카드로 켤지 한 번 묻는다.

### 3-4. 알림줄 `UndoToast`
화면 위쪽(머리줄 아래), 자동으로 사라지지 않는다(닫기 · 되돌리기 · 화면 이동 때까지) — 읽고 누를 시간을 제한하지 않는다. 실패 변형(`is-error`): 「항로 지킴이를 바꾸지 못했어요. 연결을 확인하고 다시 시도해 주세요. [다시 시도하기]」, 상태는 그대로 둔다.

### 3-5. ③④ 로딩 중 질문 `QuestionPager`
- 질문 카드 슬라이드: ‹ › 아이콘 단추(도구 설명 `이전 질문 보기 ←` · `다음 질문 보기 →`) · `i / N` · 제목 20px · 선택지 48px 단추(16px) · 점 표시 · 힌트 「좌우로 밀면 이전 · 다음 질문을 볼 수 있어요」.
- 밀기 50px 이상 + 가로 우세(`|dx| > 1.5·|dy|`)일 때 이동, `touch-action: pan-y`. 방향키 ← →도 같은 동작. 이미 답한 질문은 선택 표시(✓)와 함께 다시 눌러 고칠 수 있고 **바로 저장**(덮어쓰기). 건너뛴 질문도 돌아와 답할 수 있다.
- 답하면 400ms 뒤 다음 열린 질문으로(없으면 그대로). 이미 다 답한 뒤 고쳐도 「다 답했어요」가 다시 뜨지 않는다(마지막 열린 질문에 답한 순간에만).
- 로딩 중 아래 큰 단추는 **비활성이 아니라** 「계획 읽는 중…」 상태(`aria-disabled` · `aria-busy`, 눌러도 이유를 알려 줌). 로딩이 끝나면 「읽어 온 계획 확인하기」.
- 자동 넘김: 한 번도 안 만지고 로딩 끝 → 바로 계획 확인. 다 답함 → 아래 단추 자리에 3초 막대 + 「읽어 온 계획 확인하기」 + 「자동으로 넘어가지 않기」(대화창 아님), 질문 카드를 만지면 멈춤. 가만히 30초 → 20초 경고 대화(`alertdialog`, 「계속 답하기」 몇 번이든 · 「자동으로 넘어가지 않기」).

## 6. 움직임
| 요소 | 방아쇠 | 움직임 | 시간 | 곡선 |
|---|---|---|---|---|
| 카드(넓은 곳) | 열기 | 오른쪽에서 `translateX` + 바탕 투명도 | 200ms | ease-out |

## 7. 접근성
- 초점 순서(카드): 제목 → 닫기 → 주 단추 → 보조 단추 → (바닥 안내는 글). Tab 은 카드 안에서 순환, 닫으면 눌렀던 단추로 복귀.
- 눌러야 하는 곳 전부 44×44px 이상(주·보조 단추 48px). 이모지 없음(선 아이콘만).
- 글자 대비 4.5:1(제품 값은 미달 — §9), 초점 윤곽은 `--focus`(초록, 흰색 테마는 검정) 2px · 오프셋 2px.
- 알림줄은 `role=status`, 실패는 `role=alert`. 시간 제한: 20초 경고 + 끄기 수단(WCAG 2.2.1). 밀기만으로는 못 쓰는 사람을 위해 ‹ › 단추와 방향키를 함께 둔다.
- 못 해 본 것: 화면 읽기 프로그램(NVDA · VoiceOver) 낭독, 실제 손가락 밀기, 움직임 줄이기를 켠 화면.

## 8. 엣지
- 영어 UI: 같은 구조, 줄이 길어지면 본문만 스크롤. 제목 「Course Keeper」는 이미 영어.
- 글자 확대 200%: 시트가 `max-height` 안에서 본문 스크롤, 단추 고정.
- 질문 0개: 로딩 화면에 질문 카드 없음(서버가 안 줬을 때 — 빈 화면 만들지 않음).
- 서버가 `questions[]` 를 안 주는 옛 서버: ④는 나타나지 않는다(웹이 모른 척하지 않고 아무것도 안 묻는다).
- 폭이 768 경계에서 흔들릴 때: 층 폭 기준이라 화면 회전에도 같은 규칙.
