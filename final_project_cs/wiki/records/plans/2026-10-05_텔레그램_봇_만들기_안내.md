# 텔레그램 봇 만들기 — 「텔레그램으로 연결」 버튼을 쓰려면 한 번만 하는 설정

작성: ui 세션(웹) · 2026-10-05 · 읽는 사람: 프로젝트 담당자(텔레그램 계정이 있는 사람)

## 먼저 답부터

| 궁금한 것 | 답 |
|---|---|
| 돈이 드나요? | **무료**입니다. 봇이 고객에게 메시지를 보내는 것도 무료입니다(텔레그램 공식 FAQ). |
| 몇 개를 만드나요? | **봇 2개** — 운영용 1개, 시험용 1개. 시험 알림이 실제 고객에게 나가는 사고를 막으려고 따로 둡니다. |
| 얼마나 걸리나요? | 봇 하나에 3분 안팎. |
| 무엇을 얻나요? | 봇마다 **토큰**(긴 글자열 하나). 토큰은 **비밀번호처럼** 다룹니다 — 채팅·문서·커밋에 적지 말고 서버의 `.env` 같은 git 밖 파일에만 넣습니다. |
| 서버 주소 같은 것을 등록해야 하나요? | 아니요. 텔레그램 쪽 등록(웹훅 주소)은 서버 담당이 배포 뒤에 합니다. 여기서는 봇을 만들고 토큰을 받기만 합니다. |

★이 문서는 **텔레그램 화면을 직접 보지 않고** 공식 안내(`core.telegram.org/bots/tutorial`)와 알려진 BotFather 대화 순서를 바탕으로 적었습니다. 대화 문구가 다르면 알려 주세요, 고치겠습니다.

## 그림으로 보는 순서

```
텔레그램 앱 ──▶ @BotFather 와 대화 ──▶ /newbot ──▶ ① 표시 이름 ──▶ ② 아이디(…bot) ──▶ ③ 토큰 받음
                                                                                     │
                                                                                     ▼
                                                              서버 .env 에 직접 넣기 (채팅에 붙이지 않음)
```

## 따라 하기 (운영용 봇 → 같은 방법으로 시험용 봇)

| 단계 | 어디서 | 무엇을 | 끝나면 보이는 것 |
|---|---|---|---|
| 1 | 휴대폰이나 PC 의 텔레그램 앱 | 설치하고 전화번호로 로그인 | 대화 목록 화면 |
| 2 | 위쪽 **검색창** | `BotFather` 입력 → 이름 옆에 **파란 확인 표시**가 있는 **@BotFather** 를 고르기 | BotFather 대화창, 아래에 **시작(Start)** 단추 |
| 3 | BotFather 대화창 | **시작** 누르기 → `/newbot` 입력해 보내기 | 「Alright, a new bot. How are we going to call it?」 같은 질문(봇 표시 이름을 묻는 말) |
| 4 | 같은 대화창 (표시 이름) | 운영용: `triPilot 알림` / 시험용: `triPilot 알림 (시험)` 입력 | 이어서 사용자 아이디를 묻는 말 |
| 5 | 같은 대화창 (아이디) | 운영용: `tripilot_alert_bot` / 시험용: `tripilot_alert_test_bot` 입력. **반드시 `bot` 으로 끝나야 하고**, 이미 누가 쓰는 이름이면 안 됩니다 | 「Done! Congratulations on your new bot…」 와 함께 **토큰**(예: `숫자:영문숫자 긴 글자`) |
| 6 | 토큰 | 길게 눌러 복사 → **서버의 환경 파일(git 밖)** 에 직접 넣기. 이름은 서버 세션이 정합니다(제안: 운영 `ACOP_TELEGRAM_BOT_TOKEN`, 아이디는 `ACOP_TELEGRAM_BOT_USERNAME`) | 서버를 다시 켜면 마이페이지에 「텔레그램으로 연결」 줄이 생김(서버 구현이 끝난 뒤) |
| 7 | 시험용 봇 | 3~6 을 한 번 더. 시험용 토큰은 **개발·시험 서버의 환경 파일에만** | 개발 서버에서만 시험 알림이 감 |

### 건드리지 않는 것

- 봇의 **그룹 추가 허용 / 개인정보 모드**: 바꾸지 않습니다(고객과 1:1 대화만 씁니다).
- 봇 **프로필 사진·소개 글**: 선택 사항입니다. 꾸미고 싶으면 BotFather 의 `/mybots` 에서 봇을 골라 설정합니다(이 메뉴 이름은 이번에 공식 문서로 확인하지 못했습니다).

## 막혔을 때

| 보이는 문구 | 원인 | 고치는 법 |
|---|---|---|
| 「Sorry, this username is already taken. Please try something different.」 | 아이디가 이미 쓰이는 중 | 뒤에 숫자나 단어를 붙여 다른 아이디로(예 `tripilot_alert_2025_bot`) |
| 「Sorry, the username must end in 'bot'. E.g. 'Tetris_bot' or 'TetrisBot'」 | 아이디 끝이 `bot` 이 아님 | 끝에 `bot` 을 붙임 |
| 검색에 BotFather 가 여러 개 | 가짜 계정이 섞여 있음 | **파란 확인 표시**가 있는 `@BotFather` 만 |
| 토큰을 실수로 채팅·문서에 붙임 | 유출 | 그 토큰을 폐기하고 새로 받기(BotFather 가 토큰을 언제든 폐기할 수 있게 해 줍니다 — 공식 안내. 메뉴 위치는 이번에 확인하지 못했습니다). 서버 설정도 새 토큰으로 |
| 연결 단추를 눌러도 봇이 반응이 없음 | 서버에 웹훅이 아직 등록되지 않음 | 서버 담당에게 `setWebhook` 등록 확인 요청(배포 뒤 작업) |

## 끝난 뒤 확인

마이페이지 → **텔레그램으로 연결** → 텔레그램이 열리면 **시작** → 봇이 「연결됐어요」라고 인사 → 마이페이지에 「연결됨」 → **시험 메시지 보내기** → 텔레그램에 시험 메시지가 오면 끝입니다. (서버 구현이 끝나기 전에는 마이페이지에 이 줄이 보이지 않는 것이 정상입니다.)
