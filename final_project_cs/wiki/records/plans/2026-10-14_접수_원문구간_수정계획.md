# 접수 원문 구간 수정 구현 계획

**목표:** 사용자에게 보고하고 수정을 승인받은 다섯 접수 읽기 결함을 고친다. 같은 줄의 장소별 시각·끼니·상대 날짜를 구분하고, 재방문과 항목 삭제 후에도 원문 근거를 보존한다.

**구조:** 장소별로 서로 겹치지 않는 원문 구간을 한 번 정한다. 모델 추출 결과의 제목 근거에 그 구간을 함께 저장하고 조립·날짜 해석이 재사용한다. 오래된 근거에는 같은 분리 함수를 적용해 호환한다. 값과 장소 이름은 원문에서만 얻는다.

**기술:** 기존 Python·pytest와 접수 Claim/Span 구조. 새 외부 패키지·DB 스키마·공개 API 변경 없음.

**범위 근거:** 2026-10-14 사용자 「고칠거 고치자」 — 직전 리뷰의 원문 구간 중첩, 실제 식사 누락, 같은 장소 재방문 누락, 후치 현재시각 오연결, 상대 날짜 오연결 5건 승인.
