# D-CS-008 활동 판정 일부를 LLM 으로 — **실험**, 섀도 모드부터

`[결정 2026-10-06]` 사용자 결정.
- 1차 범위: 「글 해석 판정 4종 + 실시간 운영 상태」
- 시작 모드: 섀도 모드
- 계획과 진행 기록: [액티비티 LLM 연동 계획서](../teams/액티비티%20LLM%20연동%20계획서.md)

## 무엇을 바꾸나

활동팀은 「판정은 계산으로 한다. LLM 을 부르지 않는다(v10 §4-D)」를 전제로 짜여 있다(`app/modules/travel_ops/activity/team.py:7`).
그런데 판정 가운데 일부는 계산이 아니라 **글을 정규식과 키워드로 해석**하고 있고, 그 해석이 놓치는 표현이 많다.

| 판정 | 지금 코드 | 놓치는 것 |
|---|---|---|
| 정기휴무 요일 | `feasibility.py:545` — `매주 X 휴무` 정규식 | 「매월 둘째 주」, 「공휴일 다음날」 |
| 운영시간 원문 | `feasibility.py:420` — 원문을 전달만 함 | 판정에 전혀 쓰이지 않는다 |
| 실내·실외 | `weather.py:572` 키워드, `csv_places` 분류 | 단서가 없으면 `None` |
| 재난문자 관련성 | `feasibility.py:441` — 등급만 봄 | 지역·주제 관련성 |
| 실시간 운영 상태 | 없음 | 임시휴무, 행사, 공사 공지 |

이 다섯 가지를 gpt-5.4-nano(Responses API, 필요 시 `web_search`)로 판정하는 실험을 한다.

## 지키는 것 — 바꾸지 않는다

- **계산 판정은 코드에 남는다.** 남은 시간, 이미 시작, 정원 초과, 취소 기한, 위약금율이 여기에 해당한다. 특히 위약금율은 D-CS-006이 「산문에서 LLM 이 뽑는다」를 버린 그대로다.
- **「모름」을 「없음」이나 「성립」으로 읽지 않는다.** 아래 경우는 `unknown` 으로 처리한다.
  - LLM 이 근거를 대지 못한 경우
  - 인용이 원문에 없는 경우
  - 인용한 URL 이 실제 검색 출처 목록에 없는 경우
  - 시간 초과, 스키마 위반, 429 응답이 온 경우
- **LLM 은 코드가 확정한 불가를 뒤집지 못한다.**
- **섀도 기간에는 고객 답변·`decisions`·실패 코드가 지금과 같다.** LLM 결과는 차이 로그에만 남는다.

## 범위 — 어디까지인가

- **`role-activity-test` 브랜치 안에서만** 적용한다. `develop`·`main` 에 합치는 것은 이 결정의 범위가 아니다. 합치려면 평가 결과를 붙여 결정을 새로 받는다.
- 기본값은 `activity_judge_mode = shadow` 다.
- `llm` 모드로 넘어가는 기준은 판정 종류마다 평가 수치를 보고 계획서 §8에 적은 뒤 정한다.

## 스파이크에서 확인한 제약 (2026-10-06)

근거: [스파이크 실측](../records/evidence/2026-10-06_액티비티_LLM_스파이크_실측.md)

1. **재현성을 seed로 확보할 수 없다.**
   - `seed` 는 400 오류를 낸다.
   - `temperature` 는 effort=none 일 때만 받는다.
   - 같은 질의 8회 중 `open` 6회, `unknown` 2회가 나왔다.
   - 그래서 평가는 반복 측정으로 하고, 재현의 근거는 감사 기록(`record_llm_call`)의 응답 원문으로 삼는다.
2. **스키마를 강제하면 `url_citation` 주석이 오지 않는다.**
   - 그래서 출처 검증은 `include=["web_search_call.action.sources"]` 로 받은 실제 출처 목록과 모델이 적은 URL 을 대조하는 방식으로 한다.
   - 실측에서 5/5건이 일치했다.
3. **지연이 가드레일을 넘는다.**
   - effort=low + web_search 5회 중 2회가 20초를 넘었다(20.10초, 27.99초).
   - 섀도 모드에서는 고객 응답을 막지 않도록 LLM 판정을 응답 경로 밖에서 돌리거나, 시간 제한을 넘으면 버린다.
4. **비용은 대부분 검색 요금이다.** 건당 약 $0.02~0.04(추정)다. 실시간 운영 상태는 실외이거나 시작까지 72시간 안일 때만 부른다.

## 되돌리는 조건

아래 가운데 하나라도 해당하면 `activity_judge_mode = rule` 로 되돌리고 이 결정을 `superseded` 로 닫는다.
- 평가에서 LLM 이 규칙보다 정답 라벨 대비 정확도가 낮다
- 인용·출처 검증 탈락률이 높아 대부분 `unknown` 이 된다
- 건당 비용이나 지연을 운영에서 감당할 수 없다

## 이 결정이 **말하지 않는 것**

- 대체 장소 운영 확인(`alternatives.py`)은 2차 대상이라 아직 정하지 않았다.
- 다른 Team(Dining·Mobility)의 판정은 해당하지 않는다.
- 웹에서 가져온 본문을 저장하지 않는다. URL, 짧은 인용, 조회 시각만 근거로 남긴다.
