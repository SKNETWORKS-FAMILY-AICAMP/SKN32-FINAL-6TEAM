# D-CS-010 구글 API 는 새벽 3시 확인 창에 몰아서만 부른다

`[결정 2026-09-29 사용자]` 「구글 api 는 한도 있으니까 … 3시에 1회」 — 「한 번은 진짜 1번 콜하라는 게 아니라 **그 시간에 몰아서**
구글 api 호출할 작업들 다 처리하라는 소리」.

## 무엇이 바뀌나

| | 전 | 지금 |
|---|---|---|
| 새벽 확인(`dawn_check`, 03:00~08:00 창) | 그날 식사·활동이 계획한 시각에 여는지 구글로 확인 | 그대로 — **구글을 부르는 유일한 자리** |
| 채팅 「운영시간 알려 줘」 | 오전에 잠깐, 요식 원장 · 관광공사가 모르면 구글에 바로 물었다 | **부르지 않는다**(걷어냄) |

예: 무구옥처럼 요식 원장에 영업시간이 없고 관광공사에도 없는 식당은, 지금 채팅 답이 「운영시간은 모르겠어요 — (이유)」다.

## 팀이 정할 것

- **비는 값을 어떻게 메우나** — 새벽 창에서 구글로 무엇을 더 처리할지(예: 그날 일정 식당의 영업시간 확인을 넓히기),
  구글 결과는 약관상 **저장할 수 없다**(`place_id` 와 판정·확인 시각만 — 마이그레이션 026)는 점과 함께 정한다.
- 결정 15(값을 모르는 상황을 만들지 않는다)와의 관계 — 새벽 창 밖에서 모르는 값을 어떻게 답할지.
- 낮 임시휴무 감지([D-CS-009](D-CS-009-daytime-closure-detection.md))도 구글을 쓴다면 이 결정과 맞물린다.

## 코드

- 채팅 장소 조회 `app/domains/travel_ops/components/conversation/trip_facts.py` `look_up_place` — 요식 원장 → 관광공사까지만. 시험
  `tests/integration/travel/test_place_info.py::test_the_chat_never_calls_google_even_when_the_hours_are_unknown`.
- 구글을 부르는 곳(코드 검색 기준): `scripts/run_sweepers.py` 의 새벽 확인 조립 하나. 요식 세션의 수동 스크립트
  `scripts/dining/google_link.py`(가게에 구글 식별자를 붙이는 일회성 작업, 사람이 돌린다)는 별도다 — 이 결정에 맞출지 팀이 본다.
- ★웹 화면의 **지도 표시**(`frontend/apps/web/src/features/map/providers/google.ts`)도 구글을 쓴다 — 화면을 열 때 브라우저가
  부르는 것이라 새벽에 몰 수 없다. 지도 표시를 이 결정의 예외로 둘지, 다른 지도로 바꿀지 팀이 정한다.
- ★`[2026-09-29 사용자 지시]` **구글 지도도 한도를 건다** — 화면이 부르기 전에 `POST /v1/web/map-load` 로 한 칸을 확보하고,
  못 하면 무료 지도로 보인다. **개발 중에는 무료 지도를 쓴다**(이 기기 웹 설정 `NEXT_PUBLIC_MAP_PROVIDER=demo`,
  옛 설정은 같은 폴더 `.env.local.2026-09-29_1230.bak`). 실제 지도가 나오는 무료 지도(오픈스트리트맵 계열)는 화면 세션이 붙인다.
