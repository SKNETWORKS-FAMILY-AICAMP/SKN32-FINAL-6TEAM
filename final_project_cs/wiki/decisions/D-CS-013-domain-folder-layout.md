# D-CS-013 업무 도메인 폴더 구조

`[2026-10-06 사용자 결정]` 구조와 칸 이름은 사용자가 정했고, 바깥 폴더 이름은 Codex 와 2회차에 합의했다(기록: 아래 「근거」).

## 맥락

`app/domains/travel_ops/` 바로 아래에 파이썬 파일 **69개**가 하위 폴더 없이 있었다(2026-10-05 실측, 전체 130개 · 39,116줄).
웹 로그인 · 고객 채팅 · 감시 루프 · 일정 계산 · 팀이 한 줄로 나란히 있어 무엇이 필수 부품이고 무엇이 끌 수 있는 기능인지 이름으로 알 수 없었다.
지난 7일 동안 이 폴더를 건드린 커밋이 77개라 늦출수록 옮길 때 충돌이 는다.

## 결정

> **업무 도메인 코드는 `app/domains/<도메인>/` 에만 둔다. 그 안을 프로젝트의 구성 단위([../teams/composition.md](../teams/composition.md))대로 나눈다.**

```
app/
├─ core/
│  ├─ transition.py          Case 상태를 바꾸는 유일한 문
│  └─ case_lifecycle/        Case 상태 규칙(이벤트 종류 · 허용 전이표 · 리듀서) ← 옛 app/domain/
└─ domains/                  업무 도메인 자리 — 경계 시험이 지키는 울타리 (옛 이름 app/modules/)
   └─ travel_ops/
      ├─ __init__.py         팀 등록 — 설정 파일이 가리키는 이름을 다시 내보냄
      ├─ modules/            모듈 — 꺼도 나머지가 돈다 (웹 계정 · 개인 AI 입구 · 실시간 진행)
      ├─ instances/          인스턴스 — 에이전트 팀. 팀 하나 = 폴더 하나 (+ _shared 공용 부품)
      ├─ components/         컴포넌트 — 빼면 안 돈다 (일정 · 계획 · 장소 · 접수 · 대화 · 적용기 · 예약 · 감시 · 코어에 꽂는 여행 어휘)
      ├─ ports/              Port — 구현을 바꿔 끼우는 자리 (notify_channels 알림 채널 · data_sources 외부 데이터 소스)
      ├─ entry/              고객 입구 — HTTP 경로
      └─ scenarios/          시연 · 하루 대조 시험용 조립
```

파일 단위 배치표(옛 이름 → 새 자리)는 [이동 계획서](../records/plans/2026-10-06_0040_업무도메인_폴더이동_계획.md) 「대응표」. 적용하면서 바뀐 점 셋 — ① `booking_handoff.py` · `locked_bookings.py` 는 팀 폴더의 `__init__.py` 가 본체가 됐다(`instances/booking_handoff/` · `instances/locked/`, Activity 폴더 규칙과 같은 모양) ② 함께 옮긴 묶음(이동 · 활동 · 요식 · 접수 · 데이터 소스) **안끼리의 import 는 상대 경로 그대로** 둔다 — 이동 엔진은 저장소 밖에서 단독으로 불러 쓰도록 만들어져 있다 ③ 칸이 달라진 파일끼리는 절대 경로로 바꿨다.

## 이름 — 선택지와 이유

| 자리 | 채택 | 버린 것과 이유 |
|---|---|---|
| 바깥 울타리 | **`domains/`** | `modules`(프로젝트 안에서 「모듈 = 끌 수 있는 기능」이라 안쪽 칸과 겹침) · `packs`(ContextPack 과 겹침, 현행 계획서에 없는 옛 용어) · `contexts`(Context Broker · ContextPack 과 겹침, 코드 179회) · `services`(case_service 등 124회) · `plugins`(필수 부품까지 들어 있어 「덧붙이는 것」과 안 맞음) |
| 옛 `app/domain/` | **`app/core/case_lifecycle/`** | 내용이 업무 도메인이 아니라 Case 상태 규칙 두 파일이다. 구성 문서가 이미 「Case lifecycle」이라 부르고, 유일한 상태 변경 문 `app/core/transition.py` 옆이다. 그대로 두면 `domain`·`domains` 가 한 글자 차이로 함께 있게 된다(사용자 거부) |
| 팀 칸 | **`instances/`** | `agents`(프로젝트 구성 단위 이름이 「인스턴스」) |
| 모듈 칸 | **`modules/`** | `features`(바깥이 `domains` 가 되면 겹침이 사라져 바꿀 이유가 없다) |

## 옮기는 순서 — 실제로 한 것

처음에는 칸마다 한 단계씩(0~6) 나눠 옮기려 했다. 실제로는 **0단계를 따로 하고, 1~5단계를 한 번에** 옮겼다 —
옮기는 순간 옮길 범위 안에 다른 세션의 미커밋 변경이 0이었고, 그 틈에 한 번에 끝내는 것이 칸마다 나눠 여러 번 부딪히는 것보다 덜 위험했다.
옛 주소 안내 파일은 **두지 않았다** — 가져다 쓰던 곳을 모두 고쳤고, 남은 옛 주소를 쓰면 import 오류로 곧바로 드러난다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 0 | 옛 `app/domain` → `app/core/case_lifecycle` · 잔재 정리 · 이 결정 문서 | **끝 (2026-10-06, 커밋 `e70b2820`)** |
| 1~5 | 울타리 `app/modules` → `app/domains` · 여행 외부 데이터 소스 `app/infrastructure/travel` → `ports/data_sources` · 68개 파일과 하위 폴더 4개를 칸으로 | **끝 (2026-10-06)** |
| 6 | 문서 갱신 · 칸끼리 규칙 시험 | **끝 (2026-10-06)** |
| 다음 | 칸끼리 규칙을 어기는 곳 줄이기 · 플랫폼 코어 쪽 폴더 점검 | 남음 |

**칸끼리 규칙** — `tests/architecture/test_travel_ops_cells.py`. 옮긴 날 이미 어기는 곳이 있어서 그날 수를 상한으로 박았다(늘면 실패, 줄이면 상한도 내려야 통과).

| 규칙 | 2026-10-06 실측 | 뜻 |
|---|---|---|
| 팀 → 다른 팀 속 | **0** | 팀끼리는 코어를 거쳐서만 만난다 |
| 필수 부품 → 팀 속 | 14 | 감시 · 대화 · 계획 부품이 요식 · 이동 · 활동 팀 내부를 직접 안다 — 그 팀을 빼면 부품이 깨진다 |
| 필수 부품 → 끌 수 있는 기능 | 4 | 일정 저장 · 대화 · 알림 발송이 웹 계정(게스트 제한 · 남용 방어)과 실시간 진행을 부른다 — **웹 계정은 지금 실제로는 끌 수 없다** |
| 바꿔 끼우는 자리 → 기능 · 부품 · 팀 | 2 | 디스코드 · 텔레그램 연결이 웹 계정(연락처 · 동의)을 부른다 |

## 울타리 밖에서 들어온 것 · 남긴 것

| 옛 자리 | 무엇 | 처리 |
|---|---|---|
| `app/infrastructure/travel/` (파일 28 + 표본 CSV) | 관광공사 · 기상청 · 재난문자 · 교통 · 구글 장소 등 **여행 외부 데이터 소스** | **`ports/data_sources/` 로 옮김.** 옛 자리는 코어 층인데 경계 시험이 못 잡았다(업무 단어 목록에 날씨 · 교통 같은 말이 없다). 팀이 이 자리를 직접 부르지 못하게 `test_team_tool_discipline.py` 금지 목록에 새 자리를 더했다 |
| `app/presentation/a2a/travel_remote_agent.py` | 원격 에이전트 왕복 검증용 상대역(시험만 쓴다) | 남김 — 플랫폼 코어 쪽 폴더 점검 때 함께 본다 |
| 여행 마이그레이션 · `config/` · `eval/` | DB 표 · 설정 · 평가 자료 | 옮기지 않음 — 마이그레이션은 실행 순서가 경로에 묶여 있고, 설정 · 평가는 이미 울타리로 인정되거나 앱 밖이다 |

## 결과

- 이 결정으로 기능은 바뀌지 않는다. 파일 자리와 가져다 쓰는 주소만 바뀐다.
- 못 하게 되는 것: 여행 코드를 `app/domains/` 밖(코어 층)에 두는 것 — 경계 시험이 막는다. 팀이 다른 팀 속을 직접 부르는 것 — 칸 규칙 시험이 막는다.
- Composer 에 저장해 둔 **옛 선언 판**은 옛 등록 문자열(`app.modules…`)이 허용 목록에 없어 되살리기가 거부된다. 조용히 틀리지는 않는다.
