## 정답을 정한 방식

- 장소 정답은 **원문 표기 그대로**(원문의 부분 문자열) — 읽은 조각과 비교한다. 찾은 장소 이름은 `canon`(공식 이름 후보)과 따로 비교한다.
- 시각은 원문에 시각이 있을 때만 정답을 둔다(「오전」「점심」은 시각 정답 없음). 「3시 체크인」은 15:00, 「6시 명동교자」는 18:00 으로 보았다.
- 날짜는 원문 · 상대 날짜(「낼」「담주 월욜」「토욜」)로 정해질 때만. 오늘은 합성 2026-10-16(금), 실제는 접수 받은 날.
- 정정이 있으면 **정정을 반영한 결과**가 정답이다(「남산타워 말고 롯데타워」 → 남산타워를 항목으로 남기면 정밀도 손해).
- 해석이 갈리는 것은 `optional`(항목) · `requests_optional` · `missing_optional` 로 두어 점수에서 뺐다.
- 빠진 값은 **고객만 아는 것**만 센다 — 날짜(`first_day_date`) · 숙소 이름(`lodging_name`) · 예약한 가게 이름(`booked_place_name`).
  지역 + 끼니(「연신내에서 점심」)의 가게는 우리가 골라도 되는 값이라 빠진 값이 아니다.
