# 요식 자유문 조건 평가 v2 — 정답 검토 시트

> **사용자 검토 전 · 측정 금지** — 정답을 승인하고 얼리기 전에는 어떤 모델로도 돌리지 마세요.

- 상황: 오늘 = 2026-10-25(1일차), 판정 대상 `lunch`(12:00)·`dinner`(18:00). 26일 점심은 대상 아님.
- 정답 표기: `식사/속성/필수(T)·선호(F)`. `—` = 조건 없음. `unclear` 표시는 expect_unclear=true.
- 고치는 법: 「수정」 칸에 새 정답(예: `dinner/halal/F`) 또는 `OK` 를 적어 주세요. ⚠ 는 판단이 필요한 줄입니다.
